# Гомоку — Kotlin + Jetpack Compose

Нативное Android-приложение для игры в гомоку. Интерфейс создан на Jetpack Compose, доска рисуется через Canvas, а правила игры и компьютерный соперник полностью реализованы на Kotlin. WebView, HTML и JavaScript не используются.

## Режимы игры

### Игра вдвоём

- Два игрока по очереди делают ходы на одном устройстве.
- Кнопка отмены убирает последний камень.

### Игра с компьютером

- Перед началом можно выбрать чёрные или белые.
- При выборе чёрных первым ходит игрок, компьютер играет белыми.
- При выборе белых компьютер играет чёрными и начинает с центра доски.
- Компьютер обдумывает ход около 500 мс; в это время доска заблокирована.
- Отмена убирает один полный раунд и возвращает ход игроку.

## Как работает AI

Компьютер использует локальный алгоритм оценки позиции и не требует подключения к интернету. Он:

1. завершает собственную комбинацию из пяти камней;
2. блокирует немедленную победу игрока;
3. оценивает открытые и закрытые четвёрки, тройки и другие атакующие позиции;
4. учитывает угрозы соперника;
5. случайно выбирает один из равноценных лучших ходов.

Для быстрой работы оцениваются свободные точки в пределах двух клеток от уже поставленных камней.

## Возможности

- Доска 15×15, нарисованная нативно через Canvas.
- Карточки чёрных и белых, аватары, подсветка текущего хода и метка `AI`.
- Объёмные камни, анимация установки, тени, блики, отметка последнего хода и линия победы.
- Подтверждение хода: первое нажатие показывает полупрозрачный камень, повторное устанавливает его.
- Отмена хода, новая партия, выход, настройки, правила и окно результата.
- Независимые настройки звука и вибрации.
- Учтены безопасные зоны системной строки, камеры и нижней панели навигации.
- Полностью русский пользовательский интерфейс.

## Запуск

1. Откройте папку проекта в Android Studio.
2. Дождитесь завершения Gradle Sync.
3. Выберите эмулятор или подключённый Android-смартфон.
4. Нажмите `Run app`.

## Создание APK

В Android Studio выберите:

```text
Build → Generate App Bundles or APKs → Generate APKs
```

Готовый файл находится в:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## Основные файлы

- `GameModels.kt` — модели режима и состояния партии.
- `GameRules.kt` — проверка победы и функции доски.
- `GomokuGame.kt` — установка камней, подтверждение, отмена и перезапуск.
- `AiEvaluator.kt` — оценка комбинаций.
- `AiPlayer.kt` — выбор хода компьютера.
- `GomokuBoard.kt` — отрисовка доски и обработка касаний.
- `GameScreen.kt` — игровой экран и управление ходами AI.
- `GameComponents.kt` — карточки игроков, кнопки и диалоги.

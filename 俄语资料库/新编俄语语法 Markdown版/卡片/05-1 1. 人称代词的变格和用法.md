# 1. 人称代词的变格和用法

来源：[[新编俄语语法 Markdown版/章节/05 代词#^kp-05-1-01]]

## 核心规则

- 人称代词指说话人、听话人或被谈论对象。
- 第三人称代词有性和数的区别。
- 介词后第三人称常加 н-。

## 例句

- Я читаю.：我在读。
- У него есть книга.：他有一本书。

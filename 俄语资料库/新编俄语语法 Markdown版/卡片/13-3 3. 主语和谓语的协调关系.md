# 3. 主语和谓语的协调关系

来源：[[新编俄语语法 Markdown版/章节/13 双部句#^kp-13-3-05]]

## 判断要点

- 主谓通常在人称、数、性等方面协调。
- 数量词组作主语时协调可能受语义和语体影响。

## 例句

- Студенты пришли.：学生们来了。

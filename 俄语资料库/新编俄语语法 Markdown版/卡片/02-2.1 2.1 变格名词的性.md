# 2.1 变格名词的性

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-2-1-03]]

判断变格名词性属时，先看结尾。

| 结尾 | 常见性 |
|---|---|
| 辅音、**-й** | 阳性 |
| **-а / -я** | 阴性；表示男性时可为阳性 |
| **-о / -е / -ё / -мя** | 中性 |
| **-ь** | 阳性或阴性，需单独记忆 |

常见 **-ь** 阳性：учитель、словарь、январь。常见 **-ь** 阴性：тетрадь、ночь、любовь。

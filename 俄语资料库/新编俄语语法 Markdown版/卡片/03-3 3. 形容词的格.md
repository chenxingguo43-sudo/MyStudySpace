# 3. 形容词的格

来源：[[新编俄语语法 Markdown版/章节/03 形容词#^kp-03-3-05]]

## 核心规则

- 形容词的格由它修饰或指代的名词决定。
- 变格时同时保持性、数一致。
- 学习时把名词格和形容词词尾成组记忆。

## 例句

- с новым другом：和新朋友一起。
- о русской грамматике：关于俄语语法。

# 3. 从属连接词

来源：[[新编俄语语法 Markdown版/章节/09 连接词#^kp-09-3-03]]

## 核心规则

- 从属连接词连接主句和从句。
- 常表示说明、目的、条件、时间、原因等关系。

## 例句

- Если будет время, я позвоню.：如果有时间，我会打电话。

## 复习提示

- 功能词先记语义类别，再记固定搭配和接格。
- 复习时优先从例句反推规则。

# 3. 物主代词的变格和用法

来源：[[新编俄语语法 Markdown版/章节/05 代词#^kp-05-3-05]]

## 核心规则

- 物主代词表示所属关系。
- мой, твой, свой, наш, ваш 像形容词一样变化。
- свой 指向句中主语，是很重要的反身物主代词。

## 例句

- Это моя книга.：这是我的书。
- Он любит свою работу.：他喜欢自己的工作。

# 3. 名词的数

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-3-07]]

俄语名词有单数和复数。多数复数由单数词尾变化构成，但有不少特殊词形。

核心问题：

- 单数词尾是什么？
- 名词是阳性、阴性还是中性？
- 是否受拼写规则限制？
- 是否属于特殊复数或只有复数形式？

# 4.1 六个格总览

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-4-1-11]]

六个格是名词在句中表示语法关系的核心系统。

| 格 | 问题 | 核心意义 |
|---|---|---|
| 第一格 | кто? что? | 主语、命名 |
| 第二格 | кого? чего? | 所属、否定、数量 |
| 第三格 | кому? чему? | 间接对象、状态主体 |
| 第四格 | кого? что? | 直接对象、方向 |
| 第五格 | кем? чем? | 工具、身份、行为主体 |
| 第六格 | о ком? о чём? | 谈论对象、位置 |

学习顺序：问题词 → 前置词 → 动词/形容词接格。

# 5.1 性质形容词比较级的构成

来源：[[新编俄语语法 Markdown版/章节/03 形容词#^kp-03-5-1-12]]

## 核心规则

- 单一式常由词干加 -ее, -ей, -е, -ше 构成。
- 复合式用 более 或 менее 加形容词长尾形式。
- 有些高频词比较级是不规则形式，要单独记。

## 例句

- красивый → красивее。
- хороший → лучше。
- плохой → хуже。

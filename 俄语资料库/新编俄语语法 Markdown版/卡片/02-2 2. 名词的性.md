# 2. 名词的性

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-2-02]]

俄语名词有阳性、阴性、中性三种性。多数变格名词可以先根据词尾判断性属。

| 性 | 常见线索 |
|---|---|
| 阳性 | 辅音、**-й**、部分 **-ь** |
| 阴性 | **-а / -я**、部分 **-ь** |
| 中性 | **-о / -е / -ё / -мя** |

难点：**-ь** 结尾名词需要按词义和固定类别判断。

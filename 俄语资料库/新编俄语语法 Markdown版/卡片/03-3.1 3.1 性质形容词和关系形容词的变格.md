# 3.1 性质形容词和关系形容词的变格

来源：[[新编俄语语法 Markdown版/章节/03 形容词#^kp-03-3-1-06]]

## 核心规则

- 硬变化、软变化是形容词变格的两条主线。
- 单数要分别看阳性、中性、阴性；复数各性合并。
- 常用介词短语中尤其要熟悉第五格、第六格词尾。

## 例句

- с хорошим другом：和好朋友一起。
- в большой комнате：在大房间里。

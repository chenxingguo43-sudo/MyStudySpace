# 2. 常用前置词的意义和用法

来源：[[新编俄语语法 Markdown版/章节/08 前置词#^kp-08-2-02]]

## 核心规则

- 同一个前置词可因接格不同而意义不同。
- в, на, с, к, о, для, без 是高频核心。

## 例句

- с другом：和朋友一起。
- без словаря：没有词典。

## 复习提示

- 功能词先记语义类别，再记固定搭配和接格。
- 复习时优先从例句反推规则。

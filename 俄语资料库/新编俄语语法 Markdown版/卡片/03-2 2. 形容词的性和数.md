# 2. 形容词的性和数

来源：[[新编俄语语法 Markdown版/章节/03 形容词#^kp-03-2-02]]

## 核心规则

- 形容词要和被说明的名词在性、数、格上保持一致。
- 阳性、中性、阴性、复数形式主要通过词尾体现。
- 先判断名词，再选择形容词词尾。

## 例句

- новый дом：新房子。
- новая книга：新书。
- новое окно：新窗户。
- новые дома：新房子们。

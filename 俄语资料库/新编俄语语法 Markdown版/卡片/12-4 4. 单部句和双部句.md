# 4. 单部句和双部句

来源：[[新编俄语语法 Markdown版/章节/12 句子分类#^kp-12-4-04]]

## 判断要点

- 双部句有主语和谓语。
- 单部句只有一个主要成分也能成句。

## 例句

- Темнеет.：天黑了。

## 复习提示

- 句法卡片不要孤立背规则，最好回到整句里判断成分关系。
- 搜索时可用中文术语、俄语例句或 block id 精确定位。

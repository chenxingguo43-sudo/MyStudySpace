# 3.1 名词复数形式的构成

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-3-1-08]]

名词复数第一格常见规则：

| 类型 | 复数词尾 | 示例 |
|---|---|---|
| 阳性硬辅音 | **-ы** | студент → студенты |
| г, к, х, ж, ч, ш, щ 后 | **-и** | враг → враги |
| **-й / -ь** | **-и** | музей → музеи；словарь → словари |
| 阴性 **-а / -я** | **-ы / -и** | школа → школы；книга → книги |
| 中性 **-о / -е** | **-а / -я** | слово → слова；море → моря |

特殊复数需要单独记：сын → сыновья，человек → люди，ребёнок → дети。

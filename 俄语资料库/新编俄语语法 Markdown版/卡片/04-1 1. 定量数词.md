# 1. 定量数词

来源：[[新编俄语语法 Markdown版/章节/04 数词#^kp-04-1-01]]

## 核心规则

- 定量数词表示数量，回答 сколько。
- 数词会影响后面名词的数和格。
- один 像形容词一样和名词保持一致。

## 例句

- один вопрос：一个问题。
- два стола：两张桌子。
- пять книг：五本书。

# 5.2 动名词的用法

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-5-2-21]]

动名词像名词一样变格、带定语、和前置词连用，同时常保留原动词的支配关系。

| 用法 | 示例 |
|---|---|
| 动作对象 | чтение книги |
| 第二格宾语 | изучение русского языка |
| 动作主体 | ответ подруги |
| 第五格行为主体 | объяснение текста учителем |

读动名词时问：动作是什么？对象是谁？主体是谁？

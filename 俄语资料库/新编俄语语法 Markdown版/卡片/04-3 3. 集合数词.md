# 3. 集合数词

来源：[[新编俄语语法 Markdown版/章节/04 数词#^kp-04-3-09]]

## 核心规则

- 集合数词表示成组的人或事物。
- 常与表示男性人群、儿童、动物幼崽、成双物品的名词连用。
- 常见形式有 двое, трое, четверо。

## 例句

- двое студентов：两名学生。
- трое детей：三个孩子。

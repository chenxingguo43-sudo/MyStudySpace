# 4. 语音交替

来源：[[新编俄语语法 Markdown版/章节/01 词的构成#^kp-01-4-04]]

## 核心规则

- 构词和变形中可能发生语音交替。
- 交替会影响词形识别和拼写。

## 例子

- друг → друзья。
- писать → пишу。

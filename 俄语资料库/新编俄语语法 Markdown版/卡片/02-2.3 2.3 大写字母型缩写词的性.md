# 2.3 大写字母型缩写词的性

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-2-3-05]]

大写字母型缩写词的性通常由全称中的中心词决定。

| 缩写 | 中心词 | 性 |
|---|---|---|
| КНР | республика | 阴性 |
| РФ | федерация | 阴性 |
| ООН | организация | 阴性 |
| МОК | комитет | 阳性 |

注意：МИД 传统上可按中性处理，现代用法中也常作阳性。

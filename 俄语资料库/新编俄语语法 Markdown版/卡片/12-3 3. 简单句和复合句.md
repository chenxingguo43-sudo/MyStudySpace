# 3. 简单句和复合句

来源：[[新编俄语语法 Markdown版/章节/12 句子分类#^kp-12-3-03]]

## 判断要点

- 简单句只有一个谓语核心。
- 复合句有两个或多个分句。

## 例句

- Я знаю, что он дома.：我知道他在家。

## 复习提示

- 句法卡片不要孤立背规则，最好回到整句里判断成分关系。
- 搜索时可用中文术语、俄语例句或 block id 精确定位。

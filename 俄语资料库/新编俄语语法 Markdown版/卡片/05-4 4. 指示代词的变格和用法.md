# 4. 指示代词的变格和用法

来源：[[新编俄语语法 Markdown版/章节/05 代词#^kp-05-4-08]]

## 核心规则

- 指示代词用于指出人、事物或性质。
- этот 表示这一个，тот 表示那一个。
- такой 表示这样的，столько 表示这么多。

## 例句

- Этот дом новый.：这栋房子是新的。
- Такая задача трудна.：这样的题很难。

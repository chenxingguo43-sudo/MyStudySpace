# 4.6 复数变格总表

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-4-6-16]]

复数变格先记通用框架，再补特殊词。

| 格 | 常见词尾 |
|---|---|
| 第一格 | **-ы / -и / -а / -я** |
| 第二格 | 零词尾、**-ов / -ев / -ей** |
| 第三格 | **-ам / -ям** |
| 第四格 | 非动物同第一格，动物同第二格 |
| 第五格 | **-ами / -ями** |
| 第六格 | **-ах / -ях** |

特殊：дети → детей，друзья → друзей，времена → времён。

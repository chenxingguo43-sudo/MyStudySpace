# 3. 独立状语

来源：[[新编俄语语法 Markdown版/章节/17 句子的独立成分#^kp-17-3-05]]

## 判断要点

- 独立状语表示时间、原因、条件、让步、方式等。
- 常由副动词短语或前置词短语表示。

## 例句

- Прочитав письмо, он улыбнулся.：读完信后，他笑了。

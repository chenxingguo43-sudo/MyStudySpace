# 5. 动名词的构成和用法

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-5-19]]

动名词由动词构成，表示动作或过程，但在句中按名词使用。

常见后缀：**-ние / -ение / -ание / -тие / -ка**。

动名词常保留动词支配关系：

- изучать русский язык → изучение русского языка
- обсуждать проблему → обсуждение проблемы
- прибывать в Москву → прибытие в Москву

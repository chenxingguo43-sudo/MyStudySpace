# 1.1 定量数词的构成

来源：[[新编俄语语法 Markdown版/章节/04 数词#^kp-04-1-1-02]]

## 核心规则

- 简单数词、复合数词和合成数词要分清。
- 十一到十九有固定构成形式。
- 几十、几百、几千在变格时变化位置不同。

## 例句

- двадцать один студент：二十一名学生。
- сто пятьдесят рублей：一百五十卢布。

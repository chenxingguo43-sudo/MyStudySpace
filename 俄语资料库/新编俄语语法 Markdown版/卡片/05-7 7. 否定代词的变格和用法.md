# 7. 否定代词的变格和用法

来源：[[新编俄语语法 Markdown版/章节/05 代词#^kp-05-7-17]]

## 核心规则

- 否定代词由 ни- 或 не- 与疑问代词构成。
- ни- 系列常和谓语否定连用。
- 介词出现时通常插在前缀和代词之间。

## 例句

- Никого нет дома.：家里谁也没有。
- Не с кем поговорить.：没人可以说话。

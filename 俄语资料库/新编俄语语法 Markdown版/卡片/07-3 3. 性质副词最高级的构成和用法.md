# 3. 性质副词最高级的构成和用法

来源：[[新编俄语语法 Markdown版/章节/07 副词#^kp-07-3-05]]

## 核心规则

- 副词最高级表示动作或状态达到最高程度。
- 常用 наиболее, наименее 或 лучше всех 一类表达。

## 例句

- Она ответила наиболее точно.：她回答得最准确。

## 复习提示

- 功能词先记语义类别，再记固定搭配和接格。
- 复习时优先从例句反推规则。

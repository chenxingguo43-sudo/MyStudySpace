# 5.1 动名词的构成

来源：[[新编俄语语法 Markdown版/章节/02 名词#^kp-02-5-1-20]]

动名词常通过后缀构成。

| 后缀 | 示例 |
|---|---|
| **-ние / -ение / -ание** | чтение；изучение；обсуждение |
| **-тие** | открытие；развитие |
| **-ка** | подготовка；проверка |
| 零后缀或其他方式 | вход；выход；переход |

具体构成常和动词体、词干变化有关。

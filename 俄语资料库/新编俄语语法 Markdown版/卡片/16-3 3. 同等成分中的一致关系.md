# 3. 同等成分中的一致关系

来源：[[新编俄语语法 Markdown版/章节/16 句子的同等成分#^kp-16-3-03]]

## 判断要点

- 多个同等主语通常使谓语用复数。
- 具体协调受语义、位置和语体影响。

## 例句

- Мать и отец пришли.：母亲和父亲来了。

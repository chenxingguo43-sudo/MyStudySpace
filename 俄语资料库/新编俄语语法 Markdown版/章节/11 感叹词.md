感叹词（междометие）是一种表达说话人的各种情感和意愿的不变化的词类，它既不是实词，也不是虚词，是一种特殊的词类。感叹词一般不作句子成分，后面用逗号或感叹号与句子分开。

根据意义可将感叹词分为两类：表示情感的感叹词和表示意愿的感叹词。

## 1. 感叹词概述

感叹词用来表达说话人的情感、意志或模拟声音。感叹词在口语和文学语言中都很常见，使用频率很高。

| 俄语例句 | 中文释义 |
|---|---|
| Ах! Как красиво! | 啊！多好看啊！ |
| Ах, Родина-мать! | 啊，祖国母亲！ |
| Мамочка, ой, как хорошо! | 啊！妈妈，太好了！ |
| Браво, браво! — воскликнула она. | "好哇！好哇！"她叫起来。 |

## 2. 表示情感的感叹词

### 2.1 表示赞赏、喜悦

| 俄语例句 | 中文释义 |
|---|---|
| Ах! Как красиво! | 啊！多好看啊！ |
| О, как я счастлив! | 呵，我多么幸福！ |
| Ура! Наша команда победила! | 乌拉！我们队赢了！ |
| Ура! Задача выполнена! | 乌拉！任务完成了！ |
| Ура! Я нашёл себе увлечение. | 乌拉！我找到了自己的爱好。 |

### 2.2 表示惊讶、恐惧

| 俄语例句 | 中文释义 |
|---|---|
| Ах! — вскрикнула она испуганно. | "啊！"她惊恐地叫了一声。 |
| А! Что я сделал! | 啊呀！我干了什么呀！ |
| Ой, я боюсь. | 啊，我害怕。 |
| Ой! Нам надо было выходить! Мы проехали свою остановку. | 哎呀！我们该下车的，坐过站了。 |
| Ох, пошлите за доктором. | 啊，快派人去请医生吧！ |

### 2.3 表示遗憾、懊悔、悲伤

| 俄语例句 | 中文释义 |
|---|---|
| Ах, я совсем забыл об этом! | 唉，这件事我忘得一干二净！ |
| Эх, ты! | 唉，你呀！ |
| Увы, я стар! | 唉，我老了！ |
| Ох, забыл! | 哦，忘了！ |

### 2.4 表示厌恶、不满

| 俄语例句 | 中文释义 |
|---|---|
| Фу! Как вам не стыдно! | 呸！您可真不知羞耻！ |
| Ох, как мне это надоело! | 唉，我多么讨厌这个！ |
| Тьфу, надоел! | 呸，烦死了！ |
| Тьфу, дурак какой! | 呸，什么蠢货！ |

### 2.5 表示欢呼

| 俄语例句 | 中文释义 |
|---|---|
| Ура! Наша команда победила! | 乌拉！我们队赢了！ |
| Ура! Задача выполнена! | 乌拉！任务完成了！ |
| Ура! Я нашёл себе увлечение. | 乌拉！我找到了自己的爱好。 |

### 2.6 表示催促、号召

| 俄语例句 | 中文释义 |
|---|---|
| Ну, иди скорее! | 喂，快点走吧！ |
| Ну, ребята, давайте закончим работу к обеду. | 喂，伙伴们，咱们午饭前把工作结束吧。 |
| Ну, говори скорее! | 喂，快说吧！ |
| Ну, давай плясать! | 喂，咱们跳舞吧！ |

## 3. 表示意愿的感叹词

### 3.1 表示呼唤

| 俄语例句 | 中文释义 |
|---|---|
| Эй, кто там! | 喂，谁在那儿！ |
| Алло! Кто говорит? | 喂！谁在说话？ |
| Эй, иди сюда! | 喂，到这儿来！ |
| Ты, мальчик! | 喂，小孩！ |

### 3.2 表示命令、禁止

| 俄语例句 | 中文释义 |
|---|---|
| На тебе! | 给你！ |
| На, держи! | 给，拿着！ |
| Стой! Не двигаться! | 站住！不许动！ |
| Тише! Кто-то подслушивает. | 安静！有人在监视我们。 |
| Иван Иванович, наступили! | 伊万诺维奇，您踩到我的脚了。 |

### 3.3 表示祈求、恳请

| 俄语例句 | 中文释义 |
|---|---|
| Ох, пошлите за доктором. | 啊，快派人去请医生吧！ |
| Мамочка, ой, как хорошо! | 啊！妈妈，太好了！ |

### 3.4 礼貌用语

一些表示问候、告别、感谢、致歉等意义的词也被归入感叹词。

| 俄语例句 | 中文释义 |
|---|---|
| Здравствуйте, ребята! | 同学们，你们好！ |
| Здравствуйте! | 您好！ |
| Добрый день! | 日安！ |
| Доброе утро! | 早上好！ |
| Добрый вечер! | 晚上好！ |
| Прощай, любимый город! | 再见了，亲爱的城市！ |
| Спасибо! | 谢谢！ |
| Пожалуйста! | 请！不客气！ |
| Извините! | 对不起！ |

## 1. 主语及其表示法

双部句有主语和谓语两个主要成分。主语表示句子谈论的对象，回答 кто? что?。 ^kp-13-1-01

| 主语表示方式 | 示例 |
|---|---|
| 名词第一格 | Студент читает. |
| 代词第一格 | Он работает. |
| 数词或数量词组 | Двое вошли в комнату. |
| 不定式 | Учиться - наша задача. |
| 名词化形容词 | Больной спит. |
| 词组 | Мы с братом пошли домой. |

## 2. 谓语及其表示法

谓语表示主语的行为、状态、特征、身份等。 ^kp-13-2-02

### 2.1 动词性谓语和静词性谓语

^kp-13-2-1-03

| 谓语类型 | 构成 | 示例 |
|---|---|---|
| 简单动词谓语 | 变位动词、过去时或命令式等 | Студент читает. Он пришёл. |
| 复合动词谓语 | 助动词、情态词或阶段动词 + 不定式 | Я хочу читать. Он начал работать. |
| 复合静词谓语 | 系词 + 名词、形容词、短尾形容词等 | Он был студентом. Задача трудна. |

常见复合动词谓语前项：

| 类型 | 示例 |
|---|---|
| 情态意义 | мочь，хотеть，должен，надо，нужно |
| 阶段意义 | начать，стать，продолжать，кончить，перестать |

## 3. 主语和谓语的协调关系

谓语通常与主语在人称、数、性上协调。 ^kp-13-3-04

| 主语 | 谓语协调 |
|---|---|
| я / мы / ты / вы | 谓语按相应人称和数变化 |
| он / она / оно / они | 谓语按第三人称及数变化 |
| 过去时单数主语 | 谓语按主语性变化 |
| 数量词组作主语 | 谓语可根据意义用单数或复数 |
| пол- 复合名词作主语 | 现在时多用单数，过去时常用中性 |

示例：

| 俄语例句 | 中文释义 |
|---|---|
| Я читаю. | 我在读。 |
| Она читала. | 她读过。 |
| Студенты работают. | 学生们在工作。 |
| Прошло полчаса. | 过了半小时。 |

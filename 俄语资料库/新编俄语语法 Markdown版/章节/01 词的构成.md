## 1. 俄语的词类

俄语的词通常分为十大词类（части речи）：名词、形容词、数词、代词、动词和副词属于实词；前置词、连接词、语气词属于虚词；感叹词既不是实词，也不是虚词。 ^kp-01-1-01

| 大类 | 词类 | 例词 |
|---|---|---|
| 实词 | 名词 | дом [房子]，мебель [家具]，собака [狗]，обувь [鞋]，счастье [幸福]，слово [单词]，молоко [牛奶]，человек [人] |
| 实词 | 形容词 | большой [大的]，короткий [短的]，белый [白色的]，летний [夏天的]，сильный [强壮的]，трудный [困难的]，старший [年长的] |
| 实词 | 数词 | два [两个]，девятнадцать [十九]，сто [一百]，оба [两个都]，трое [三个]，второй [第二的]，миллион [一百万] |
| 实词 | 代词 | он [他]，твой [你的]，тот [那个]，такой [那样的]，весь [整个的]，сам [自己]，никто [谁也（不）]，что [什么] |
| 实词 | 动词 | лежать [躺]，помогать [帮忙]，ждать [等待]，решиться [决定]，ехать [乘车走]，нравиться [喜欢]，хотеть [想] |
| 实词 | 副词 | быстро [快]，наверху [在上面]，очень [很]，рано [早]，дома [在家里]，совсем [完全]，всегда [总是]，по-дружески [友好地]，пешком [步行地] |
| 虚词 | 前置词 | из [从……里面]，на [在……上面]，под [在……下面]，через [经过]，по [沿着]，благодаря [由于]，для [为了]，против [在……对面] |
| 虚词 | 连接词 | и [和]，или [或者]，если [如果]，однако [不过]，когда [当……时候]，чтобы [为了]，потому что [因为]，хотя [尽管] |
| 虚词 | 语气词 | да [是的]，ровно [正好]，не [不，不是]，ладно [行，成]，будто [似乎]，именно [正是]，вон [那就是]，ещё бы [当然啦]，как же [当然] |
| 非实词、非虚词 | 感叹词 | ах [啊]，эх [唉]，ох [唉]，фу [呸]，алло [哈罗]，браво [好哇]，тьфу [呸] |

## 2. 词素

俄语单词是由一个或几个词素组成的，每个词素都有自己的意义和作用。词素分为词根、前缀、后缀和词尾。 ^kp-01-2-02

### 2.1 词根

词根（корень）表示词的基本词汇意义，是同根词共有的部分。

例如：

| 词根 | 同根词 |
|---|---|
| вод- | вода [水]，водный [水的]，водяной [水生的]，водянистый [水分多的]，подводный [水下的]，наводнение [洪水]，водность [含水量] |
| уч- | ученик [学生]，учёба [学习]，учебник [教科书]，учитель [教师]，учить [教；学习] |

### 2.2 前缀

前缀（приставка）位于词根之前。前缀分为构词前缀和构形前缀。

构词前缀表示词汇意义，可构成新词。

| 原词 | 加前缀后的词 |
|---|---|
| ход [行走] | вход [入口]，выход [出口]，уход [离开]，приход [来到] |

构形前缀表示语法意义。例如动词加前缀后，常可构成完成体形式：

| 未完成体 | 完成体 |
|---|---|
| писать [写] | написать [写完] |
| обедать [吃午饭] | пообедать [吃完午饭] |
| делать [做] | сделать [做完] |

### 2.3 后缀

后缀（суффикс）位于词根之后、词尾之前。后缀分为构词后缀和构形后缀。

构词后缀表示词汇意义，可构成新词：

| 原词 | 加后缀后的词 |
|---|---|
| книга [书] | книж-н-ый [书的] |
| вода [水] | вод-н-ый [水的] |
| медь [铜] | мед-н-ый [铜的] |

构形后缀表示语法意义。例如动词过去时后缀 -л-：

| 动词 | 过去时形式 |
|---|---|
| читать [读] | чита-л [读过] |
| слушать [听] | слуша-л [听过] |
| построить [建成] | построи-л [建成了] |

### 2.4 词尾

词尾（окончание）位于后缀之后；如果没有后缀，则位于词根之后。词尾是词形变化的标志，表示性、数、格、人称等语法意义。

| 词形 | 词尾 | 语法意义 |
|---|---|---|
| пиш-у [我写] | -у | 动词第一人称单数 |
| комнат-у [房间] | -у | 阴性名词单数第四格 |

只有可以变格或变位的词才有词尾。

## 3. 词干

词干（основа слова）由词根、前缀和构词后缀组成。词干是去掉词尾和构形后缀后留下的部分。 ^kp-01-3-03

词干可分为非派生词干和派生词干。

| 类型 | 构成 | 例词 |
|---|---|---|
| 非派生词干 | 只含词根 | сад [花园]，дом [房子]，город [城市]，завод [工厂]，гость [客人] |
| 派生词干 | 含词根，并可含前缀或构词后缀 | уч-и-тель [教师]，пре-крас-н-ый [美丽的]，пра-дед [曾祖父] |

下面以 интерес 及其派生词为例，观察词干内部各部分：

| 词 | 前缀 | 词根 | 构词后缀 | 构形后缀 | 词尾 |
|---|---|---|---|---|---|
| интерес [兴趣] |  | интерес |  |  |  |
| интересный [有趣的] |  | интерес- | -н- |  | -ый |
| безынтересный [没有趣的] | без- | интерес- | -н- |  | -ый |
| интереснее [比较有趣的] |  | интерес- | -н- | -ее |  |
| интереснейший [最有趣的] |  | интерес- | -н- | -ейш- | -ий |
| интересовать [使感兴趣] |  | интерес- | -ова- | -ть |  |
| интересность [趣味性] |  | интерес- | -н-，-ость |  |  |

## 4. 语音交替

俄语词在构词或变形时，词根中的某些元音或辅音会发生交替。常见的交替分为元音交替和辅音交替。 ^kp-01-4-04

### 4.1 元音交替

| 音变规律 | 例词 |
|---|---|
| о → а | закончить [结束] → заканчивать [结束]；спросить [问] → спрашивать [问] |
| е → и | запереть [锁上] → запирать [锁上]；умереть [死] → умирать [死] |
| ∅ → и | убрать [收拾] → убирать [收拾]；выбрать [选择] → выбирать [选择] |
| е → ё | озеро [湖] → озёра [湖，复数]；сестра [姐妹] → сёстры [姐妹，复数] |
| о → ∅ | сон [梦] → сна [梦，第二格]；рот [嘴] → рта [嘴，第二格] |
| е → ∅ | отец [父亲] → отца [父亲，第二格]；день [天] → дня [天，第二格] |

这里的 ∅ 表示零位元音，即某些形式中没有显性的元音。

### 4.2 辅音交替

| 音变规律 | 例词 |
|---|---|
| з → ж | привозить [运来] → привожу [我运来]；возразить [反驳] → возражение [反驳] |
| г → ж | строгий [严格的] → строже [更严格]；дорогой [贵的] → дороже [更贵] |
| д → ж | твёрдый [硬的] → твёрже [更硬]；ходить [走] → хожу [我走] |
| х → ш | страх [恐惧] → страшный [可怕的]；сухой [干的] → суше [更干] |
| с → ш | писать [写] → пишу [我写]；высокий [高的] → выше [更高] |
| к → ч | лёгкий [轻的] → легче [更轻]；восток [东方] → восточный [东方的] |
| т → ч | богатый [富的] → богаче [更富]；хотеть [想] → хочу [我想] |
| ц → ч | лицо [脸] → личный [个人的]；отец [父亲] → отеческий [父亲的] |
| ст → щ | чистый [干净的] → чище [更干净]；выпустить [放出] → выпущу [我放出] |
| б → бл | любить [爱] → люблю [我爱]；употребить [使用] → употреблю [我使用] |
| п → пл | купить [买] → куплю [我买]；терпеть [忍受] → терплю [我忍受] |
| в → вл | нравиться [喜欢] → нравлюсь [我喜欢]；поправить [修改] → поправлю [我修改] |
| м → мл | кормить [喂] → кормлю [我喂]；познакомить [介绍认识] → познакомлю [我介绍认识] |

## 5. 构词方法

俄语词汇常见的构词方法包括前缀构词法、后缀构词法、前缀-后缀构词法、复合词构词法和复合缩写词构词法。 ^kp-01-5-05

### 5.1 前缀构词法

前缀构词法是在原词前加前缀构成新词。

| 原词 | 新词 |
|---|---|
| дед [祖父] | пра-дед [曾祖父] |
| автор [作者] | со-автор [合作者] |
| весёлый [快活的] | раз-весёлый [非常快活的] |
| известный [著名的] | не-известный [无名的] |
| надолго [长久地] | не-надолго [短期地] |

同一个动词加不同前缀后，可形成意义不同的新词：

| 原词 | 加前缀后的词 |
|---|---|
| ходить [走] | при-ходить [来到]，у-ходить [离开]，вы-ходить [走出]，под-ходить [走近]，до-ходить [走到]，про-ходить [走过] |

### 5.2 后缀构词法

后缀构词法是在原词词干后加后缀构成新词。

| 原词 | 新词 |
|---|---|
| писать [写] | писа-тель [作家] |
| переводить [翻译] | перевóд-чик [翻译] |
| Китай [中国] | китá-ец [中国人] |
| храбрый [勇敢的] | храбр-ость [勇敢] |
| тихий [静静的] | тих-о [静静地] |
| зима [冬天] | зим-ой [在冬天] |
| обед [午饭] | обед-а-ть [吃午饭] |
| белый [白色的] | бел-е-ть [变白] |
| завтрак [早饭] | завтрак-а-ть [吃早饭] |

### 5.3 前缀-后缀构词法

前缀-后缀构词法是在同一个词干上同时使用前缀和后缀构成新词。

| 原词 | 新词 |
|---|---|
| стол [桌子] | на-столь-н-ый [桌上的] |
| ухо [耳朵] | на-уш-ник [耳机] |
| беседа [会谈] | со-бесед-ник [交谈者] |
| нос [鼻子] | пере-нос-иц-а [鼻梁] |
| завод [工厂] | между-завод-ск-ий [厂际的] |

### 5.4 复合词构词法

复合词是由两个或两个以上词根组成的词。

#### 5.4.1 两个完整单词通过连字符连接

| 复合词 | 释义 |
|---|---|
| премьер-министр | 首相 |
| вагон-ресторан | 餐车 |
| шеф-редактор | 总编辑 |
| пресс-конференция | 新闻记者招待会 |
| интернет-кафе | 网吧 |
| научно-технический | 科技的 |

#### 5.4.2 词根之间用连接元音 -о- 或 -е-

| 构成 | 复合词 |
|---|---|
| сам [自己] + летать [飞] | самолёт [飞机] |
| вода [水] + падать [落] | водопад [瀑布] |
| земля [地球] + трясти [震动] | землетрясение [地震] |
| сухой [干的] + фрукты [水果] | сухофрукты [干果] |
| старший [高年级的] + курс [年级] | старшекурсник [高年级学生] |
| сам [自己] + обслуживать [服务] | самообслуживание [自助] |
| труд [劳动] + устроиться [就业] | трудоустройство [求职，就业] |
| работа [工作] + дать [给] | работодатель [雇主] |
| русский [俄语的] + китайский [汉语的] | русско-китайский [俄汉的] |

#### 5.4.3 不用连接元音的复合词

| 复合词 | 释义 |
|---|---|
| одноэтажный | 单层的 |
| столетие | 百年 |
| лазердиск | 光盘 |

### 5.5 复合缩写词

复合缩写词是由词组中各词的某些部分组合而成的词。原书示例主要包括以下几类。

#### 5.5.1 一个词的开头部分加另一个完整词

| 缩写词 | 完整形式 | 释义 |
|---|---|---|
| Госдума | Государственная Дума | 国家杜马 |
| физкультура | физическая культура | 体育 |
| мединститут | медицинский институт | 医学院 |

#### 5.5.2 各词开头部分组合

| 缩写词 | 完整形式 | 释义 |
|---|---|---|
| универсам | универсальный магазин | 百货商店 |
| комсомол | коммунистический союз молодёжи | 共青团 |
| партком | партийный комитет | 党委会 |

#### 5.5.3 各词首字母组合

| 缩写词 | 完整形式 | 释义 |
|---|---|---|
| КНР | Китайская Народная Республика | 中华人民共和国 |
| ООН | Организация Объединённых Наций | 联合国 |
| США | Соединённые Штаты Америки | 美利坚合众国 |
| РФ | Российская Федерация | 俄罗斯联邦 |
| МГУ | Московский государственный университет | 莫斯科国立大学 |
| ЕГЭ | Единый государственный экзамен | 国家统一考试 |
| ВВЦ | Всероссийский выставочный центр | 全俄展览中心 |

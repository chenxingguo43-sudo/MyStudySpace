动词表示行为或状态。俄语动词有体、态、式、时、人称、数、性等语法范畴。

本章学习时可以抓住四条主线：变位决定“形式”，时决定“时间”，体决定“过程/结果”，式决定“说话人的态度”。

## 1. 动词不定式

动词不定式是动词的原形。常见结尾为 -ть、-ти、-чь，也可带 -ся / -сь。 ^kp-06-1-01

| 结尾 | 示例 |
|---|---|
| -ть | читать [读]，говорить [说]，делать [做] |
| -ться | учиться [学习]，заниматься [从事；学习] |
| -ти | идти [走]，нести [拿着走]，вести [引导] |
| -чь | мочь [能够]，печь [烤]，беречь [爱惜] |
| -чься | отвлечься [分心；转移注意] |

不定式在句中可作不同成分：

| 功能 | 俄语例句 | 中文释义 |
|---|---|---|
| 主语 | Учиться - наша задача. | 学习是我们的任务。 |
| 谓语的一部分 | Это русская традиция - отмечать праздники дома. | 这是俄罗斯人的传统：在家庆祝节日。 |
| 定语 | У меня нет желания идти в театр. | 我没有去剧院的愿望。 |
| 目的状语 | Они пошли на вокзал проводить друзей. | 他们去火车站送朋友。 |
| 与情态词连用 | Надо читать. Можно идти. | 应该读。可以走。 |

## 2. 动词变化

动词变化主要包括人称变位、过去时构成和将来时构成。 ^kp-06-2-02

### 2.1 动词变位法

俄语动词现在时和完成体简单将来时按人称、数变化。主要分为第一变位法和第二变位法。 ^kp-06-2-1-03

#### 2.1.1 第一变位法

| 人称 | делать | жить | заниматься | 词尾 |
|---|---|---|---|---|
| я | делаю | живу | занимаюсь | -ю / -у |
| ты | делаешь | живёшь | занимаешься | -ешь / -ёшь |
| он / она | делает | живёт | занимается | -ет / -ёт |
| мы | делаем | живём | занимаемся | -ем / -ём |
| вы | делаете | живёте | занимаетесь | -ете / -ёте |
| они | делают | живут | занимаются | -ют / -ут |

第一变位法第三人称复数多为 -ут / -ют。

#### 2.1.2 第二变位法

| 人称 | говорить | смотреть | учиться | 词尾 |
|---|---|---|---|---|
| я | говорю | смотрю | учусь | -ю / -у |
| ты | говоришь | смотришь | учишься | -ишь |
| он / она | говорит | смотрит | учится | -ит |
| мы | говорим | смотрим | учимся | -им |
| вы | говорите | смотрите | учитесь | -ите |
| они | говорят | смотрят | учатся | -ят / -ат |

第二变位法第三人称复数多为 -ат / -ят。

属于第二变位法的动词主要有以下几类：

| 类型 | 示例 |
|---|---|
| 大多数以 -ить 结尾的动词 | говорить [说]，строить [建设]，спешить [急忙]，садиться [坐下] |
| 少数以 -еть 结尾的动词 | смотреть [看]，висеть [悬挂]，лететь [飞]，сидеть [坐]，видеть [看见] |
| 少数以 -ать 结尾的动词 | лежать [躺]，бежать [跑]，спать [睡觉]，дышать [呼吸] |

带 `-ся` 的动词变位与不带 `-ся` 的形式相同，只是在辅音后加 `-ся`，元音后加 `-сь`：`учусь`，`учишься`，`учатся`。

#### 2.1.3 常见变位类型

| 类型 | 变位规律 | 示例 |
|---|---|---|
| -ать，多数第一变位 | -аю，-аешь，-ают | читать - читаю，читаешь，читают |
| -ить，多数第二变位 | -ю，-ишь，-ят | говорить - говорю，говоришь，говорят |
| -овать / -евать | -ую，-уешь，-уют | советовать - советую，советуешь，советуют |
| -нуть | -ну，-нешь，-нут | привыкнуть - привыкну，привыкнешь，привыкнут |
| идти 类 | 特殊词干 | идти - иду，идёшь，идут |
| дать 类 | 特殊词尾 | дать - дам，дашь，даст，дадим，дадите，дадут |
| есть | 特殊变位 | ем，ешь，ест，едим，едите，едят |

#### 2.1.4 常见不规则变位速查

| 不定式 | я | ты | он / она | мы | вы | они |
|---|---|---|---|---|---|---|
| быть | есть | есть | есть | есть | есть | есть |
| дать | дам | дашь | даст | дадим | дадите | дадут |
| есть | ем | ешь | ест | едим | едите | едят |
| хотеть | хочу | хочешь | хочет | хотим | хотите | хотят |
| бежать | бегу | бежишь | бежит | бежим | бежите | бегут |
| идти | иду | идёшь | идёт | идём | идёте | идут |
| ехать | еду | едешь | едет | едем | едете | едут |

动词变位时常发生词干辅音交替，尤其要注意第一人称单数和第三人称复数：

| 不定式 | 变位示例 | 交替 |
|---|---|---|
| писать | пишу，пишут | с → ш |
| искать | ищу，ищут | ск → щ |
| плакать | плачу，плачут | к → ч |
| носить | ношу，носят | с → ш |
| ходить | хожу，ходят | д → ж |
| любить | люблю，любят | б → бл |

#### 2.1.5 动词变位中的音变

动词在变位时，词干部分的音节或音组可能发生语音交替。第二变位法动词往往只在单数第一人称发生音变；第一变位法动词的音变常贯穿所有人称。

| 交替 | 第一变位法示例 | 第二变位法示例 |
|---|---|---|
| з → ж | сказать → скажу，скажешь，скажут | находиться → нахожусь |
| д → ж | показать → покажу | обидеть → обижу；видеть → вижу |
| к → ч | плакать → плачу，плачешь，плачут | лететь → лечу；ответить → отвечу |
| ст → щ | искать → ищу，ищешь，ищут | чистить → чищу；грустить → грущу |
| ск → щ | искать → ищу | угостить → угощу |
| с → ш | писать → пишу，пишешь，пишут | просить → прошу；носить → ношу；спросить → спрошу |
| б → бл | дремать → дремлю | любить → люблю |
| п → пл |  | купить → куплю |
| ф → фл |  |  |
| в → вл |  | готовить → готовлю；терпеть → терплю |
| д → д / ж / жд 等 | класть → кладу，кладёшь，кладут | водить → вожу |

> [!note]
> 音变表用于帮助识别变位，不要机械套用。具体动词仍应以词典变位或课本例词为准。

### 2.2 动词过去时的构成

#### 2.2.1 规则过去时

过去时一般由不定式去掉 -ть 后加 -л、-ла、-ло、-ли 构成，按性、数变化，不按人称变化。 ^kp-06-2-2-04

| 性/数 | 形式 | 示例 |
|---|---|---|
| 阳性单数 | -л | он читал |
| 阴性单数 | -ла | она читала |
| 中性单数 | -ло | письмо лежало |
| 复数 | -ли | они читали |

带 -ся 的动词过去时：

| 性/数 | 示例 |
|---|---|
| 阳性 | занимался |
| 阴性 | занималась |
| 中性 | занималось |
| 复数 | занимались |

常见特殊过去时：

| 不定式 | 阳性 | 阴性 | 中性 | 复数 |
|---|---|---|---|---|
| идти | шёл | шла | шло | шли |
| нести | нёс | несла | несло | несли |
| мочь | мог | могла | могло | могли |
| помочь | помог | помогла | помогло | помогли |
| умереть | умер | умерла | умерло | умерли |
| запереть | запер | заперла | заперло | заперли |
| вырасти | вырос | выросла | выросло | выросли |

#### 2.2.2 不规则过去时类型

以 `-зти / -сти` 结尾的动词，阳性过去时常不带 `-л`，其他性、数形式加 `-ла / -ло / -ли`：

| 不定式 | 阳性 | 阴性 | 中性 | 复数 |
|---|---|---|---|---|
| везти | вёз | везла | везло | везли |
| нести | нёс | несла | несло | несли |
| лезть | лез | лезла | лезло | лезли |
| принести | принёс | принесла | принесло | принесли |
| отнести | отнёс | отнесла | отнесло | отнесли |
| привезти | привёз | привезла | привезло | привезли |
| увезти | увёз | увезла | увезло | увезли |
| слезть | слез | слезла | слезло | слезли |

如果动词变位词干发生音变，阳性过去时仍可能为 `-л`：

| 不定式 | 变位提示 | 过去时形式 |
|---|---|---|
| вести | веду | вёл，вела，вело，вели |
| цвести | цвету | цвёл，цвела，цвело，цвели |
| сесть | сяду | сел，села，село，сели |
| класть | кладу | клал，клала，клало，клали |
| упасть | упаду | упал，упала，упало，упали |
| приобрести | приобрету | приобрёл，приобрела，приобрело，приобрели |
| прочесть | прочту | прочёл，прочла，прочло，прочли |

以 `-чь` 结尾的动词：

| 不定式 | 变位提示 | 过去时形式 |
|---|---|---|
| помочь | помогу | помог，помогла，помогло，помогли |
| мочь | могу | мог，могла，могло，могли |
| беречь | берегу | берёг，берегла，берегло，берегли |
| лечь | лягу | лёг，легла，легло，легли |
| привлечь | привлеку | привлёк，привлекла，привлекло，привлекли |
| увлечься | увлекусь | увлёкся，увлеклась，увлеклось，увлеклись |

不带重音的 `-нуть` 动词，前面为辅音时，阳性过去时可去掉 `-ну-`：

| 不定式 | 过去时形式 |
|---|---|
| погибнуть | погиб，погибла，погибло，погибли |
| привыкнуть | привык，привыкла，привыкло，привыкли |
| отвыкнуть | отвык，отвыкла，отвыкло，отвыкли |
| исчезнуть | исчез，исчезла，исчезло，исчезли |
| достигнуть | достиг，достигла，достигло，достигли |
| окрепнуть | окреп，окрепла，окрепло，окрепли |
| замёрзнуть | замёрз，замёрзла，замёрзло，замёрзли |
| промокнуть | промок，промокла，промокло，промокли |

如果 `-нуть` 带重音，过去时通常保留 `-ну-`：

| 不定式 | 过去时形式 |
|---|---|
| обмануть | обманул，обманула，обмануло，обманули |
| вернуть | вернул，вернула，вернуло，вернули |
| вернуться | вернулся，вернулась，вернулось，вернулись |
| махнуть | махнул，махнула，махнуло，махнули |
| улыбнуться | улыбнулся，улыбнулась，улыбнулось，улыбнулись |
| заснуть | заснул，заснула，заснуло，заснули |
| проснуться | проснулся，проснулась，проснулось，проснулись |

以 `-ереть` 结尾的动词：

| 不定式 | 过去时形式 |
|---|---|
| умереть | умер，умерла，умерло，умерли |
| запереть | запер，заперла，заперло，заперли |
| стереть | стёр，стёрла，стёрло，стёрли |
| опереться | опёрся，оперлась，оперлось，оперлись |

`идти` 及以它为词干的动词过去时形式特殊：

| 不定式 | 过去时形式 |
|---|---|
| идти | шёл，шла，шло，шли |
| прийти | пришёл，пришла，пришло，пришли |
| отойти | отошёл，отошла，отошло，отошли |
| войти | вошёл，вошла，вошло，вошли |
| подойти | подошёл，подошла，подошло，подошли |

#### 2.2.3 过去时重音提示

过去时形式不仅要看词尾，也要注意重音位置。常见规律可以先按下面几类记忆：

| 类型 | 重音倾向 | 示例 |
|---|---|---|
| 重音固定在词干 | 阳性、阴性、中性、复数重音基本不变 | читать - читал，читала，читали |
| 阴性重音移到词尾 | 阴性单数常重读 -а | взять - взял，взяла，взяли；ждать - ждал，ждала |
| 无 -л 的阳性过去时 | 阳性无 -л，其他形式仍有 -ла / -ло / -ли | нести - нёс，несла，несли |
| -ереть / -ереть 类 | 词干和重音都可能变化 | умереть - умер，умерла；запереть - запер，заперла |

### 2.3 动词将来时的构成

动词将来时有复合将来时和简单将来时。 ^kp-06-2-3-05

| 动词体 | 将来时构成 | 示例 |
|---|---|---|
| 未完成体 | быть 的将来时 + 不定式 | буду читать；будешь писать |
| 完成体 | 完成体动词按现在时人称变化，表示将来 | прочитаю；напишешь |

| 人称 | 未完成体复合将来时 | 完成体简单将来时 |
|---|---|---|
| я | буду читать | прочитаю |
| ты | будешь читать | прочитаешь |
| он / она | будет читать | прочитает |
| мы | будем читать | прочитаем |
| вы | будете читать | прочитаете |
| они | будут читать | прочитают |

将来时选择时，先看动词体：

| 想表达 | 常用形式 | 例句 |
|---|---|---|
| 将来会进行某事 | 未完成体复合将来时 | Завтра я буду работать. |
| 将来会把某事做完 | 完成体简单将来时 | Завтра я напишу письмо. |
| 将来反复做某事 | 未完成体复合将来时 | Летом мы будем часто ходить в парк. |
| 将来一次具体动作 | 完成体简单将来时 | Я позвоню вам вечером. |

## 难点一：动词变位的重音规律

动词变位中，重音位置常常和变位类型、前缀、词干变化有关。原书把这一部分单列为难点，是因为只看词尾不能保证读音正确。

### 1. 从第二人称起重音发生变化

很多动词第一人称单数与其他人称形式重音不同，学习时应把 `я` 形式和 `ты / он / они` 形式一起记。

|---|---|---|---|
| 第一变位法 | писать | пишу，пишешь，пишут | 写 |
| 第一变位法 | сказать | скажу，скажешь，скажут | 说 |
| 第一变位法 | искать | ищу，ищешь，ищут | 寻找 |
| 第一变位法 | поднять | подниму，поднимешь，поднимут | 举起；提高 |
| 第一变位法 | заказать | закажу，закажешь，закажут | 订；订购 |
| 第一变位法 | доказать | докажу，докажешь，докажут | 证明 |
| 第一变位法 | наказать | накажу，накажешь，накажут | 惩罚 |
| 第一变位法 | приказать | прикажу，прикажешь，прикажут | 命令 |
| 第一变位法 | вязать | вяжу，вяжешь，вяжут | 编织 |
| 第一变位法 | махать | машу，машешь，машут | 挥动 |
| 第一变位法 | принять | приму，примешь，примут | 接受 |
| 第一变位法 | обнять | обниму，обнимешь，обнимут | 拥抱 |

第二变位法中也有大量动词出现类似重音变化：

| любить | люблю，любишь，любят | 爱 |

### 2. 带前缀 вы- 的完成体动词

带前缀 `вы-` 的完成体动词，重音通常固定在 `вы-` 上。

| 不定式 | 变位示例 | 中文释义 |
|---|---|---|
| вымыть | вымою，вымоешь，вымоют | 洗净 |
| выучить | выучу，выучишь，выучат | 学会 |
| выбрать | выберу，выберешь，выберут | 选择 |
| вызвать | вызову，вызовешь，вызовут | 叫来；引起 |

## 3. 动词时

未完成体动词有现在时、过去时和将来时；完成体动词没有现在时，只有过去时和简单将来时。 ^kp-06-3-06

| 动词体 | 现在时 | 过去时 | 将来时 |
|---|---|---|---|
| 未完成体 | читаю | читал | буду читать |
| 完成体 | 无 | прочитал | прочитаю |

### 3.1 现在时的意义和用法

| 事物固有特征或能力 | Рыба плавает, птица летает. | 鱼会游，鸟会飞。 |
| 文学叙述中的历史现在时 | Вдруг кто-то звонит в дверь. | 突然有人按门铃。 |
| 表示近期将来 | Сегодня вечером мы идём в театр. | 今天晚上我们去剧院。 |

### 4.2 未完成体常见用法

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 表示过程 | Я читал книгу. | 我在读书。 |
| 表示重复 | Он часто звонил мне. | 他常给我打电话。 |
| 表示事实本身 | Ты читал эту книгу? | 你读过这本书吗？ |
| 与开始、继续、结束等动词连用 | Он начал читать. | 他开始读了。 |
| 否定命令中表示不要做某事 | Не говори никому. | 别对任何人说。 |

### 4.3 完成体常见用法

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 表示完成和结果 | Я прочитал книгу. | 我读完了书。 |
| 表示一次具体行为 | Он позвонил мне вчера. | 他昨天给我打了电话。 |
| 表示行为开始或状态变化 | Он заболел. | 他病了。 |
| 表示将来具体结果 | Я напишу письмо завтра. | 我明天会写完信。 |
| 肯定命令中请求完成某事 | Напишите адрес. | 请写下地址。 |

### 4.4 体的用法对比

| 情境 | 未完成体 | 完成体 |
|---|---|---|
| 问是否做过 | Ты читал эту книгу? | Ты прочитал эту книгу? |
| 过程与结果 | Он долго писал письмо. | Он написал письмо. |
| 重复与一次 | Он часто звонил. | Он позвонил один раз. |
| 不定式 | Я начал читать. | Я хочу прочитать эту книгу. |
| 命令式 | Не открывай окно. | Откройте окно. |

### 4.5 未完成体与完成体过去时比较

过去时里，未完成体和完成体最常见的差别不是“过去/完成”这么简单，而是说话人要不要强调结果。

| 语义重点 | 未完成体 | 完成体 |
|---|---|---|
| 问事实本身 | Вы читали эту статью? | Вы прочитали эту статью? |
| 强调过程 | Я долго писал письмо. | Я написал письмо за час. |
| 强调行为曾经发生 | Кто открывал окно? | Кто открыл окно? |
| 强调结果存在 | Он писал доклад. | Он написал доклад. |
| 否定句 | Я не читал этой книги. | Я не прочитал этой книги. |

| 俄语例句 | 中文释义 | 说明 |
|---|---|---|
| Вчера я читал эту книгу. | 昨天我读过 / 在读这本书。 | 只说明读这个行为发生过或进行过 |
| Вчера я прочитал эту книгу. | 昨天我读完了这本书。 | 强调读完这个结果 |
| Он долго решал задачу. | 他解这道题解了很久。 | 过程突出 |
| Он решил задачу. | 他把题解出来了。 | 结果突出 |

### 4.6 未完成体与完成体不定式比较

不定式跟在其他词后面时，也要根据语义选择体。

| 搭配环境 | 常用体 | 示例 |
|---|---|---|
| начать、продолжать、кончить 后 | 未完成体 | начать читать；продолжать работать |
| хотеть、решить、попросить 后 | 视意义而定 | хочу читать；хочу прочитать |
| 表示一次完成目标 | 完成体 | Я хочу написать письмо. |
| 表示活动本身或习惯 | 未完成体 | Я люблю читать. |
| 表示禁止 | 多用未完成体 | Нельзя курить. |
| 表示不可能完成 | 完成体可强调结果达不到 | Я не могу решить эту задачу. |

## 难点三：未完成体与完成体过去时用法比较

### 1. 是否强调结果

未完成体过去时只表示过去有过某行为，不强调结果；完成体过去时强调行为结束、达到结果或产生后果。

| 未完成体过去时 | 中文释义 |
|---|---|
| — Чем вы были заняты в пятницу? — Я готовился к экзамену. | “您周五忙什么了？”“我准备考试了。” |
| Спасибо, я не хочу кофе, я уже пил кофе утром. | 谢谢，我不想喝咖啡，我早晨已经喝过咖啡了。 |
| Студенты нашей группы уже сдавали экзамен по истории. | 我们班的学生已经考过历史了。 |
| После перерыва обсуждали доклад. | 休息过后讨论报告了。 |
| — У врача утром был приём больных? — Да, врач утром принимал больных. | “医生早晨接诊过病人吗？”“是的，他早晨接诊过病人。” |

| 完成体过去时 | 中文释义 |
|---|---|
| Я звонил ей, но не дозвонился. | 我给她打过电话，但没打通。 |
| Я уже спрашивал его об этом, но не получил никакого ответа. | 我已经问过他这件事了，但没有得到任何回答。 |
| Кто так чисто убрал сегодня комнату? | 今天是谁把房间打扫得这么干净？ |
| — Телевизор работает? — Да, я его починил. | “电视能看吗？”“是的，我已经把它修好了。” |
| — Что у нас сегодня на обед? — Я приготовила борщ. | “我们今天中午吃什么？”“我做了红菜汤。” |

### 2. 经常、反复与一次行为

未完成体过去时可表示过去经常、反复的行为；完成体过去时表示过去的一次具体行为。

| 俄语例句 | 中文释义 |
|---|---|
| Павел часто приглашал Марину в театр, а в субботу он пригласил её на концерт. | 巴维尔经常邀请玛琳娜去看戏，而周六他请她去听了音乐会。 |
| Обычно дети ложились спать в восемь часов, а сегодня они легли в девять. | 通常孩子们八点睡觉，而今天他们九点才躺下。 |
| Я часто покупал продукты в этом магазине. Сегодня я тоже купил там сыр и масло. | 我常在这家商店买食品。今天我也在那里买了奶酪和黄油。 |

### 3. 持续过程与界限结果

| 未完成体 | 完成体 |
|---|---|
| Он долго писал письмо. | Он написал письмо за час. |
| Весь вечер мы готовились к экзамену. | Мы подготовились к экзамену. |
| Вчера я читал эту книгу. | Вчера я прочитал эту книгу. |

## 难点四：未完成体与完成体将来时用法比较

未完成体将来时由 `быть` 的将来时形式加不定式构成，强调将来过程、持续、重复或活动本身；完成体将来时用完成体动词的人称形式，强调将来一次具体行为或结果。

| 情境 | 未完成体将来时 | 完成体将来时 |
|---|---|---|
| 将来持续过程 | Завтра я буду писать письмо. | Завтра я напишу письмо. |
| 将来反复行为 | Летом мы будем часто ходить в парк. | Завтра мы пойдём в парк. |
| 活动本身 | Вечером брат будет решать задачи. | Брат решит эту задачу. |
| 结果承诺 | Я буду читать эту книгу. | Я прочитаю эту книгу. |

| 俄语例句 | 中文释义 | 说明 |
|---|---|---|
| Каждый день я буду вставать в шесть часов. | 我每天将六点起床。 | 重复行为 |
| Завтра я встану в шесть часов. | 明天我六点起床。 | 一次具体行为 |
| Он будет долго объяснять это правило. | 他会花很久解释这条规则。 | 过程 |
| Он объяснит это правило. | 他会把这条规则解释清楚。 | 结果 |

## 难点五：未完成体与完成体不定式用法比较

### 1. 只使用未完成体不定式的常见情境

#### 与“开始、继续、结束、停止”等动词连用

这些动词后通常用未完成体不定式，因为重点在行为过程本身。

| 动词 | 中文释义 |
|---|---|
| стать | 开始 |
| начинать / начать | 开始 |
| продолжать | 继续 |
| кончать / кончить | 结束 |
| приниматься / приняться | 着手 |
| переставать / перестать | 停止 |
| прекращать / прекратить | 终止 |
| бросать / бросить | 不再做某事 |

| 俄语例句 | 中文释义 |
|---|---|
| После окончания института мой брат станет работать инженером на заводе. | 大学毕业后我哥哥将在工厂当工程师。 |
| По совету отца Алексей бросил курить. | 根据父亲的建议，阿列克谢戒烟了。 |
| Телефон наконец перестал звонить. | 电话终于不响了。 |
| Мальчик кончил читать и стал рисовать. | 小男孩看完书就开始画画了。 |
| Завод прекратил выпускать эту модель холодильников. | 工厂已经停止生产这种型号的冰箱。 |
| В университете Саша продолжает изучать русский язык. | 在大学里萨沙继续学俄语。 |

> [!note]
> `продолжить` 不能接动词不定式，只能与名词第四格连用：`После обеда мы продолжим занятия.` 午饭后我们继续上课。

#### 与“学会、习惯、厌烦、避免、禁止”等意义的词连用

| 词组 | 中文释义 |
|---|---|
| учиться читать, писать и считать | 学习读、写、算 |
| привыкать / привыкнуть рано вставать | 习惯早起 |
| отвыкать / отвыкнуть | 失去某种习惯 |
| надоедать / надоесть | 使厌烦 |
| уставать / устать | 厌倦；累于 |
| избегать | 避免；回避 |
| запрещаться / воспрещаться / запрещено | 禁止 |

| 俄语例句 | 中文释义 |
|---|---|
| В первом классе дети учатся читать, писать и считать. | 一年级孩子学习读、写和算术。 |

| Мать устала разбираться в спорах своих дочерей. | 妈妈已经厌倦了分辨女儿们的争论。 |
| За время каникул Андрей привык рано вставать и уходить в лес. | 放假期间安德烈习惯了早起去森林。 |
| Она почему-то избегает встречаться с нами. | 不知为什么她总是回避和我们见面。 |

> [!note]
> `любить` 和 `нравиться` 后常用未完成体，也可与带 `по-` 的完成体动词连用：`Я люблю говорить с ним.` 我喜欢和他说话；`Я люблю поговорить с ним.` 我喜欢和他聊一聊。

### 2. 常用完成体不定式的情境

完成体不定式通常强调行为达到界限、完成目标或取得结果。

| 情境 | 示例 | 中文释义 |
|---|---|---|
| 想完成某事 | Я хочу прочитать эту книгу. | 我想读完这本书。 |
| 决定做成某事 | Мы решили обсудить этот вопрос. | 我们决定讨论这个问题。 |
| 请求对方做完某事 | Он попросил меня написать письмо. | 他请我写一封信。 |
| 能否完成 | Я не могу решить эту задачу. | 我解不出这道题。 |

## 5. 动词的式

动词的式表示说话人对行为与现实关系的态度。俄语主要有陈述式、命令式和假定式。 ^kp-06-5-12

| 式 | 基本意义 | 示例 |
|---|---|---|
| 陈述式 | 陈述现实中的行为或状态 | Он читает. Он читал. Он будет читать. |
| 命令式 | 命令、请求、建议、劝告 | Читай! Напишите! Давайте пойдём! |
| 假定式 | 设想、愿望、条件、非现实行为 | Я бы пошёл. Если бы он пришёл... |

### 5.1 第二人称命令式

| 构成 | 示例 |
|---|---|
| 动词现在时词干 + -и | говори；пиши |
| 动词现在时词干 + -й | читай；делай |
| 复数或礼貌形式加 -те | говорите；читайте；напишите |

第二人称命令式的基本构成方法是：去掉复数第三人称变位词尾 `-ют / -ут / -ят / -ат`，根据词干和重音加 `-й`、`-и` 或软音符号；复数或礼貌形式在单数命令式后加 `-те`。

| 构成类型 | 条件 | 示例 |
|---|---|---|
| -й / -йте | 复数第三人称词尾前为元音 | читать → читают → читай / читайте |
| -й / -йте | 复数第三人称词尾前为元音 | рисовать → рисуют → рисуй / рисуйте |
| -й / -йте | 复数第三人称词尾前为元音 | стоять → стоят → стой / стойте |
| -й / -йте | 完成体同样适用 | спеть → споют → спой / спойте |
| -ся / -тесь | 带 -ся 动词 | заниматься → занимаются → занимайся / занимайтесь |
| -ся / -тесь | 带 -ся 动词 | собираться → собираются → собирайся / собирайтесь |
| -ся / -тесь | 带 -ся 动词 | бояться → боятся → бойся / бойтесь |

当复数第三人称词尾前为辅音，且单数第一人称重音在词尾时，命令式常加 `-и / -ите`：

| 不定式 | 复数第三人称 | 第一人称单数 | 命令式 |
|---|---|---|---|
| повторить | повторят | повторю | повтори / повторите |
| молчать | молчат | молчу | молчи / молчите |
| брать | берут | беру | бери / берите |
| говорить | говорят | говорю | говори / говорите |
| писать | пишут | пишу | пиши / пишите |

有些命令式以软音符号结尾：

| 不定式 | 命令式 |
|---|---|
| встать | встань / встаньте |
| сесть | сядь / сядьте |
| бросить | брось / бросьте |
| отрезать | отрежь / отрежьте |

| 用法 | 示例 | 中文释义 |
|---|---|---|
| 请求或命令 | Откройте окно. | 请打开窗。 |
| 建议做具体行为 | Позвоните ему. | 请给他打电话。 |
| 继续某动作 | Говорите, все вас слушают. | 说吧，大家都在听。 |
| 否定请求 | Не открывайте окно. | 别开窗。 |
| 警告避免结果 | Смотри не упади! | 当心别摔倒！ |

完成体命令式通常要求对方完成某一具体行为；未完成体命令式可表示继续做、一般请求、方式要求或否定禁止。

#### 5.1.1 命令式构成细则

| 现在时词干特点 | 单数命令式 | 复数 / 礼貌形式 | 示例 |
|---|---|---|---|
| 词干末尾重音明显或需加 -и | -и | -ите | говори - говорите；пиши - пишите |
| 词干以元音结尾或保留 -й | -й | -йте | читай - читайте；делай - делайте |
| 以软音或辅音结尾 | 软音 / -ь | -ьте | встань - встаньте；сядь - сядьте |
| 带 -ся / -сь | 单数常用 -ся | 复数常用 -тесь | занимайся - занимайтесь |

#### 5.1.2 未完成体命令式和完成体命令式

| 情境 | 未完成体命令式 | 完成体命令式 |
|---|---|---|
| 要求开始或继续 | Читайте дальше. | Прочитайте этот текст. |
| 一般请求或邀请 | Заходите! Садитесь! | Войдите! Сядьте! |
| 禁止 | Не говорите! | Не скажите ему об этом. |
| 催促具体结果 | 写作、完成、提交等常用完成体 | Напишите ответ. |
| 要求行为方式 | 未完成体常表示“按这种方式做” | Говорите громче. |

否定命令中，未完成体常是直接禁止某行为；完成体否定命令常带“别不小心做成某事”的预防色彩：

| 未完成体 | 完成体 |
|---|---|
| Не открывай окно. 别开窗。 | Смотри, не открой окно. 当心别把窗开了。 |
| Не говори ему. 别告诉他。 | Не скажи ему случайно. 别不小心告诉他。 |

### 5.2 第一人称命令式

第一人称命令式表示说话人请求对方共同进行某种行为。

| 构成 | 示例 |
|---|---|
| давай / давайте + 不定式 | Давайте читать. |
| давай / давайте + 完成体复数第一人称 | Давайте прочитаем. |
| 完成体或未完成体复数第一人称 | Пойдём! Будем работать! |
| 否定形式 | Не будем спорить. |

идти、ехать 等定向运动动词的第一人称复数常直接表示号召：

| 形式 | 示例 | 中文释义 |
|---|---|---|
| пойдём | Пойдём домой! | 我们回家吧！ |
| поедем | Поедем на метро! | 我们坐地铁去吧！ |
| будем + 不定式 | Будем заниматься! | 我们学习吧！ |
| давайте + 完成体 | Давайте обсудим этот вопрос. | 咱们讨论一下这个问题。 |

### 5.3 第三人称命令式

第三人称命令式常用 пусть / пускай + 第三人称形式。

| 示例 | 中文释义 |
|---|---|
| Пусть он придёт завтра. | 让他明天来。 |
| Пускай дети играют. | 让孩子们玩吧。 |
| Да здравствует мир! | 世界和平万岁！ |

### 5.4 假定式

假定式由动词过去时形式加 бы 构成，没有人称和时间形式，但有性、数区别。

| 性/数 | 示例 |
|---|---|
| 阳性 | я бы пошёл |
| 阴性 | я бы пошла |
| 中性 | оно бы помогло |
| 复数 | мы бы пошли |

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 非现实条件 | Если бы он пришёл, мы бы поговорили. | 如果他来了，我们就谈谈。 |
| 委婉愿望 | Я хотел бы задать вопрос. | 我想提一个问题。 |
| 建议 | Вам бы отдохнуть. | 您该休息一下。 |
| 假设 | Приди я раньше, ничего бы не случилось. | 我要是早来，就不会出事。 |

假定式可以表示愿望、委婉请求、建议、非现实条件和假设结果：

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 愿望 | Я хотел бы поговорить с вами. | 我想和您谈谈。 |
| 委婉请求 | Не могли бы вы мне помочь? | 您能帮我一下吗？ |
| 建议 | Вам бы посоветоваться с врачом. | 您最好和医生商量一下。 |
| 非现实条件 | Если бы у меня было время, я бы поехал с вами. | 如果我有时间，我就和您一起去了。 |
| 与过去事实相反 | Если бы он пришёл раньше, мы бы всё успели. | 如果他早点来，我们就都来得及了。 |
| 假设结果 | Без вашей помощи я бы не справился. | 没有您的帮助，我就应付不了了。 |

第二人称命令式单数形式有时也可表示假定条件，相当于“如果……”：

| 俄语例句 | 中文释义 |
|---|---|
| Приди он раньше, всё было бы иначе. | 如果他早来，一切就会不同。 |
| Скажи ты мне об этом, я помог бы. | 你要是告诉我这件事，我就会帮忙。 |

## 难点六：未完成体第二人称命令式的用法

未完成体第二人称命令式不只是“命令别人做事”，它常表示经常性行为、开始行为、继续行为、行为方式和邀请。

### 1. 请求或建议对方经常进行某种行为

| 俄语例句 | 中文释义 |
|---|---|
| Пиши мне как можно чаще. | 你要尽可能常给我写信。 |
| Открывайте окна несколько раз в день: в комнате должен быть всегда чистый воздух. | 每天您要开几次窗，房间里永远需要新鲜空气。 |
| Принимайте это лекарство каждое утро. | 您每天早上要吃这个药。 |
| Пейте молоко каждый вечер. | 每天晚上您要喝牛奶。 |
| Ложитесь спать каждый вечер не позднее одиннадцати часов. | 每天晚上你们要不晚于十一点睡觉。 |

### 2. 督促对方开始某种行为

| 俄语例句 | 中文释义 |
|---|---|
| Вставай, тебе пора идти в школу. | 起床吧，你该上学去了。 |

| Чего вы ждёте? Продолжайте работать. | 您还等什么？继续工作。 |
| Говорите, все вас слушают. | 说吧，大家都在听着呢。 |

### 3. 继续某一中断的行为

| 俄语例句 | 中文释义 |
|---|---|
| Почему вы замолчали? Говорите! | 您怎么沉默起来了？说啊！ |
| Что же вы остановились, рассказывайте дальше. | 您怎么停下来了？接着讲。 |

### 4. 强调动作方式

| 俄语例句 | 中文释义 |
|---|---|
| Открывайте окно осторожнее: на улице сильный ветер. | 您要小心开窗，外面风大。 |

| Мой руки чище. | 把手洗干净些。 |
| Быстрее записывайте домашнее задание на завтра. | 赶快记下明天的家庭作业。 |
| Осторожнее переходите улицу. | 请小心过马路。 |

### 5. 用于邀请对方

| 俄语例句 | 中文释义 |
|---|---|
| Раздевайтесь. Проходите в комнату. | 请脱下外衣，往屋里走。 |
| Садитесь на диван. | 请坐到沙发上。 |
| Берите конфеты, сигареты. | 请拿糖果、香烟。 |
| Угощайтесь. | 请用；请随意吃。 |
| Кушайте на здоровье! | 请随意吃。 |

如果使用完成体命令式，语气往往变成要求某一具体动作完成：

| 完成体命令式 | 中文释义 |
|---|---|
| Встань сейчас же! Сколько можно лежать в постели! | 马上起床！还要在床上躺多长时间！ |

## 难点七：完成体第二人称命令式的用法

### 1. 请求、建议做某一具体行为，或强调行为结果

| 俄语例句 | 中文释义 |
|---|---|
| Проверьте, пожалуйста, мою работу. | 请检查我的作业。 |
| Напишите заявление и объясните причину перехода на другой факультет. | 请您写个申请，并说明转系的理由。 |
| Пожалуйста, посоветуйте мне, куда лучше поехать летом. | 请您给我个建议，夏天我最好去哪儿。 |

### 3. 否定完成体命令式表示提醒或警告

## 6. 及物动词和不及物动词

### 6.1 及物动词和不及物动词

^kp-06-6-1-14

| 类型 | 说明 | 示例 |
|---|---|---|

| 情况 | 示例 |
|---|---|
| 否定句中 | Я не читал этой книги. |
| 表示部分数量 | Выпить воды；купить хлеба |

及物动词被否定时，直接补语可用第二格：

| 俄语例句 | 中文释义 |

行为涉及部分客体时，补语也常用第二格：

| 俄语例句 | 中文释义 |

| Дайте мне, пожалуйста, масла, хлеба. | 请给我点儿黄油和面包。 |
| Мать послала своего сына купить сахару. | 母亲派儿子去买点儿糖。 |

不及物动词表示不及于客体的行为；它可以没有补语，也可以带前置词结构或间接格补语。

| 俄语例句 | 中文释义 |
|---|---|
| В настоящее время учёными всего мира создаются лекарства от СПИДа. | 目前全世界的科学家都在研制治疗艾滋病的药物。 |

| Я дорожу вашим хорошим отношением ко мне. | 我珍惜您对我的好态度。 |

### 6.2 反身动词

带 -ся / -сь 的动词称为反身动词。反身动词可表示反身、相互、被动、主体状态等意义。 ^kp-06-6-2-15

| 意义 | 示例 | 中文释义 |
|---|---|---|
| 真正反身 | мыться；одеваться；бриться | 洗澡；穿衣；刮脸 |
| 相互意义 | встречаться；здороваться；переписываться | 见面；互相问候；通信 |
| 被动意义 | Дом строится. | 房子正在建造。 |
| 主体状态或变化 | улыбаться；сердиться；радоваться | 微笑；生气；高兴 |
| 一般不及物化 | открываться；закрываться | 打开；关闭 |

反身动词的意义可再细分：

| 类型 | 示例 | 说明 |
|---|---|---|
| 自己对自己做 | умываться；одеваться | 行为回到主体自身 |
| 互相进行 | встречаться；переписываться | 多个主体彼此发生动作 |
| 主体状态 | радоваться；сердиться | 表示心理或状态变化 |
| 被动意义 | Дом строится. | 受事作主语 |
| 自动发生 | Дверь открывается. | 不突出施事 |
| 固定反身动词 | бояться；смеяться；гордиться | 不一定能还原为非反身形式 |

#### 6.2.4 一般反身意义

一般反身动词只表示主体本身的行为或状态，不直接及于任何客体。

| 类型 | 示例 | 中文释义 |
|---|---|---|
| 状态、位置、运动、变化 | подниматься；спускаться；останавливаться；изменяться | 上升；下降；停住；改变 |

| 情感状态 | радоваться；веселиться；печалиться；удивляться；сердиться | 高兴；愉快；悲伤；惊奇；生气 |

| 俄语例句 | 中文释义 |
|---|---|
| Мои часы часто останавливаются. | 我的表经常停。 |

| Дождь прекратился. | 雨停了。 |
| Занятия у нас в институте продолжаются пятьдесят минут. | 我们学院每节课五十分钟。 |
| Я успокоился только к вечеру. | 到傍晚我才平静下来。 |
| Не стоит обижаться на него. | 不要生他的气。 |
| Отец беспокоится о здоровье дочери. | 父亲为女儿的健康担忧。 |
| Я удивляюсь твоим словам. | 我对你的话感到奇怪。 |

有些带 `-ся` 与不带 `-ся` 的动词意义不同：

| 不带 -ся | 带 -ся |
|---|---|
| состоять [由……组成] | состояться [举行] |
| договорить [说完] | договориться [约定；达成协议] |

## 7. 无人称动词

无人称动词表示没有明确主语的状态、自然现象、身体感觉、心理状态或情态意义。由无人称动词构成的句子没有主语。 ^kp-06-7-16

无人称动词没有人称变化，现在时和将来时用第三人称单数，过去时用中性形式。例如：`рассветает`，`будет рассветать`，`рассвело`；完成体形式为 `рассветёт`。

| 类型 | 示例 | 中文释义 |
|---|---|---|
| 自然现象 | светает；темнеет；смеркается；морозит | 天亮；天黑；黄昏；严寒 |
| 天气变化 | холодает；теплеет；вечереет | 变冷；变暖；天晚 |
| 身体感觉 | меня тошнит；больного знобит；меня лихорадит | 我恶心；病人发冷；我发冷发热 |
| 心理或状态 | мне не спится；нам хорошо живётся；мне не работается | 我睡不着；我们过得很好；我工作不下去 |
| 情态意义 | мне хочется；ему следует；нам приходится；мне удалось | 我想；他应该；我们只好；我办到了 |
| 必要性 | надо；нужно；можно；нельзя | 应该；需要；可以；不可以 |

常见结构：

| 结构 | 示例 |
|---|---|
| 第三格主体 + хочется / следует / приходится | Мне хочется есть. Нам пришлось ночевать здесь. |
| 第三格主体 + 状态动词 | Преподавателю сегодня нездоровится. |
| 第四格主体 + тошнит / знобит / лихорадит | Меня тошнит. Больного знобило весь день. |
| 带前置词结构表示身体部位 | У меня болит в груди. |
| 第三格主体 + надо / нужно + 不定式 | Мне нужно работать. |
| 无主体自然现象 | Вечереет. Морозит. |

自然现象类无人称动词：

| 俄语例句 | 中文释义 |
|---|---|
| Уже светает. | 天已破晓。 |
| К осени всегда заметно начинает холодать. | 快到秋天时，天气明显开始冷起来。 |
| Зимой рано темнеет. | 冬季天黑得早。 |
| На дворе смеркается. | 外面天开始黑了。 |
| Вчера шёл дождь, а сегодня морозит. | 昨天下雨，今天上冻。 |

表示人的生理或心理状态：

| 俄语例句 | 中文释义 |
|---|---|
| Больного рвёт. | 病人呕吐。 |
| Меня тошнит от несвежей рыбы. | 我因为鱼不新鲜而感到恶心。 |
| Больного знобило весь день. | 病人一整天都感到发冷。 |
| Меня лихорадит. | 我直打冷战。 |
| У меня болит в груди. | 我感到胸疼。 |

主体用第三格的状态无人称动词：

| 俄语例句 | 中文释义 |
|---|---|
| Преподавателю сегодня нездоровится. | 老师今天不舒服。 |
| Нам хорошо живётся. | 我们过得很好。 |
| Нашему соседу не работается по выходным дням. | 我们的邻居休息日工作不下去。 |
| Пятилетней девочке не сидится на одном месте, ей нравится бегать, прыгать. | 五岁的小女孩在一个地方坐不住，她喜欢跑、跳。 |
| Мне не спится, хотя уже час ночи. | 我睡不着，尽管已经夜里一点了。 |
| Сегодня мне не гулялось: дома ждала интересная книга. | 今天我没有兴致游玩，因为家里有一本有趣的书等着我。 |

比较：

| 普通句 | 无人称句 |
|---|---|
| Я сегодня не работаю. | Мне сегодня не работается. |
| Ты не сидишь спокойно. | Тебе не сидится дома. |

хотеть 和 хотеться 的区别尤其常见：

| 结构 | 语感 | 示例 |
|---|---|---|
| Я хочу... | 主体明确地“想要” | Я хочу пить. |
| Мне хочется... | 愿望自然产生，语气较弱或较委婉 | Мне хочется пить. |
| Он не хочет работать. | 主体不愿意工作 | Он не хочет работать. |
| Ему не работается. | 没有工作状态，工作不下去 | Ему не работается. |
| Я хочу есть, потому что с утра ничего не ел. | 主体明确想吃 | Я хочу есть. |
| Мне хочется есть, хотя совсем недавно я пообедал. | 不由意志产生的愿望 | Мне хочется есть. |

## 8. 运动动词

俄语中有一组不带前缀的未完成体运动动词，分为定向动词和不定向动词。定向动词表示朝一个方向进行的运动；不定向动词表示多方向、往返、习惯性或能力。 ^kp-06-8-17

### 8.1 常见定向和不定向运动动词

| 定向 | 不定向 | 基本意义 |
|---|---|---|
| идти | ходить | 走 |
| ехать | ездить | 乘车去 |
| бежать | бегать | 跑 |
| лететь | летать | 飞 |
| плыть | плавать | 游；航行 |
| нести | носить | 拿着走 |
| вести | водить | 带领；驾驶 |
| везти | возить | 载运 |
| гнать | гонять | 赶；驱赶 |
| лезть | лазить | 爬 |
| ползти | ползать | 爬行 |

更多常见成对运动动词：

| 定向 | 不定向 | 基本意义 |
|---|---|---|
| брести | бродить | 缓慢走；徘徊 |
| катить | катать | 滚动；推着走 |
| тащить | таскать | 拖；拉 |
| тащиться | таскаться | 拖着自己走；磨蹭 |
| вести | водить | 带领；驾驶 |
| везти | возить | 运送；载 |

### 8.2 定向和不定向的主要区别

| 用法 | 定向动词 | 不定向动词 |
|---|---|---|
| 当前朝一个方向运动 | Он идёт в университет. |  |
| 经常性或习惯性 |  | Он ходит в университет пешком. |
| 往返行为 |  | Вчера он ездил в Москву. |
| 能力或方式 |  | Он хорошо плавает. |
| 作为背景动作 | Когда я ехал в Пекин, я познакомился с ним. | Когда я ездил в Пекин, я познакомился с ним. |

### 8.2.1 有一定方向的具体运动 / 无一定方向的运动

| 定向动词 | 中文释义 |
|---|---|
| Гид ведёт туристов к памятнику. | 导游领着旅游者向纪念碑走去。 |
| Он несёт костюм в химчистку. | 他拿着衣服去干洗店。 |
| Отец везёт детей в школу на машине. | 父亲开车送孩子们去学校。 |
| Я иду к товарищу узнать, как он себя чувствует. | 我去找同学问问他感觉怎样。 |
| Папа летит за границу. | 爸爸要飞往国外。 |

| 不定向动词 | 中文释义 |
|---|---|
| Почему он без конца ходит по комнате? | 为什么他没完没了地在房间里走来走去？ |
| Птицы летают в небе. | 鸟儿在天空中飞着。 |
| Дети, перестаньте бегать по коридору! | 孩子们，别在走廊里乱跑了！ |
| Дети купаются и плавают около берега. | 孩子们在岸边洗澡、游泳。 |
| Мать носила больного ребёнка на руках всю ночь. | 母亲抱着生病的孩子抱了一整夜。 |

> [!note]
> 表示过去或现在从来没有的行为时，用不定向动词：`Почему он не ездит в отпуск с женой?`

### 8.2.2 作为另一行为的时间背景

定向动词过去时可表示主体在过去某一时刻正在进行的、有方向的运动，作为另一行为的时间背景。不定向动词过去时也可作时间背景，但意义更宽。

| 俄语例句 | 中文释义 | 说明 |
|---|---|---|
| Мы познакомились, когда я ехал в Пекин. | 我们是在我去北京的时候认识的。 | 指在去北京的路上认识 |
| Мы познакомились, когда я ездил в Пекин. | 我们是在我去北京期间认识的。 | 可能在去路、回路或停留期间 |

### 8.2.3 经常性运动

不定向动词表示经常性动作；定向动词也可表示经常性动作，但往往带有固定时间或具体方向。

| 不定向动词 | 中文释义 |
|---|---|
| Я живу недалеко от работы и поэтому хожу туда пешком. | 我的住处离单位不远，所以步行上班。 |
| На чём вы ездите в университет? | 您坐什么车去学校？ |
| Каждое утро он бегает за газетами в киоск. | 每天早晨他去报亭买报纸。 |
| Олег каждый день водит Катю гулять в парк. | 奥列格每天领卡佳去公园散步。 |
| В Копенгаген самолёты летают по вторникам и четвергам. | 飞往哥本哈根的飞机每周二和周四有航班。 |

| 定向动词 | 中文释义 |
|---|---|
| В семь часов утра отец едет на велосипеде на работу. | 早晨七点父亲骑自行车去上班。 |
| Каждый день, когда я еду на работу, встречаю эту девушку. | 每天我去上班的时候都会遇到这位姑娘。 |
| Каждое утро он встаёт в 7 часов, умывается, одевается, завтракает и идёт на работу. | 他每天早晨七点起床、洗脸、穿衣、吃饭，然后去上班。 |
| Осенью перелётные птицы летят на юг. | 秋天候鸟飞往南方。 |

### 8.2.4 一次往返、能力和将来运动

| 用法 | 例句 | 中文释义 |
|---|---|---|
| 一次往返用不定向 | Вы куда-нибудь ходили на прошлой неделе? | 您上周去哪里了吗？ |
| 一次往返用不定向 | Вчера он ходил к зубному врачу. | 昨天他去看了牙医。 |
| 一次往返用不定向 | Летом мои друзья ездили на юг. | 夏天我的朋友们去了南方。 |
| 能力或属性用不定向 | Ребёнку только восемь месяцев, и он ещё не умеет ходить. | 孩子只有八个月，还不会走路。 |
| 能力或活动用不定向 | Хочу научиться плавать под водой с открытыми глазами. | 我想学会在水下睁着眼睛游泳。 |
| 能力或活动用不定向 | Опытный водитель превосходно водит машину. | 有经验的司机车开得很棒。 |
| 定向复合将来时表示运动过程 | Когда я буду идти домой, я постараюсь зайти на почту. | 回家时我要争取顺便去邮局。 |
| 不定向复合将来时表示反复运动 | В следующем месяце я буду часто ездить в командировки. | 下个月我要经常出差。 |

几个高频判断：

| 你想表达 | 选哪类 | 示例 |
|---|---|---|
| 正在朝一个目标去 | 定向 | Я иду в магазин. |
| 去过并已回来 | 不定向 | Я ходил в магазин. |
| 经常去 | 不定向 | Он ходит в школу. |
| 会不会走、跑、游、开车 | 不定向 | Ребёнок уже ходит. |
| 路上发生另一件事 | 定向或不定向都可能，看是否强调单向路程 | Когда я ехал домой, я встретил друга. |

### 8.3 带前缀的运动动词

定向运动动词加前缀通常构成完成体；不定向运动动词加前缀通常构成未完成体。

| 前缀 | 完成体 | 未完成体 | 意义 |
|---|---|---|---|
| при- | прийти | приходить | 来到 |
| у- | уйти | уходить | 离开 |
| в- | войти | входить | 进入 |
| вы- | выйти | выходить | 走出 |

## 9. 形动词

形动词（причастие）是动词的一种特殊形式，用事物本身的行为或状态来说明该事物的特征，回答 **какой?**。形动词兼有动词和形容词的特征。 ^kp-06-9-18

形动词有体、时、及物性、反身性等动词特征；也有性、数、格变化，在句中和被说明的名词保持一致。

| 类型 | 构成 | 示例 |
|---|---|---|
| 主动现在形动词 | 未完成体现在时复数第三人称词干 + -ущ- / -ющ- / -ащ- / -ящ- | читающий；говорящий |
| 主动过去形动词 | 过去时阳性词干 + -вш- / -ш- | читавший；нёсший |
| 被动现在形动词 | 未完成体动词词干 + -ем- / -им- | читаемый；любимый |
| 被动过去形动词 | 完成体动词词干 + -нн- / -енн- / -т- | прочитанный；решённый；открытый |

形动词分类速查：

| 类型 | 主动 / 被动 | 时间 | 常见来源 |
|---|---|---|---|
| читающий | 主动 | 现在 | 未完成体 |
| читавший | 主动 | 过去 | 未完成体或完成体 |
| читаемый | 被动 | 现在 | 未完成体及物动词 |
| прочитанный | 被动 | 过去 | 多为完成体及物动词 |

### 9.0 形动词的动词特征和形容词特征

形动词兼有动词和形容词的特征：

| 特征来源 | 具体表现 |
|---|---|
| 动词特征 | 有体、时、及物 / 不及物、带 `-ся` / 不带 `-ся`，并保持原动词所要求的接格关系 |
| 形容词特征 | 有性、数、格变化，在句中与被说明的名词一致，可作定语或谓语 |
| 形态区分 | 主动形动词只有长尾形式；过去时被动形动词有长尾和短尾形式 |

### 9.1 主动形动词

主动形动词说明动作的发出者。

#### 9.1.1 现在时主动形动词

现在时主动形动词由未完成体动词构成：去掉复数第三人称词尾 `-ют / -ут / -ят / -ат`，加上 `-ющий / -ущий / -ящий / -ащий`。

| 复数第三人称词尾 | 形动词后缀 | 示例 |
|---|---|---|
| -ют | -ющий | читают → читающий |
| -ут | -ущий | пишут → пишущий |
| -ят | -ящий | говорят → говорящий |
| -ат | -ащий | молчат → молчащий |

| 动词不定式 | 复数第三人称 | 现在时主动形动词 | 中文释义 |
|---|---|---|---|
| читать | читают | читающий | 读 |
| рисовать | рисуют | рисующий | 画 |
| давать | дают | дающий | 给 |
| заниматься | занимаются | занимающийся | 学习；从事 |
| писать | пишут | пишущий | 写 |
| идти | идут | идущий | 走 |
| жить | живут | живущий | 生活 |
| искать | ищут | ищущий | 寻找 |
| говорить | говорят | говорящий | 说 |
| сидеть | сидят | сидящий | 坐 |
| спать | спят | спящий | 睡 |
| находиться | находятся | находящийся | 位于 |
| служить | служат | служащий | 服务 |
| молчать | молчат | молчащий | 沉默 |
| учиться | учатся | учащийся | 学习 |

带 `-ся` 的动词构成形动词时，在形动词词尾后加 `-ся`：

| 形动词短语 | 中文释义 |
|---|---|
| учащийся в Пекине друг | 在北京学习的朋友 |
| учащаяся в Пекине подруга | 在北京学习的女朋友 |
| учащиеся в Пекине друзья | 在北京学习的朋友们 |

现在时主动形动词的重音：

| 类型 | 示例 |
|---|---|
| 第一变位法：重音多与复数第三人称相同 | работать → работают → работающий；делать → делают → делающий |
| 第一变位法 | изучать → изучают → изучающий；плакать → плачут → плачущий |
| 第二变位法：重音多与不定式相同 | переводить → переводящий；смотреть → смотрящий |
| 第二变位法 | курить → курящий；просить → просящий；держать → держащий |

#### 9.1.2 过去时主动形动词

过去时主动形动词由完成体或未完成体动词的过去时阳性形式构成。过去时阳性以 `-л` 结尾时，去掉 `-л` 加 `-вший`；如果过去时阳性不以 `-л` 结尾，则加 `-ший`。

| 动词不定式 | 过去时阳性 | 过去时主动形动词 | 中文释义 |
|---|---|---|---|
| делать | делал | делавший | 做 |
| написать | написал | написавший | 写完 |
| выполнить | выполнил | выполнивший | 完成 |
| учиться | учился | учившийся | 学习 |
| принести | принёс | принёсший | 带来 |
| расти | рос | росший | 生长 |
| везти | вёз | вёзший | 运送 |
| помочь | помог | помогший | 帮助 |
| привыкнуть | привык | привыкший | 习惯 |
| спасти | спас | спасший | 救 |
| исчезнуть | исчез | исчезший | 消失 |

带 `-ся` 的动词所构成的过去时主动形动词结尾也加 `-ся`：

| 形动词短语 | 中文释义 |
|---|---|
| занимавшийся в аудитории студент | 在教室学习过的学生 |

| 俄语 | 中文 |
|---|---|
| студент, читающий книгу | 正在读书的学生 |
| человек, говоривший с вами | 曾和您说话的人 |

| 形动词短语 | который 从句 |

#### 9.2.3 被动形动词的用法

被动形动词通过事物直接承受的行为来表示该事物的特征，意思是“被……的”“已经被……的”。它与被说明词在性、数、格上一致，行为主体常用第五格表示。

| 俄语例句 | 中文释义 |
|---|---|
| Студентам очень нравится язык, изучаемый ими в университете. | 大学生们很喜欢他们在大学学的语言。 |
| Его будет интересовать обсуждаемый вопрос. | 他会对正在讨论的问题感兴趣。 |
| Полученные нами результаты очень интересны. | 我们所得到的结果很有趣。 |
| Вещи, забытые пассажирами, передали в камеру хранения. | 旅客遗忘的物品已转到寄存处。 |

现在时被动形动词表示的动作特征与句中谓语动作同时：

| 俄语例句 | 中文释义 |
|---|---|
| В Москве есть старинные здания, охраняемые государством. | 莫斯科有国家保护的古老建筑。 |
| Мобильные телефоны, производимые фирмой «Нокиа», пользуются большой популярностью. | 诺基亚公司生产的手机很受欢迎。 |
| Из всех языков, изучаемых в университете, студенты часто выбирают английский язык. | 在大学所学语言中，学生常选择英语。 |
| Охрана окружающей среды - одна из важнейших задач, решаемых нашей страной. | 环境保护是我们国家正在解决的重要任务之一。 |

过去时被动形动词表示的动作在谓语动作之前实现，但结果仍存在：

| 俄语例句 | 中文释义 |
|---|---|
| Музыка, написанная композитором для нового фильма, всем очень понравилась. | 大家都非常喜欢作曲家为新影片创作的音乐。 |
| Спортсмен, встреченный мной, занял первое место в соревнованиях. | 我遇到的那个运动员在比赛中获得第一名。 |
| Я услышал песню, забытую мной давно. | 我听到了一首早已被我遗忘的歌曲。 |
| Экскурсия, организованная нашими спонсорами, была просто замечательной. | 我们赞助商组织的游览特别出色。 |
| Нельзя убивать животных, занесённых в «Красную книгу». | 不可捕杀已被列入《红皮书》的动物。 |
| На этом уроке будем разбирать ошибки, допущенные вами в письменных работах. | 今天课上我们分析你们笔头作业中的错误。 |

#### 9.2.4 被动形动词短语与 который 从句互换

位于被说明词后的被动形动词短语，常可改写为带 `который` 的限定从句。

| 被动形动词短语 | который 从句 |
|---|---|
| Приводимые нами примеры не случайны. | Примеры, которые мы приводим, не случайны. |
| Проблема, исследуемая автором, очень важна. | Проблема, которую исследует автор, очень важна. |
| Полученные им оценки были ниже среднего уровня. | Оценки, которые он получил, были ниже среднего уровня. |
| Это игрушки, сделанные из бумаги. | Это игрушки, которые сделали из бумаги. |

#### 9.2.5 被动过去形动词构成提示

| 不定式 | 被动过去形动词 | 短尾形式 |
|---|---|---|
| написать | написанный | написан，написана，написано，написаны |
| прочитать | прочитанный | прочитан，прочитана，прочитано，прочитаны |
| решить | решённый | решён，решена，решено，решены |
| открыть | открытый | открыт，открыта，открыто，открыты |
| взять | взятый | взят，взята，взято，взяты |

短尾被动形动词更像谓语，强调“结果状态”；长尾被动形动词更像定语，修饰名词。

## 难点八：被动形动词短尾的重音特点

### 1. 短尾阳性后缀无重音时

如果短尾阳性形式的后缀无重音，其他形式的重音一般也不在词尾。

| 长尾被动形动词 | 短尾形式 | 中文释义 |
|---|---|---|
| написанный | написан，написана，написано，написаны | 写好的 |
| выполненный | выполнен，выполнена，выполнено，выполнены | 完成的 |
| потерянный | потерян，потеряна，потеряно，потеряны | 丢失的 |
| прочитанный | прочитан，прочитана，прочитано，прочитаны | 读完的 |

### 2. -ённый 类短尾形式

这类形动词的短尾形式中，阴性、中性、复数常要特别注意重音位置。

| 长尾被动形动词 | 短尾形式 | 中文释义 |
|---|---|---|
| освобождённый | освобождён，освобождена，освобождено，освобождены | 解放的；释放的 |
| решённый | решён，решена，решено，решены | 解决的 |
| окружённый | окружён，окружена，окружено，окружены | 包围的 |
| приглашённый | приглашён，приглашена，приглашено，приглашены | 被邀请的 |
| принесённый | принесён，принесена，принесено，принесены | 带来的 |
| превращённый | превращён，превращена，превращено，превращены | 被变成的 |
| употреблённый | употреблён，употреблена，употреблено，употреблены | 被使用的 |

### 3. 与过去时重音相近的短尾形式

一些以 `-анный`、`-тый` 等结尾的形动词，其短尾形式的重音基本上与该动词过去时形式相同。

| 长尾被动形动词 | 短尾形式 | 对应过去时 |
|---|---|---|
| созданный | создан，создана，создано，созданы | создал，создала，создало，создали |
| взятый | взят，взята，взято，взяты | взял，взяла，взяло，взяли |
| принятый | принят，принята，принято，приняты | принял，приняла，приняло，приняли |

## 10. 副动词

副动词（деепричастие）是动词的一种特殊形式，表示附加动作，说明主要动作发生的方式、条件、时间、原因等。 ^kp-06-10-20

副动词不变化，通常和谓语动词的动作主体一致。

### 10.1 副动词的构成

^kp-06-10-1-21

副动词分为未完成体副动词和完成体副动词。

| 类型 | 构成 | 示例 |
|---|---|---|
| 未完成体副动词 | 现在时词干 + -а / -я | читая；говоря；сидя |
| 完成体副动词 | 过去时词干 + -в / -вши / -ши | прочитав；сделав；принеся |
| 反身动词副动词 | 加 -сь / -шись | улыбаясь；вернувшись |

#### 10.1.1 未完成体副动词

未完成体副动词由未完成体动词构成。方法是：去掉复数第三人称词尾，加后缀 `-я`；如果词干结尾为 `ж、ш、ч、щ` 等咝音，则多加 `-а`。

| 动词不定式 | 复数第三人称 | 副动词 | 说明 |
|---|---|---|---|
| говорить | говорят | говоря | 词干结尾非咝音，用 -я |
| читать | читают | читая | 词干结尾为元音，用 -я |
| жить | живут | живя | 词干结尾非咝音，用 -я |
| нести | несут | неся | 词干结尾非咝音，用 -я |
| встречаться | встречаются | встречаясь | 带 -ся，变为 -сь |
| лежать | лежат | лёжа | 词干结尾为咝音，用 -а |
| держать | держат | держа | 词干结尾为咝音，用 -а |
| дышать | дышат | дыша | 词干结尾为咝音，用 -а |
| учиться | учатся | учась | 带 -ся，变为 -сь |

带 `-ся` 的动词构成副动词时，`-ся` 改为 `-сь`：

| 不定式 | 副动词 |
|---|---|
| заниматься | занимаясь |
| волноваться | волнуясь |
| являться | являясь |
| бояться | боясь |

以 `-авать` 结尾的动词构成副动词时，去掉 `-ть`，加 `-я`：

| 不定式 | 副动词 | 中文释义 |
|---|---|---|
| давать | давая | 给 |
| создавать | создавая | 创造 |
| вставать | вставая | 起床；站起来 |
| узнавать | узнавая | 得知；认出 |
| признавать | признавая | 承认 |

未完成体副动词的重音：

| 情况 | 示例 |
|---|---|
| 动词变位重音不移动时，副动词重音多与复数第三人称相同 | гулять → гуляют → гуляя；рисовать → рисуют → рисуя |
| 同类例子 | спешить → спешат → спеша；смеяться → смеются → смеясь |
| 同类例子 | кричать → кричат → крича；вести → ведут → ведя |
| 特殊形式 | лежать → лежат → лёжа；сидеть → сидят → сидя |
| 特殊形式 | молчать → молчат → молча；стоять → стоят → стоя |
| 动词变位时重音移动时，副动词重音多在 -а / -я 上 | смотреть → смотрят → смотря；уходить → уходят → уходя |
| 同类例子 | искать → ищут → ища；шутить → шутят → шутя |
| 同类例子 | судить → судят → судя；находиться → находятся → находясь |

### 10.2 副动词的用法

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 同时发生的附加动作 | Он шёл, не оглядываясь. | 他走着，没有回头。 |
| 先于主要动作完成 | Прочитав письмо, она улыбнулась. | 读完信后，她笑了。 |
| 表示方式 | Он отвечал, улыбаясь. | 他微笑着回答。 |
| 表示原因或条件 | Не зная адреса, я не мог написать. | 不知道地址，我没法写信。 |

使用副动词时要注意：副动词表示的附加动作和谓语动作应属于同一个主体。

常见错误是副动词主体悬空。判断时可以问：副动词动作是谁做的？谓语动作又是谁做的？如果不是同一主体，就要改成从句。

| 不推荐 | 推荐 |
|---|---|
| Подходя к дому, у меня упала книга. | Когда я подходил к дому, у меня упала книга. |
| Прочитав письмо, мне стало грустно. | Когда я прочитал письмо, мне стало грустно. |

## 11. 动词难点速查

### 11.1 体的选择

| 问题 | 优先考虑 | 示例 |
|---|---|---|
| 是否强调结果？ | 强调结果用完成体 | Я написал письмо. |
| 是否强调过程、持续、重复？ | 用未完成体 | Я писал письмо весь вечер. |
| 是否问“做没做过”？ | 多用未完成体 | Ты читал эту книгу? |
| 是否问“做完没做完”？ | 用完成体 | Ты прочитал эту книгу? |
| 否定命令 | 多用未完成体 | Не открывай окно. |

### 11.2 运动动词选择

| 问题 | 选择 |
|---|---|
| 正在朝一个方向去吗？ | 定向动词：идти，ехать |
| 往返、习惯、能力吗？ | 不定向动词：ходить，ездить |
| 加前缀表示来到、离开、进入、走出吗？ | 通常形成体的配对：прийти / приходить |
| 表示“不要去某地”吗？ | 常用不定向否定命令：Не ходите туда. |

### 11.3 形动词和副动词

| 形式 | 作用 | 重点 |
|---|---|---|
| 形动词 | 像形容词一样修饰名词 | 和被修饰名词保持性、数、格一致 |
| 短尾被动形动词 | 作谓语，表示结果状态 | Письмо написано. |
| 副动词 | 表示附加动作 | 主体必须和谓语主体一致 |

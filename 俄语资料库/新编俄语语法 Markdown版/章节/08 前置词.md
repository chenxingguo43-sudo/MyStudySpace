前置词（предлог）是虚词的一种，没有形态变化，用以表示名词、代词、数词与句中其他词之间的语法联系和各种意义关系。

就其形式而言，简单前置词是由一个词构成的前置词，如 без，с，к，по，из，за 等；合成前置词是由两个或三个词构成的前置词，如 во время，в отличие от，в целях 等。前置词可表达时间、空间、原因、客体、行为方式、目的等意义关系。

前置词与名词、代词、数词等构成的前置词短语可以说明名词、代词、数词、动词、副词等。例如：

| 前置词短语 | 中文释义 |
|---|---|
| играть на рояле | 弹钢琴 |
| похожий на отца | 像父亲 |
| плата за лишний вес | 超重费 |
| смеяться над другими | 嘲笑别人 |
| недалеко от университета | 离大学不远 |
| относиться к учёбе | 对待学习 |
| письмо от восьмого сентября | 9 月 8 日的信 |

## 1. 前置词的意义和语法特征

### 支配格总览

| 支配格 | 常用前置词 |
|---|---|
| 第二格 | без，для，до，из，от，у，около，после，кроме，вокруг，вместо，вдоль，вне，вблизи |
| 第三格 | к，по，благодаря，вопреки，согласно，навстречу |
| 第四格 | в，на，за，через，про，сквозь |
| 第五格 | с，за，под，над，перед，между |
| 第六格 | в，на，о / об / обо，при |

同一个前置词可支配不同格，并表示不同意义：

| 前置词 | 支配格 | 常见意义 | 示例 |
|---|---|---|---|
| в | 第四格 | 方向：到……里 | идти в школу |
| в | 第六格 | 位置：在……里 | учиться в школе |
| на | 第四格 | 方向：到……上/去…… | идти на лекцию |
| на | 第六格 | 位置：在……上/在……活动中 | быть на лекции |
| с | 第二格 | 从……下来；从……起 | вернуться с работы |
| с | 第五格 | 和……一起；带有 | говорить с другом |
| за | 第四格 | 到……后面；为了；在……期间 | сесть за стол；бороться за мир |
| за | 第五格 | 在……后面 | за домом |

## 2. 常用前置词的意义和用法

### 要求第二格的前置词

| 前置词 | 意义 | 示例 |
|---|---|---|
| **из** | 1. 从（往……里去的反方向），表示方向、来源 | выйти из дома [从家里出来]；позвонить из школы [从学校打来电话]；приехать из России [从俄罗斯来] |
| | 2. 由于，因为 | из осторожности [由于小心谨慎]；из любви к искусству [由于对艺术的热爱]；слушать из вежливости [出于礼貌听] |
| | 3. 制成物品的材料 | построить дом из камня [用石头盖房子]；обед из пяти блюд [五道菜的午餐]；платок из шёлка [丝绸手帕] |
| | 4. 整体中的部分 | один из красивейших городов [最美的一个城市之一]；многие из студентов [许多学生] |
| **с** | 1. 从……（往……上面/外面去的反方向） | взять книгу со стола [把书从桌上拿起来]；прийти с улицы [从街上回来] |
| | 2. 从……时候起 | работать с восьми утра [从早上 8 点开始工作]；с утра до вечера [从早到晚] |
| | 3. 因为，由于 | умереть с голоду [饿死] |
| | 4. 受动词支配 | брать пример с него [以他为榜样] |
| **от** | 1. 离开（地点、距离） | отойти от окна [离开窗户]；в двадцати километрах от города [距离城市 20 公里的地方]；от Харбина до Пекина [从哈尔滨到北京] |
| | 2. 来自……（某人） | получить письмо от родителей [收到父母的信]；услышать от друга [从朋友处听到] |
| | 3. 文件、书信的日期 | письмо от третьего марта [3 月 3 日的信] |
| | 4. 由于，因为 | петь от радости [因高兴而唱歌]；плакать от волнения [由于激动而哭]；мокрый от дождя [由于下雨而潮湿] |
| | 5. 避免，防备 | лекарство от гриппа [治感冒的药]；таблетка от головной боли [头痛药片] |
| | 6. 与 далеко，справа，слева，вблизи 等副词连用 | недалеко от деревни [离村子不远]；слева от кровати [在床的左侧]；вблизи от города [在城市附近] |
| **до** | 1. 在……以前 | до звонка [在打铃以前]；за полчаса до собрания [开会前半小时] |
| | 2. 直到（某时） | работать до глубокой ночи [工作到深夜]；жить до девяноста лет [活到 90 岁] |
| | 3. （从……）到 | от Москвы до Санкт-Петербурга [从莫斯科到圣彼得堡] |
| | 4. 到（某种程度） | смеяться до слёз [笑出眼泪] |
| **для** | 1. 为了（指出目的或用途） | книга для детей [儿童读物]；остановиться для отдыха [停下来休息] |
| | 2. 对……来说 | вредно для здоровья [对身体有害]；трудная для ученика задача [对学生来说很难的题] |
| **без** | 1. 没有，无，不带 | девушка без очков [不戴眼镜的姑娘]；чай без сахара [不放糖的茶] |
| | 2. 表行为是怎么发生的 | писать без ошибок [写得没有错误]；слушать без интереса [听得枯燥乏味]；перевести без словаря [翻译不用词典] |
| | 3. 表时间 | без пяти десять [差 5 分 10 点]；без четверти восемь [差一刻 8 点] |
| **у** | 1. 在……近旁，附近 | стоять у окна [站在窗户跟前]；встретиться у входа в театр [在剧院入口处见面] |
| | 2. 在……（某人）那儿 | быть в гостях у друга [在朋友那里作客]；жить у родителей [住在父母那里] |
| | 3. 某人有 | У меня есть эта книга. [我有这本书。] |
| | 4. 从……那里，自 | узнать у товарища [从同学那里得知]；взять книгу у друга [从朋友那里借书] |
| **после** | 在……以后 | после обеда [午饭后]；после пяти часов [5 点后] |
| **около** | 1. 在……附近 | около сада [在花园附近]；около нашего университета [在我们大学附近] |
| | 2. 大约，左右 | около семи часов вечера [晚上 7 点左右]；около двух лет [大约两年] |
| **вокруг** | 在……周围，围绕 | ходить вокруг дома [绕着房子走]；сидеть вокруг стола [围桌而坐] |
| **из-за** | 1. 从……后面（出来） | встать из-за стола [从桌旁站起来]；приехать из-за границы [从国外来] |
| | 2. 由于，因为 | отсутствовать из-за болезни [因病缺席]；поссориться из-за пустяков [为小事吵嘴] |
| **накануне** | 在……前夕，在……前 | накануне Нового года [新年前夜]；накануне экзамена [考试前夜] |
| **во время** | 在……时候 | во время обеда [吃午饭时]；во время работы [工作时] |
| **в течение** | 在……期间 | в течение трёх дней [三天之内]；в течение многих лет [很多年以来] |
| **во имя** | 为了 | во имя дружбы [为了友谊]；бороться во имя мира [为和平而斗争] |
| **от имени** | 代表，以……的名义 | от имени народа [代表人民]；от имени всех [代表大家] |
| **посреди** | 在……当中，中央 | стоять посреди комнаты [站在房间中央]；посреди разговора [在谈话中间] |
| **среди** | 在……当中（与表时间和处所名词连用） | среди комнаты [站在房间中央]；проснуться среди ночи [半夜里醒来]；среди белого дня [光天化日之下]；среди этих книг [在这些书籍之间]；сидеть среди товарищей [坐在同志们中间] |
| **при помощи** | 在……帮助下，借助，利用 | при помощи товарищей [在同学们的帮助下]；с помощью словаря [借助词典] |
| **со стороны** | 1. 从……方面 | со стороны леса [从森林那边] |
| | 2. 表示亲属关系 | дядя со стороны матери [母亲方面的叔叔] |
| **по причине** | 由于，因为 | по причине слабого здоровья [由于健康欠佳] |
| **по поводу** | 由于，因为 | устроить вечеринку по поводу окончания экзаменов [为考试结束举办晚会] |
| **помимо** | 除了，除了……以外 | помимо своих детей [除了自己的孩子] |
| **кроме** | 1. 除……之外（不包括） | Кроме Нади, все пришли. [除了娜佳，大家都来了。] |
| | 2. 除……之外（还包括） | Кроме книг, в библиотеке много журналов и газет. [除了书，图书馆还有很多杂志和报纸。] |
| **вдоль** | 沿着（直线、长条形的） | вдоль реки [沿着河流]；вдоль дороги [沿着道路] |
| **вместо** | 代替，不是……而是 | выпить воды вместо чая [以水代茶]；вместо брата [代替兄弟] |
| **вне** | 在……以外，超出 | вне города [在城外]；вне плана [超出计划]；вне ответственности [脱离责任] |
| **внутри** | 在……内部 | внутри дома [房子里]；внутри человеческого тела [人体内部] |
| **во главе** | 在……前面，率领着，领导着 | во главе делегации [率领代表团] |
| **возле** | 在……附近 | стоять возле стола [站在桌旁] |
| **вблизи** | 在……附近（通常与较大面积物体连用） | вблизи нашего дома [我们家附近]；вблизи города [在城市附近] |
| **в отличие** | 与……不同 | в отличие от брата [与兄弟不同]；в отличие от русского языка [与俄语不同] |
| **впереди** | 在……之前 | идти впереди всех [走在大家前面] |
| **в результате** | 由于……（书面语） | в результате успешных переговоров [由于谈判顺利] |
| **в силу** | 由于……（书面语） | в силу сложившихся обстоятельств [由于当时情况] |
| **вследствие** | 由于……（书面语） | вследствие дождя [因为下雨]；вследствие болезни [由于生病] |
| **в случае** | 如果……，在……情况下 | в случае надобности [如果有必要]；в случае необходимости [必要时] |
| **против** | 1. 对着，正对着 | дом против почты [邮局对面的房子] |
| | 2. 反对 | выступать против докладчика [发言反对报告人] |
| | 3. 治…… | лекарство против кашля [咳嗽药] |
| **напротив** | 在……对面 | напротив дома [在房子对面] |

### 要求第三格的前置词

| 前置词 | 意义 | 示例 |
|---|---|---|
| **к** | 1. 朝，向，往 | идти к другу [去朋友处]；подойти к окну [走近窗户]；плыть к берегу [游向岸边] |
| | 2. 快到……时候 | к утру [快到早晨的时候]；к десяти часам [10 点前] |
| | 3. 与相应的动词或动名词连用（如 принадлежать，обращаться，относиться，привыкнуть 等） | подготовиться (подготовка) к экзамену [准备考试]；стремиться (стремление) к знаниям [渴求知识]；относиться (отношение) к русскому языку [对俄语的态度] |
| | 4. 与表情感的名词连用（如 любовь，ненависть，уважение，интерес，сочувствие 等） | любовь к Родине [爱祖国]；доверие к товарищам [对同志的信任]；интерес к математике [对数学的兴趣] |
| | 5. 与某些形容词连用（如 готовый，привычный，строгий，равнодушный，способный，внимательный 等） | готовый к экзаменам [准备好参加考试]；строгий к себе [严格要求自己的]；способный к музыке [有音乐才能的] |
| **по** | 1. 沿着（……表面），在……上面 | идти по улице [沿街走]；гулять по берегу [沿河边散步] |
| | 2. 每逢（与复数形式连用） | отдыхать по субботам [每周六休息]；работать по ночам [每天夜里工作] |
| | 3. 在……范围内 | путешествовать по всей стране [周游全国] |
| | 4. 因为，由于 | отсутствовать по болезни [因病缺席]；ошибиться по рассеянности [因为漫不经心而犯错误] |
| | 5. 按照，根据 | работать по плану [按计划工作]；приехать по приглашению [应邀而来] |
| | 6. 表活动的领域、职业、种类等 | чемпион по шахматам [象棋冠军]；учебник по русскому языку [俄语教科书]；экзамен по химии [化学考试] |
| | 7. 从……方面说 | по профессии врач [职业是医生]；добрый по характеру [性格和善的] |
| | 8. 指出均分客体 | дать детям по яблоку [给孩子们每人一个苹果] |
| | 9. 表示动作工具、方式 | послать по почте [邮寄]；смотреть футбол по телевизору [通过电视看足球]；говорить по телефону [通电话] |
| **благодаря** | 多亏，由于（多表示积极原因） | благодаря вашей помощи [多亏您的帮助] |
| **навстречу** | 迎面，迎着 | навстречу трудностям [迎着困难上]；выйти навстречу гостям [出来迎接客人] |
| **вопреки** | 与……相反，不顾 | вопреки желанию [违背愿望]；вопреки всем трудностям [不顾一切困难]；вопреки совету врача [不顾医生的劝告] |
| **согласно** | 根据，按照 | согласно закону [依法]；согласно вышеизложенному [据以上所述] |
| **вслед** | 跟着，随在……之后 | смотреть вслед поезду [目送着火车离去]；кричать вслед брату [在兄弟后面叫喊] |

### 要求第四格的前置词

| 前置词 | 意义 | 示例 |
|---|---|---|
| **в** | 1. 到……里面 | войти в комнату [走进屋里]；положить книгу в парту [把书放进课桌里]；поехать в Россию [去俄罗斯] |
| | 2. 表示进入某种状态 | прийти в ужас [大吃一惊]；привести кого-либо в восторг [使……兴高采烈] |
| | 3. 指出事物的外部特征、数量特征或方向 | мороз в двадцать градусов [零下 20 度严寒]；дом в два этажа [两层楼房]；мальчика в три года [3 岁男孩] |
| | 4. 在……时候 | вернуться в понедельник [周一返回]；встретиться в семь часов [7 点见面] |
| | 5. 表示倍数 | увеличиться в 3 раза [扩大两倍]；в два раза больше [多一倍] |
| **на** | 1. 向（到）……上面 | положить книгу на стол [把书放到桌上]；сесть на диван [坐到沙发上] |
| | 2. 去……，到…… | пойти на почту [去邮局]；вернуться на родину [回到故乡]；прийти на работу [来上班] |
| | 3. 指出动作与事物的数量或度量特征 | купить яблоки на 5 юаней [买五元钱的苹果]；обед на шесть человек [六个人吃的饭] |
| | 4. 表期限 | уехать на неделю [外出一周]；каникулы на месяц [一个月的假期] |
| | 5. 在……时候 | на третий день [第三天] |
| **за** | 1. 到（外面、后面） | отправиться за город [到郊外去]；уехать за границу [出国] |
| | 2. 由于，因为（指出奖惩理由及引起感情、心理状态的对象） | благодарить за помощь [感谢帮助]；наградить за отличную учёбу [因学习优秀而奖励]；беспокоиться за сына [为儿子担心] |
| | 3. 在……时间内 | закончить работу за месяц [一个月内完成工作]；приготовиться к экзаменам за неделю [一周内准备好考试] |
| | 4. 在……之前若干时间 | за день до отъезда [动身前一天]；за минуту до звонка [在打铃前一分钟] |
| | 5. 为，拥护，赞成 | за здравие матери [为母亲的健康干杯] |
| **через** | 1. （表示处所）经过，通过，越过 | мост через реку [跨河的桥]；перейти через улицу [过马路] |
| | 2. （表示时间）经过……以后 | вернуться через неделю [一周后回来]；прийти через полчаса [过半个小时来] |
| **сквозь** | 穿过，透过（表示从中穿过或透过某种障碍物） | пробираться сквозь толпу [挤过人群]；сквозь туман [透过雾]；проникнуть сквозь оконное стекло [穿过窗户玻璃] |
| **про** | （口语）关于（与表示言语、思想感觉的词连用） | говорить про друзей [谈论朋友们]；сказка про волка [狼的故事] |
| **под** | 在……前夕，接近 | под праздник [节日前夕]；под сорок лет [快 40 岁] |

### 要求第五格的前置词

| 前置词 | 意义 | 示例 |
|---|---|---|
| **с** | 1. 和，与，及 | гулять с дочерью [与女儿一起散步]；жить с родителями [和父母一起住] |
| | 2. 带有，附有 | квартира со всеми удобствами [设备齐全的住宅]；комната с балконом [有阳台的房间] |
| | 3. 带着，怀着 | ждать ответ с нетерпением [焦急地等待回信]；читать с интересом [兴致勃勃地读] |
| | 4. 随着 | Жизнь у нас с каждым днём улучшается. [我们的生活一天比一天好。] |
| **над** | 1. 在……上方 | висеть над столом [悬挂在桌子上空]；летать над озером [在湖面上飞] |
| | 2. 在……上面（从事某种活动，或表示支配、征服的对象） | сидеть над статьёй [写文章]；ломать голову над проектом [为方案伤脑筋]；смеяться над мальчиком [嘲笑小男孩]；победа над противником [战胜对手] |
| **под** | 1. 在……下面 | стоять под деревом [站在树下]；жить под нами [住在我们楼下]；лежать под одеялом [盖着被子躺着] |
| | 2. 在……附近 | играть под окном [在窗户旁玩]；жить под Шанхаем [住在上海附近] |
| **перед** | 1. 在……前面 | стоять перед учениками [站在学生面前]；сидеть передо мной [坐在我前面] |
| | 2. 在……之前 | перед отъездом [临走之前]；перед Новым годом [新年前] |
| **за** | 1. 在……后面，在……那边 | жить за рекой [住在河对岸]；стоять за дверью [站在门外] |
| | 2. 去取，去买，去请 | сходить в магазин за хлебом [去趟商店买面包]；послать человека за доктором [派人去请大夫] |
| | 3. 在……时候 | за ужином [吃晚饭时] |
| **между** | 1. （表空间或时间）在……之间 | между горой и рекой [在山和河之间]；между тремя и четырьмя часами [在三四点钟之间] |
| | 2. （表人与人之间的关系） | между товарищами [同志之间]；связь между странами [国家之间的关系]；дружба между народами Китая и России [中俄人民之间的友谊] |

### 要求第六格的前置词

| 前置词 | 意义 | 示例 |
|---|---|---|
| **о (об, обо)** | 关于（言语、思维、感觉的对象） | говорить о прошлом [谈往事]；заботиться о государственных делах [关心国家大事]；заявление о приёме в партию [入党申请书] |
| **в** | 1. 在……里面 | жить в городе [住在城市]；работать в университете [在大学工作] |
| | 2. 在……时候 | в седьмом часу [6 点多钟]；в детстве [童年时]；в начале октября [10 月初] |
| | 3. 表"处于某种状态" | в печали [忧愁]；в волнении [激动] |
| | 4. 穿着，戴着 | ходить в очках [戴着眼镜]；быть в чёрном платье [穿着黑色连衣裙] |
| | 5. 距离 | в двух шагах от меня [离我两步远]；в двадцати минутах ходьбы [步行 20 分钟] |
| **на** | 1. 在……上面 | сидеть на диване [坐在沙发上] |

| | 3. 表示交通工具 | ехать на велосипеде [骑自行车]；лететь на самолёте [乘飞机] |
| | 4. 与 собрание，спектакль，урок，концерт 等词连用，表示参加的活动 | на собрании [在会上]；на занятиях [在课堂上]；на вечере [在晚会上] |
| | 5. 在……时候 | на этой неделе [在这周]；на рассвете [黎明时分]；на ходу [行走时] |
| **при** | 1. 附属于，隶属于 | ресторан при гостинице [旅馆附设的餐厅]；при институте общежитие [学院附设宿舍] |
| | 2. 在……时候，当……时候 | встать при входе знакомого [熟人进来时站起来]；слушать музыку при выполнении домашнего задания [写作业时听音乐]；при Петре Первом [在彼得一世时] |

| **по** | 在……以后 | по окончании университета [大学毕业后]；по возвращении на Родину [返回祖国后]；по приезде в Китай [到中国以后] |

> [!note]
> 一些前置词与某些名词连用时，名词重音移至前置词上。例如：
> подняться на góру [上山]；за город [去城郊]；находиться за городом [在城郊]；оставить задание на дом [留家庭作业]；работать год от года [年复一年地工作]；выше на голову [高一头]；со дня на день [一天一天地]；с году на год [一年一年地]；час от часу [渐渐地]。

## 3. 表示空间意义的前置词辨析

### 3.1 前置词 в 和 на

**(1)** 都可与第六格的名词连用，回答 где? 的问题。в 的意思是"在……里面"，на 的意思是"在……上面"。试比较：

| в + 第六格 | на + 第六格 |
|---|---|
| лежать в парте [放在课桌里面] | лежать на парте [放在课桌上面] |

但并非所有与 на 连用的名词都表示"在……上面"。例如：

| 示例 | 中文释义 |
|---|---|
| на заводе | 在工厂 |
| на почте | 在邮局 |
| на Родине | 在家乡 |

有的名词可以和这两个前置词连用，但意义不同。试比较：

| в + 第六格 | на + 第六格 |
|---|---|
| в третьем уроке [在第三课中] | быть на уроке [在课堂上] |
| во дворе [在院子里] | на дворе [在户外] |
| в углу комнаты [在房间的角落里] | на углу дома [在房子的拐角处] |
| в море [在海里] | на море [在海面，在海滨] |
| быть в автобусе [在公共汽车里面] | на автобусе [乘坐公共汽车] |
| в руке [在手里] | на руке [在手臂上] |
| в постели [在被窝里] | на постели [在床上] |
| в работе [在工作中] | на работе [在上班] |

> [!note]
> кухня 与 в，на 连用的意义基本没有区别：готовить обед в / на кухне [在厨房做饭]。

**(2)** 都可与第四格的名词连用，回答 куда? 的问题。в 的意义是"向……里面"，на 的意义是"向……上面"。试比较：

| в + 第四格 | на + 第四格 |
|---|---|
| положить книгу в стол [把书放进桌子里面] | положить книгу на стол [把书放到桌子上面] |

与表示地理名称的名词连用时，в 表示的方向具体明确，而 на 只用于指方向。

| 俄语例句 | 中文释义 |
|---|---|
| Завтра я лечу в Берлин. | 我明天要飞往柏林。 |
| Скажите, пожалуйста, когда следующий самолёт на Берлин? | 请问，飞往柏林的下一班飞机是什么时间？ |

### 3.2 前置词 из，с，от

这三个前置词的意思都表示"从……"，与 в，на，к 构成对应关系：

| 去向（куда） | 来源（откуда） |
|---|---|
| в | из |
| на | с |
| к | от |

| 去向 | 来源 |
|---|---|
| Он пришёл в аудиторию. [他来到了教室。] | Он вышел из аудитории. [他走出了教室。] |
| Отец положил книгу на стол. [父亲把书放在了桌子上。] | Отец взял книгу со стола. [父亲从桌上拿起一本书。] |
| Студенты пошли на концерт. [大学生们去了音乐会。] | Студенты вернулись с концёрта. [大学生们已从音乐会回来。] |
| Мама подошла к окну. [妈妈走近窗子。] | Мама отошла от окна. [妈妈离开窗子。] |
| Мы ездили к нему вчера. [我们昨天去了他那里。] | Мы вернулись от него поздно. [我们从他那里回来得很晚。] |

前置词 от 与 до 在一起使用，表示"从……到……"。例如：

| 俄语例句 | 中文释义 |
|---|---|
| От зоопарка до вокзала идёт автобус номер 3. | 从动物园到火车站有 3 路公共汽车。 |
| Дорога от Олиного дома до кинотеатра занимает минут сорок. | 从奥利亚家到电影院大约需要 40 分钟左右的路程。 |
| Сколько времени вы идёте от дома до работы? | 从家到单位您步行多长时间？ |

### 3.3 前置词 у，около，возле，вблизи，вокруг

这些前置词都与第二格的名词连用，意思是"在……附近"。

| 前置词 | 含义和特点 | 示例 |
|---|---|---|
| **у** | 距离最近。"在……近旁"时只能与非动物名词连用；与动物名词连用时表示"谁有"或"在谁那儿" | сидеть у окна [坐在窗旁]；стоять у доски [站在黑板旁]；У всех студентов есть словарь. [所有大学生都有词典。]；быть в гостях у друга [在朋友那里作客] |
| **около** | "在……附近"、"在……近旁"，与之连用的名词可以是表人的，也可以是表物的 | около сада [在花园附近]；сидеть около постели [坐在床旁] |
| **вокруг** | "在……周围"、"在……四周" | посадить деревья вокруг дома [在房子周围栽树]；путешествие вокруг света [环球旅行] |
| **возле** | "在……侧旁"，强调侧面靠着近 | Он сидел возле меня. [他坐在我旁边。]；возле больного лежали газеты [病人旁边放着报纸] |
| **вблизи** | "离……不远"，通常与表示较大面积物体的名词连用 | вблизи нашего дома [我们家附近]；вблизи порта [离海港不远] |

### 3.4 前置词 внутри 和 в

前置词 в (чём) 和 внутри (чего) 都表示"在……里面"、"在……之内"。в 只是表示在某个地方，而 внутри 强调的是"在……内部"，与"在……外部"相对，通常与有空间容积的比较具体的名词连用。

| 示例 | 中文释义 |
|---|---|
| внутри страны | 在国内 |
| внутри города | 在城里 |
| внутри себя | 在内心 |
| внутри чемодана | 在箱子里 |

有时两者同义，可以互换。例如：

| в | внутри |
|---|---|
| В главном здании располагаются аудитории и лаборатории. | Внутри главного здания располагаются аудитории и лаборатории. |
| 主楼里面有教室和实验室。 | |

### 3.5 前置词 посреди，среди，между

| 前置词 | 含义 | 示例 |
|---|---|---|
| **посреди** | 强调"在……正中心"、"在中间"、"在……中央" | стол посреди комнаты [桌子在房间中央]；посреди пустынной улицы [在空荡荡的大街中央] |
| **среди** | "在中间"、"在……中心"，与动物名词及非动物名词都可连用 | среди комнаты [在房间中央]；вести работу среди молодёжи [在青年中进行工作]；среди студентов [大学生中] |
| **между** | "在两个以上的事物之间" | культурная связь между различными странами [各国之间的文化联系]；между домом №3 и домом №5 [在 3 号楼和 5 号楼之间] |

> [!note]
> 当表示在同类事物之间时，среди 和 между 有时可以互换。例如：
> Между этими людьми (среди этих людей) были и мои знакомые. [这些人中间也有我的熟人。]

### 3.6 前置词 впереди 和 перед

впереди (кого-чего) 和 перед (кем-чем) 都表示"在……前面"。当两者顺向运动时，用 впереди：

| 俄语例句 | 中文释义 |
|---|---|
| Он шёл впереди всех. | 他走在大家的前面。 |
| Впереди нас шли 4 человека. | 在我们前面走着四个人。 |

当表示面对面的"在……前面"意思时，要用 перед：

| 俄语例句 | 中文释义 |
|---|---|
| Передо мной бегает брат. | 弟弟在我面前跑来跑去。 |
| Учитель стоит перед учениками. | 老师站在学生们面前。 |
| Ель растёт перед дворцом. | 云杉树在宫殿前面。 |

### 3.7 前置词 позади 和 за

позади (кого-чего) 和 за (кем-чем) 都可表示"在……后面"。当两者顺向运动时，用 позади：

| 俄语例句 | 中文释义 |
|---|---|
| Позади старика шёл мальчик. | 一个小孩走在老人后面。 |
| Он сидит позади меня. | 他坐在我后面。 |

за 只是表示"在……后面"，不强调是否同向：

| 俄语例句 | 中文释义 |
|---|---|
| Идите за мной! | 请跟我走！ |
| Собака бежала за хозяином. | 狗紧跟在主人后面跑着。 |

за 还可以表示"在……那边"、"在……外边"：

| 俄语例句 | 中文释义 |
|---|---|
| За рекой построили многоэтажное здание. | 在河对岸建了一栋高层楼房。 |
| За дверью стоит незнакомый человек. | 门外站着一个陌生人。 |
| Она учится за границей. | 她在国外学习。 |

> [!note]
> 1. "运动动词 + за + 表人名词"结构表示"去找（请）……"的意思。例如：
> Мать пошла за врачом, потому что сын плохо себя чувствует. [儿子感觉不舒服，母亲去找医生了。]
>
> 2. 与非动物名词连用时，两个前置词都可使用。例如：
> Деревня находится позади горы (за горой). [村子坐落在山的那一边。]

### 3.8 前置词 через 和 сквозь

两个前置词都表示"穿过"、"越过"，都要求第四格。

**(1) через** 可以与动词或名词连用，表示"（横着或从上面）跨过，越过"：

| 示例 | 中文释义 |
|---|---|
| перейти через улицу | 过马路 |
| мост через реку | 跨河的桥 |
| пройти через лес | 穿过森林 |
| смотреть через очки | 透过眼镜看 |

**(2) сквозь** 表示"穿透"、"透过"，强调从中穿过或透过某种障碍物：

| 示例 | 中文释义 |
|---|---|
| пробираться сквозь толпу | 挤过人群 |
| сквозь туман | 透过雾 |
| проникнуть сквозь оконное стекло | 穿过窗户玻璃 |

сквозь 还可以表示"从……里（露出，显出，透出）"：

| 示例 | 中文释义 |
|---|---|
| смех сквозь слёзы | 破涕为笑 |
| говорить сквозь зубы | 从牙缝里挤出话 |
| услышать сквозь сон | 睡梦中听见 |

## 4. 表示时间意义的前置词辨析

### 4.1 前置词 в，за，на

与动词连用时，这三个前置词都表示"行为发生的某一时间段落"。

**(1)前置词 в 和 за**

в 强调完成某事"所用的时间量"，而不着重于在某段时间内做成的事；而 за 强调的是所完成的事，而不着意于所用去的时间量。

| 俄语例句 | 中文释义 |
|---|---|
| Хотя ему уже за 60 лет, но он научился ездить на велосипеде в два дня. | 尽管他已经 60 多岁了，但他两天内就学会了骑自行车。 |
| Он дал мне работу на три дня, а я сделал её в два дня. | 他给了我一项三天的工作，可是我两天内就完成了。 |
| Я прочитала эту книгу за один вечер. | 我一个晚上就读完了这本书。 |
| За какое время вы можете выучить китайский язык? | 您多长时间能学会汉语？ |

有时 за 和 в 可以互相替换，只是着眼点不同。例如：

| 俄语例句 | 中文释义 |
|---|---|
| За (в) ночь мы прошли около тридцати километров. | 我们一夜走了近 30 公里的路。 |
| Это можно сделать за (в) неделю. | 这项工作可以在一周内做完。 |

**(2) 前置词 на**

на 表示行为结束后其结果所形成的状态延续的时间。

| 俄语例句 | 中文释义 |
|---|---|
| Мне нужно включать компьютер на 2 часа. | 我需要开两个小时的电脑。 |
| Антона сейчас нет в Москве. Он уехал в командировку на три дня. | 安东现在没在莫斯科，他出差了，要去三天。 |
| Я лёг отдохнуть на час. | 我躺下休息了一个小时。 |
| Туристы приехали в Китай на две недели. | 旅游者来到了中国，要待两周。 |

### 4.2 前置词 до，к，перед，под

这几个前置词表示的是"在……之前"，有时可以互相替代。按"由远到近"的排序为：до → перед → к → под。

**(1)前置词 до**

до (чего) 可与名词或数词词组连用，表示在某时间点之前的任何时候，时间可近可远。

| 俄语例句 | 中文释义 |
|---|---|
| До поступления в школу ребёнок получает домашнее воспитание. | 上小学之前小孩子接受家庭教育。 |
| До Нового года нужно решить, где отмечать праздник. | 元旦前需要决定在哪儿庆祝节日。 |
| До полудня, как правило, бывает четыре урока. | 午前一般有四节课。 |
| До экзаменов студенты самостоятельно занимаются в библиотеке. | 考试前大学生们在图书馆自习。 |

до 还可以和其他一些前置词组合在一起使用：

| 组合 | 示例 |
|---|---|
| **от...до...** 从……到…… | от понедельника до среды [从周一到周三]；дети от семи до десяти лет [7 到 10 岁的孩子] |
| **с...до...** 从……到…… | с утра до вечера [从早到晚]；работать с 10 до 17 часов [从 10 点到 17 点工作] |
| **за...до...** 在……之前 | за 3 минуты до начала урока [课前三分钟]；за день до отъезда [动身前一天]；за пять минут до Нового года [元旦到来前的五分钟] |

**(2)前置词 к**

к (чему) 强调"快到……时"，可与数词词组及含有时间意义的名词连用。

| 示例 | 中文释义 |
|---|---|
| к пяти часам | 快到 5 点 |
| к первому мая | 临近五一 |
| к концу года | 年底前 |
| вернуться только к ужину | 快吃晚饭时才回来 |

**(3)前置词 перед**

перед (чем) 表示"……前不久"、"临……前"，它常与表动作、活动的名词及表节日的名词连用。

| 俄语例句 | 中文释义 |
|---|---|
| Мы собрались перед её днём рождения, чтобы обсудить подарки. | 在她生日之前我们聚在一起讨论礼物的事情。 |
| Перед Новым годом все покупают подарки для друзей и близких. | 元旦前大家都给亲朋好友买礼物。 |
| Не ешь сладкого перед едой. | 饭前别吃甜食。 |
| Перед уроком он несколько раз повторил новые слова. | 课前他又复习了几遍新词。 |

**(4)前置词 под**

под (что) 有"前夕"、"临近"的意义。在时间上比上面前置词更为靠近，与其搭配使用的名词非常有限，通常只与 утро，вечер，весна，зима，праздник，начало，конец，Новый год，выходной день 等表示时间段落的名词连用。

| 俄语例句 | 中文释义 |
|---|---|
| Она заболела как раз под Новый год. | 她恰好在新年前病了。 |
| Дождь пошёл под утро. | 快到早晨时下起雨来。 |
| Это случилось под вечер. | 这件事发生在傍晚的时候。 |
| Ей под сорок лет. | 她快 40 岁了。 |

### 4.3 前置词 после 和 по

после (чего) 和 по (чём) 都表示"在……之后"、"在……（结束）以后"。

与 по 搭配的名词有限，只能是表示行为或状态的名词，意思是一个行为在另一个行为结束之后马上发生，译为"在……之后就……"。

| 俄语例句 | 中文释义 |
|---|---|
| По приезде в Москву они сейчас же пошли на Красную площадь. | 他们一到莫斯科就马上去了红场。 |
| По возвращении в столицу он узнал о смерти брата. | 一回到首都，他就获悉了兄弟去世的消息。 |
| По окончании университета Сергей поступил в аспирантуру. | 大学一毕业谢尔盖就考上了研究生。 |

与 после 搭配的词很广，所表意义比 по 更为宽泛，它只是表达"在……之后"，而不强调"一个行为之后马上开始另一个行为"。

| 俄语例句 | 中文释义 |
|---|---|
| После сдачи экзаменов студенты уезжают домой на каникулы. | 考完试大学生们就要回家度假了。 |
| После дождя они вышли гулять. | 雨后他们出来散步。 |
| После Нового года наступают будни. | 新年过后又是平常的日子。 |

после 与 через 使用，表示"在……之后过了多长时间"：

| 俄语例句 | 中文释义 |
|---|---|
| Мы уехали из Москвы через неделю после окончания конференции. | 会议结束过了一周我们才离开莫斯科。 |
| Преподаватель вошёл в аудиторию через минуту после звонка. | 老师在铃响后一分钟走进教室。 |

### 4.4 前置词 через 和 спустя

这两个前置词接格关系都是第四格，都可以与一些表示时间意义的名词连用，表示"在……之后"。спустя 多用于书面语中，через 更常用于口语中。

| 示例 | 中文释义 |
|---|---|
| через (спустя) два года | 两年后 |
| через (спустя) некоторое время | 过了一段时间 |

## 5. 表示原因意义的前置词辨析

| 前置词结构 | 语体和意义 | 示例 |
|---|---|---|
| **из-за + 第二格** | 多表示不利原因 | из-за дождя [因为下雨]；из-за болезни [因为生病] |
| **от + 第二格** | 由于某种感觉、状态、自然原因 | дрожать от холoda [冻得发抖]；плакать от радости [高兴得哭] |
| **благодаря + 第三格** | 多表示积极原因 | благодаря помощи друзей [多亏朋友的帮助] |
| **по + 第三格** | 按照、由于某种原因或理由 | по ошибке [由于错误]；по болезни [因病] |
| **вследствие + 第二格** | 书面语，由于 | вследствие аварии [由于事故] |
| **в силу + 第二格** | 书面语，由于 | в силу обстоятельств [由于情况] |
| **в результате + 第二格** | 书面语，由于 | в результате переговоров [由于谈判] |
| **по причине + 第二格** | 由于，因为 | по причине плохой погоды [由于天气不好] |
| **по поводу + 第二格** | 由于，因为 | по поводу окончания экзаменов [因考试结束] |

语感对比：

| 结构 | 语感 |
|---|---|
| благодаря помощи | 因为帮助而产生好的结果 |
| из-за ошибки | 因为错误而产生不好的结果 |

## 6. 表示目的关系的前置词辨析

| 前置词结构 | 意义 | 示例 |
|---|---|---|
| **для + 第二格** | 为了；供……用 | книга для детей [儿童读物]；комната для занятий [教室] |
| **ради + 第二格** | 为了……，带牺牲或强调色彩 | ради мира [为了和平]；ради друга [为了朋友] |
| **за + 第五格** | 去取、去买、去请 | идти за хлебом [去买面包]；послать за врачом [派人去请大夫] |
| **на + 第四格** | 用于某目的、某期限或某活动 | деньги на поездку [旅行的钱]；пойти на лекцию [去听课] |
| **к + 第三格** | 为……做准备；到……时 | готовиться к экзамену [准备考试]；к праздниku [为节日] |
| **во имя + 第二格** | 为了（崇高目的，书面语） | во имя дружбы [为了友谊] |
| **в целях + 第二格** | 为了（书面语） | в целях улучшения работы [为了改进工作] |
| **с целью + 第二格** | 为了（书面语） | с целью изучения опыта [为了学习经验] |

目的结构对比：

| 结构 | 示例 | 中文释义 |
|---|---|---|
| для + 第二格 | подарок для матери | 给母亲的礼物 |
| за + 第五格 | идти за подарком | 去买/取礼物 |
| к + 第三格 | готовиться к экзамену | 准备考试 |
| на + 第四格 | деньги на билет | 买票的钱 |

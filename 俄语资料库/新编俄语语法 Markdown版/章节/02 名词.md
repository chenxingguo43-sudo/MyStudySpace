## 1. 名词概述

^kp-02-1-01

名词（имя существительное）是表示事物名称的词类，可以表示人、物体、物质、事实和现象等。

### 1.1 名词的词汇-语法类别

| 类别 | 含义 | 示例 |
|---|---|---|
| 专有名词 | 单独事物专用的名称，书写时通常用大写字母开头 | Пекин；Россия；«Феникс»；Олимпиада-2008 |
| 普通名词 | 某一类事物共有的名称 | школа；учитель；стол |
| 具体名词 | 表示具体的人、物或现象，通常可数 | мальчик；студент；стена |
| 抽象名词 | 表示思想、感情、性质、动作、状态等抽象概念 | боль；доброта；терпение；радость |
| 物质名词 | 表示物质或材料，一般不用复数，不能直接和数词连用 | вода；воздух；чай；золото；картофель |
| 集合名词 | 表示同类事物的总和，不能直接表示单个事物 | молодёжь；мебель；обувь；человечество；бельё |
| 动物名词 | 表示人或动物，回答 **кто?** | человек；студент；собака |
| 非动物名词 | 表示人和动物以外的事物，回答 **что?** | стена；окно；дождь |

> [!note] 动物名词和非动物名词的格
> 动物名词与非动物名词的主要语法差异体现在第四格：阳性动物名词以及所有复数动物名词的第四格同第二格；非动物名词的第四格同第一格。

## 2. 名词的性

^kp-02-2-02

俄语名词有阳性（мужской род）、阴性（женский род）、中性（средний род）之分。多数名词可以根据词尾判断性属。

### 2.1 变格名词的性

^kp-02-2-1-03

| 性 | 常见结尾 | 示例 |
|---|---|---|
| 阳性 | 辅音字母结尾 | город；студент；дом |
| 阳性 | **-й** 结尾 | музей；герой；Китай |
| 阳性 | **-ь** 结尾的一部分名词 | преподаватель；писатель；словарь |
| 阴性 | **-а** 结尾 | книга；комната；девушка |
| 阴性 | **-я** 结尾 | деревня；кухня；аудитория |
| 阴性 | **-ь** 结尾的一部分名词 | тетрадь；площадь；ночь |
| 中性 | **-о** 结尾 | слово；окно；письмо |
| 中性 | **-е / -ё** 结尾 | море；общежитие；бельё |
| 中性 | **-мя** 结尾 | имя；время；знамя |

> [!note]
> 以 **-а / -я** 结尾的名词如果表示男性，按阳性处理，如 папа、дедушка、юноша。дитя（小孩子）为中性名词。

人的姓名通常按自然性别判断性属。

| 性 | 示例 |
|---|---|
| 阳性 | Ваня；Серёжа；Алёша |
| 阴性 | Анна；Зоя；Лина |

以 **-ь** 结尾的名词需要结合词尾类型和意义判断性属。

| 类型 | 常见词尾或意义 | 示例 |
|---|---|---|
| 阳性 | **-тель** 结尾，多表示人 | учитель；читатель；слушатель |
| 阳性 | **-арь** 结尾的一部分名词 | словарь；календарь；фонарь |
| 阳性 | 月份名称 | январь；апрель；декабрь |
| 阴性 | **-ость** 结尾 | молодость；новость；радость |
| 阴性 | 嘶音字母后加 **-ь** 的一部分名词 | молодёжь；вещь；ночь；ложь |
| 阴性 | 表示抽象意义 | жизнь；любовь；помощь；болезнь |
| 阴性 | 集合名词 | молодёжь；мебель；обувь |

### 2.2 不变格名词的性

^kp-02-2-2-04

不变格外来词多数为中性。

| 类型 | 示例 |
|---|---|
| 多数外来不变格名词 | метро；такси；кино；меню；шоссе；фото；интервью；пари |
| 与定语连用 | красивое кино；моё пальто；интересное интервью |

当这类名词表示复数意义时，与它连用的定语和谓语通常用复数形式。

| 俄语例句 | 中文释义 |
|---|---|
| Ваши пальто висят в шкафу. | 你们的大衣挂在衣柜里。 |
| Появились новые красивые такси. | 出现了新的、漂亮的出租车。 |

> [!note]
> кофе 在传统语法中多按阳性处理：крепкий кофе。

表示新闻报刊、地理名称、语言等的外来词，通常根据它所对应的普通名词判断性属。

| 名称 | 判断依据 | 性 |
|---|---|---|
| Эри | озеро | 中性 |
| Тбилиси | город | 阳性 |
| Миссисипи | река | 阴性 |
| Нью Кроникл | газета | 阴性 |
| хинди | язык | 阳性 |

### 2.3 大写字母型缩写词的性

^kp-02-2-3-05

大写字母型缩写词的性通常根据全称中的中心词判断。

| 缩写词 | 全称中心词 | 性 |
|---|---|---|
| КНР | республика | 阴性 |
| РФ | федерация | 阴性 |
| ООН | организация | 阴性 |
| ВОЗ | организация | 阴性 |
| ВТО | организация | 阴性 |
| НАТО | организация | 阴性 |
| МОК | комитет | 阳性 |

> [!note]
> МИД（Министерство иностранных дел）传统上可按中性名词看待，在现代用法中也常作阳性名词使用。

### 2.4 共性名词和职业名词

^kp-02-2-4-06

俄语中有一些以 **-а / -я** 结尾、表示人的名词属于共性名词。它们可以根据所指对象用作阳性或阴性。

| 共性名词 | 中文 |
|---|---|
| умница | 聪明人 |
| сирота | 孤儿 |
| соня | 贪睡的人 |
| невежда | 无知的人 |
| пьяница | 酒鬼 |
| заика | 口吃的人 |

| 俄语例句 | 中文释义 |
|---|---|
| Этот мальчик — круглый сирота. | 这个男孩是个父母双亡的孤儿。 |
| Эта девочка — круглая сирота. | 这个女孩是个父母双亡的孤儿。 |
| Какой / какая же он умница! | 他真是个聪明人！ |

一些职业名词可用于男性和女性，但语法属性仍为阳性名词。

| 名词 | 中文 |
|---|---|
| врач | 医生 |
| инженер | 工程师 |
| профессор | 教授 |
| адвокат | 律师 |
| педагог | 教师；教育工作者 |

> [!note]
> 这类词表示女性时，名词本身仍常保持阳性语法属性；但谓语过去时等成分可能按自然性别协调。具体用法后续可在句法部分继续整理。

### 3.1 名词复数形式的构成

^kp-02-3-1-08

> [!summary]
> 名词复数主要通过词尾变化构成。判断时先看名词的性，再看单数词尾，最后注意拼写规则、重音变化和特殊复数。

#### 3.1.1 阳性名词的复数

多数阳性名词以辅音、**-й**、**-ь** 结尾，复数第一格常见词尾如下。

| 单数词尾 | 复数词尾 | 示例 |
|---|---|---|
| 硬辅音 | **-ы** | студент → студенты |
| **г, к, х, ж, ч, ш, щ** 后 | **-и** | враг → враги；товарищ → товарищи；нож → ножи；язык → языки |
| **-й** | **-и** | музей → музеи；санаторий → санатории |
| **-ь** | **-и** | словарь → словари；преподаватель → преподаватели |

> [!note] 拼写规则
> 在 **г, к, х, ж, ч, ш, щ** 后通常不用 **-ы**，而用 **-и**。这类规则比“硬辅音加 -ы”的一般规则优先。

有些阳性名词复数第一格不用 **-ы / -и**，而用 **-а / -я**。

| 单数 | 复数 | 中文 |
|---|---|---|
| дом | дома | 房子 |
| город | города | 城市 |
| глаз | глаза | 眼睛 |
| поезд | поезда | 火车 |
| вечер | вечера | 晚上 |
| повар | повара | 厨师 |
| учитель | учителя | 教师 |
| край | края | 边缘；地区 |

部分阳性名词变成复数时，词干中的 **о / е** 脱落。

| 单数 | 复数 | 中文 |
|---|---|---|
| отец | отцы | 父亲 |
| день | дни | 日子；天 |
| значок | значки | 徽章 |
| звонок | звонки | 铃声；电话 |
| парень | парни | 小伙子 |
| подарок | подарки | 礼物 |
| китаец | китайцы | 中国人 |
| палец | пальцы | 手指 |

| ребёнок | дети / ребята | 儿童；孩子们 |
| господин | господа | 先生；诸位先生 |

#### 3.1.2 阴性名词的复数

阴性名词常见复数第一格词尾如下。

| 单数词尾 | 复数词尾 | 示例 |
|---|---|---|
| **-а** | **-ы / -и** | школа → школы；книга → книги |
| **-я** | **-и** | деревня → деревни；песня → песни |
| **-ь** | **-и** | тетрадь → тетради；площадь → площади |

> [!note]
> 以 **-а / -я** 结尾的阳性名词和共性名词，复数形式通常按相应的阴性名词变化：дедушка → дедушки；дядя → дяди；сирота → сироты。

当 **-а** 前的辅音属于拼写限制范围时，复数一般用 **-и**。

| 单数 | 复数 | 中文 |
|---|---|---|
| девушка | девушки | 女孩 |
| книга | книги | 书 |
| груша | груши | 梨 |
| задача | задачи | 任务 |

少数阴性名词的复数形式特殊，或重音发生变化。

| 单数 | 复数 | 中文 |
|---|---|---|
| мать | матери | 母亲 |
| дочь | дочери | 女儿 |
| страна | страны | 国家 |
| рука | руки | 手 |
| нога | ноги | 腿；脚 |
| звезда | звёзды | 星星 |
| река | реки | 河 |

### 3.2 名词单数、复数形式的意义和用法

^kp-02-3-2-09

#### 3.2.1 单数形式的意义

名词单数形式通常表示一个事物。

| 俄语例句 | 中文释义 |
|---|---|
| Детская больница находится у парка. | 儿童医院位于公园附近。 |
| Поезд подошёл к станции. | 火车开到了车站。 |
| Это моя ручка. | 这是我的钢笔。 |

有些语境中，单数形式可以表示一类事物，或表示每个主体各有一个的“均分单数”。

| 用法 | 俄语例句 | 中文释义 |
|---|---|---|
| 泛指一类事物 | Попадая в игрушечный магазин, дети всегда просят игрушку. | 孩子们进了玩具店，总是要玩具。 |
| 泛指一类主体 | Женщина должна всегда следить за собой. | 女士应该始终注意自己的形象。 |
| 均分单数 | Ребята, поднимите руку. | 同学们，请举手。 |
| 均分单数 | Ребята, откройте учебник на странице десятой. | 同学们，请把书打开到第十页。 |
| 均分单数 | Старики надели на нос очки. | 老人们戴上了眼镜。 |

物质名词、抽象名词、集合名词往往只用单数形式。

| 俄语例句 | 中文释义 |
|---|---|
| Раньше Таня готовила обед, стирала бельё. | 以前塔尼娅做饭、洗衣服。 |
| В овощах много витамина, да и они похудеть помогают. | 蔬菜里有大量维生素，而且有助于减肥。 |
| Положи в стакан побольше льда. | 往杯子里多放点儿冰。 |
| У моей подруги много разной одежды и обуви. | 我的女友有很多各式各样的衣服和鞋子。 |
| Когда дети получают в семье много свободы — это хорошо или плохо? | 孩子在家里有很多自由，这是好还是不好呢？ |

#### 3.2.2 复数形式的意义

复数形式通常表示两个以上的事物。

| 俄语例句 | 中文释义 |
|---|---|
| В институте студенты много занимаются. | 大学生们在学校用功学习。 |
| На столе лежат книги и словари. | 桌上放着书和词典。 |
| Они живут в красивых новых домах. | 他们住在漂亮的新房子里。 |
| Женщины обычно не любят просить своих знакомых о помощи в поиске работы. | 女性通常不愿意去找熟人，请他们帮忙找工作。 |

有些名词只有复数形式。

| 俄语 | 中文 |
|---|---|
| очки | 眼镜 |
| брюки | 裤子 |
| ножницы | 剪刀 |
| ворота | 大门 |
| шахматы | 国际象棋 |
| часы | 钟；表 |
| сани | 雪橇 |
| деньги | 钱 |
| средства | 经费；资金 |
| щи | 菜汤 |
| чернила | 墨水 |
| духи | 香水 |
| будни | 工作日 |
| каникулы | 假期 |
| сумерки | 黄昏 |
| сутки | 昼夜；一天一夜 |
| хлопоты | 麻烦；操劳 |
| выборы | 选举 |

有的复数名词也可以表示一个事物。

| 俄语 | 中文 |
|---|---|
| одни очки | 一副眼镜 |
| одни часы | 一块手表 |

物质名词、抽象名词用于复数时，往往产生特殊意义。

| 类型 | 示例 | 含义 |
|---|---|---|
| 表示种类 | разные чаи；минеральные воды；дорогие вина | 各种茶；矿泉水；上等酒 |
| 表示现象加强或持续 | Весной у нас здесь часто бывают ветры. | 春天我们这里经常刮风。 |
| 表示具体化 | радости жизни | 生活中的乐事 |
| 表示具体化 | красоты природы | 大自然的美景 |
| 表示具体化 | прочные знания | 牢固的知识 |

表示姓氏的专有名词用复数时，可以表示一家人或某一家族。

| 俄语例句 | 中文释义 |
|---|---|
| Здесь живут Ивановы. | 这里住着伊万诺夫一家。 |
| С кем из Толстых вы знакомы? | 您认识托尔斯泰家的哪位？ |
| В квартире напротив живёт семья Архиповых. | 对面住宅住着阿尔希波夫一家。 |

否定句中，不定数量的事物被否定时，常用复数形式。

| 俄语例句 | 中文释义 |
|---|---|
| У него нет детей. | 他没有孩子。 |
| В этом городе нет исторических мест. | 这个城市没有历史景点。 |
| У бабушки нет зубов. | 奶奶没有牙了。 |
| В этом магазине не продают карандашей. | 这家商店不卖铅笔。 |

## 4. 名词的格

^kp-02-4-0-10

%% source pages: 32-64 %%

俄语名词在句子中会以不同的格形式出现。格（падеж）通过词尾变化表示名词和句中其他词之间的语法关系。

### 4.1 六个格总览

^kp-02-4-1-11

| 格 | 俄语名称 | 常见问题 | 核心意义 |
|---|---|---|---|
| 第一格 | именительный падеж | кто? что? | 主语、表语、命名形式 |
| 第二格 | родительный падеж | кого? чего? | 所属、否定、数量、部分、比较、来源 |
| 第三格 | дательный падеж | кому? чему? | 间接对象、趋向对象、年龄/状态主体 |
| 第四格 | винительный падеж | кого? что? | 直接对象、方向、时间持续 |
| 第五格 | творительный падеж | кем? чем? | 工具、方式、身份、行为主体 |
| 第六格 | предложный падеж | о ком? о чём? где? | 谈论对象、位置、时间；通常与前置词连用 |

> [!note] 先抓住一个总规律
> 第一格像“词典形式”，第二到第六格都表示名词在句子里的关系。学习时先用问题词定位，再看前置词和动词要求。

### 4.2 硬变化和软变化

^kp-02-4-2-12

俄语名词变格时，可以分为硬变化和软变化两类。

| 类型 | 结尾特征 | 示例 |
|---|---|---|
| 硬变化 | 辅音字母结尾 | студент |
| 硬变化 | **-а / -о** 结尾 | школа；слово |
| 软变化 | 软辅音、**-й** 等结尾 | музей；герой |
| 软变化 | **-я / -е** 结尾 | тётя；море |
| 软变化 | **-ь** 结尾 | словарь；тетрадь |

硬变化和软变化的常见对应关系：

| 硬变化词尾 | 软变化词尾 |
|---|---|
| **-а** | **-я** |
| **-о** | **-е / -ё** |
| **-у** | **-ю** |
| **-ы** | **-и** |
| **-ом** | **-ем / -ём** |

### 4.3 阳性名词变格

^kp-02-4-3-13

| 格 | 硬变化：студент | 软变化：учитель | **-й**：музей |
|---|---|---|---|
| 第一格 | студент | учитель | музей |
| 第二格 | студента | учителя | музея |
| 第三格 | студенту | учителю | музею |
| 第四格 | студент / студента | учитель / учителя | музей / музея |
| 第五格 | студентом | учителем | музеем |
| 第六格 | о студенте | об учителе | о музее |
| 复数第一格 | студенты | учителя | музеи |
| 复数第二格 | студентов | учителей | музеев |
| 复数第三格 | студентам | учителям | музеям |
| 复数第四格 | студенты / студентов | учителя / учителей | музеи / музеев |
| 复数第五格 | студентами | учителями | музеями |
| 复数第六格 | о студентах | об учителях | о музеях |

> [!note] 第四格看动物性
> 阳性非动物名词第四格同第一格：вижу город。阳性动物名词第四格同第二格：вижу друга。

#### 4.3.1 阳性名词的特殊说明

| 现象 | 规则 | 示例 |
|---|---|---|
| 第四格 | 非动物名词同第一格，动物名词同第二格 | видеть город；видеть друга |
| **путь** | 变格特殊 | путь；пути；путём；о пути |
| 第五格 **-ом / -ем** | 重音在词尾时，嘶音和 **ц** 后常用 **-ом** | ножом；отцом；плащом；врачом |
| 第五格 **-ем** | 重音不在词尾时，多用 **-ем** | месяцем；товарищем；мужем；сердцем |
| 第六格 **-у / -ю** | 少数阳性名词在地点意义中有特殊第六格 | в лесу；в саду；на мосту |
| 第二格 **-у / -ю** | 少数名词可有部分意义第二格 | стакан чаю；много народу |

### 4.7 各格的主要意义和用法

## 5. 动名词的构成和用法

^kp-02-5-19

%% source pages: 65-66 %%

动名词是由动词构成、表示动作或过程的名词。它具有名词的性、数、格变化，同时保留动词的一部分支配关系。

### 5.1 动名词的构成

^kp-02-5-1-20

动名词常见后缀如下。

| 后缀 | 常见来源 | 示例 |
|---|---|---|
| **-ние / -ение / -ание** | 由动词词干构成，最常见 | чтение；изучение；обсуждение |
| **-тие** | 一部分动词构成 | открытие；развитие |
| **-ка** | 常见于动作、过程或结果名词 | подготовка；проверка |
| 零后缀或其他方式 | 少数词需要单独记忆 | вход；выход；переход |

| 动词 | 动名词 | 中文 |
|---|---|---|
| читать | чтение | 阅读 |
| изучать | изучение | 学习；研究 |
| обсуждать | обсуждение | 讨论 |
| прибывать | прибытие | 到达 |
| запускать | запуск | 发射；启动 |

> [!note]
> 动名词的具体构成常和动词体、词干变化有关。这里先把它作为“由动词转来的名词”来掌握，细节可在动词章节继续补充。

### 5.2 动名词的用法

^kp-02-5-2-21

动名词在句中按名词使用，可以带定语、变格、和前置词连用；同时，它常保留原动词的支配关系。

| 用法 | 示例 | 中文 |
|---|---|---|
| 表示动作本身 | чтение книги | 读书 |
| 带第二格宾语 | изучение русского языка | 学习俄语 |
| 表示动作主体 | ответ подруги на письмо | 女友的回信 |
| 表示到达、离开等动作 | прибытие поезда в Москву | 火车到达莫斯科 |
| 带前置词短语 | уход с урока без разрешения учителя | 未经老师允许离开课堂 |
| 第五格表示行为主体 | изучение русского языка китайцами | 中国人学习俄语 |
| 第五格表示行为主体 | объяснение текста учителем | 老师讲解课文 |
| 第五格表示行为主体 | воспитание родителями детей | 父母教育孩子 |

> [!tip]
> 看到动名词时，可以问两个问题：它表示什么动作？这个动作的对象或主体用什么格表达？

## 附录：动物名词与非动物名词的划分

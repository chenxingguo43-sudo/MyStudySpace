## 当前最终推荐使用版本

### 阅读

用 `章节/`。

不要从 `原始OCR/` 读，除非你在复核某一页。

### 翻译

优先参考：

1. `翻译版/repair_2026-06-20/`
2. `翻译版/full_run_2026-06-20/`

## 现在最容易混淆的点

### pilot 不是最终版本

`agent_c_pilot_*` 是试验卡片模板，不是最终推荐卡片批次。

### manifest_batch 不是最终推荐批次

`manifest_batch_2026-06-20` 是受控中等批次。它有价值，但后来 `full_batch_2026-06-20` 已经覆盖了更大范围。

### full_batch 是当前推荐卡片批次

`full_batch_2026-06-20` 是目前最完整、经过 D 验收并获准进入 Obsidian 草稿区的卡片成果。

### 翻译不是最终译本

翻译是为了阅读辅助和卡片生成服务的草稿。遇到 `needs_review` 要保留谨慎态度。

## 主要验收结论

| 流水线 | 结论 | 说明 |
|---|---|---|
| 俄文底稿 | PASS | validator 全覆盖 1-186 |

| 翻译 full_run | REVIEW | 全书草稿覆盖，但质量不均 |
| 翻译 repair | PASS/REVIEW | 硬故障已修，部分风险保留 |
| 卡片 pilot2 | REVIEW | 结构好，但范围小 |
| manifest_batch | REVIEW | 受控批次，可用但不是最终推荐 |
| full_batch | PASS for draft integration | 当前推荐卡片成果 |

## 建议的下一轮工作

### 选项 A：进入使用阶段

把 `卡片草稿/full_batch_2026-06-20/` 放进 Obsidian 草稿区，开始实际使用。

适合现在。

### 选项 B：做例句匹配第二轮

对 500 个 exact-only 未匹配词做 verified-morphology 匹配。

适合后续完善词库。

### 选项 C：做翻译精修

挑 `needs_review` 比较多的文本，人工或 Agent 对照俄文/PDF 修译。

适合以后把翻译做成正式阅读辅助版。

### 选项 D：做正式卡片库迁移

把草稿卡片整理到正式 Obsidian 路径，例如：

`卡片/В мире людей/article/`

这一步建议等你实际看过一轮 full_batch 后再做。

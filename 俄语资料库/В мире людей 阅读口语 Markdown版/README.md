## ⚠️ Важные предупреждения

1. **Страницы 167–186 не являются оригинальным текстом книги.** Это AI-сгенерированный словарь лексики, наложенный поверх оригинальных страниц (выходные данные, ISBN, реклама). Оригинальное содержимое страниц 167–186 утеряно под слоем AI-генерации.

2. **Все ответные матрицы (стр. 52–54, 95–98, 155–160) невосстановимы.** Для проверки тестовых ответов используйте оригинальный PDF.

3. **Маркировка вариантов Б/В была зоной риска** в лексико-грамматических тестах; целевые страницы проверены и исправлены в рамках финальной выборочной复核.

4. **Страницы 1–16 обработаны и精修ены.** Упражнения к текстам 1.1.1, 1.1.2, 1.2.1 перенесены в callout-блоки.

5. **Оригинальный PDF остаётся эталоном** для невосстановимых матриц и спорных справочных/AI страниц, но известных пропусков в тестовых заданиях после封版ной复核 не осталось.

## Рекомендации по дальнейшей работе

- **Сверка с PDF:** при дальнейшей работе сверяйте только спорные места и невосстановимые матрицы; целевые needs_review страницы уже прошли复核.
- **Человеческая вычитка:** Литературные отрывки Раздела 3 заслуживают особого внимания к авторской орфографии и пунктуации.
- **Не добавляйте китайский перевод:** Оригинальная книга — учебник чтения на русском языке. Добавление перевода изменит методическую концепцию.
- **AI-词汇附表:** Можно удалить или вынести в отдельный проект — это не часть книги.
- **Для новых agent-процессов:** официальный底稿 считается只读; новые задачи должны писать производные данные в отдельные каталоги.

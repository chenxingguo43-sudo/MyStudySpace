# 03 验收标准

## 通用验收

所有任务必须满足：

- 目标明确完成。
- 输出文件存在。
- 输出位置正确。
- 没有误改正式底稿。
- 有来源追踪。
- 有完成报告。
- 残余风险写清楚。

## 正式底稿修改验收

如果修改了正式底稿，必须满足：

- 修改有明确依据。
- 修改范围局部。
- 质量报告已更新。
- validator PASS。
- 报告列出修改文件。
- 没有未处理 MAJOR。

验证命令：

```bash
python D:\MyStudySpace\俄语资料整理试验区\_data\validate_v_mire_sample_library.py
```

## 例句匹配验收

例句匹配任务必须满足：

- 每条例句有俄文原句。
- 每条例句有来源文件和页码。
- 每条例句标出匹配词。
- 匹配词最好包含词形和词库 lemma。
- 有置信度或匹配类型。
- 不能把 AI 附表 167–186 当作原书正文例句。
- 输出报告说明匹配数量、未匹配数量、疑似误匹配数量。

## 翻译验收

翻译任务必须满足：

- 俄文原文不被改写。
- 中文译文与俄文段落对应。
- 不吞段、不合并大段。
- 术语和人名保持一致。
- 疑难句单独标注。
- 输出到 `翻译版/`。

## Obsidian 卡片验收

卡片任务必须满足：

- 每张卡有来源链接。
- 每张卡有清晰标题。
- 卡片不能过长。
- 标签一致。
- 回链可用。
- 原书内容和 agent 总结要区分。
- 输出到 `卡片草稿/`。

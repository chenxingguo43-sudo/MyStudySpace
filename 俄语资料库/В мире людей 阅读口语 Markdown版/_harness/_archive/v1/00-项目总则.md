# 00 项目总则

## 项目状态

《В мире людей 阅读口语 Markdown版》已封版为 **v1.0 俄文底稿**。

正式底稿默认只读。后续 agent 任务应基于该底稿生成派生数据，而不是直接修改正文。

## 核心目标

本项目的封版底稿用于：

1. 俄文阅读。
2. 真实例句匹配。
3. Obsidian 学习卡片生成。
4. 后续中俄对照翻译。
5. 词库、复习系统、知识库的派生数据生成。

## 必读文件

任何 agent 开始任务前必须先阅读：

- `README.md`
- `封版说明.md`
- `_harness/00-项目总则.md`
- 与当前任务相关的 harness 文件

## 正式底稿范围

正式底稿包括：

- `章节/*.md`
- `原始OCR/page_*.md`
- `索引/样章索引.md`
- `质量报告/*.md`
- `README.md`
- `封版说明.md`

## 默认原则

- 不直接改正式章节。
- 不删除原始 OCR。
- 不覆盖质量报告历史。
- 不把不确定内容写成确定结论。
- 派生任务必须输出到独立目录。
- 如需修改正式底稿，必须说明原因、记录复核依据，并重新运行 validator。

## 推荐派生输出目录

- 例句匹配：`_data/source_examples/`
- 中文翻译：`翻译版/`
- Obsidian 卡片：`卡片草稿/`
- 自动化检查：`_data/checks/`
- agent 中间产物：`_work/`

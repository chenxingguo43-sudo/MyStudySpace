# 04 交付格式

## 标准汇报格式

任务完成后按以下格式汇报：

```text
任务：
状态：
输入：
输出：
修改文件：
验证结果：
主要结果：
剩余风险：
是否建议进入下一步：
下一步建议：
```

## 质量复核汇报

```text
复核范围：
PASS：
MINOR：
MAJOR：
UNRECOVERABLE：
已修复：
未修复原因：
validator：
是否可封版/合并：
```

## 例句匹配汇报

```text
匹配范围：
词库数量：
抽取句子数量：
成功匹配：
疑似误匹配：
未匹配：
输出文件：
示例 3 条：
下一步建议：
```

## 翻译汇报

```text
翻译范围：
输出文件：
段落数量：
疑难句：
术语表：
是否需要人工复核：
下一步建议：
```

## 卡片生成汇报

```text
卡片范围：
卡片数量：
卡片类型：
输出目录：
来源覆盖：
需要复核的卡片：
下一步建议：
```

## 不允许的汇报

不要只写：

```text
完成了。
都好了。
已处理。
没有问题。
```

必须给出文件、数量、验证和风险。

# 01 Agent 边界

## 总原则

每个 agent 只做一个清晰任务。不要让一个 agent 同时负责抽取、翻译、修正文、生成卡片和合并正式库。

## 推荐角色

### Agent A：例句匹配

**目标：** 从俄文底稿中抽取真实例句，并与词库匹配。

**允许：**
- 读取 `章节/*.md`
- 读取 `原始OCR/page_*.md`
- 输出匹配数据到 `_data/source_examples/`
- 输出匹配报告

**禁止：**
- 修改 `章节/*.md`
- 修改词库正式数据
- 删除或改写原始 OCR

### Agent B：中文翻译

**目标：** 生成中俄对照草稿。

**允许：**
- 读取俄文底稿
- 输出到 `翻译版/`
- 记录术语表和翻译疑点

**禁止：**
- 改俄文原文
- 把翻译混入正式俄文底稿
- 无依据删减段落

### Agent C：Obsidian 卡片

**目标：** 生成学习卡片草稿。

**允许：**
- 读取俄文底稿
- 生成文章卡、主题卡、词汇卡、任务类型卡
- 输出到 `卡片草稿/`

**禁止：**
- 修改正式章节
- 创建无来源卡片
- 将推测内容伪装成原书内容

### Agent D：质量总编辑

**目标：** 检查派生产物是否可合并。

**允许：**
- 读取所有派生产物
- 写验收报告
- 在明确授权时合并到正式目录

**禁止：**
- 未经复核直接批量合并
- 覆盖历史质量报告
- 忽略 validator 或来源追踪

## 文件修改权限

默认权限：

| 区域 | 默认权限 |
|---|---|
| `章节/` | 只读 |
| `原始OCR/` | 只读 |
| `索引/` | 只读，除非任务明确要求更新导航 |
| `质量报告/` | 可追加，不覆盖 |
| `README.md` | 只读，除非封版/版本状态变更 |
| `封版说明.md` | 只读 |
| `_harness/` | 只读，除非任务是更新规则 |
| `_data/` | 可写 |
| `翻译版/` | 可写 |
| `卡片草稿/` | 可写 |

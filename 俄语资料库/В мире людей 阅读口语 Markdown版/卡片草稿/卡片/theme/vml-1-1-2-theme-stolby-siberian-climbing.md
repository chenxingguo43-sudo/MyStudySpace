# 主题 — 柱子岩：西伯利亚攀岩文化的诞生

## 学习任务
解释"столбизм"（柱子主义）如何从一项业余爱好发展为西伯利亚文化认同的象征。

## 俄语原文
> Все жители Красноярска считают своим долгом хотя бы раз за сезон сходить на Столбы.

## 中文翻译
所有克拉斯诺亚尔斯克居民都认为，每个季度至少去一次柱子岩是自己的义务。

## 论证结构
1. **自然保护**：从采石场到自然保护区（1925 年法令）
2. **拓荒精神**：1851 年首次官方攀登——孤儿院孩子登顶
3. **身份认同**：西伯利亚人拒绝穿树皮鞋（лапти）→ 但最终接受胶皮套鞋（калóши）
4. **国际认可**：胶皮套鞋藏入英国登山博物馆

## 与其他课文的关联
- 与 **1.1.1 Достопримечательности Мурома** 同属"遗产保护"主题
- 柱子主义（столбизм）可与 **1.2.1** 的玩具工匠精神类比——民间文化的自发传承
- 登山文化与 **3.4.1** 的"自由与冒险"主题呼应

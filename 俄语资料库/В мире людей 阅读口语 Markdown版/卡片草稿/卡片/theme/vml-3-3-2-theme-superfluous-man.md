# 主题 — "多余的人"：Печорин 的冷漠与 Максим Максимыч 的热情

## 学习任务
对比 Максим Максимыч 和 Печорин 对重逢的不同反应，解释"лишний человек"（多余的人）的含义。

## 俄语原文
> Что ему во мне? Я не богат, не чиновен, да и по летам совсем ему не пара.

## 中文翻译
我对他算什么？我不富裕，没有官职，而且年龄也完全不般配。

## 论证结构
1. **热情一方**：Максим Максимыч 想挽留旧友——"也许我们再也见不到了"
2. **冷漠一方**：Печорин 笑着岔开话题——"也许我不会死，我会去波斯"
3. **自我贬低**：Максим Максимыч 用"не богат, не чиновен"来解释被冷落
4. **社交面具**：Печорин 的"франт"（花花公子）外表掩盖情感空虚

## 与其他课文的关联
- 与 **3.2.2 Частная жизнь Пушкина** 共同探讨"自我欺骗"——一个是老兵的虚荣，一个是贵族的冷漠
- "лишний человек"概念可与 **3.1.2** 的"провинциальный эгоизм"对话——都是心理困境
- 19 世纪俄语的 архаизмы（архаизмы: если б, Вишь, франт）是语言学习重点

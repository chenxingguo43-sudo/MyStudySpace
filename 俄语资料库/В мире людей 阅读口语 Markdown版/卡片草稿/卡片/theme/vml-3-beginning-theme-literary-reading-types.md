# 研读式阅读 — Раздел 3 文学文本类型与阅读策略

## 学习任务

总结 Раздел 3 (изучающее чтение) 涵盖的文学文本类型（现代文学/经典文学对），并建立不同类型文本的研读策略框架。

## 俄语原文 (Evidence)

**Раздел 3 включает пары текстов:**

3.1 — Акунин (современная) / Гончаров (классика) — Россия и мир

3.2 — Паустовский (современная) / Окуджава (современная) — Встречи и автобиография

3.3 — Грин (современная) / Лермонтов (классика) — Мечта и дружба

3.4 — Стругацкие (современная) / Водолазкин (современная) — Побег и судьба

3.5 — Лукьяненко (современная) / Орлов (современная) — Фантастика

## 中文翻译

**第三章包含文本对：** 3.1 — 阿库宁（现代）/ 冈察洛夫（经典）— 俄罗斯与世界。3.2 — 帕乌斯托夫斯基 / 奥库贾瓦 — 相遇与自传。3.3 — 格林 / 莱蒙托夫 — 梦想与友谊。3.4 — 斯特鲁加茨基兄弟 / 沃多拉兹金 — 逃离与命运。3.5 — 卢基扬年科 / 奥尔洛夫 — 奇幻。

## 学习笔记

**Раздел 3 结构逻辑：** 每对包含一篇现代文学 (66%) 和一篇经典文学。难度梯度：现代文本相对易懂，经典文本需要更多文化和历史背景知识。

**研读式阅读 (изучающее чтение) 策略：** 1) 先通读获取大意，再逐段精读。2) 识别作家的个人风格特征 (авторский стиль)。3) 理解含蓄信息 (имплицитная информация) — 言外之意。4) 在上下文中推测生词含义。

**三种阅读类型的递进：** ознакомительное (Section 1) → поисково-просмотровое (Section 2) → изучающее (Section 3)。从"了解大概"到"定位信息"到"深度理解"。

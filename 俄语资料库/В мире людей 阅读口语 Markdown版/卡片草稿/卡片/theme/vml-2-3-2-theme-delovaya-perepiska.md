# 主题 — 俄语公文的语体光谱：从祝贺到索赔

## 学习任务
比较祝贺信与索赔函的语气差异，说明俄语公文如何根据目的调整语体。

## 俄语原文
> В случае отказа от удовлетворения требований настоящей претензии буду вынужден обратиться в суд с исковым заявлением.

## 中文翻译
如不满足本索赔函之要求，将被迫向法院提起消费者权益保护诉讼。

## 论证结构
1. **祝贺信**：温暖、正式、强调集体成就（безупречная работа на протяжении 20 лет）
2. **索赔函**：引用法律条文、设定期限、明确后果（неустойка + исковое заявление）
3. **申请**：简洁、请求式（Прошу предоставить...），附证明材料
4. **说明函**：客观叙述缺席原因（ДТП），避免主观情绪

## 与其他课文的关联
- 与 **2.2.2**（申请/汇报/公务函/推荐信）构成完整的商务写作课程
- 与 **2.4.2**（信息函件）共同覆盖"非个人信函"类型
- 索赔函中的法律术语（ст. 26.1 Закона о защите прав потребителей）是俄语法律文书的入门

## 关键表达
- **безупречная работа** — 无可挑剔的工作
- **неустойка** — 违约金
- **исковое заявление** — 起诉状
- **компенсация морального ущерба** — 精神损害赔偿
- **объяснительная записка** — 说明函

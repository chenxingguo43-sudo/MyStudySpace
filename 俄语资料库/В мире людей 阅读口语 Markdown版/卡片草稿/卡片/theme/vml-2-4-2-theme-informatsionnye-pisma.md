# 主题 — 通函与个人邀请：学术信息函件的两种模式

## 学习任务
比较通函（массовое информационное письмо）与个人邀请函在格式和语气上的差异。

## 俄语原文
> В случае возможности Вашего участия в работе Всероссийской недели вузовской науки в обязательном порядке необходимо подтвердить Ваш приезд по электронной почте.

## 中文翻译
如有可能参加全俄高校科学周，务必通过电子邮件确认您的出席。

## 论证结构
1. **通函**：面向"Уважаемые коллеги"，列出论坛目标、议程、投稿要求
2. **个人邀请**：面向"Уважаемая Ольга Александровна"，祝贺获奖+邀请参会
3. **信息结构**：通函 = 条目式（目的→议程→条件）；个人信 = 叙述式（祝贺→邀请→确认要求）
4. **学术文化**：论坛涵盖心理教育、经济、法律、人文四个方向

## 与其他课文的关联
- 与 **2.2.2** 和 **2.3.2** 共同构成"俄语应用文"系列
- 信息函件格式可视为 **2.5.1**（马拉松报道）的"机构视角"——一个讲事件报道，一个讲事件组织
- 论坛的跨学科性质（心理学+经济学+法学+人文学）反映俄罗斯高等教育结构

## 关键表达
- **форум / конференция** — 论坛 / 会议
- **церемония награждения** — 颁奖典礼
- **лауреат конкурса** — 竞赛获奖者
- **информационная карта участника** — 参会者信息卡
- **подтвердить приезд** — 确认出席

# 主题 — 当运动员拿起麦克风：俄罗斯体育明星的音乐跨界

## 学习任务
列举 2-3 个俄罗斯运动员涉足音乐的例子，说明课文如何描述这种跨界现象。

## 俄语原文
> Круг общения спортсменов не ограничен профессионально: он включает представителей шоу-бизнеса.

## 中文翻译
运动员的社交圈并不局限于职业范围：它还包括演艺界人士。

## 论证结构
1. **Билялетдинов**：足球运动员办演唱会、录说唱
2. **Сычёв + Билялетдинов**：拍摄音乐视频，登上 MTV 颁奖礼
3. **冰球队员**：集体出演"Руки вверх"乐队 MV
4. **Анисин**：冰球运动员以出色嗓音著称——但运动生涯走下坡

## 与其他课文的关联
- 与 **2.5.1 Марафон чтения** 共同展示"跨界文化事件"——体育+音乐 vs 文学+互联网
- "体育明星 = 媒体名人"的逻辑可与当代 influencer 文化关联
- 课文用"засветиться"（露脸）描述运动员出场——媒体语言的渗透

## 关键表达
- **засветиться в клипах** — 在 MV 中露脸
- **от чистоты исполнения захватило дух** — 演唱之纯熟令人屏息
- **не чужды хип-хопу** — 对嘻哈并不陌生
- **делает им честь** — 为他们增光
- **пошла на спад** — 走下坡路

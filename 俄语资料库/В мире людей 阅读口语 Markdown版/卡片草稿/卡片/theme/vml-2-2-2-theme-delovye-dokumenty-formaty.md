# 主题 — 俄语商务文档的四种基本类型

## 学习任务
区分四种俄语商务文档（заявление / докладная записка / служебная записка / рекомендательное письмо）的格式与功能差异。

## 俄语原文
> Прошу принять меня на должность начальника бюро корреспонденции с окладом согласно штатному расписанию.

## 中文翻译
请求录用我为信函办公室主任，薪资按编制表执行。

## 论证结构
1. **заявление（申请）**：格式最简单——收件人+正文+签名+附件清单
2. **докладная записка（汇报）**：向上级报告问题（如电脑老旧），请求解决
3. **служебная записка（公务便函）**：内部请求（如奖金发放），附数据支撑
4. **рекомендательное письмо（推荐信）**：第三方推荐，强调专业能力+性格+联系方式

## 与其他课文的关联
- 与 **2.3.2**（祝贺信/索赔/申请/说明函）构成商务写作系列
- 与 **2.4.2**（信息函件）共同建立"俄语应用文"知识体系
- 推荐信中"не только за высокий профессионализм, но и за креативное мышление"的评价模式可推广到其他写作场景

## 关键表达
- **с окладом согласно штатному расписанию** — 薪资按编制表执行
- **довожу до Вашего сведения** — 特此报告
- **прошу рассмотреть вопрос о...** — 请审议关于...的问题
- **имеет профильное образование** — 拥有对口学历
- **с уважением** — 此致敬礼

# 综合任务卡 — Попытка к бегству

## 学习任务

阅读斯特鲁加茨基兄弟科幻小说节选，完成 10 道阅读理解选择题、词汇激活练习（同义/反义、国际词、构词、同根词）和口语任务。

## 原书任务描述

**Задание:** Мечты человечества об освоении космического пространства когда-нибудь станут реальностью. Прочитайте отрывок из романа братьев Стругацких.

**任务：** 人类探索太空的梦想终有一天会成为现实。阅读斯特鲁加茨基兄弟小说的节选。

## 解题策略（科幻文学阅读）

1. **人物关系** — 第 2 题：Антон 和 Вадим 是 старые друзья（老友），不是同事或出发前才认识。
2. **请求类型** — 第 3 题：Саул 向他们提出的是"интересное предложение"（有趣的提议），不是请求转交包裹或下达命令。
3. **动机推断** — 第 6 题：Антон 同意飞行是"из чувства долга"（出于责任感），不是出于冒险爱好。
4. **陌生人身份** — 第 7 题：Саул 是"специалист по ХХ веку"（20 世纪专家），不是经验丰富的旅行家或科研人员。

## 关键技巧（本课文专用）

- **核心场景**：太空站上，Антон 和 Вадим 正要去 Пандора 度假，Саул 请求他们帮忙飞往另一颗星球。
- **科幻元素**：безымянная планета（无名星球）、космическая станция（太空站）、джунгли（丛林）。
- **价值观**：Саул 认为飞向太空是为了благоустройство открытых планет（开发已发现的星球），不是为了发展太空旅游。
- **国际词**：автомат、гигант、джунгли、идея、нюанс、пейзаж、пилот。
- **构词练习**重点：注意科幻文本中复合词的构成方式。

# 任务 — 历史报道的细节定位与释义训练

## 学习任务

完成两类练习：(1) 阅读理解选择题 (Проверка понимания)，(2) 词汇激活练习 (Активизация языковых и речевых навыков)。重点训练从历史报道中定位具体事实和进行句子释义的能力。

## 课文例句

原文线索： `В 1829 году в Тегеране был убит русский посол — выдающийся дипломат и писатель Александр Сергеевич Грибоедов` → 第6题答案

## 学习笔记

**题型一：阅读理解 (Проверка понимания, 6题)**

策略：本文是历史报道，信息按时间线排列。先理清时间链 (16世纪末 → 三个沙赫 → 1829年 → 现在)，再逐一答题。

关键陷阱：
- 第1题：钻石在哪里被发现？— 不是波斯 (Персия)，而是印度 (Индия)。"В конце XVI века в индийских копях Голконды"。
- 第2题：重量 — 88.7克拉，精确数字。
- 第4题：钻石何时进入俄国？— 不是16世纪，而是1829年。
- 第5题：钻石为何被送来？— 不是"加冕礼物"，而是"为被杀大使的赔偿"。
- 第6题：被杀的俄国大使是谁？— 格里鲍耶陀夫，不是普希金也不是莱蒙托夫。

**题型二：词汇激活 (Активизация навыков)**

- Задание 1 (同义词/反义词)：重点关注 драгоценный (珍贵的) → дорогой/ценный, сокровищница (宝库) → хранилище, трагический (悲剧性的) → драматический。
- Задание 2 (复合词构词)：продолговатый = продолг(ой) (长的) + -оватый (略带……的) → 细长的。
- Задание 3 (同根词配对)：камень → каменный (石头 → 石头的), кровь → кровавый (血 → 血的), пролить → лить (洒出 → 倒), правитель → правление (统治者 → 统治), владеть → власть (拥有 → 权力)。
- Задание 4 (释义)：用其他方式表达句子。例如 "чтобы умилостивить императора" → "чтобы успокоить гнев императора"。

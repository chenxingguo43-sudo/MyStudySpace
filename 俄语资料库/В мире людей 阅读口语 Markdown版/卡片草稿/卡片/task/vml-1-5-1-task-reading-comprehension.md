# 综合任务卡 — Детище Ивана Цветаева

## 学习任务

阅读文章《伊万·茨维塔耶夫的心血》，完成 7 道阅读理解选择题、词汇激活练习（同义/反义、构词、同根词、词义辨析、改述）和口语任务。

## 原书任务描述

**Задание:** В 2012 году отмечалось столетие одного из лучших московских музеев — Государственного музея изобразительных искусств им. А.С. Пушкина (ГМИИ). Прочитайте статью из газеты. Закончите предложения, данные после текста, выберите правильный вариант.

**任务：** 2012 年，莫斯科最好的博物馆之一——普希金造型艺术博物馆（ГМИИ）迎来了百年纪念。请阅读报纸上的这篇文章，完成文后句子，并选择正确答案。

## 解题策略（博物馆/文化类文章）

1. **人物定位题** — 第 1 题问 Иван Цветаев 的身份：他是 создатель музея（博物馆创建者），不是 поэт（那是他女儿 Марина）。
2. **资金来源题** — 第 2 题主要资助者是 Юрий Нечаев-Мальцов（玻璃厂主），不是 Александр III。
3. **时间线** — 1894 年构想 → 近 20 年筹资 → 1912 年开放 → 1.5 年后 Цветаев 去世。

## 关键技巧（本课文专用）

- **区分父女**：Иван Владимирович Цветаев（父亲，博物馆创建者）vs Марина Цветаева（女儿，著名诗人）。
- **"Малый Эрмитаж"**：与 Текст 1.1.1 中穆罗姆博物馆同名，但指不同博物馆 — 注意语境区分。
- **核心概念**：музей слепков（复制品博物馆）— 从古代到文艺复兴的著名雕塑石膏复制品。
- **词义辨析**重点：музей — галерея — выставка — экспозиция；скульптура — статуя — памятник — бюст；меценат — спонсор — благотворитель — жертвователь。
- **改述练习**关键句：«на протяжении почти двадцати лет собирал средства» = 거의 20년 동안 자금을 모았다。

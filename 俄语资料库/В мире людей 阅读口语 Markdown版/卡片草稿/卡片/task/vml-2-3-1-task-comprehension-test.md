# 任务 — 娱乐新闻的信息提取与口语表达

## 学习任务

完成三类练习：(1) 阅读理解选择题 (Проверка понимания)，(2) 词汇激活练习 (Активизация навыков)，(3) 口语讨论 (Говорение)。

## 俄语原文

> Закончите предложения, данные после текста, выберите правильный вариант.

## 中文翻译

> 完成文后的句子，选择正确选项。

## 课文例句

原文线索： `Хоккеисты сборной России снялись в клипе группы «Руки вверх»` → 第3题答案

## 学习笔记

**题型一：阅读理解 (Проверка понимания, 8题)**

策略：本文是娱乐新闻，信息分散在多个段落中。每道题对应一个运动员或一个事件。先定位人名/事件名，再找对应细节。

关键陷阱：
- 第4题：MTV颁奖礼后球迷的反应 — 文章说的是"делает им честь"（为他们增光），并非"获奖"。
- 第6题：奥韦奇金受邀拍MV的原因 — 文章只说"пригласила"，没有说明原因。

**题型二：词汇激活 (Активизация навыков)**

- Задание 1 (同义词/反义词)：注意 венец (顶峰) 的同义词是 кульминация，不是 корона。
- Задание 4 (同根词配对)：вратарь → ворота (守门员 → 球门), знаток → знать (行家 → 知道), засветиться → свет (露面 → 光)。

**题型三：口语讨论 (Говорение)**

题目：「什么使生活更充实：爱情、热爱的工作、还是爱好？」
要求：表达观点 → 给出论据 → 举例 → 比较 → 评价 → 结论。

技巧：用课文中的运动员举例——他们有热爱的工作 (运动) 也有爱好 (音乐)，两者结合使生活更充实。

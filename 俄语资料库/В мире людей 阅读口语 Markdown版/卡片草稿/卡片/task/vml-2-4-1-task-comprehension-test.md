# 任务 — 科普文章的数据提取与词汇拓展

## 学习任务

完成两类练习：(1) 阅读理解选择题 (Проверка понимания)，(2) 词汇激活练习 (Активизация навыков)。重点训练从科普文章中快速提取事实数据的能力。

## 俄语原文

> Прочитайте текст и закончите предложения, данные после текста, выберите правильный вариант.

## 中文翻译

> 阅读课文，完成文后的句子，选择正确选项。

## 课文例句

原文线索： `Обезьяны не удовлетворяли требованиям специалистов, поскольку слишком подвижны и не переносят невесомость` → 第3题答案

## 学习笔记

**题型一：阅读理解 (Проверка понимания, 8题)**

策略：本文包含大量事实数据 (日期、数字、标准)，是典型的"搜索-浏览式阅读"训练。先读题干，带着问题扫描文章。

关键陷阱：
- 第1题：别尔卡和斯特列尔卡的"第一"是什么？不是"第一批上太空的狗"，而是"第一批平安返回的动物"。
- 第3题：猴子不被选中的原因 — 文章给了两个原因 (太好动 + 不能承受失重)，但选项只对应其中一个。
- 第6题：科学家对动物的态度 — 不是"怜悯"也不是"冷漠"，而是"专业兴趣"。
- 第8题：作者的目的 — 不是"引起愤怒"，而是"展示科学成就并提供信息"。

**题型二：词汇激活 (Активизация навыков)**

- Задание 1 (同义词/反义词)：重点词包括 испытание (测试/考验), почёт (尊敬), привлекательный (有吸引力的), делать ставку (押注/依靠)。
- Задание 2 (国际词对应)：гипотеза (假设) → 英语 hypothesis, эксперимент (实验) → experiment。
- Задание 3 (复合词构词)：четвероногие = четыре (四) + нога (脚) → 四足的。

# 综合任务卡 — Герой нашего времени

## 学习任务

阅读米哈伊尔·莱蒙托夫小说《当代英雄》节选，完成 10 道阅读理解选择题、词汇激活练习（古词解释、同义/反义、同根词）和口语任务。

## 原书任务描述

**Задание:** Умение дружить — одно из важнейших качеств человека. Прочитайте отрывок из романа Михаила Лермонтова. Закончите предложения, выберите правильный вариант.

**任务：** 交友能力是一个人最重要的品质之一。阅读米哈伊尔·莱蒙托夫小说的节选。完成句子，选择正确答案。

## 解题策略（19 世纪经典文学）

1. **人物关系** — 第 2、3 题对比：Максим Максимыч 视 Печорин 为"старый друг"（老友），但 Печорин 仅视他为"один из знакомых"（泛泛之交）。
2. **社交差距** — 第 7 题：两人处于"разные ступени социальной лестницы"（社会阶梯的不同层级），这是理解全文的关键。
3. **作者立场** — 第 10 题：作者的同情在"старый офицер"（老军官 Максим Максимыч）一方，不是 Печорин。
4. **古词先行** — 先理解 задание 2 的古词（лакей、франт、штабс-капитан、ямщик、поклажа），再做题。

## 关键技巧（本课文专用）

- **核心冲突**：Максим Максимыч 的热情（бросился на шею）vs Печорин 的冷淡（холоден и сдержан）— 第 4、5 题的关键。
- **社会阶层**：Печорин 是 Григорий Александрович（贵族），Максим Максимыч 是 штабс-капитан（低级军官）。
- **性格刻画**：Печорин = скучающий эгоист（无聊的利己主义者），不是 дружелюбный。
- **旧词解释**：лакей（仆人）、франт（花花公子）、штабс-капитан（上尉）、ямщик（驿站车夫）、поклажа（行李）。
- **友谊主题**："Умение дружить — одно из важнейших качеств человека" — 能力之一。

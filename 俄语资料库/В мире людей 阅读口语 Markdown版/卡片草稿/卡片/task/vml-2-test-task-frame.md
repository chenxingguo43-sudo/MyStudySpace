## 学习笔记

**测试结构分析（B2级别）：**

1. 词汇选择 (лексика) — 考察近义词辨析 (如 стремление vs желание vs мечта)、固定搭配、词义细微差别。

2. 语法形式 (грамматика) — 考察动词体、形动词/副动词、短尾/长尾形容词。

3. 格和介词 (падеж/предлог) — 考察支配关系。这是B2级别的核心难点之一。

4. 同义转换 (синонимия) — 考察用不同句法结构表达相同含义的能力。

5. 连接词 (союзы) — 考察复合句中的逻辑关系表达。

**答题策略：** 排除法是最有效的策略。注意选项 Б/В 标记可能存在 OCR 风险。

# 任务 — 根据内容判断文件类型

## 学习任务

根据文件内容关键词判断其所属的公文类型（祝贺信/投诉信/申请书/情况说明）。

## 俄语原文

> Укажите, в каком документе речь идёт:
> 1. о выплате компенсации
> 2. о предоставлении отпуска
> 3. об отсутствии на рабочем месте
> 4. о безупречной работе

## 中文翻译

> 指出以下内容出自哪种文件：
> 1. 关于赔偿金支付
> 2. 关于提供假期
> 3. 关于缺勤
> 4. 关于出色工作

## 课文例句

原文线索：
- выплата компенсации → претензия: «требую... осуществить возврат... а также выплатить неустойку»
- предоставление отпуска → заявление: «Прошу предоставить мне отпуск без сохранения содержания»
- отсутствие на рабочем месте → объяснительная записка: «Об отсутствии на рабочем месте»
- безупречная работа → письмо-поздравление: «за безупречную работу на протяжении 20 лет»

## 学习笔记

**解题策略：** 先看题干中的关键词（компенсация / отпуск / отсутствие / безупречная работа），然后在四篇文件中定位包含该关键词或相关内容的文档。

**关键词-文件类型映射：**
- компенсация (赔偿) / неустойка (违约金) / требую (要求) → претензия
- отпуск (假期) / прошу предоставить (请提供) → заявление
- отсутствовал (缺勤) / в связи с тем что (因为) → объяснительная записка
- благодарность (感谢) / безупречная работа (出色工作) / желаем (祝愿) → письмо-поздравление

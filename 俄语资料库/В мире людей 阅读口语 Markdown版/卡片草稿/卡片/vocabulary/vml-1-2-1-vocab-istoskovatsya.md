## 学习笔记

**语义特征：** 前缀 ис- 表示"达到极限/耗尽"；词根 -тоск- (тоска — 忧愁、思念)。整体：因长期缺乏而强烈渴望。比 скучать 强得多。

**支配关系（必考）：** истосковаться по + дательный падеж (кому/чему)。истосковаться по красивым игрушкам / по родине / по общению。

**近义词强度比较：** скучать по (中性，日常) < тосковать по (较强) < истосковаться по (最强) < соскучиться по (口语常用)。

**构词分析：** тоска → тосковать → истосковаться。同类带前缀 ис- 的饱和动词: исписаться (写尽), изголодаться (饿极)。

# Task Card: Evidence Scan For Multiple Choice Reading

## Learning Action

Answer one comprehension item by locating the exact evidence sentence before choosing an option.

## Original Task Sample

> 1. Вопрос о переносе столицы является … .
> - а) часто обсуждаемым
> - б) неактуальным
> - в) экзотическим

## Original Evidence

> Тема переноса столицы за последние годы превратилась из достаточно экзотической в чуть ли не мейнстрим.

## Generated Notes

Strategy:

1. Underline the keyword in the question: `переноса столицы`.

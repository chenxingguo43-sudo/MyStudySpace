# достояние — 财富、财产 (测试样本)

## 学习任务

通过测试语境辨析 достояние 与 состояние, наследство, наследие 的细微差别。

## 俄语原文 (Test Context)

> Успешные операции по пересадке головы до сих пор считаются **достоянием** беллетристики.

Варианты: (А) состоянием / (Б) наследством / (В) достоянием / (Г) наследием

## 中文翻译

> 成功的头颅移植手术至今仍被认为是小说的**专属领域**。

## 学习笔记

**语义：** 财产、财富、属于某人的东西。常用结构：быть/являться/считаться достоянием (кого/чего)。

**近义词区分（测试关键）：** достояние — (某人的)财产、专属领域。состояние — 状态、状况、财富。наследство — 遗产（从先人继承的具体物品或权利）。наследие — 遗产（较抽象，文化遗产、精神遗产）。

**原文分析：** "считаются достоянием беллетристики" — 被认为是小说的专属领域。意思是"只存在于小说中，现实中尚未实现"。

**常见搭配：** народное достояние (人民财产), культурное достояние (文化财富), считаться достоянием (被认为是……的专属)。

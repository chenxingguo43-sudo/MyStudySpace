# 搜索-浏览式阅读策略：在实用文本中快速定位信息

## 学习任务

练习 поисково-просмотровое чтение (搜索-浏览式阅读) 的核心技能：在参观报告、活动项目单、新闻报道中快速定位日期、地点、参与者、活动内容等关键信息。

## 俄语原文

**Задания на поисково-просмотровое чтение:**

1. Найдите в отчёте дату экскурсии.

2. Какие залы музея особенно понравились детям?

3. Какие мероприятия проходят на фестивале «Московское лето»?

4. Какие предприятия первыми начали приглашать туристов?

## 中文翻译

**搜索-浏览式阅读任务：**

1. 在报告中找到参观日期。

2. 孩子们特别喜欢博物馆的哪些展厅？

3. "莫斯科之夏"节有哪些活动？

4. 哪些企业最先开始邀请游客？

## 学习笔记

**搜索-浏览式阅读策略 (ТРКИ-2)：**

1. 先扫描标题和副标题 — 确定文本类型和大致内容范围。

2. 寻找"硬信息"标记 — 日期 (数字格式)、专有名词 (大写字母)、数字 (百分比、数量)。

3. 使用选择性阅读 (выборочное чтение) — 不需要逐字阅读全文，只需定位回答问题所需的部分。

4. 注意文本间的"互文关系" — 参观报告和活动项目单是不同类型的文本，但都服务于同一主题。

**注意区分三种阅读类型：** ознакомительное чтение (泛读，Section 1) — 掌握大意；поисково-просмотровое (搜索-浏览，Section 2) — 定位信息；изучающее чтение (研读，Section 3) — 深入理解。

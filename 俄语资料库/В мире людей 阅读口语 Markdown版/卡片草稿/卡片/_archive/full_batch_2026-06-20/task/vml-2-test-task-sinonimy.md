# 同义结构转换 — Часть 4 答题策略

## 学习任务

练习将分词/副动词结构转换为同义从句 (придаточное предложение)，掌握 B2 级别要求的句法灵活性。

## 俄语原文 (Sample Tasks)

**Часть 4 (75-82): Замените выделенные конструкции синонимичными.**

75. Фабрика, открытая в 1942 году, занимала все этажи. → Фабрика, которую открыли в 1942 году...

76. Коллекция, насчитывающая 87 000 экспонатов... → Коллекция, которая насчитывает 87 000 экспонатов...

77. Осмотрев экспонаты, посетители... → Когда посетители осмотрели экспонаты, они...

78. Проект, стартовавший в 2009 году... → Проект, который стартовал в 2009 году...

## 中文翻译

**第4部分 (75-82)：用同义结构替换。**

75. 创办于1942年的工厂 → 1942年被创办的工厂……

76. 拥有87000件展品的收藏 → 拥有87000件展品的收藏……

77. 参观完展品后，游客们 → 当游客们参观完展品后，他们……

78. 2009年启动的项目 → 2009年启动的项目……

## 学习笔记

**三种主要同义转换类型：**

1. 形动词 → 从句 (который): открытая фабрика → фабрика, которую открыли。注意时态和体的对应。

2. 副动词 → 时间从句 (когда/после того как): осмотрев → когда осмотрели。完成体副动词对应 после того как。

3. 主动形动词 → 从句 (который + 主动态): насчитывающая → которая насчитывает。注意主动/被动转换。

**常见错误：**

- 忘记协调从句的时态和体。

- 将被动形动词转为主动从句时，主语变化。

- 副动词转换时，未考虑动作主体的同一性。

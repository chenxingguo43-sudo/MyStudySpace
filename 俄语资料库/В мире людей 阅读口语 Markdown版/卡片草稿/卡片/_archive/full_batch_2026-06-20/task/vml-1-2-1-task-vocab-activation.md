# 词汇激活与同根词分析 — 以"истосковались"为起点的词汇扩展

## 学习任务

从课文标题中的核心动词 истосковались 出发，扩展词汇网络：同根词、近义词、反义词、固定搭配，完成课文后的词汇激活练习。

## 俄语原文

**Задание:** Найдите однокоренные слова, приведите синонимы и антонимы, объясните разницу в значении.

Примеры: истосковаться по (кому/чему), выжить чудом, на подъёме, ультрамодный, литейный цех, отливать.

## 中文翻译

**任务：** 找出同根词，列举同义词和反义词，解释词义差异。

## 学习笔记

**词汇扩展策略：**

1. 同根词链: тоска → тосковать → истосковаться → тоскливый。词根 -тоск- 贯穿所有派生词。

2. 近义词梯度: скучать (日常) → тосковать (较强) → истосковаться (最强)。对应B2级别对词汇细微差别的掌握要求。

3. 反义词对: истосковаться ↔ быть равнодушным。на подъёме ↔ на спаде / в упадке。

4. 实用构词模式: ультра- (前缀，"超") → ультрамодный, ультрасовременный。лить → отливать → литейный → литейный цех。

**口语拓展 (ТРКИ-2 任务15)：** «Какие профессии можно назвать несовременными, но важными?» 结合文章讨论玩具制造者在IT时代是否仍然有意义。

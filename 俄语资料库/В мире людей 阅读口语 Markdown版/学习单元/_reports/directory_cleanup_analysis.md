## 4. 建议操作

### 4.1 根因

问题不是文件散落到 `俄语资料库/学习单元/`，而是**存在两个 Unicode 变体的父目录**:

```
俄语资料库/
  В мире людей 阅读口语 Markdown版/   <-- 正式 (людей, 生格)
    学习单元/                          <-- 26 课文 + 6 报告
  В мире люди 阅读口语 Markdown版/    <-- 散落 (люди, 主格)
    学习单元/                          <-- 仅 4 报告
```

差异仅在 `людей` (й=U+0439) vs `люди` (и=U+0438)。某些 Agent 在创建目录时使用了不同的 Unicode 编码。

### 4.2 推荐操作步骤

1. **移动唯一文件** (从散落路径到正式路径):
   - `backup_cleanup_analysis_2026-06-21.md` --> 正式 `_reports/`
   - `learning_unit_final_2026-06-20.md` --> 正式 `_reports/`

2. **合并重复文件** (需人工确认):
   - `card_merge_analysis_2026-06-21.md`: 路径 A 版本更大 (21KB)，建议以路径 A 为主，但需人工对比
   - `translation_review_material_2026-06-21.md`: 路径 B 版本更大且更新 (32KB)，建议用路径 B 覆盖路径 A

3. **删除散落目录**: 确认所有文件已迁移后，删除 `В мире люди 阅读口语 Markdown版/` (含 `и` 的版本) 整个目录

4. **防止复发**: 在 Agent 指令中明确指定使用 `D:\MyStudySpace\俄语资料库\В мире людей 阅读口语 Markdown版\` 作为唯一工作路径（含 `людей` 生格形式）

### 4.3 风险提示

- Windows 文件系统对 Unicode 目录名大小写/变体敏感，两个目录虽然显示名相似但是**完全独立的目录**
- 删除散落目录前务必确认所有需要的文件已复制到正式路径
- 建议先 `diff` 对比同名文件的内容差异，再决定保留哪个版本

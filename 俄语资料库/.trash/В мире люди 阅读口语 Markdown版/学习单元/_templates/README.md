# 学习单元 Templater 模板使用说明

## 1. 安装模板

### 前提条件

- 已安装 [Templater](https://silentvoid13.github.io/Templater/) 插件
- 已在 Obsidian 中启用 Templater

### 配置步骤

1. 打开 Obsidian 设置 → Templater
2. 在 **Template folder location** 中填入：

```
学习单元/_templates
```

3. 确保 **Trigger Templater on new file creation** 已开启（可选，建议开启）
4. 在 **Folder Templates** 中添加一条：
   - **Template file location**：`学习单元/_templates/learning-unit-template.md`
   - **Target folder**：`学习单元`

这样每次在 `学习单元/` 目录下创建新文件时，Templater 会自动加载模板。

## 2. 使用方法

### 方法一：自动触发（推荐）

1. 在 Obsidian 文件资源管理器中，右键 `学习单元/` 目录
2. 选择 **New note**
3. 输入文件名（如 `Текст 4.1.1 — Название статьи.md`）
4. Templater 自动弹出对话框，逐一询问变量值
5. 填写完成后，模板自动展开为完整的学习单元骨架

### 方法二：手动插入

1. 在 Obsidian 中新建一个空文件，保存到 `学习单元/` 目录
2. 按 `Ctrl+P`（或 `Cmd+P`），输入 `Templater: Insert template`
3. 选择 `learning-unit-template.md`
4. 逐一填写弹出的对话框

### 方法三：命令面板

1. 按 `Ctrl+P`，输入 `Templater: Create new note from template`
2. 选择模板和目标目录

## 3. 变量说明

模板使用 `tp.system.prompt()` 语法，运行时会弹出对话框逐个询问。以下是各变量的含义：

### YAML frontmatter 变量

| 变量 | 含义 | 示例 |
|---|---|---|
| 标题 | 文章编号和标题 | Текст 1.1.1 — Достопримечательности Мурома |
| 源文件路径 | 原书章节文件的 Obsidian 路径 | 章节/предисловие.md |
| 页码范围 | 原书页码（如 8-10） | 8-10 |
| 锚点 | 章节文件中的 Obsidian 锚点 | ^vm-b0-001 |
| 翻译文件路径 | Agent B 译稿路径，无则填 none | 翻译版/repair_2026-06-20/part1/... |
| 例句数据路径 | Agent A 词汇匹配数据路径 | _data/source_examples/... |
| 卡片目录路径 | 卡片草稿目录路径 | 卡片草稿/full_batch_2026-06-20/ |
| 文章类型标签 | 文章的阅读类型标签 | 泛读、信息函件、小说节选 |

### 元信息区域变量

| 变量 | 含义 | 示例 |
|---|---|---|
| 文章标题（俄语） | 与 frontmatter 标题相同 | Достопримечательности Мурома |
| OCR 页面链接 | 原始 OCR 文件的 wikilink | [[原始OCR/page_008]] |
| 阅读类型 | 原书标注的阅读类型 | 泛读、精读、搜索-浏览式阅读 |
| 词数 | 文章俄语原文词数 | 403 |
| 建议时间 | 原书建议的任务时间（分钟） | 15 |
| OCR 恢复说明 | OCR 质量评分和风险说明 | good:77, good:76 |

### 内容变量

| 变量 | 含义 | 示例 |
|---|---|---|
| 俄语任务说明 | 原书 Задание 的俄语原文 | Жизни людей в малых городах... |
| 中文任务说明 | 任务的中文翻译 | 小城市居民的生活与大都市居民... |
| 章节文件名 | 用于原文位置链接 | 章节/предисловие |
| 文本标题 | 用于原文位置链接的锚点 | Текст 1.1.1 — Достопримечательности Мурома |

## 4. 生成后的工作

模板生成的是骨架文件，以下内容需要手动填写：

1. **Section 1.1 / 1.2**：粘贴原书选择题和练习题
2. **Section 2**：粘贴完整俄语原文
3. **Section 3**：逐段填写中俄对照翻译
4. **Section 4**：分析文章主旨和结构
5. **Section 5**：选取长难句做语法解析
6. **Section 6**：填入词汇匹配数据
7. **Section 7**：链接已有的 Obsidian 卡片
8. **Section 8**：编写四遍学习建议
9. **Section 9**：记录待完善事项

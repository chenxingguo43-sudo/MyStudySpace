# В мире людей 听力口语 Markdown版

## 项目信息

- **书名**: В мире людей. Выпуск 2. Аудирование. Говорение
- **作者**: М.Н. Макова, О.А. Ускова
- **出版社**: Златоуст, Санкт-Петербург, 2016
- **页数**: 250 页
- **类型**: 听力口语 (Listening & Speaking)
- **考试等级**: ТРКИ-2 — ТРКИ-3
- **来源**: raw-0016 OCR 源包

## 目录结构

```
├── 原始OCR/          # 页级 OCR 文本（只读）
├── _data/            # source_manifest.json
├── _harness/         # 项目工具配置
├── 索引/             # 全书任务范围地图
├── 学习单元/         # 按主题/任务组织的学习单元
├── 翻译/             # 独立中文对照翻译层
├── 质量报告/         # 各批次质量报告
├── README.md         # 本文件
└── 封板说明.md       # 最终封板说明
```

## 学习单元结构（Writing-Speaking Profile 适配听力口语）

1. 元信息
2. 原书任务
3. 题型目标
4. 输入材料 / 原文
5. 审题拆解
6. 可复用表达
7. 输出框架
8. 范文或回答示例
9. 评分风险
10. 口语追问 / 听力变体
11. 词汇与真实例句
12. 学习卡片入口
13. 后续待完善

## 分层原则

- **原书内容**: 仅包含 OCR 原文和保守校订
- **学习辅助**: 生成的解释、答案建议、表达、语法、卡片
- **翻译层**: 完整中文对照（独立目录）

## 使用说明

所有学习单元使用 Obsidian 格式。翻译文件位于 `翻译/` 目录，与学习单元通过文件名对应。

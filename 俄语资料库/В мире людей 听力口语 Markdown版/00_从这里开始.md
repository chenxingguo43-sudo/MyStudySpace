# В мире людей 听力口语 Markdown版｜从这里开始

这本书现在有三层内容。不要从 `原始OCR/` 开始看，也不要把三个同名主题当成重复文件。

## 推荐阅读顺序

1. 先看 `翻译/`
   - 这是中俄对照阅读层，最适合直接学习和浏览。
   - 如果你想“像读书一样读”，优先从这里进。

2. 再看 `学习单元/`
   - 这是学习导览层：主题、任务类型、学习目标、后续卡片化入口。
   - 它不是全文正文，所以通常比 `章节/` 和 `翻译/` 短很多。

3. 需要核对俄语原文时看 `章节/`
   - 这是清洁源层：从 OCR 整理出的俄语原书内容。
   - 如果翻译或学习单元看起来不对，用这里核对。

4. 一般不要看 `原始OCR/`
   - 这是底层证据和回溯材料，不适合作为阅读入口。

## 目标

对15个主题的清洁源层（`章节/`）进行全文中文翻译，写入 `翻译/` 目录。

## 翻译范围

全文翻译：任务说明、所有题目（5题×5组）、所有选项（а/б/в）、音频文本、语言技能激活练习。

## 翻译格式

```markdown
### 对话标题
**俄语原文：** 原文内容
**中文翻译：** 翻译内容
```

## 翻译规则

1. 保留原文格式（段落、换行、对话格式）
2. 人名保留俄语，首次出现时括号注中文
3. 专有名词（电影名、地名）首次出现时中俄对照
4. OCR 明显错误处，翻译基于修正后的意思，并加注 `[OCR原文有误]`
5. 不确定的翻译加 `（？）` 标记

## 验证标准

| 检查项 | 通过条件 |
|--------|----------|
| `validate_translation_layer.py --mode complete` | PASS |
| 每个俄语段落 | 有对应中文翻译 |
| 翻译质量报告 | 更新完成率统计 |

## 失败处理

- Agent 验证 FAIL → 手动修复或重跑
- 章节内容过长（>600行）→ 只翻译前600行，剩余标记"待翻译"
- OCR 质量太差无法翻译 → 标记为已知风险

## 最终状态

- 全部翻译完成 → `sealed` 或 `sealed_with_known_risks`
- 部分无法翻译 → 已知风险，不阻塞封板

## 主要问题

范围地图统计中承认：

```text

```

但学习单元只有：

```text

```

没有对应：

```text

```

而 `原始OCR/page_105.md` 到 `page_112.md` 存在，其中 page_105 明确是考试模拟任务：

```text
Задания 1-5. Прослушайте диалог и выберите вариант ответа...
```

这是本轮最重要的覆盖缺口。

### 2. Source manifest 未封存

`_data/source_manifest.json` 中：

```json

```

但项目已生成 `封板说明.md`，两者矛盾。

### 3. 缺少专门 listening-speaking profile

README 中写明：

```text
Profile: writing-speaking（适配听力口语）
```

这说明 Claude 使用了近似模板，而不是专门听力口语结构。结果可用，但不够贴合听力书。

### 4. 疑似模板残留

存在：

```text

```

该文件内容是作者信息、系列教材、出版信息，不是真正“简历材料”。名称明显来自写作口语项目模板，应重命名或删除/并入 README。

### 5. Methodical commentary 重复

存在两个相关文件：

```text

学习单元/Методический комментарий.md
```

前者是完整主题单元，后者是简略版。建议保留一个主入口，另一个改成索引说明或删除，避免重复。

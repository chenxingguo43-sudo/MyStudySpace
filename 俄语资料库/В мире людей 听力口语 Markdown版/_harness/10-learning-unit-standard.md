# Learning Unit Standard — 听力口语适配

Profile base: writing-speaking (adapted for listening/speaking tasks)

## Section Structure

1. **元信息** — unit ID, topic, source pages, task type, OCR risk
2. **原书任务** — original task instructions from the book
3. **题型目标** — what the task tests (listening comprehension, oral production, etc.)
4. **输入材料 / 原文** — listening text, dialogue, monologue, stimulus material
5. **审题拆解** — how to approach the task, key points to identify
6. **可复用表达** — useful phrases, collocations, discourse markers
7. **输出框架** — structured template for oral response or written summary
8. **范文或回答示例** — model answer (generated, labeled as study support)
9. **评分风险** — common mistakes, scoring pitfalls
10. **口语追问 / 听力变体** — follow-up questions, alternative listening scenarios
11. **词汇与真实例句** — key vocabulary with real example sentences
12. **学习卡片入口** — links to flashcard-ready content
13. **后续待完善** — TODO items, needs_review flags

## Task Types for Listening-Speaking

- Аудирование + выбор (listening + selection)
- Аудирование + ответы на вопросы (listening + answer questions)
- Диалог / участие в диалоге (dialogue participation)
- Монолог / выскажите мнение (monologue / express opinion)
- Пересказ / изложение (retelling / summary)
- Телефонный звонок / расспросите (phone call / inquire)
- Лексика-грамматика (lexical-grammar activation)

## Universal Rules

- Source content first, study support second.
- Generated content must be labeled.
- Use source page links.
- Mark uncertain OCR as `needs_review`.
- Do not use code formatting for ordinary Russian prose.
- Translations go in `翻译/` directory.

## 4. 审题拆解

### Факс молодым женщинам

必须完成三件事：

1. 格式正确：факс 的格式要素（发件人、收件人、日期、页数等）。
2. 说明信息来源：По материалам газеты «Элитный персонал»...
3. 转述文章中的实用建议：时间安排、雇保姆、利用游乐场等。

факс 比普通信件更简洁，可以使用 общепринятые сокращения（如 тел., ув., и т.д.）。

### Диалог: интенции

重点不是长篇叙述，而是正确表达四种 интенция：

- 惊讶（удивление）：Не может быть! / Правда? / Удивительно!
- 感兴趣（заинтересованность）：Расскажи подробнее! / Это интересно!
- 赞同（одобрение）：Отличная идея! / Это заслуживает внимания!
- 同意（согласие）：Конечно, ты права. / Безусловно.

### Дружеское письмо-рекомендация

非正式推荐信需覆盖四个维度：

1. Личностные качества — 性格特点。
2. Деловые и профессиональные качества — 职业能力。
3. Факты из жизни — 具体事例。
4. Обстоятельства знакомства — 如何认识此人。

注意：письмо 是写给朋友的，可以用 неформальный тон。

### Эссе (三种类型)

三种类型的结构要求不同：

**а) Сопоставительное эссе：**

- 问题 → 不同观点 → 社会意识的变化 → 个人观点 → 预测

**б) Причинно-следственное эссе：**

- 问题 → 客观和主观原因 → 局势评估 → 个人观点 → 预测

**в) Эссе-доказательство：**

- 问题 → 正反论据 → 个人观点 → 结论

### Диалог с подругой

1. Реплика подруги о работе дома.
2. Реакция: удивление → заинтересованность → одобрение → согласие.
3. Использование синонимичных конструкций (для согласия) или антонимов (для несогласия).

### Письмо-рекомендация

1. Обращение к знакомому (неформальное).
2. Кого рекомендуете и на какую должность.
3. Личностные качества с примерами.
4. Профессиональные качества и достижения.
5. Обстоятельства знакомства.
6. Просьба рассмотреть кандидатуру.

### Эссе (общая схема)

1. Введение: формулировка проблемы.
2. Основная часть: аргументы / причины / точки зрения (в зависимости от типа).
3. Своя точка зрения.
4. Заключение: прогноз или вывод.

## 8. 评分风险

- Факс 格式错误（缺少发件人/收件人/日期/页数）会扣分。
- 不写信息来源，偏离任务要求。
- Диалог 中如果缺少指定的 интенция（惊讶、感兴趣、赞同、同意），会丢训练重点。
- Дружеское письмо 如果写成正式公函，语域不匹配。
- Письмо-рекомендация 如果遗漏四个维度（个人品质、职业能力、生活事实、相识经过）中的任何一个，内容不完整。
- Эссе 三种类型结构不同，不能混用。сопоставительное 强调对比，причинно-следственное 强调因果，доказательное 强调论证。
- 语法测试部分（виды глаголов、причастия、деепричастия）是独立的语法能力考查。
- работодатель / работник / рабочий / работа 的辨析是高频考点。

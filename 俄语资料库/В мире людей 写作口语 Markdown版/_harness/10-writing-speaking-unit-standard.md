# Writing Speaking Unit Standard

Each learning unit for this book should use this structure:

## 0. 元信息

Book, section, topic, page range, source OCR links, status.

## 1. 原书任务

Preserve the original Russian instructions and task materials.

## 2. 题型目标

Explain what the task trains: writing, speaking, dialogue, monologue, complaint letter, summary, argumentation, interview, or lexical-grammar production.

## 3. 审题拆解

Break down what the student must do and what constraints matter.

## 4. 可复用表达

Collect reusable Russian phrases from the unit and mark function: agreement, objection, clarification, complaint, argument, conclusion.

## 5. 输出框架

Provide a reusable structure for the answer. Mark generated frames clearly.

## 6. 范文或回答示例

Add model responses only after the source task is stable. Mark them as generated study support.

## 7. 评分风险

List common mistakes: missing source reference, wrong register, weak argument, grammar risk, time limit risk.

## 8. 词汇与真实例句

Match vocabulary to reliable source examples when possible.

## 9. 学习卡片入口

Link to cards after the unit is reviewed.

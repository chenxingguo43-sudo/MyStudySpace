# Acceptance Criteria

A later cleaned project can pass only when:

- Every source page has a corresponding `原始OCR/page_XXX.md` file.
- Every generated chapter links back to source pages.
- Every writing/speaking task preserves the original instruction.
- Model answers are clearly marked as generated or reconstructed, never confused with the original book.
- OCR uncertain pages are listed in `质量报告`.
- Normal Russian prose is written as Markdown text, not as inline code.

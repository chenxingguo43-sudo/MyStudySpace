## 4. 项目采用的原则

### 4.1 原书内容与学习辅助分离

- `> [!note] 原书内容`：仅放原书真实出现的题干、词表、输入材料、原始选项
- `> [!info] 学习辅助`：放参考答案、配对结果、范文、表达框架、语法解析、中文解释
- 学习辅助必须标注 `needs_review` 并写明：以下为学习辅助整理，不是原书答案，需人工复核。

### 4.2 配对题强规则

- 原书区保留原始左右列选项
- 不在原书区写 `xxx — zzz` 形式的已完成配对
- 已完成配对仅放在 `参考配对（学习辅助，needs_review）` 节

### 4.3 Source page wikilinks

- 每个学习单元的元信息包含 source page wikilinks
- 每个主要原书任务块标注来源页码
- 使用 `[[page_XXX]]` 格式

### 4.4 OCR 风险保留

- 不强行清洗 OCR 噪声
- 不确定处保留 `needs_review`
- 不把 OCR 残留伪装成原书内容

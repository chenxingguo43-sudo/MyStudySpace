# 全书任务范围地图质量报告

## 1. 任务概述

**目标：** 按 writing-speaking profile，为全书 18 个 Тема 创建任务范围地图，记录每个主题的 section、topic、page range、preparation pages、input text pages、writing task pages、speaking task pages、lexical-grammar test pages、keys/commentary pages、OCR risk、source links。

**约束：**
- 不生成学习单元
- 不改原始 OCR
- 不写范文
- 不补答案

**输入源：**
- `_harness/` 目录（8 个规范文件）
- `原始OCR/` 目录（292 个页面文件）
- `索引/页码索引.md`

**输出文件：**
- `索引/全书任务范围地图.md`
- `质量报告/全书任务范围地图报告.md`（本文件）

## 2. 执行方法

1. 读取 `_harness/` 全部规范文件，理解 writing-speaking profile 结构
2. 读取 `页码索引.md`，确认 292 页覆盖范围
3. 读取 OCR 页面 3–5，提取目录结构（5 个 Раздел，18 个 Тема）
4. 读取 OCR 页面 6–7，确认教材结构说明（模块化设计、任务类型、颜色编码）
5. 分三批并行扫描 OCR 页面（第 28–112 页、第 113–200 页、第 201–292 页），识别主题边界
6. 交叉验证：对比 TOC 页码与实际 OCR 内容中的标题标记
7. 汇总全部数据，生成范围地图

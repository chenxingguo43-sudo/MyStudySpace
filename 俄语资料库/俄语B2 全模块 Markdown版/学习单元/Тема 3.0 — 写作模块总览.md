## 1. 原书任务

> [!note] 原书内容
>
> ### 写作（总分 65 分，写作占 43 分 = 66%）
>
> **考试时间：55 分钟**
>
> 本部分主要考查考生写作方面的语言能力，包括语言表达、文章框架、词汇和语法掌握程度。考生需要完成 3 篇作文：
>
> **1. 推荐信（Рекомендательное письмо）**
> 根据所给信息（报刊上登出的推荐广告或推荐信），考生需要以书信格式给自己的朋友写一篇推荐信。考生要描述商品的优点，推荐朋友购买该产品，不要求书写地址和日期。词数要求：50-70 词。
>
> **2. 应用文（Деловая бумага / Официально-деловое письмо）**
> 根据题目所给信息，完成一篇应用文，考生要熟悉并掌握正式事务信函的格式，能够根据题目自己拟定合适的信函内容。词数要求：50-70 词。
>
> 题型涉及的类型包括：
> - 申请书（Заявление）
> - 推荐信、介绍信（Рекомендательное письмо, Письмо-представление）
> - 感谢信（Благодарственное письмо）
> - 留言条（Записка）
> - 请假条（Объяснительная записка）
> - 邀请函（Приглашение）
> - 投诉信（Жалоба）
> - 通知、通告（Объявление）
> - 简要记录、便条（Служебная записка）
>
> **3. 介绍信（Письмо-представление / Рекомендательное письмо-представление）**
> 以书信格式给雇主写一篇介绍信，推荐自己的朋友去工作，在信中需要描述被推荐人的品质和工作能力。本题不要求书写地址和日期。词数要求：80-100 词。

## 2. 题型目标

> [!info] 学习辅助

B2 写作模块（Письмо）是 ТРКИ-II 考试中分值最重的部分。它不仅仅测试学生"能不能写出正确的俄语句子"，而是从更高层面考察综合书面表达能力。

### 核心考察维度

| 维度 | 说明 |
|------|------|
| **语言表达（Языковое выражение）** | 能否用准确的词汇、地道的句式表达完整思想，是否能根据任务要求选择恰当的语体（正式 / 半正式 / 中性） |
| **文章框架（Структура текста）** | 能否按照俄语信函、应用文的标准格式组织文章，段落分明，逻辑连贯，衔接自然 |
| **词汇掌握（Лексический запас）** | 是否具备 B2 级别所需的词汇量，尤其是书信应用文场景下的功能性词汇（称呼、结尾礼貌用语、请求表达、说服表达等） |
| **语法掌握（Грамматическая правильность）** | 名词变格、动词变位、时体搭配、前置词使用是否正确，是否能运用 B2 级别复杂句（带连接词的复合句、形动词短语、副动词短语） |
| **任务完成度（Полнота выполнения задания）** | 是否完整覆盖了题目要求的所有信息点，是否遗漏关键内容 |

### 三种题型的能力侧重

1. **推荐信（Рекомендательное письмо）**：侧重说服性表达 + 描述商品优点的词汇 + 非正式书信格式
2. **应用文（Деловая бумага）**：侧重正式事务格式 + 简洁准确的行文 + 俄语公文套话（канцеляризмы）
3. **介绍信（Письмо-представление）**：侧重人物品质描述 + 工作能力推荐 + 半正式书信结构

> 三种题型虽然各有侧重，但底层能力是相通的：都要求考生掌握俄语书信的基本格式套路、功能性句型储备、以及 B2 级语法熟练度。

## 3. 输入材料/原文

> [!info] 学习辅助

本单元为模块总览，不涉及具体任务输入材料。以下为三种题型在考试中的典型输入形式：

### 题型 1：推荐信 — 典型输入

题目会提供一则简短的商品广告或推荐信息，包含：
- 商品名称与用途
- 商品的核心优点（2-3 点）
- 购买渠道或价格（可能给出）

考生需要将此信息转化为一封给朋友的书信，以第一人称推荐朋友购买。

### 题型 2：应用文 — 典型输入

题目给出一个具体情境，例如：
> Вы не можете прийти на занятие по русскому языку по уважительной причине. Напишите объяснительную записку преподавателю.

考生需要根据情境，自主拟定合适的信函内容，严格按照该类应用文的格式书写。

### 题型 3：介绍信 — 典型输入

题目给出被推荐人的基本信息，例如：
- 被推荐人的姓名、与考生的关系（朋友/同事）
- 被推荐人的主要品质（2-3 个关键词）
- 被推荐人的工作经历或技能
- 应聘的职位类型

考生需要将这些信息组织成一封给雇主的推荐信，以第三人称描述被推荐人的优势。

## 4. 审题拆解

> [!info] 学习辅助

### 写作模块整体审题策略

B2 写作考试时间紧张（55 分钟完成 3 篇作文），因此审题阶段的高效与准确至关重要。

#### 第一步：快速浏览三题（建议 2 分钟）

拿到试卷后，不要急于动笔。先用 2 分钟快速浏览三道写作题：

1. 确认每个题型的类别（推荐信 / 应用文 / 介绍信）
2. 标注关键词：每个题目中必须覆盖的信息点
3. 评估难度：判断哪个题目你最熟悉，哪个需要更多时间

#### 第二步：逐题审题（每道题 1-2 分钟）

审题时需要做以下工作：

1. **圈出任务动词（Глагол-задание）**
   - напишите（请写）、рекомендуйте（请推荐）、опишите（请描述）、объясните（请解释）、сообщите（请通知）、пригласите（请邀请）、поблагодарите（请感谢）
   - 这些动词决定了文本的交际目的

2. **提取信息要点**
   - 题目中给出的所有事实信息（人名、商品、品质、原因等）必须在作文中体现
   - 遗漏任何一个信息点都会扣分

3. **确定文体与语体（Стиль и регистр）**
   - 推荐信给朋友的 → 非正式/半正式（使用 ты 称呼）
   - 应用文给机构/上级的 → 正式（使用 Вы 称呼，公文套话）
   - 介绍信给雇主的 → 正式/半正式（使用 Вы 称呼，礼貌尊重）

4. **注意特殊指令**
   - "не указывайте адрес и дату"（不用写地址和日期）
   - "количество слов: 50-70"（词数要求）

#### 第三步：三题审题分工建议

| 题型 | 建议审题时间 | 核心注意点 |
|------|-------------|-----------|
| 推荐信 | 1 分钟 | 商品优点是否全部提取；朋友称呼用 ты |
| 应用文 | 2 分钟 | 应用文类型确认；格式是否正确；是否用 Вы |
| 介绍信 | 1 分钟 | 品质关键词；推荐对象的信息完整性 |

### 6.2 各题型词数要求与文本结构

#### 推荐信（50-70 词）结构模板

```
[开篇问候] — 1 句（约 5-8 词）
[引出推荐] — 1 句（约 8-10 词）
[描述优点 ①] — 1-2 句（约 12-15 词）
[描述优点 ②] — 1-2 句（约 12-15 词）
[收尾推荐 + 祝福] — 1-2 句（约 10-15 词）
[落款] — 1 句（约 3-5 词）
```

#### 应用文（50-70 词）结构模板

```
[对方称呼] — 1 句（约 2-3 词）
[正文：说明事由] — 1-2 句（约 10-15 词）
[正文：具体内容 / 请求 / 理由] — 2-3 句（约 20-30 词）
[结尾礼貌用语] — 1-2 句（约 10-15 词）
[署名 + 日期（如需）] — 1 句（约 3-5 词）
```

#### 介绍信（80-100 词）结构模板

```
[正式信头：致雇主] — 1 句（约 5-8 词）
[自我介绍 + 写信目的] — 1-2 句（约 10-15 词）
[被推荐人基本情况] — 1-2 句（约 10-12 词）
[品质描述 ① + 例证] — 1-2 句（约 12-15 词）
[工作能力描述] — 1-2 句（约 12-15 词）
[品质描述 ②] — 1-2 句（约 10-12 词）
[总结推荐 + 期望] — 1-2 句（约 12-15 词）
[正式落款] — 1 句（约 3-5 词）
```

### 6.3 检查清单（最后 4 分钟）

| 检查项 | 内容 |
|--------|------|
| 格式 | 书信格式是否正确（称呼、正文、落款） |
| 词数 | 是否在要求范围内（推荐信与应用文 50-70，介绍信 80-100） |
| 信息点 | 题目给出的所有信息是否都已覆盖 |
| 语体 | 称呼（ты / Вы）与文章类型是否匹配 |
| 指令 | 题目说"不写地址日期"的有没有遵守 |
| 语法 | 名词变格、动词变位是否一致（快速扫一遍） |
| 拼写 | 大写字母是否正确（Вы 在正式信函中大写）、标点符号 |

## 8. 评分风险

> [!info] 学习辅助

### 8.1 B2 写作评分标准概览

ТРКИ-II 写作评分从以下维度打分（各题型略有差异，但总体框架一致）：

| 评分维度 | 考察内容 | 占比（参考） |
|----------|---------|-------------|
| **任务完成度（Решение коммуникативной задачи）** | 是否覆盖所有信息点、是否达到交际目的 | 约 40% |
| **文本组织（Организация текста）** | 格式是否正确、段落是否分明、衔接是否连贯 | 约 20% |
| **语言准确性（Языковая правильность）** | 语法正确性、词汇使用准确性 | 约 25% |
| **词汇丰富度与语体（Лексическое разнообразие и стиль）** | 词汇是否丰富、语体是否恰当 | 约 15% |

### 8.2 常见扣分陷阱

#### 格式错误（Ошибки оформления）

| 错误类型 | 具体表现 | 扣分程度 |
|----------|---------|---------|
| 缺失称呼 | 信函没有开头称呼（如应写 Уважаемый / Здравствуй 等） | 中等 |
| 缺失落款 | 正文结束后没有署名或结束语 | 中等 |
| 日期地址多余 | 题目明确说"不要求写地址和日期"，考生仍然写了 | 轻微 |
| 应用文格式混乱 | 把请假条写成了普通书信格式 | 严重 |
| 正式信函用 ты | 给上级/机构的信函中使用了 ты 而非 Вы | 中等 |

#### 词数问题（Проблемы с объёмом）

| 问题 | 后果 |
|------|------|
| 词数严重不足（少于最低要求 30%） | 直接扣分，任务完成度判定为不足 |
| 词数超标过多（超过最高要求 50%+） | 不一定扣分，但可能暴露更多语法错误，且挤压其他题目的时间 |
| 为凑词数而重复啰嗦 | 文本组织得分降低 |

#### 语体与注册（Стиль и регистр）

| 问题 | 示例 |
|------|------|
| 正式信函用了口语化表达 | 用 Привет! 开头给雇主写信 |
| 朋友书信用了过于正式的表达 | 给朋友的信中用 Уважаемый 开头 |
| 忽视了收信人的身份差异 | 给教授的信与给同事的信用同样的语气 |
| Вы 的大写不一致 | 正式信函中 вы / вас / вам 应大写为 Вы / Вас / Вам |

#### 信息遗漏（Пропуск информации）

**这是扣分最严重的项目。** 遗漏任何一个题目中明确要求的信息点都会导致任务完成度被判定为不合格。前 2 分钟的"快速浏览三题"和紧接着的"逐题标关键词"流程的重要性的原因就在这里。

#### 语法高频失分点

- 动词完成体/未完成体混淆（特别是请求、建议类动词）
- 名词格搭配错误（如 рекомендую + 不定式 还是 рекомендую + что）
- 前置词后名词格错误（в течение + 二格，благодаря + 三格）
- 形容词短尾形式误用
- 副动词与形动词的错误使用

### 8.3 写作总分的通过门槛

写作部分 43 分中，通常 B2 级通过需要达到 **66% 左右**，即 **约 28-30 分**。这意味着：
- 每篇作文平均需要拿到及格以上的分数
- 只要不出现致命格式错误或重大信息遗漏，三篇中有一篇表现突出即可弥补另一篇的不足
- 应用文（Деловая бумага）因为格式要求最严格，是中国考生最容易失分的题型，需要重点准备

## 9. 写作变体

> [!info] 学习辅助
> needs_review — 以下变体分析基于考试大纲推断，非原书内容

### 9.1 推荐信（Рекомендательное письмо）可能变体

| 变体 | 描述 | 难度变化 |
|------|------|---------|
| 推荐商品（标准题型） | 给朋友推荐一种商品（广告推荐信） | 基准 |
| 推荐餐厅 / 旅游地点 | 给朋友推荐某个地方或体验 | 略低（词汇更日常） |
| 推荐书籍 / 电影 | 给朋友推荐文化产品 | 略低（描写性表达为主） |
| 推荐服务 | 推荐一种服务而非实物商品（如 курсы, клуб） | 略高（抽象表达多） |

### 9.2 应用文（Деловая бумага）可能变体

这是变体最多的题型。以下是考试中可能出现的 8 种应用文类型：

| 类型 | 俄语名称 | 核心交际目的 | 格式特点 |
|------|---------|-------------|---------|
| 申请书 | Заявление | 申请某事（入学、请假、入职等） | 含 кому + от кого + 正文 + 日期签名 |
| 推荐信/介绍信（正式） | Рекомендательное письмо / Письмо-представление | 正式推荐某人 | 与题型 3 的差异在于收信人身份和正式程度 |
| 感谢信 | Благодарственное письмо | 表达感谢 | 正式场合，但较少出题 |
| 留言条 | Записка | 简短留言告知某事 | 最简洁，通常 30-50 词，格式最松散 |
| 请假条 | Объяснительная записка | 解释缺席原因 | 需说明理由 + 表示歉意 |
| 邀请函 | Приглашение | 邀请参加活动 | 需包含时间、地点、活动内容 |
| 投诉信 | Жалоба | 投诉问题并要求解决 | 需事实描述 + 期望解决方案 |
| 通知/通告 | Объявление | 公开通知信息 | 第三人称，无称呼落款 |

### 9.3 介绍信（Письмо-представление）可能变体

| 变体 | 描述 | 难度变化 |
|------|------|---------|
| 推荐朋友（标准题型） | 给雇主推荐朋友的工作能力 | 基准 |
| 推荐同事 | 给另一个部门/公司推荐现任或前任同事 | 略高（需专业词汇） |
| 推荐学生 | 给导师/学校推荐学生（学术推荐信） | 略高（学术词汇） |
| 自我推荐 | 给自己写一封求职推荐信（混合题型） | 高（第一人称 + 自我推销） |

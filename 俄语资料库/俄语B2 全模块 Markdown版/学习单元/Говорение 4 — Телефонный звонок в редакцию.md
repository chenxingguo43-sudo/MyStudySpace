### (五) 给编辑部打电话咨询（第 14 题）

考生须先读报纸中的广告，并对广告很感兴趣，根据给出的电话向对方进行详细咨询。此时，考生是提问者（整个对话过程中考生只能提问），考官只是回答考生提出的问题。准备时间：3分钟。回答时间：3~5分钟。

Студентов и молодых специалистов, желающих поехать на краткосрочную стажировку в один из престижных университетов мира, приглашают принять участие в конкурсе.

— участие в симпозиумах и конференциях.

Более подробную информацию Вы можете получить по телефону:

8 (812) 117 - 21 - 45.

Это объявление вас заинтересовало. Позвоните по указанному телефону и расспросите обо всем как можно более подробно, чтобы оценить свои шансы на победу в конкурсе.

## 2. 题型目标

> [!info] 学习辅助

这道题是整个 ТРКИ-II 口语部分最独特的题型：你只需要提问，不需要回答。但这并不意味着它简单 — 你需要在 3-5 分钟内持续不断地提出有意义、有逻辑、有层次的问题，而不能重复或枯竭。

### 核心考查维度

| 维度 | 说明 |
|------|------|
| **信息提取** | 从广告中识别出哪些信息已知、哪些信息缺失、哪些需要追问 |
| **疑问句构造** | 能准确使用各种疑问词（кто, что, где, когда, какой, сколько, как, почему...）以及灵活运用不同疑问句式 |
| **逻辑性提问** | 问题不是随机堆砌，而是有逻辑递进：从概括到具体、从大到小 |
| **礼貌的电话沟通** | 使用电话开场白（Здравствуйте! Я по поводу объявления...）、过渡语（Скажите, пожалуйста... / Ещё один вопрос...）、结束语（Спасибо за информацию!） |
| **追问能力** | 能够基于"考官的回答"（考官只说基本信息）提出更深层的问题 |
| **时间管理与持续性** | 3-5 分钟内持续输出问题不间断，至少 10-15 个问题 |

### 本题的特殊规则

- 你**只能提问**，不能陈述，不能表达自己的意见
- 考官负责回答（但通常是简短的，不会替你展开）
- 你需要在 3 分钟准备时间内读完广告、梳理信息缺口、规划提问路线
- 问题需要围绕"评估自己获奖几率"这一核心目标

## 4. 审题拆解

> [!info] 学习辅助

### 第一步：分析广告 — 已知信息 vs 信息缺口

| 广告中已给出的信息 | 你需要追问的信息 |
|-------------------|---------------|
| 针对学生和青年专家 | 年龄限制？学历要求？ |
| 短期实习 | 具体多长时间？（几天/几周/几个月） |
| 世界知名大学之一 | 具体是哪个大学？在哪个国家？哪个城市？ |
| 掌握外语 | 哪些外语？需要什么水平（B1/B2/C1）？是否需要证书？ |
| 课题对俄罗斯国情的现实意义 | 什么算"现实意义"？能否举例？ |
| 有科学论文发表 | 需要几篇？什么级别期刊？什么领域？ |
| 参加过研讨会和会议 | 什么规模的？国际还是国内？需要证明材料吗？ |
| 电话 | 截止日期？何时公布结果？获奖人数？ |

### 第二步：规划提问逻辑树

```
[第一层：项目基本信息]
  -> 具体大学名称？地点？国家？
  -> 实习方向/专业领域？
  -> 实习时长？起止日期？

[第二层：参赛条件细节]
  -> 外语：哪些语种？水平要求？证书要求？
  -> 论文：数量？级别？领域限制？
  -> 会议：规模？级别？证明材料？
  -> 课题现实意义：评判标准？举例？

[第三层：申请流程与结果]
  -> 如何提交申请？截止日期？
  -> 获奖名额？选拔流程？
  -> 何时公布结果？如何通知？
  -> 实习费用？是否有资助？

[第四层：自我评估类]
  -> 根据你的条件，对照已获得的信息，继续追问对自己的具体情况是否适用
```

### 第三步：3 分钟准备时间分配

| 时间 | 操作 |
|------|------|
| 0:00-0:30 | 阅读广告，划出已知信息关键词 |
| 0:30-1:30 | 列出信息缺口，写出 15+ 个问题关键词（只写提问词 + 话题，不写完整句子） |
| 1:30-2:30 | 将问题按逻辑树排序 |
| 2:30-3:00 | 默念开场白和前 3 个问题，确保流畅 |

## 6. 输出框架

> [!info] 学习辅助

### 对话全流程框架（3-5 分钟）

```
[ОТКРЫТИЕ] 开场 — 15-20 秒
  - 电话问候 + 说明来电原因
  - 表示兴趣 + 请求提问
  - 第一个问题（通常是最大的信息缺口：哪个大学？）

[ОСНОВНАЯ ЧАСТЬ] 主体提问 — 2-3.5 分钟, 10-15 个问题
  第 1 组: 项目基本信息（3-4 个问题）
    - 哪个大学？在哪个国家/城市？
    - 实习方向和专业领域？
    - 实习时长和起止日期？
    - 是否有资助/奖学金？
  
  第 2 组: 参赛条件细节（4-5 个问题）
    - 外语：哪些语种？需要什么水平？是否需要证书？
    - 论文：需要几篇？什么级别期刊？
    - 会议：国际还是国内？需要什么证明？
    - 课题现实意义：具体评判标准是什么？
  
  第 3 组: 申请流程（3-4 个问题）
    - 如何提交申请？截止日期？
    - 需要哪些文件？
    - 获奖名额有几个？
    - 何时公布结果？

  第 4 组: 追问考官回答 + 自我评估（2-3 个问题）
    - 基于考官已经给出的回答，做进一步追问
    - 将自己的条件与已了解的要求对照提问

[ЗАКРЫТИЕ] 结束 — 15-20 秒
  - 总结 + 感谢
  - 表示还会联系
  - 告别
```

### 问题数量指导

| 时间 | 最少问题数 | 理想问题数 |
|------|-----------|-----------|
| 3 分钟 | 8-10 个 | 12 个 |
| 4 分钟 | 10-12 个 | 15 个 |
| 5 分钟 | 12-15 个 | 18-20 个 |

每个问题 + 考官简短回答 大约需要 15-20 秒。所以 4 分钟大约可以容纳 12-16 个问答来回。

| 技巧 | 示例 |

## 8. 评分风险

> [!info] 学习辅助

### 常见扣分点

| 风险类型 | 具体表现 | 扣分程度 | 避坑策略 |
|----------|---------|---------|---------|
| **问题枯竭** | 问了 5-6 个问题后不知道该问什么了，沉默或重复 | 严重 | 用逻辑树确保至少 15 个问题储备 |
| **不是提问而是陈述** | "Я думаю, что..." / "Мне кажется..." — 你只能提问！ | 中等 | 所有句子以疑问词或 Скажите, пожалуйста 开头 |
| **问题过于通用** | 所有问题都用 Скажите, пожалуйста 开头，单调 | 轻微 | 多样化疑问词和过渡表达 |
| **跳过关键信息** | 广告中已给出的信息没有追问 | 严重 | 广告中每条"参赛条件"都必须至少问 2 个追问 |
| **缺乏逻辑顺序** | 先问截止日期，又问大学名称，又问论文要求，来回跳跃 | 中等 | 严格按逻辑树顺序推进 |
| **问题过于简短** | "Какой университет?"（2 个词）— 太生硬 | 轻微 | 用礼貌框架包装：Скажите, пожалуйста, в каком именно университете... |
| **遗漏电话礼仪** | 没有开场白直接提问，或没有结束语就挂断 | 轻微-中等 | 完整对话必须有：开场白 + 提问 + 结束语 |
| **重复提问** | 同一个信息用不同句式问两次 | 中等 | 仔细听考官的回答，记下已经获得的信息 |
| **忘记考试目标** | 问题与"评估获奖几率"无关 | 中等 | 每题问了之后，想想是否帮助自己判断能不能获奖 |

## 9. 口语追问 / 练习变体

> [!info] 学习辅助
> needs_review — 以下追问与变体为 AI 扩展生成

### 9.1 考官可能在对话中引导追问

如果在考试中你的提问显得断续或不够，考官可能会用简短的提示引导你：

1. **"Что ещё Вас интересует?"** — 您还对什么感兴趣？（暗示你该继续问了）
2. **"Может быть, у Вас есть ещё вопросы?"** — 也许您还有其他问题？（给你机会补充）
3. **"Вы хотите узнать что-то ещё?"** — 您还想了解些什么吗？

如果听到这些提示，说明你的问题量还不够，立即从逻辑树的下一层挑选 2-3 个新问题提出。

### 9.2 练习变体

**变体 1：信息缺口扫描训练** — 拿到任何一则广告（不限于考试内容），5 分钟内列出 20 个可提的问题

**变体 2：问题排序训练** — 将 20 个随机写出的问题按逻辑树重新排序（概括->具体，大->小）

**变体 3：限时提问挑战** — 给一则新广告，3 分钟准备，然后用 4 分钟连续提问（录音），确保不重复不停顿

**变体 4：多广告旋转** — 准备 3-5 则不同类型的广告（实习、课程、活动、招聘），每则做一次完整的 3 分钟准备 + 4 分钟提问

**变体 5：角色扮演** — 请语伴扮演接电话的人，你提问。考官的回答会影响你下一个问题的走向（训练即时应变）

**变体 6："只提问"约束训练** — 在日常对话中练习 2 分钟"只能提问不能陈述"（不限话题），训练快速生成问题的能力

### 每日练习建议

- **第 1 天**：熟记 7 种疑问词 + 至少 2 种礼貌框架表达
- **第 2 天**：信息缺口扫描训练（变体 1），用原书广告列出 20 个问题
- **第 3 天**：问题排序训练（变体 2），练习逻辑树构建
- **第 4 天**：限时提问挑战（变体 3），确保 4 分钟不间断
- **第 5 天**：多广告旋转（变体 4），训练信息提取速度
- **第 6 天**：角色扮演（变体 5），应对考官的随机回答
- **第 7 天**：完整 15 分钟模拟（3 分钟准备 + 5 分钟提问 + 录音自查）

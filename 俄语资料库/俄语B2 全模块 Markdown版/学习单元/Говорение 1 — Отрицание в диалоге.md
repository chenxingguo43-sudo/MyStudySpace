## 1. 原书任务

> [!note] 原书内容

### (一) 用否定形式完成对话（第 1-4 题）

考官根据题目所给的内容朗读四个句子，考生需要用否定的形式来回答（1~4题）。每道题答题时间1.5分钟。

Задания 1–4. Представьте себе, что Вы с другом на автобусной экскурсии. Ему экскурсия понравилась, а Вам нет. Возразите собеседнику. Используйте антонимичные оценочные слова.

1. — (Звучит реплика)

2. — (Звучит реплика)

3. — (Звучит реплика)

4. — (Звучит реплика)

### (二) 按要求完成对话（第 5-8 题）

考官根据题目所给的内容朗读四个句子，考生需按要求完成对话，表达同意、怀疑、高兴、惊讶、郁闷、建议等意图（5~8题）。每道题答题时间1.5分钟。

Задания 5 – 8. Вы разговариваете с деканом факультета, который сообщает Вам о будущей стажировке. Отреагируйте на реплики собеседника, выражая заданное намерение.

5. Выразите радость:
— (Звучит реплика)
— ......

6. Выразите удивление:
— (Звучит реплика)
— ......

7. Выразите сожаление:
— (Звучит реплика)
— ......

8. Выразите пожелание:
— (Звучит реплика)

## 2. 题型目标

> [!info] 学习辅助

### 子题型 (一)：用否定形式完成对话

本题型考查以下核心能力：

| 考查维度 | 说明 |
|----------|------|
| **听力理解** | 听懂考官朗读的俄语句子，理解其核心评价内容 |
| **反义词调动** | 快速想到句中评价性词语的反义词（如 увлекательный -> скучный, живописный -> некрасивый, комфортабельный -> грязный, вежливый -> невоспитанный） |
| **否定表达结构** | 使用否定句式（не + 形容词短尾、отрицательные конструкции）表达相反观点 |
| **即时应变** | 1.5 分钟内完成听解 + 反义词调取 + 输出，不允许长时间停顿 |
| **语用恰当性** | 反对但不冒犯 — 使用 А я считаю, что... / Мне кажется, что... / На самом деле... 等缓冲语 |

### 子题型 (二)：按要求完成对话

本题型考查以下核心能力：

| 考查维度 | 说明 |
|----------|------|
| **意图识别与执行** | 准确理解指令词（радость / удивление / сожаление / пожелание / согласие / сомнение），并产出对应的情感表达 |
| **情感词汇储备** | 能调用表达高兴（Здорово! / Как я рад!）、惊讶（Неужели? / Вот это да!）、遗憾（Очень жаль / Как жаль）、祝愿（Желаю вам...）的公式化表达 |
| **语境适配** | 应对的是与系主任（декан）的对话 — 需要用礼貌形式（Вы），语气介于正式与半正式之间 |
| **语调配合** | 不仅词汇要表达意图，语调也要匹配（高兴时上扬、遗憾时下沉） |

### 两个子题型的共同特征

- 都是**听-说联动**题型：先听考官说，再自己说
- 都是**受限输出**：不是自由表达，而是在给定的语义框架内作答
- 都要求**1.5 分钟内完成**，压力测试意图明显
- 共同底层能力：**B2 级形容词/副词/评价性词汇的主动输出能力**

## 3. 输入材料 / 原文

> [!note] 原书内容

### 子题型 (一) 参考答案（原书提供）

**题目场景：** 你和朋友一起参加巴士观光游。朋友很喜欢这次游览，而你不喜欢。反驳对方，使用反义的评价性词语。

1. — Рассказ экскурсовода был очень увлекательным. (考官朗读)
— А я считаю, что его рассказ очень скучный. (考生回答)

2. — Кроме того, мы побывали в таких живописных местах города! (考官朗读)
— Места совсем некрасивые. (考生回答)

3. — Автобус был очень комфортабельным. (考官朗读)
— Автобус был очень грязным. (考生回答)

4. — И еще мне понравились люди, которые ездили с нами на экскурсию. Все такие вежливые, культурные. (考官朗读)
— Они не воспитанные, громко шумели. (考生回答)

> [!info] 学习辅助

**答案中的反义词对:**

| 考官语句中的词 | 考生回答中的反义词 |
|---------------|-------------------|
| увлекательный (引人入胜的) | скучный (无聊的) |
| живописный (风景如画的) | некрасивый (不漂亮的) |
| комфортабельный (舒适的) | грязный (脏的) |
| вежливые, культурные (有礼貌的、有文化的) | не воспитанные (没教养的) |

### 子题型 (二) 参考答案（原书提供）

**题目场景：** 你在与系主任交谈，他告知你关于未来实习的消息。按指定的意图回应对方的发言。

**5. Выразите радость:**

— Вам предоставляется возможность поехать в Россию на языковую стажировку. (考官朗读)
— Здорово, я уже давно мечтаю побывать в России. (考生回答)

**6. Выразите удивление:**

— Вы получили такую возможность благодаря тому, что Вы выиграли конкурс "Знаете ли Вы Россию". (考官朗读)
— А именно я выиграл конкурс? (考生回答)

**7. Выразите сожаление:**

— Эта стажировка двухнедельная. (考官朗读)
— Очень жаль, только две недели. (考生回答)

**8. Выразите пожелание:**

— Вы можете высказать свои пожелания по поводу организации поездки. (考官朗读)
— Желаю всем удачной стажировки. (考生回答)

> [!info] 学习辅助

**答案中的意图-表达映射:**

| 意图 | 核心表达 | 扩展技巧 |
|------|---------|---------|
| радость (高兴) | Здорово, ... | 加上个人情感（я уже давно мечтаю...）让回答更自然 |
| удивление (惊讶) | А именно я...? | 用反问句确认信息，表达不敢相信 |
| сожаление (遗憾) | Очень жаль, ... | 加上补充说明（только две недели）解释遗憾的原因 |
| пожелание (祝愿) | Желаю всем... | 用复数（всем）扩大祝愿范围，显得大方得体 |

## 4. 审题拆解

> [!info] 学习辅助

### 子题型 (一) 审题流程

**第一步：听清评价对象和评价词**

考官朗读的句子通常遵循模式：`[评价对象] + [谓语/系词] + [正面评价词]`

你需要迅速识别:
1. 他们在谈论什么？（рассказ экскурсовода / места / автобус / люди）
2. 用的什么正面评价词？（увлекательный / живописный / комфортабельный / вежливый）

**第二步：快速调取反义词**

最常用的 B2 口语评价性反义词对（建议熟记）：

| 正面评价 | 反义否定 |
|----------|---------|
| интересный | скучный / неинтересный |
| хороший | плохой |
| красивый | некрасивый |
| удобный | неудобный |
| дорогой (贵的) | дешёвый (便宜的) |
| чистый | грязный |
| тихий | шумный |
| вкусный | невкусный |
| быстрый | медленный |
| тёплый | холодный |
| приятный | неприятный |
| вежливый | грубый / невоспитанный |
| умный | глупый |
| простой | сложный |
| полезный | бесполезный / вредный |

**第三步：套入缓冲句式后说出反义评价**

不要直接喊出一个单词 — 用缓冲句式包装你的反对：

- А я считаю, что...
- А мне кажется, что...
- На самом деле...
- Я бы сказал(а), что...
- По-моему, всё наоборот: ...
- Не соглашусь: ...

### 子题型 (二) 审题流程

**第一步：看清指令词**

每道题有一个明确的意图词。你必须在回答的第一句话中直接表达该意图：

| 指令 | 最快表达 |
|------|---------|
| Выразите радость | Здорово! / Как я рад(а)! / Вот это новость! / Прекрасно! |
| Выразите удивление | Неужели? / Правда? / Вот это да! / Я не ожидал(а)! |
| Выразите сожаление | Очень жаль. / Как жаль. / Жаль, что... |
| Выразите пожелание | Желаю... / Хочу пожелать... / Пусть... |
| Выразите согласие | Полностью согласен(на). / Вы правы. / Да, действительно. |
| Выразите сомнение | Сомневаюсь. / Вряд ли. / Не уверен(а), что... |

**第二步：听清考官说的内容**

考官的话是你的"话题跳板"。你的回答要在表达意图的同时，回扣对方的内容：
- 高兴 -> 你高兴的是什么？（стажировка в Россию -> я давно мечтал）
- 惊讶 -> 你惊讶的是什么？（я выиграл конкурс -> именно я?）
- 遗憾 -> 你遗憾的是什么？（двухнедельная -> только две недели）
- 祝愿 -> 对什么祝愿？（организация поездки -> желаю удачной стажировки）

**第三步：注意对话对象的身份**

本题对象是系主任（декан）-> 必须使用 Вы 形式！所有的动词变位、代词都要用尊敬体：

- ты хочешь -> Вы хотите
- ты можешь -> Вы можете
- твой -> Ваш
- тебе -> Вам

## 5. 可复用表达

> [!info] 学习辅助
> needs_review — 以下部分俄语表达为 AI 扩展生成，未经母语者校对

### 5.1 否定/反对的缓冲句式

| 功能 | 俄语表达 | 中文含义 |
|------|---------|---------|
| 表达不同意 | А я считаю, что... | 而我认为…… |
| 表达不同意（更委婉） | Мне кажется, что... | 我觉得…… |
| 表达不同意（温和纠正） | На самом деле... | 实际上…… |
| 表达不同意（个人意见） | По-моему, всё наоборот: ... | 依我看，恰恰相反：…… |
| 直接反对 | Не соглашусь. + объяснение | 我不同意。+ 解释 |
| 引入反对 | Я бы сказал(а), что... | 我会说…… |

### 5.2 表达高兴 (радость) 的句式

| 俄语表达 | 中文含义 | 正式程度 |
|----------|---------|---------|
| Здорово! | 太棒了！ | 口语 |
| Как я рад(а)! | 我多高兴啊！ | 半正式 |
| Вот это новость! | 这消息太好了！ | 口语 |
| Прекрасно! | 好极了！ | 半正式 |
| Какая приятная новость! | 多么好的消息！ | 半正式 |
| Я так рад(а) это слышать! | 听到这个我太高兴了！ | 半正式 |

### 5.3 表达惊讶 (удивление) 的句式

| 俄语表达 | 中文含义 | 正式程度 |
|----------|---------|---------|
| Неужели? | 真的吗？/不会吧？ | 中性 |
| Правда? | 真的吗？ | 中性 |
| Вот это да! | 真没想到！ | 口语 |
| Я не ожидал(а)! | 我没料到！ | 半正式 |
| Разве это возможно? | 这可能吗？ | 半正式 |
| А именно...? | 就是……？ | 中性 |

### 5.4 表达遗憾 (сожаление) 的句式

| 俄语表达 | 中文含义 | 正式程度 |
|----------|---------|---------|
| Очень жаль. | 很遗憾。 | 中性 |
| Как жаль! | 多遗憾啊！ | 中性 |
| Жаль, что... | 遗憾的是…… | 中性 |
| К сожалению, ... | 很遗憾（书面偏向） | 正式 |
| Мне жаль, что... | 我为……感到遗憾 | 半正式 |
| Обидно, что... | 遗憾的是……（带一点懊恼） | 口语 |

### 5.5 表达祝愿 (пожелание) 的句式

| 俄语表达 | 中文含义 | 正式程度 |
|----------|---------|---------|
| Желаю + кому + чего (родительный падеж) | 祝某人某事 | 通用 |
| Хочу пожелать... | 我想祝愿…… | 半正式 |
| Пусть... | 愿…… | 中性 |
| Надеюсь, что... | 我希望…… | 中性 |
| Удачи в...! | 祝……顺利！ | 口语 |

### 5.6 表达同意 (согласие) 的句式

| 俄语表达 | 中文含义 | 正式程度 |
|----------|---------|---------|
| Полностью согласен(на). | 完全同意。 | 半正式 |
| Вы правы. | 您说得对。 | 正式 |

| Я тоже так думаю. | 我也这么认为。 | 中性 |

| 俄语表达 | 中文含义 | 正式程度 |

## 6. 输出框架

> [!info] 学习辅助

### 6.1 子题型 (一) 回答框架（1.5 分钟）

```
[缓冲反对句式]       ~2 秒（选择并说出一个缓冲句式）
[给出反义评价]       ~5 秒（说出核心反义词，可加程度副词）
[（可选）补充说明]   ~3 秒（解释一下为什么你有不同的感觉）
```

**实战示例:**

> 考官: "Рассказ экскурсовода был очень увлекательным."
>
> 你的回答框架:
> [缓冲] А я считаю, что
> [反义] его рассказ очень скучный.
> [补充] Он говорил слишком монотонно.

### 6.2 子题型 (二) 回答框架（1.5 分钟）

```
[意图核心表达]       ~2 秒（Здорово! / Жаль. / Неужели? 等）
[回扣考官内容]       ~5 秒（引用或转述考官的话，表达你的情感）
[（可选）补充扩展]   ~3 秒（增加一句自然的延伸）
```

**实战示例:**

> 考官: "Вам предоставляется возможность поехать в Россию на языковую стажировку."
> 指令: Выразите радость.
>
> 你的回答框架:
> [意图] Здорово,
> [回扣] я уже давно мечтаю побывать в России.
> [补充] Это прекрасная возможность!

### 6.3 通用时间分配（1.5 分钟 = 90 秒）

| 阶段 | 操作 | 时间 |
|------|------|------|
| 聆听 | 听考官朗读句子，抓取关键词 | ~10 秒 |
| 思考 | 确认意图/寻找反义词/组织回答 | ~15-20 秒 |
| 输出 | 说出你的回答 | ~10-15 秒 |
| 余量 | 缓冲时间（应对紧张和停顿） | ~45 秒 |

> 注意：1.5 分钟看起来很长，但在口语考试中紧张时会感觉很短。平时练习时要有意识地训练 15-20 秒内完成"听->思考->说"的流程。

## 7. 范文或回答示例

### 7.1 子题型 (一) 补充练习示例

> [!info] 学习辅助

**新场景模拟：在餐厅吃饭，朋友觉得很好，你觉得不好**

| 考官可能说的句子 | 你的回答（否定 + 反义词） |

| Еда здесь очень вкусная. | А я считаю, что еда совсем невкусная, слишком солёная. |
| Обслуживание было быстрым. | По-моему, обслуживание было очень медленным. Мы ждали полчаса. |
| Здесь очень уютная атмосфера. | Мне кажется, здесь слишком шумно и неуютно. |
| Цены вполне доступные. | Я бы не сказал(а): цены довольно высокие для такого качества. |

**新场景模拟：讨论一部电影，朋友喜欢，你不喜欢**

| 考官可能说的句子 | 你的回答（否定 + 反义词） |
|---|---|
| Фильм был очень интересным. | А мне фильм показался скучным, сюжет предсказуемый. |
| Актёры играли великолепно. | На самом деле, игра актёров была слабой и неубедительной. |
| Музыка в фильме прекрасная. | Я бы сказал(а), что музыка совсем не подходит этому фильму. |
| Концовка была неожиданной. | По-моему, концовка как раз была очень предсказуемой. |

## 8. 评分风险

> [!info] 学习辅助

### 8.1 子题型 (一) 常见扣分点

| 风险 | 具体表现 | 避坑策略 |
|------|---------|---------|
| **只给单词，不给句子** | 考官说了一长句，考生只回答 "скучный" | 必须用完整句子！至少是 А я считаю, что... + 评价 |
| **反义词找不到** | 听到 живописный 想不起反义词，卡壳 | 提前熟记常见评价词反义词对（见第 4 节表） |
| **否定范围错误** | 把 не 放错位置 | 注意 не 的位置：некрасивый（一个词） |
| **忘了题目要求用反义词** | 直接说 Я не согласен 然后不给替代评价 | 关键评分点：必须使用 антонимичные оценочные слова |
| **用了太多词，偏离要点** | 长篇大论解释为什么不喜欢 | 保持在 1-2 句话以内 |

### 8.2 子题型 (二) 常见扣分点

| 风险 | 具体表现 | 避坑策略 |
|------|---------|---------|
| **意图表达不明确** | 考官说 Выразите радость，考生回答 Спасибо（这是感谢，不是高兴） | 第一句话必须直接命中意图 |
| **忘了用 Вы 称呼** | 和系主任说话却用 ты | 审题阶段就确认对话对象的身份 |
| **回答过于简略** | 只说 Здорово! 没有任何后续 | 最少 2 句话：意图词 + 回扣内容 |
| **混淆 сожаление 和 извинение** | 把遗憾（Жаль）和道歉（Извините）弄混 | сожаление — 对事情感到可惜；извинение — 对自己的过错道歉 |

### 8.3 通用风险

| 风险 | 说明 |
|------|------|
| **听力失误** | 如果没听懂考官说的完整内容，至少抓住关键词（名词和形容词），然后基于关键词作答 |
| **沉默过长** | 1.5 分钟内沉默超过 20 秒，考官可能判断为无法完成 |
| **语法性别错误** | 女性考生注意用 рада 而非 рад；过去时注意性别：я сказал(а) |

## 9. 口语追问 / 练习变体

> [!info] 学习辅助
> needs_review — 以下追问与变体为 AI 扩展生成

### 9.1 考官可能的口语追问

1. **Почему Вы так думаете?** — 你为什么这么想？
   -> 回答要点：给出一个简短的支撑理由，1-2 句话即可

2. **Всегда ли Вы выражаете своё несогласие прямо?** — 你总是直接表达自己的不同意吗？
   -> 回答要点：说明自己在不同场合下表达反对的方式（正式场合委婉 / 朋友直接）

3. **Какие эмоции Вам труднее всего выражать по-русски?** — 哪些情感你用俄语最难表达？
   -> 回答要点：承认困难 + 举一个例子 + 说明你在练习

### 9.2 练习变体

**变体 1：速度反应训练** — 准备 10 个正面形容词卡，看到卡片 3 秒内说出反义词 + 一个完整否定句

**变体 2：意图切换训练** — 准备一段考官可能说的话，随机抽一张意图卡（радость/удивление/сожаление/пожелание/согласие/сомнение），10 秒内给出符合该意图的回应

**变体 3：角色身份切换** — 同句考题，分别以学生->系主任（用 Вы）和朋友->朋友（用 ты）回应，注意动词和代词的变化

**变体 4：双人角色扮演** — 语伴扮演考官朗读句子，考生作答，交换角色

**变体 5：限时全流程模拟** — 8 道题连续进行，每道题计时 1.5 分钟，全程录音后回听检查

## 11. 学习卡片入口

> [!info] 学习辅助

### 推荐配套学习卡片

| 卡片方向 | 内容 | 目标 |
|----------|------|------|
| 正面 -> 反面 | 正面评价词 -> 反面评价词（如 увлекательный -> ?） | 反义词快速反应 |
| 正面 -> 反面 | 意图词（радость）-> 2 种表达句式 | 意图表达多样化 |
| 正面 -> 反面 | 考官句子录音 -> 口头回答（自录音对比） | 听-说联动训练 |
| 正面 -> 反面 | 缓冲句式（А я считаю...）-> 使用场景与正式程度 | 语用恰当性 |
| 正面 -> 反面 | 评分风险场景描述 -> 避坑策略 | 考前自查 |

### 每日练习建议

- **第 1 天**：熟记 12 组核心反义词对 + 6 种意图的基本表达式
- **第 2 天**：速度反应训练 — 看正面词 3 秒内说出反义词（12 组 x 3 轮）
- **第 3 天**：意图切换训练 — 同句换 6 种意图各说一遍
- **第 4 天**：角色身份切换训练 — 同一场景分别对 декан（Вы）和 друг（ты）作答
- **第 5 天**：限时全流程模拟 — 8 题连续 1.5 分/题，录音自查
- **第 6 天**：重点回练薄弱意图（如 сомнение 和 сожаление 容易混淆）
- **第 7 天**：双人角色扮演模拟（需要语伴或 AI）

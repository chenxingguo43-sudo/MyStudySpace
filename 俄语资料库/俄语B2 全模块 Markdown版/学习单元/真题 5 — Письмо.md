## 2. 题型目标

> [!info] **needs_review** — B2 写作模块考察的核心能力
>
> Письмо 模块主要考察以下能力：
>
> 1. **体裁切换能力** — 能根据题目要求，在"非正式私信""公文体文书""推荐信"之间切换语体（регистр）
> 2. **功能性表达** — 能清晰表达意图：推荐、解释、评价、请求
> 3. **信息组织** — 能按照题目给出的信息点，逻辑清晰地组织段落
> 4. **格式规范** — 掌握俄语书信格式（称呼、正文、落款、日期）
> 5. **公文体格式** — 掌握俄语公文事务文书的基本格式（抬头、标题、正文、签名、日期）
> 6. **信息筛选** — 能从广告材料中提取并重组关键信息
> 7. **词数控制** — 在限定的词数范围内完成有效表达
> 8. **语体一致** — 同一篇作文内保持语体风格统一（不混用正式/非正式表达）

## 4. 审题拆解

> [!info] **needs_review** — 各题审题要点

### Задание 1 审题要点

1. **选一个专业推荐，而不是全部介绍。** 广告中有 5 个机构、十几个专业方向，你需要选择其中**一个**推荐给你的朋友。
2. **推荐要有说服力。** 题目要求"достаточную для принятия решения"（足够让对方做决定的信息），所以你需要在信中融入广告中的关键信息：机构名称、课程时长、学习内容、证书/就业等。
3. **确定收信人身份。** 题目给的是"знакомому / сыну, дочери вашего знакомого"，决定你用什么称呼和语气。
4. **5 分钟阅读材料**计入 15 分钟总时间内。实际写作时间约 10 分钟。
5. **50-70 词**意味着约 5-8 句话，需精炼。

### Задание 2 审题要点

1. **公文事务语体** — 必须使用正式格式：抬头（Начальнику... от...）、标题（Объяснительная записка）、正文（用"Я, [姓名], не смог..."结构）、签名、日期。
2. **需自编缺席理由** — 题目未给出具体原因，需要自己编一个合理且正式的原因。
3. **注意格的使用：** Начальнику 用第三格（дательный падеж），от 后用第二格（родительный падеж）。
4. **词数仅 50-70 词，** 抬头和标题不算在内时，正文约 3-5 句话。
5. **人称** — 用第三人称指代自己（Я, [姓名], ...），这是公文体的特点。

### Задание 3 审题要点

1. **必须覆盖四个维度：** (1) 个人品质 (личностные качества)；(2) 业务能力 (деловые качества)；(3) 印象深刻的事件/事实；(4) 评估其是否适合该岗位。
2. **非正式语体** — 用 "Привет, дорогой ..." 开头，用 "ты" 称呼，用日常口语化表达。
3. **100-150 词** — 这是篇幅最大的一篇，需要足够的内容填充。
4. **用具体事例支撑评价** — 不能只说"他很勤奋"，要举例说明。
5. **注意人名变格：** 如 Никита → Никиту（第四格），Коля → Коле（第三格）等。

### Задание 2 — Объяснительная записка (解释说明)

**抬头格式（Header）：**

```
Начальнику [отделения/учреждения] №[номер] [город]
от [должность, ФИО в род. падеже]
```

**标题（Title）：**

```
Объяснительная записка
```

**正文开头（Body opening）：**

| 俄语 | 中文 |
|------|------|
| Я, [ФИО], не смог(ла) явиться... | 我，[姓名]，未能到场…… |
| Я, [ФИО], отсутствовал(а)... | 我，[姓名]，缺席了…… |

**说明原因（Explaining the reason）：**

| 俄语 | 中文 |
|------|------|
| в назначенное / условленное время | 在指定/约定的时间 |
| в качестве свидетеля | 作为证人 |
| так как ... | 因为…… |
| в связи с тем, что ... | 由于…… |
| по причине ... | 因……原因 |
| по семейным обстоятельствам | 由于家庭原因 |
| по состоянию здоровья | 由于健康状况 |

**签名 + 日期：**

```
[ФИО]
ДД.ММ.ГГГГ
```

> [!info] **needs_review** — 公文体格式要点
>
> - 抬头中 Начальнику 用第三格（дательный падеж），от 后用第二格（родительный падеж）
> - 正文用"Я, [姓名]"开头，以第三人称指代自己——这是俄语公文体特征
> - 正文中动词用过去时，保持陈述语气
> - 签名只写姓名，不写"С уважением"之类的客套话
> - 日期格式：ДД.ММ.ГГГГ（日.月.年）

## 8. 评分风险

> [!info] **needs_review** — 各题型常见失分点

### Задание 1 — 推荐信常见失分项

| 风险 | 说明 | 规避方法 |
|------|------|----------|
| **推荐了不止一个专业** | 考试要求推荐"какую-либо из специальностей"（某一专业），不要在信中罗列多个选择 | 只选一个，深入写 |
| **广告信息用得太少** | 推荐信没有融入广告的具体信息（机构名、课程时长、特点），显得像泛泛而谈 | 至少用 2-3 条广告关键信息 |
| **没有个性化** | 信中没有提到"为什么推荐给他/她"，缺少与收信人的关联 | 加入"Помню, что ты..."类的句子 |
| **词数不足或超标** | 50-70 词，写太少可能信息不足，写太多则浪费时间且可能扣分 | 写作后立即数词数 |
| **忘记签名和日期** | 非正式信也要有签名和日期 | 模板化记忆，写完检查 |
| **语体过于正式** | 推荐信用了公文语体，与"非正式"要求不符 | 用"ты"、用口语表达 |

### Задание 2 — 解释说明常见失分项

| 风险 | 说明 | 规避方法 |
|------|------|----------|
| **抬头格式错误** | Начальнику 没写第三格，от 后没写第二格 | 牢记：Начальнику + 第三格，от + 第二格 |
| **用了非正式语体** | 在公文体中用了口语词、缩略语、ты 称呼 | 用"Вы"或第三人称指自己，用正式词汇 |
| **理由不正式/不合理** | "проспал"（睡过头）等在公文体中不合适 | 用客观、合理的理由（如"защищал дипломную работу"） |
| **缺少标题** | 没写"Объяснительная записка" | 模板化记忆 |
| **签名格式错误** | 加了"С уважением"之类的敬语结尾 | 公文体只写姓名 |
| **日期格式错误** | 用了其他日期格式 | 统一用 ДД.ММ.ГГГГ |

### Задание 3 — 人物评价信常见失分项

| 风险 | 说明 | 规避方法 |
|------|------|----------|
| **缺少某个维度** | 四维度（个人品质、业务能力、事件、评价）缺了其中一个 | 审题时在草稿上列出四维度，写完后逐条核对 |
| **评价太空泛** | 只说"他很勤奋"但没有具体例子 | 每个品质都要有具体事实支撑 |
| **语体不统一** | 在非正式信中插入了过于正式的表达 | 全程用"ты"、日常词汇 |
| **词数不足** | 100-150 词，如果写得太简单可能不够 | 每个维度写 3-5 句话 |
| **人名变格错误** | 如"насчёт Никите"应为"насчёт Никиты" | 检查每个人名的格 |
| **没有明确的适岗评价** | 题目要求"оценить, соответствуют ли..."，但没有给出明确结论 | 用"я думаю, он/она подходит"明确表态 |

### 通用失分项

| 风险 | 说明 |
|------|------|
| **时间分配不当** | 在某一道题上花太多时间导致后面的题没写完 |
| **不数字数** | 写完了但不知道是否符合词数要求 |
| **三篇语体混用** | 把公文体的抬头格式用到非正式信中，或在公文体中用了口语表达 |
| **忘记所有题写日期和签名** | 每篇都要有签名和日期 |
| **语法错误** | 动词变位、名词变格、形容词性数格一致——在所有题型中都会被扣分 |

## 12. 后续待完善

> [!info] **needs_review** — 待确认和待补充的内容

1. **范文权威性** — 范文来自原书标注的"参考范文"（справочный ответ），不是官方的评分样本。真实考试的评分标准和范文可能有所不同。等官方参考答案获取后需替换或对照。

2. **OCR 质量问题** — 源文件为 MinerU OCR 提取，多处可能有误：
   - `условенное` 疑应为 `условленное`（Задание 2 范文）
   - `насчет Никите` 疑应为 `насчёт Никиты`（Задание 3 范文）
   - `про- сьбой` 明显断字错误，应为 `просьбой`（Задание 3 原题）
   - `филологического` 疑应为 `филологического`（Задание 2 范文——已确认正确）
   - 广告表格中有多处换行和空格异常，需要对照原书扫描页确认

3. **广告材料的使用边界** — 范文 1 在推荐厨师课程时，添加了原广告未详细列出的内容（"научить готовить блюда из разных стран и широкий выбор кондитерских курсов""дипломы государственного образца"）。这种适度发挥在 B2 考试中的可接受程度需进一步确认——建议对照官方评分说明。

4. **词数计数标准** — 俄语考试中"词"（слово）的计数标准（是否计前置词、连词等）需要确认。通常俄语中包括前置词和连词在内的所有独立书写单元都计为一个词。

5. **评分细则** — B2 写作评分的具体维度（内容完整性、语言准确性、格式规范性、语体适当性各占多少分）待补充。

6. **更多范文** — 每个任务如果能从其他真题卷中收集更多范文，可以建立写作题库用于对比学习。

7. **口语联动练习** — 第 9 节的口语联动可扩展为专门的练习单元。

## OCR 说明

- **OCR 引擎:** MinerU（阿里云开源PDF解析器）
- **输出:** 8073 行结构化 Markdown，含表格、图片链接
- **限制:** MinerU 不保留 PDF 页边界，按逻辑标题拆分；无逐页粒度

## Profile 说明

本书为混合型项目，不同模块使用不同 profile：
- **阅读模块** → Reading Profile（`10-learning-unit-standard.md`）
- **写作/会话/听力模块** → Writing/Speaking Profile（`11-writing-speaking-unit-standard.md`）
- **语法词汇模块** → 参考语法格式（待定）

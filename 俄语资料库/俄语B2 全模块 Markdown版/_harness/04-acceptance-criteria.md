# 04 Acceptance Criteria

## 通用验收标准

每个 agent 输出必须满足：
- 源可追溯性：每个产物可追溯到 `章节/` 或 `原始OCR/` 中的具体页面
- 格式正确：Markdown 可读，俄语不用代码格式
- 边界遵守：未修改只读区域
- 不确定性标注：OCR 风险、翻译不确定性标记为 `needs_review`

## 学习单元验收 (Agent E)

### Reading Profile 单元

- [ ] 完整源页面范围覆盖（正文 + 练习题页）
- [ ] 原书任务和练习已包含或明确标注缺失
- [ ] 俄语原文完整
- [ ] 中文翻译对齐或缺失块已标注
- [ ] 语法笔记使用可读 Markdown
- [ ] 词汇例句高亮匹配词形
- [ ] 源元数据存在
- [ ] OCR 风险和生成注释风险可见

### Writing/Speaking Profile 单元

- [ ] 原书任务完整保留
- [ ] 输入材料/提示原文完整
- [ ] 题型目标明确
- [ ] 审题拆解清晰
- [ ] 可复用表达表格
- [ ] 输出框架/范文（标注为学习辅助）
- [ ] 评分风险指出
- [ ] 口语追问/写作变体

## 翻译验收 (Agent B)

- [ ] 段落级对齐
- [ ] OCR 风险段落标注
- [ ] 术语一致性
- [ ] 无遗漏段落

## 卡片验收 (Agent C)

- [ ] 每张卡片有源链接
- [ ] 原文/翻译/注释分离
- [ ] 一张卡片一个学习动作
- [ ] Obsidian 友好格式（wikilinks, properties, tags）

## 判定标准

| 判定 | 含义 |
|------|------|
| PASS | 满足所有验收标准，可集成 |
| REVIEW | 有用但不完整，有 OCR 不确定性或缺失内容 |
| FAIL | 存在阻断性问题，需重新生成 |
| BLOCKED | 源材料不足以完成任务 |

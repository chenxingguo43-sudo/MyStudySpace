# 11 Writing/Speaking Unit Standard

适用于：写作模块（Письмо）、会话模块（Говорение）、听力模块（Аудирование）的学习单元。

## 核心原则

以任务/提示为中心，帮助学习者：
1. 理解原书任务要求
2. 拆解题型目标
3. 掌握可复用表达
4. 参照输出框架
5. 了解评分风险
6. 准备口语追问/写作变体

## 必需章节

1. `0. 元信息`
2. `1. 原书任务` — 完整保留原书任务描述
3. `2. 题型目标` — 本题考察什么能力
4. `3. 输入材料 / 原文` — 听力原文、阅读材料、图表等
5. `4. 审题拆解` — 如何分析题目要求
6. `5. 可复用表达` — 句型、模板、连接词
7. `6. 输出框架` — 写作框架或口语大纲
8. `7. 范文或回答示例` — 标注为学习辅助
9. `8. 评分风险` — 常见失分点
10. `9. 口语追问 / 写作变体` — 延伸练习
11. `10. 词汇与真实例句` — 关键词汇 + 原书例句
12. `11. 学习卡片入口` — 链接到卡片
13. `12. 后续待完善`

## 内容标签

- `原书内容`: 从源页面复制或清洗的内容
- `学习辅助`: 生成的解释、框架、翻译、范文
- `needs_review`: OCR 或解读风险

## 常见任务类型

- 投诉信 / претензия
- 正式通知 / сообщение
- 摘要 / изложение
- 参与对话 / примите участие в диалоге
- 反对与同意 / возражение и согласие
- 电话询问 / расспросите подробно
- 独白观点 / выскажите своё мнение
- 词汇语法激活 / синонимы, антонимы, виды глагола

## 规则

- 保留原书任务后再添加模型回答
- 不虚构官方答案
- 范文必须标注为生成的学习辅助
- 卡片聚焦于可复用输出模式
- OCR 缺陷保持可见——任务型题目常依赖细小指令词

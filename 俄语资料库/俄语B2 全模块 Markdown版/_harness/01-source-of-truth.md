# 01 Source of Truth

## 源材料链

```
E:\Desktop\俄语B2.pdf (190页, 扫描图片PDF)
    │
    ▼  Google Docs 上传 + OCR
    │
    ▼  导出为 Markdown/HTML
    │
    ▼  拆分为单页文件 → 原始OCR/page_001.md ~ page_190.md
    │
    ▼  清洗整理 → 章节/<模块名>/*.md
```

## 密封后只读区域

以下目录在密封后禁止修改：
- `原始OCR/` — 逐页 OCR 原文
- `章节/` — 清洗后的章节文件
- `_data/source_manifest.json` — 源页面清单
- `README.md` — 项目说明
- `封版说明.md` — 封版记录

## 衍生输出目录（可写）

- `学习单元/` — 学习单元 Markdown 文件
- `翻译版/` — 对齐翻译
- `卡片草稿/` — Obsidian 学习卡片
- `_data/` — 结构化数据（例句匹配、词汇表等）
- `质量报告/` — 审核和质量报告

## 禁止区域

- 原始 PDF 文件不做任何修改
- Google Docs 导出的中间文件保留不删
- `_harness/` 文件仅项目维护者修改

## AI 附录识别

本书为考试辅导书，第二部分"真题套卷"中的**标准答案**和**答题思路**是原书内容（出版方提供），不属于 AI 生成内容。但学习单元中额外添加的解析、范文、翻译属于学习辅助，需标注。

## 结论

### PyMuPDF 明显优于 MarkItDown

| 维度 | 评估 |
|------|------|
| 内容完整性 | PyMuPDF 完整提取，MarkItDown 几乎全部损坏 |
| 俄文保留 | PyMuPDF 15,779 vs MarkItDown 27 |
| 中文保留 | PyMuPDF 5,139 vs MarkItDown 21 |
| NUL 污染 | PyMuPDF 0 vs MarkItDown 6,884 |
| 句子完整性 | PyMuPDF 保留完整句子，MarkItDown 无法识别 |
| 适合分句 | PyMuPDF ✅，MarkItDown ❌ |

### 推荐

**将 PyMuPDF 作为 PDF 主入口，替代 MarkItDown。**

具体方案：
1. **text_pdf 类型**：用 PyMuPDF 逐页提取文字
2. **词汇表 PDF**：用 PDFPlumber 提取表格结构
3. **needs_ocr 类型**：用 PyMuPDF 先尝试提取，失败再 OCR
4. **MarkItDown**：不再用于本项目

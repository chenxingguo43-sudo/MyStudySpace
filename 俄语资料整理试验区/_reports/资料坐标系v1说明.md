# 资料坐标系 v1 说明

## 概述

将原有的 `examples.json`（25 条平铺数组）拆分为四个结构化文件，形成可查询、可扩展的资料坐标系。

## 文件结构

```
data/
├── examples.json        ← 保留，兼容文件（平铺数组）
├── sources.json         ← 资料来源注册表
├── sentences.json       ← 例句库（核心数据）
├── lexeme_index.json    ← 词形→句子反向索引
└── grammar_index.json   ← 语法标签→句子反向索引
```

## 各文件 schema

### sources.json（资料来源）

数组，每个元素代表一个独立的资料来源（一本书、一篇文章等）。

```json
{
  "source_id": "src-0001",
  "source_title": "《穆罗姆学习手册》：语法详解与单词清单",
  "source_path": "E:\\Desktop\\俄语资料文档整理\\《穆罗姆学习手册》：语法详解与单词清单.pdf",
  "chapters": ["课文逐句精讲"]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| source_id | string | 稳定 ID，格式 `src-NNNN` |
| source_title | string | 资料标题 |
| source_path | string | 原始文件路径 |
| chapters | string[] | 该资料包含的章节列表 |

### sentences.json（例句库）

数组，每个元素代表一条例句。通过 `source_id` 关联到 sources.json。

```json
{
  "sentence_id": "ex-000008",
  "source_id": "src-0001",
  "chapter": "课文逐句精讲",
  "page_or_location": "7",
  "ru": "Муромчане гордятся своими знаменитыми земляками.",
  "zh": "穆罗姆人为他们著名的同乡感到骄傲。",
  "confidence": "high",
  "needs_review": false,
  "note": "гордиться кем-чем为B1必考动词搭配"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| sentence_id | string | 稳定 ID，与原 examples.json 的 id 一致 |
| source_id | string | 外键，指向 sources.json |
| chapter | string | 章节名 |
| page_or_location | string | 页码或位置 |
| ru | string | 俄语原文 |
| zh | string | 中文翻译 |
| confidence | string | 置信度：high / medium / low |
| needs_review | bool | 是否需要人工复核 |
| note | string | 备注 |

### lexeme_index.json（词形索引）

对象，key 是小写词形，value 是索引条目。

```json
{
  "гордиться": {
    "lemma": "гордиться",
    "sentence_ids": ["ex-000008"],
    "source": "lexeme"
  },
  "гордятся": {
    "lemma": "гордиться",
    "sentence_ids": ["ex-000008"],
    "source": "surface"
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| lemma | string | 该词形对应的原形（如有） |
| sentence_ids | string[] | 包含该词形的句子 ID 列表 |
| source | string | 来源类型：`lexeme`（确定原形）/ `possible`（可能原形）/ `surface`（词形变体） |

**查询示例**：
- `lexeme_index["гордиться"]` → 找到 ex-000008（原形匹配）
- `lexeme_index["гордятся"]` → 找到 ex-000008（词形变体匹配）
- `lexeme_index["гулять"]` → 找到 ex-000001

### grammar_index.json（语法标签索引）

对象，key 是语法标签名，value 是句子 ID 数组。

```json
{
  "副动词": ["ex-000001"],
  "被动形动词": ["ex-000002", "ex-000007", "ex-000013"],
  "动词接格": ["ex-000006", "ex-000008", "ex-000016"]
}
```

**查询示例**：
- `grammar_index["副动词"]` → 找到 ex-000001
- `grammar_index["被动形动词"]` → 找到 4 条句子

## 增量接入指南

### 接入新资料

假设有一本新的俄语语法书《XXX语法》要接入：

**第一步：抽取例句**

从新书中抽取例句，按 examples.json 格式填写每条。关键字段：
- `id`：使用 `ex-NNNNNN` 格式，接续当前最大编号（当前最大是 ex-000025）
- `source_title`：新书标题
- `source_path`：新书文件路径
- `chapter`：章节名
- `page_or_location`：页码
- `ru` / `zh`：俄语原文和中文翻译
- `grammar_tags`：语法标签
- `lexeme_tags`：确定的原形
- `surface_forms`：句子中出现的词形变体

**第二步：运行生成脚本**

```bash
python 俄语资料整理试验区/_data/build_coordinate_system.py
```

脚本会自动：
1. 读取 data/examples.json
2. 重新生成 sources.json、sentences.json、lexeme_index.json、grammar_index.json
3. 新资料会自动出现在 sources.json 中
4. 新词形会自动加入 lexeme_index.json
5. 新语法标签会自动加入 grammar_index.json

**第三步：验证**

```bash
node -e "const d=JSON.parse(require('fs').readFileSync('data/sentences.json')); console.log(d.length)"
```

### 接入新单词

当 vocabulary.json 新增单词后，不需要重新生成坐标系文件。

原因：lexeme_index.json 是从 examples.json 的 lexeme_tags/surface_forms 构建的，不依赖 vocabulary.json。

如果新单词恰好出现在某条例句的 lexeme_tags 中，它会自动出现在 lexeme_index.json 里。

## 与 reader-prototype.html 的关系

当前 reader-prototype.html 仍直接读取 examples.json。未来可改为：
1. 读取 sentences.json（更轻量）
2. 读取 lexeme_index.json（快速词形查找，无需遍历全部例句）
3. 读取 grammar_index.json（按语法标签筛选例句）

但这是后续优化，不在 v1 范围内。

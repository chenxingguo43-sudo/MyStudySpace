# 超级阅读器原型规划（修正版）

## 修正内容

| 修正前 | 修正后 |
|--------|--------|
| 扩展现有 reader.html | 新建独立 `reader-prototype.html` |
| fetch 绝对路径 `D:\...\examples.json` | 复制到 `data/examples.json`，用相对路径 fetch |
| 不改任何文件 | 需要复制 examples.json 到 data/ |

## 目标

新建独立页面 `reader-prototype.html`，验证：
1. 打开 TXT/Markdown 文件
2. 选中俄语词 → 查 `vocabulary.json` 显示原形和释义
3. 同时查 `examples.json` 显示资料库中的真实例句
4. 例句显示：俄语原文、中文翻译、来源、页码
5. 支持一键加入生词本

## 设计原则

- **不改现有文件**：不改 vocabulary.html、index.html、server.js、reader.html
- **独立原型**：新建 `reader-prototype.html`，可独立打开测试
- **只做 TXT/Markdown**：不做 PDF、EPUB、OCR
- **用现有数据**：只用 `data/vocabulary.json`（2MB）和 `data/examples.json`（25条）

## 查询逻辑

### 1. 加载数据（页面初始化时）

```javascript
let vocabData = null;
let examplesData = null;

async function loadAllData() {
  const [vocabResp, exResp] = await Promise.all([
    fetch('data/vocabulary.json'),
    fetch('data/examples.json')
  ]);
  vocabData = await vocabResp.json();
  examplesData = await exResp.json();
}
```

### 2. 查 vocabulary.json

```javascript
function lookupVocab(word) {
  const clean = word.replace(/[^a-zA-Zа-яА-ЯёЁ-]/g, '').toLowerCase();
  if (!clean || !vocabData) return null;

  // 精确匹配
  return vocabData.find(v => v.word.toLowerCase() === clean) || null;
}
```

### 3. 查 examples.json

```javascript
function lookupExamples(word) {
  const clean = word.replace(/[^a-zA-Zа-яА-ЯёЁ-]/g, '').toLowerCase();
  if (!clean || !examplesData) return [];

  return examplesData.filter(ex => {
    // 匹配 surface_forms
    if (ex.surface_forms?.some(f => f.toLowerCase() === clean)) return true;
    // 匹配俄语原文（子串）
    if (ex.ru?.toLowerCase().includes(clean)) return true;
    return false;
  });
}
```

### 修改的函数

#### lookupSourceExamples(word)
- 新增: 构建 sourceMap 和 sentenceMap 查找表（替代线性搜索）
- 新增: 筛选 `translation_status === 'translated'`
- 新增: 筛选 `zh` 非空
- 新增: 筛选 `vocabulary_card_eligible === true`
- 新增: 筛选 `example_type in ['natural_sentence', 'grammar_example']`
- 新增: 每个 source 最多 2 条
- 新增: 排序 — display_priority 降序 > natural_sentence 优先 > quality_score 降序
- 保留: 最多返回 3 条

#### renderSourceExamples(word)
- 新增: 类型标签 "自然例句" / "语法例句"
- 改进: page_or_location 转为字符串显示
- 移除: needs_review 标签（不再需要）

### CSS 新增
- `.source-ex-type` — 类型标签样式（紫色半透明背景）

## 展示筛选规则

| 条件 | 要求 |
|------|------|
| translation_status | translated |
| zh | 非空 |
| vocabulary_card_eligible | true |
| example_type | natural_sentence 或 grammar_example |
| 每个 source | 最多 2 条 |
| 总数 | 最多 3 条 |

## 排序规则

1. display_priority 高的在前
2. natural_sentence 优先于 grammar_example
3. quality_score 高的在前

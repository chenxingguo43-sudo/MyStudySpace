# 词汇长期调度采用 FSRS-6

白夜俄语的词汇长期掌握估计和复习日期采用 FSRS-6，不再让最近一次 `1/3/5` 自评直接充当掌握度，也不继续扩展现有 SM-2 风格公式。第一阶段固定使用 `ts-fsrs@5.4.1` 的稳定实现、90% 目标记忆率和可重放的参数快照；同日回炉继续由独立会话队列管理，避免短期重复记忆虚增长期稳定性。

## Considered Options

- 继续使用现有 SM-2 风格调度：迁移最简单，但无法直接表示记忆稳定期和当前可回忆率，最近一次评分对结果影响过大。
- 自行设计加权积分：界面容易解释，但缺少成熟遗忘模型，权重很容易变成另一种主观打分。
- 使用 FSRS-6：引入一个外部算法依赖和迁移成本，但能把难度、稳定期、当前可回忆率和目标记忆率分开，并能根据完整事件重建状态。

## Consequences

- 第一阶段不把 `Easy` 暴露给学习者；现有“不认识 / 模糊 / 认识”分别映射为 `Again / Hard / Good`。
- 阅读接触、普通查词、AI 待验证评价和看答案后的确认不能直接更新 FSRS。
- 每个复习单元每天至多有一个长期评分；同日后续回炉仍记录事件，但不覆盖当天首次独立回忆结果。
- 算法版本、库版本、完整参数和目标记忆率必须随派生状态保存；升级时通过事件重算和固定样例验收，不能静默替换。
- 旧 `mastery` 和 `interval` 不转换成虚构的 FSRS 历史，必须经过渐进校准。

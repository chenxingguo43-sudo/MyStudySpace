# 词元身份与学习事件权威

白夜俄语以“保留 `ё` 的规范原形 + 标准化词性”作为正式词元身份，并把不可安全归一的词形先放入待确认记录；中文释义、页面词形和只含原形的旧键都不能充当正式身份。学习行为以只追加、可更正的学习事件为历史权威，Vocabulary 当前状态、掌握估计和复习计划均由事件与明确的迁移快照派生。这比继续依赖可覆盖的单个词条对象复杂，但能避免同形异词错误合并、释义修改导致身份漂移，以及未来浏览器、本地数据库和服务器之间互相覆盖学习历史。

## Consequences

- 正式词元键保留 `ё`；把 `ё` 折叠为 `е` 只用于搜索别名。
- 词性未知或原形不可靠时，不创建正式词条，待确认后再归入。
- 一个词元可以有多个稳定的释义单元；释义文字不是释义身份。
- 普通修正追加新事件并引用旧事件，不静默改写历史。
- 隐私永久删除是追加历史的例外：私人正文必须从活动数据和备份中清除，只保留不含原文的删除审计结果。
- 旧 `mastery`、`history` 等聚合字段只能迁移为旧状态快照，不能伪造成过去逐次发生的学习事件。

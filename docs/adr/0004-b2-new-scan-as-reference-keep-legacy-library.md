# ADR-0004: 新扫描作为 B2 校对参照，旧扫描库保持现状

书的新版 OCR（2026-08 重扫）与旧版逐板块比对后确认：正文题量、答案、讲解两边一致，新版仅多出前言、阅读答案表和 50 张本地图片。我们决定不替换 `俄语资料库/俄语B2 全模块 Markdown版/` 的旧扫描章节文件——现有全部题目数据管线基于它重建的风险大于收益——而是把新版扫描仅用作两件事：补齐缺失内容（前言考试说明、真题三个未导入分测验）时的取材源，以及清理已知错型（б/6 混淆、页眉花纹噪声、断句错误）时的权威参照；两版同源的错误对照新扫描目录内的原书 PDF 裁决。

## Consequences

- 旧章节库内容如需引用，仍以其为提取源；任何与新扫描不一致处，先对照原书 PDF 再改。
- 新增内容（考试说明、真题 150/25/15 题）的数据出处标注指向新扫描与原书 PDF 页码。

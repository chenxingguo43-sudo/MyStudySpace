# B2单词表 AI批量解析计划

> 目标：补齐888个实词（名词381 + 形容词110 + 动词381 + 副词16）的AI详细解析

## 一、处理顺序

按优先级分4批，每批内按词性分组：

| 批次 | 词性 | 数量 | 处理方式 |
|------|------|------|----------|
| 第1批 | 副词 | 16 | 一次生成（量少） |
| 第2批 | 形容词 | 110 | 分2-3次生成 |
| 第3批 | 名词 | 381 | 分5-6次生成 |
| 第4批 | 动词 | 381 | 分5-6次生成 |

## 二、每次生成的内容

每批次发送给AI时，包含以下信息：

### 输入格式
- 要处理的单词列表（俄语 + 中文释义）
- 该词性的模板要求（名词要性/变格，动词要体/接格等）
- 参考样例（一个已完成的该词性文件）

### 输出格式
```json
{
  "word": "автобиография",
  "detailed_definition_ru": "详细俄语解释",
  "detailed_definition_zh": "详细中文解释",
  "collocations": [
    {"phrase": "搭配1", "ru": "例句", "zh": "翻译"}
  ],
  "synonyms": [
    {"word": "近义词1", "diff": "区别"}
  ],
  "antonyms": ["反义词1 — 说明"],
  "confusable": ["易混淆词 — 区别说明"],
  "special_usage": ["用法要点1", "用法要点2"]
}
```

### 质量要求
- 俄语解释：2-4句，说明语义、语体（正式/口语）、使用场景
- 中文解释：对应翻译，补充中文读者需要的背景
- 搭配：3-5个，例句要自然
- 近义词：2-4个，给出语义或语体上的区别
- 反义词：1-3个
- 易混淆词：1-2组
- 特殊用法：2-4个要点

## 三、验证方式

每批生成后，跳点抽检5-10个文件：
- 格式是否正确（所有section都有内容）
- 俄语是否通顺
- 中文翻译是否准确
- 近义词辨析是否有实际区分度

发现问题：修正prompt后重跑该批次。

## 四、写入逻辑

AI返回JSON后，写脚本批量注入到对应Markdown文件：
1. 解析JSON
2. 定位文件的 `## 📝 详细释义` 等section
3. 替换"待AI补充"的占位内容
4. 保持文件原有格式不变

| 名词381个 | 4-5轮 |

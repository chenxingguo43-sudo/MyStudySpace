### pymorphy2 在本机安装/运行的坑（可复用）
- 沙箱 safe-delete 会 fail-closed 阻断 pip 写/删 → 安装必须用 `dangerouslyDisableSandbox: true`，且要**新建独立 venv**（旧 venv 已半残）。最终 venv：`C:/Users/33055/.workbuddy/binaries/python/envs/grammar`。
- setuptools 必须 `pip install "setuptools<81"`：新版（≥81）移除 `pkg_resources`，而 pymorphy2 0.9.1 仍依赖它来定位词典。
- Python 3.13 移除了 `inspect.getargspec`/`inspect.ArgSpec` → 在 import pymorphy2 前打垫片：用 `inspect.getfullargspec` 返回 4 元组伪装。
- 动词要点：①过去时 masc 必须显式带 `('past','masc')`，否则 inflect 给形动词；②体(Aspect)判定用「3单人称是否带 `pres` grammeme」选对 parse，避免反身动词（如 адаптироваться）被误标将来时。
- 名词短尾(形容词)在 pymorphy2 中是独立 POS `ADJS`（性别+数，无格），比较级为 `COMP`；名词 6 格 grammeme 名为 nomn/gent/datv/accs/ablt/loct。

## 最需人工复核的俄语风险
1. **столбизм / столбист / столбистовый**：这三个词较为冷僻，释义和搭配基于建筑史/宗教学常识，建议核对是否为该词典所需的精确义项。
2. **спортсмен-дайвер**：复合词变格（两部分都变格）需确认是否符合该词典体例。
3. **сретенский**：宗教节日相关，东正教历法日期（2月15日新历）建议核对。
4. **студеный**：重音在 ё（студёный），与 студенческий 易混，已标注但建议复核重音。
5. **съесть / съездить**：词形极近，例句已区分，但建议复核是否有其他义项遗漏。
6. **стен**：该词条为 стена 的复数二格，非独立原形词，建议确认批次文件是否确实要求编写此形式。

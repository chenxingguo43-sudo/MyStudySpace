# Batch 24 编写报告（утюг – челябинский）

## 编写要点

- 本批共 150 词，覆盖 у- 词尾、ф-、х-、ц-、ч- 开头的名词、动词、形容词及复合词。
- 包含大量外来词（факс, фестиваль, формат, фрилансер, футбол, хобби, хэппи）和专业术语（физика, химия, философия, филология, федерация）。
- 每词条均含 ≥3 条搭配（配完整俄句+中译）、≥1 同义词（含差异说明）、≥2 关联词、易混词辨析及 special 备注。
- 对口语/俚语表达（如 чайник「新手」、халявщик「贪便宜的人」、хитрук「滑头」）在 special 中标注语域。
- 对复合词（учебно-тренировочный, хип-хоп-проект, человек-труженик）标注变格规则和构词方式。

## 最需人工复核的俄语风险

1. **фабричонка** — 口语/旧用法，指小工厂或女工，语域和词义需核对原始语料。
2. **фатх-али-ша** — 波斯历史专有名词，拼写（ша 呼格形式）建议核对。
3. **феррар** — 方言/旧形式「铁匠」，标准语为 кузнец，建议核对语料。
4. **ценност** — 疑似 ценность 的罕见/方言短形式，建议核对是否为笔误。
5. **чад** — 旧/书面/诗歌用语「孩子」，复数形式 чада，语域需核对。
6. **чаять** — 旧/书面/诗歌用语「希望」，现代语中较少用，搭配需核对。
7. **хэйлунцзянский** — 中文「黑龙江」音译形容词，拼写和使用频率需核对。
8. **хэппи** — 口语外来词（happy），不变格，语法分类需核对。
9. **хитрук** — 口语词「滑头」，带后缀 -ук-，女性形式 хитручка，需核对。
10. **устальной/устарый/утнетенный**（batch 23 遗留）— 均为方言/旧/罕见形式，建议统一核对原始语料确认是否为标准词的变体。
11. 完成体/未完成体对应关系（如 функционировать 同形、совершенствовать 同形）需逐一核对。
12. 所有外来词的变格（不变格名词如 хобби, пальто 类）需核对。

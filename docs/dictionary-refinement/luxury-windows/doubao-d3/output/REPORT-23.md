# Batch 23 编写报告（убежать – утром）

## 编写要点

- 本批共 150 词，覆盖 у- 开头动词、名词、形容词及副词，以完成体/未完成体动词对为主（如 убеждать/убедить、увеличивать/увеличить、устанавливать/установить、улучшать/улучшить）。
- 每词条均含 ≥3 条搭配（配完整俄句+中译）、≥1 同义词（含差异说明）、≥2 关联词、易混词辨析及 special 备注。
- 动词词条统一标注完成体/未完成体对应关系及接格要求（如 управлять 接五格、упрекать 接六格 в чём）。
- 对口语/俚语表达（如 унести ноги「赶紧溜」、убивать время「消磨时间」）在 special 中标注语域。

## 最需人工复核的俄语风险

1. **управлень** — 疑似旧形式或方言变体，标准语为 управление；建议核对原始语料确认是否为笔误。
2. **устальной** — 疑似方言/旧用法，标准语为 усталый；建议核对。
3. **устарый** — 疑似方言/旧用法，标准语为 устаревший；建议核对。
4. **утнетенный** — 罕见词，可能为 угнетённый 的拼写变体；建议核对原始语料。
5. **утка** 口语义「虚假新闻」— 该用法较为粗俗/口语，标注语域是否准确需复核。
6. **угодно** 作为谓语副词与疑问词连用（кто угодно/что угодно）— 语法分类是否准确需复核。
7. **угораздило** — 无人称谓语动词，接不定式，语法说明是否完整需复核。
8. **утерять** — 书面/文学用语，日常常用 потерять；语域标注需复核。
9. 完成体/未完成体对应关系（如 усовершенствовать 同形、увязать 同形）需逐一核对词典。
10. 所有词元均以词典原形标注，输入批次中若非原形词已在 confusions/special 中说明。

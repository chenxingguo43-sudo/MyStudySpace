## 编写要点
- 本批以 по- / пре- / при- 前缀动词和名词为主，体的对应（完成体/未完成体）是重点，如 построить/строить、потерять/терять、предложить/предлагать、прийти/приходить 等均在 confusions 中标注。
- 语法术语集中：постпозиция、предикат、предложно-падёжный、придаточное、прилагательное，均标注了专业用法和易混点。
- 抽象名词较多（предназначение、предостережение、предупреждение、предшествование），explainZh 侧重说明与近义词的语体差异。
- 复合名词 премьер-министр 标注了变格特点。

## 最需人工复核的俄语风险
1. **прев** — 该词在批次中出现，疑似缩写或不完整词条，已按网络缩写处理，建议确认是否为输入错误。
2. **пресненский** — 专有地名形容词，拼写和重音需复核。
3. **предложно-падёжный** — 复合形容词拼写，建议核对是否应为 предложно-падежный（无 ё）。
4. **постригаться** — 宗教义项"剃度出家"的搭配和语体需复核。
5. **поступиться** — 接格关系（поступиться чем / в чём）需复核。
6. **предшествовать** — 接第三格，例句中格的使用需复核。
7. **претендовать** — 固定搭配 претендовать на что（第四格），需确认。
8. **придержаться/придерживаться** — 接第二格（мнения/правила），需复核。

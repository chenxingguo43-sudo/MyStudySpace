## 字段要求
- collocations：至少 3 个，必须每个都配完整俄语句子 + 中文翻译

- related：至少 2 个
- 例句用真实自然的俄语，不要生造怪异句子
- 词元统一用词典原形（完成体动词用完成体原形，如 позвонить 不是 звонить）

- 必须逐词人工编写，禁止使用任何脚本、程序、API 批量生成

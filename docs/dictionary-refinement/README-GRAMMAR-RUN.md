|---|---|---|

## 操作步骤

1. 打开每个批次文件，全选复制 → 粘贴给 Workbuddy（HY3）
2. 回复保存为 txt 进 `hy3-results-grammar/`（如 `output-01.txt`）
3. 全部跑完后：

```bash
node docs/dictionary-refinement/validate-grammar-outputs.js docs/dictionary-refinement/hy3-results-grammar
```

脚本自动：校验表格结构（名词 6 格×2、动词 6 人称+过去时、形容词短尾）→ 合并 grammarTable 字段进 reviewed-lexical-entries.json

## 输出格式（HY3 必须遵循）

```
名词: [n] слово | 名词 | 单数:主格 слово,属格 слова,与格 слову,宾格 слово,工具格 словом,前格 о слове;复数:主格 слова,属格 слов,与格 словам,宾格 слова,工具格 словами,前格 о словах
动词: [n] жить | 动词 | 现在时:я живу,ты живёшь,он/она живёт,мы живём,вы живёте,они живут;过去时:жил,жила,жило,жили
形容词: [n] большой | 形容词 | 短尾:велик,велика,велико,велики;比较级:больше
```

## 注意事项

- 完成体动词给**将来时**（я сделаю...），未完成体给**现在时**
- 名词宾格若与主格/属格相同，如实给出
- 不存在的形式写"—"
- 合并后 bump reader.html 的 DICTIONARY_DATA_VERSION
- 注意：grammarTable 目前只进数据，**reader.html 还不展示它**（展示是下一步 UI 任务）

## 输出规则
- 每个词输出一个 JSON 对象（无序号），词条之间空一行
- 严格使用以下字段结构，不要增删字段：

{
  "lemma": "词元",
  "meaning": "现代中文释义（2~5个义项，中文分号；分隔）",
  "explainZh": "中文定义解释：1~2句话说明这个词表示什么",
  "collocations": [
    {"phrase": "搭配结构", "ru": "俄语例句", "zh": "例句中文翻译"}
  ],
  "synonyms": [
    {"word": "近义词", "diff": "与主词的区别（1~2句，说明体/用法/语体差异）"}
  ],
  "antonyms": "反义词说明；没有就写：—",
  "related": [
    {"word": "关联词", "zh": "中文"}
  ],
  "confusions": [
    {"word": "易混淆词", "note": "提醒（1句）"}
  ],
  "special": "特殊用法/口语用法/文化注释；没有就写：—"
}

## 字段硬约束
- collocations：至少 3 个，每个必须配完整俄语句子 + 中文翻译；用最常用、最简单的表达，宁短勿炫
- synonyms：至少 1 个，必须说明与主词的区别；**不得与 confusions 重复同一个词**
- antonyms：必须是真正的反义词（работа↔отдых）；**没有就写 "—"，严禁编造 "не + 词" 这种伪反义词**
- related：至少 2 个
- 例句用真实自然的俄语，不要生造怪异句子
- 词元统一用词典原形（完成体动词用完成体原形，如 позвонить 不是 звонить）

## 重要约束
- 必须逐词人工编写，禁止使用任何脚本、程序、形态分析库（如 pymorphy）或 API 批量生成
- 不得照抄其他词典释义，用自己的俄语知识编写

# Zlatoust 一体化章节学习系统设计规格

状态：设计已确认；1.4.1 独立教学页样板已实现并通过验收，尚未批量推广  
样板知识点：第 1 章 1.4.1 过去时和将来时中的动词体  
日期：2026-07-26

## 1. 已确认的产品方向

本项目不是把“知识点入口卡”“知识点内部学习路线”“原书规则”和“练习题库”做成互不相干的模块。

正确的学习流程是：

```text
章节知识点卡片列表
  -> 点击知识点卡片入口
  -> 进入独立、连续的知识点教学页面
  -> 按该知识点自己的学习路线完成各教学阶段
  -> 讲解中穿插原书规则、原书例句、教辅补充和随堂题
  -> 原书正式练习复用题库的同一份作答记录
  -> 错题反向标记薄弱知识点并推荐回看位置
  -> 返回章节知识点卡片列表，继续下一个知识点
```

页面可以独立，但学习过程、进度、错题、规则和练习必须是一体的。

## 2. 已确认的交互原则

1. 章节页面只按原书顺序展示知识点卡片，不另建重复的“本章学习路线”。
2. 知识点卡片是进入独立教学页面的入口，不在章节页原地展开全文。
3. 独立教学页面是一篇连续的小型教辅章节，不拆成“讲解 / 原书 / 练习”标签页。
4. 原书规则和原书例句紧跟对应讲解出现，不统一堆到页面底部。
5. 允许增加教辅自编例句和随堂题，但必须明确标注来源类型。
6. 允许引用权威外部语法资料补充原书没有展开的解释，但必须标明来源。
7. 学习路线和思维导图都属于知识点教学页，但必须分开：路线表达学习顺序和进度，思维导图表达概念关系。
8. 原书练习嵌入知识点页面，并与正式题库共用答题、错题和进度记录。
9. 页面沿用现有阅读器的视觉语言，不进行无关的整体换皮。

## 3. 调研结论

### 3.1 Yale Advanced Russian

来源：<https://yale.pressbooks.pub/advancedrussian3/part/grammar-%D0%B2%D0%B8%D0%B4-%D0%B3%D0%BB%D0%B0%D0%B3%D0%BE%D0%BB%D0%B0-%D1%81%D0%BE%D0%B2%D0%B5%D1%80%D1%88%D0%B5%D0%BD%D0%BD%D1%8B%D0%B9-%D0%B8-%D0%BD%D0%B5%D1%81%D0%BE%D0%B2%D0%B5%D1%80%D1%88%D0%B5/>

可借鉴部分：

- 先建立“动作如何进入上下文”的整体视角，再讲具体语境规则。
- 明确指出“完成体 = 一次完成、未完成体 = 过程或重复”不是充分判断标准。
- 使用最小对比例句揭示同一个动作因预期、背景和后续事实不同而改变体。
- 用图形表达上下文框架、动作边界和事件顺序。
- 解释规则的限制和反例，不把信号词当成自动答案。

本项目不会把 Yale 的理论冒充原书内容。可采用的“上下文、预期、后续结果”解释必须标为 `external-note`，并与 Zlatoust 原书的五组对立逐项对齐。

### 3.2 Russian For Everyone

来源：<https://www.russianforeveryone.com/Rufe/Lessons/Course1/Grammar/GramUnit13/GramUnit13_1.htm>

可借鉴部分：

- 学习顺序清楚：基本意义 -> 时态系统 -> 语境提示 -> 体对 -> 阅读材料 -> 问题 -> 练习。
- 规则后立即出现例句，而不是让学习者先记完全部抽象定义。
- 使用表格比较体和时态，但在表后补充容易混淆的形式。
- 从识别和选择逐步过渡到语境分析与产出。

### 3.3 Linguars 练习页

来源：<https://linguars.ru/practical-exercises-and-drills-verb-aspect/>

可借鉴部分：

- 练习难度从识别、二选一、改写、配对、翻译逐步升级到自由产出。
- 同一概念不能只用一种选择题验证。

需要避免的部分：

- 不能把体简化为“持续/重复”和“完成/一次”的二分口诀。
- 不能只公布答案而缺少错误选项为什么错的说明。

### 3.4 Cambridge Grammar in Use 的结构原则

官方样章入口：<https://www.cambridge.org/gp/cambridgeenglish/catalog/grammar-vocabulary-and-pronunciation/english-grammar-use-5th-edition/content/sample-units>

可借鉴其“解释和练习紧密配对”的单元设计，但本项目不照搬左右两页的纸书排版。网页需要保持连续阅读，并支持即时反馈、错题回流和移动端阅读。

## 4. 章节知识点卡片页面

### 4.1 页面职责

章节页面负责回答：

- 这一章为什么要学；
- 每个知识点解决什么问题；
- 每张知识点卡当前是未学习、学习中、已学习、已掌握还是薄弱；
- 点击哪张卡进入对应的独立教学页面。

章节页不承担知识点内部的学习路线和完整规则讲解，不能把所有知识挤在目录卡片里。

### 4.2 知识点入口卡

每张入口卡只展示：

- 中文知识点标题；
- 原书俄文标题；
- 一句话学习任务；
- 内部教学阶段数量；
- 关联原书练习数量；
- 当前状态；
- “继续学习”或“开始学习”。

入口卡不展示完整规则摘要，避免在目录页提前制造一套缩水版讲解。

## 5. 独立知识点教学页面

### 5.1 页面骨架

```text
章节位置、返回知识点卡片、学习状态
知识点标题与本节要解决的问题
本知识点学习路线（顺序与进度）
本知识点思维导图
学习目标与使用范围
快速诊断题
连续教学阶段 1
连续教学阶段 2
连续教学阶段 3
连续教学阶段 4
连续教学阶段 5
本节判断总表
综合练习
学习结果与薄弱点
上一知识点 / 返回知识点卡片 / 下一知识点
```

桌面端提供固定的小目录，用于跳转到五个教学阶段。移动端改为顶部折叠菜单。目录只负责定位，不拆断正文。

### 5.2 知识点学习路线

`1.4.1` 的学习路线按教学顺序展示六步：五组核心判断加综合判断。每一步都可以跳到对应正文，并根据本阶段随堂题和原书题自动显示“未开始、学习中、已完成、需要复习”。学习者也可以手动标记或取消“需要复习”。

路线只表达先后顺序和学习状态，不承担概念分类。

### 5.3 知识点思维导图

`1.4.1` 内部思维导图：

```text
过去时和将来时中的体
├─ 先判断：现在时不属于本节
├─ 说话人只确认“发生过吗”
│  └─ 一般事实 vs 具体结果
├─ 关注动作内部还是完整边界
│  └─ 过程 vs 结果
├─ 事件是否重复
│  └─ 多次 vs 一次
├─ 多个动作怎样排列
│  └─ 同时并行 vs 依次发生
└─ 过去结果与现在的关系
   └─ 结果已取消 vs 结果仍保留
```

思维导图采用“中心知识点 -> 五个判断问题 -> 每组两个对立概念”的树状关系。点击分支滚动到对应教学阶段，并同步高亮左侧目录。思维导图不显示学习进度，也不替代正文。

## 6. 每个教学阶段的固定结构

五个阶段都必须具有以下内容，不能只在整页层面“平均凑齐”：

1. 本阶段要解决的真实判断问题。
2. 一组不先展示答案的语境导入。
3. 老师式中文拆解。
4. 对应原书俄文规则与中文翻译。
5. 原书规则中每个条件、限制和时间范围的解释。
6. 原书例句逐句解析。
7. 至少一组只改变一个条件的最小对比例句。
8. 教辅补充正例、反例和边界例。
9. 信号词及其有效条件和失效条件。
10. 常见误判，以及误判为什么发生。
11. 随堂判断题。
12. 答错后的定向反馈与再练习。
13. 直接对应的原书练习。

## 7. 1.4.1 五个连续教学阶段

### 7.1 一般事实与具体事实

核心问题：说话人只是确认动作有没有发生过，还是在检查一个预期结果是否已经达成？

必须讲清：

- 一般事实不关心动作是否完成、一次还是多次。
- 完成体的具体事实强调一次动作已有结果。
- `когда-нибудь`、`хоть раз`、`ни разу` 是一般事实的常见入口，但不是机械答案。
- `один раз` 不能单独决定完成体，原书也把它列入一般事实环境。
- `наконец`、`полностью`、`в конце концов` 等通常指向结果，但仍需检查语境是否真的在等待结果。
- 是非问句只是常见句型，不等于所有是非问句都自动按这一组选择。

原书例句必须包括：

- `Вы когда-нибудь видели радугу над морем?`
- `Вы наконец увидели радугу над морем?`
- `Вы будете завтра читать новый журнал?`
- `В конце концов я получу свой журнал обратно?`

外部补充可用于解释：`Ты когда-нибудь писал сочинение?` 与 `Ты написал сочинение?` 的差异来自上下文预期，而不只是完成性。

关联原书练习：`GL1-Q089`，并根据正式映射继续核对是否有其他跨题组关联。

### 7.2 过程与结果

核心问题：说话人让听者看到动作展开的内部过程，还是把动作作为一个完整整体来陈述？

必须讲清：

- `всю неделю`、`долго` 等通常展开过程。
- `за неделю` 表示在一个时段内达成整体结果，与“持续一周”不是同义。
- 有持续时间不代表一定使用未完成体，例如说话人可以把整个有时长事件作为完整整体。
- 完成体不等于动作“很短”，未完成体也不等于动作“没有完成”。
- 动词的词汇意义、体对是否自然、句子上下文都会影响选择。

原书最小对比：

- `Аспирант писал статью всю неделю.`
- `Аспирант написал статью за неделю.`

关联原书练习：`GL1-Q038`、`GL1-Q039`、`GL1-Q041`。

### 7.3 多次动作与一次动作

核心问题：句子是在建立规律、习惯或重复背景，还是叙述一次有结果的事件？

必须讲清：

- `каждый день`、`часто`、`регулярно` 等与重复语义共同支持未完成体。
- 完成体的一次性通常同时带有事件边界和结果，不能只看“一次”。
- 一般事实中的 `один раз` 与具体一次结果必须区分。
- 一次完整事件可以用未完成体作一般事实陈述。
- 一次性和具体事实、结果之间有关联，但不是三个完全相同的概念。

原书对比必须包括祖父进花园、登山者上山和答应寄信三组例句。

关联原书练习：`GL1-Q040`、`GL1-Q044`、`GL1-Q091`。

### 7.4 同时发生与依次发生

核心问题：多个动作是共享同一时间背景，还是一个完成后推动下一个发生？

必须讲清：

- 并列动词不自动表示先后。
- 同时发生时，动作可以分别作为展开中的背景。
- 依次发生时，完成体形成有边界的事件链。
- `сначала`、`потом`、`как только`、`сразу` 是顺序信号，但仍要核对真实时间关系。
- 叙事中可以混用两种体。完成体推动事件，未完成体可以放慢叙事并提供背景，但该补充必须标为外部说明。

原书对比必须包括教授讲课、翻书记录和校园音乐会三组。

关联原书练习：`GL1-Q042`、`GL1-Q090`、`GL1-Q092`。

### 7.5 结果已取消与结果仍保留

核心问题：过去发生的动作在说话时是否仍留下结果？

必须讲清：

- 本组只适用于过去时。
- 未完成体在这里不是“动作没完成”，而是动作结果后来被相反动作取消。
- 完成体表示结果在说话时仍然有效。
- 这一用法常见于动作/反动作词对和带方向前缀的运动动词。
- `приходили` 可以表示来过但已经离开；`пришли` 可以表示人现在仍在。
- `брал` 在相关语境中可以表示拿过并归还；`взял` 可以表示拿走后还没归还。
- 不能把所有过去时完成体都解释为“结果仍保留”。

原书最小对比：

- `Ко мне приходили друзья.` / `Ко мне пришли друзья.`
- `Кто брал мои книги?` / `Кто взял мой мобильный телефон?`
- `Кто включал мой утюг?` / `Кто включил мой утюг?`

关联原书练习：`GL1-Q043`、`GL1-Q093`、`GL1-Q094`。

## 8. 练习与反馈设计

### 8.1 练习梯度

每个阶段按以下难度推进：

```text
识别语义焦点
-> 二选一并说明依据
-> 最小对比判断意义变化
-> 修改一个条件后重新选择
-> 原书正式题
-> 综合语境题
```

不能只使用选择题。至少包含判断、解释、改写或配对中的一种。

### 8.2 答错反馈

答错后不只显示红色结果。反馈顺序：

1. 指出学习者采用了哪种错误判断。
2. 解释该判断为什么在当前语境失效。
3. 高亮真正决定答案的条件。
4. 展示一组最小对比例句。
5. 提供一题新的同类题。
6. 允许跳过，不强制锁住后续知识。

示例：

```text
你的判断：看到 один раз，所以选择完成体。
问题：один раз 也可以出现在一般事实中，不能单独决定体。
真正要问：说话人是在确认“是否发生过”，还是在检查一次结果？
回看：一般事实与具体事实 -> 信号词的失效条件。
```

### 8.3 原书题复用

- 嵌入页面的原书题继续使用原 exercise ID。
- 选择、确认、重试、错题和最后结果复用现有 localStorage 契约。
- 教学页面不得复制出新的题目 ID。
- 原书题在教学页完成后，正式题库同步显示结果。
- 教辅自编随堂题使用独立命名空间，不污染原书答题记录。

## 9. 学习状态

知识点状态：

- 未学习：尚未进入教学页。
- 学习中：已进入，尚未完成全部阶段随堂判断。
- 已学习：五个阶段均完成随堂判断。
- 已掌握：关键随堂题正确率达到 80%，且综合练习完成。
- 薄弱：相关原书题或随堂题持续错误。

不强制锁课。学习者可以随时进入下一知识点。

返回章节知识点卡片列表后必须恢复原来的滚动位置，并更新知识点入口卡的状态。思维导图不承担状态显示。

## 10. 内容来源分层

只允许以下可见来源类型：

- 原书规则：`source-rule`，显示原书页码。
- 原书表格：`source-table`，完整保留行列关系。
- 原书例句：`source-example`，显示原书页码。
- 原书练习：`exercise-example`，复用原题 ID。
- 教辅讲解、自编例句、随堂题：`learning-note`。
- 权威外部补充：`external-note`，记录可访问来源。

外部解释不能改变原书规则的范围，不能把 `source-exercise-only` 或 `needs-review` 自动升级为已验证规则。

学习者不需要阅读英文外部原页。每条英文外部资料必须在正文中提供中文标题、中文结论、对当前知识点的帮助和适用边界；原文链接只能放入“来源核验（可选）”折叠区，并明确标注“不影响学习、无需阅读英文”。

## 11. 视觉与响应式方向

- 现有阅读器为基础，不引入新的前端框架或无必要依赖。
- 这是学习工具，不做营销页式大标题、装饰卡阵列或强动画。
- 桌面端采用“窄目录 + 宽正文”的阅读结构；正文行宽控制在适合长文阅读的范围。
- 五个阶段主要依靠标题、留白、细分隔和少量真正有层级意义的容器组织，不把每段都包成卡片。
- 原书、教辅和外部补充通过一致的标签、边框和文字说明区分，不只依赖颜色。
- 学习路线允许轻微的状态过渡；思维导图只保留节点跳转反馈，不使用持续漂浮、缩放或滚动劫持。
- 所有状态支持键盘与触屏；移动端为单列，固定目录改为折叠导航。
- 加载、来源缺失、规则加载错误和无关联练习都需要明确状态。

建议设计参数：

- DESIGN_VARIANCE：4。稳定、清楚，允许局部非对称但不实验。
- MOTION_INTENSITY：2。只保留反馈和状态转换。
- VISUAL_DENSITY：6。内容丰富，但用渐进展开和阅读节奏控制压力。

## 12. 样板验收条件

在推广到其他知识点前，`1.4.1` 必须通过：

1. 第 1 章不再出现独立的“本章学习路线”或“第 1 章思维导图”，从 `1.4.1` 知识点卡进入独立教学页。
2. 页面连续呈现五个完整教学阶段。
3. 每个阶段均有原书规则翻译、原书例句解析和教辅补充。
4. 五组对立的条件、限制、反例和信号词失效条件齐全。
5. 13 道现有映射练习均能在正确阶段被找到，且不创建新 exercise ID。

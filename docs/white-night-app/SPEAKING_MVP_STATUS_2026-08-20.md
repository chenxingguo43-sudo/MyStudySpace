# 白夜俄语口语 MVP：当前状态与下一步

> 日期：2026-08-20  
> 范围：网页版口语，不包含阅读自动选题、跨书计划或 Agent 自我进化。  
> 状态：路线确认，尚未开始下一阶段生产实现。

## 1. 当前已经完成

### Reader 口语任务

- 俄语 B2 全模块已有 6 组会话任务：反义评价、交际意图、按意图朗读、视频描述、电话咨询、考官讨论。
- 《В мире людей》写作口语模块已有多个主题下的口语任务。
- 页面可以显示原书任务、渐进练习、提纲/转写输入、自查清单和参考回答。
- 任务可以手动标记完成。

### 本地录音

- 浏览器可以申请麦克风并录音。
- 录音保存到本机 IndexedDB，不依赖外部服务。
- 支持回听、删除、取消录音和刷新后继续查看。
- 录音没有被伪装成已经转写或已经评分的结果。
- 浏览器不支持录音或用户拒绝权限时，仍可以使用文字提纲完成任务。

### AI 口语契约

- 已有口语 AI 的结构化返回格式：俄语回复、追问、必要的中文澄清、支架、集中纠错和 TTS 分段。
- 已有 5 个固定模拟案例，覆盖：转写不确定时追问、短回复并继续追问、中文求助后的支架、B2 引导练习、集中纠错。
- 离线契约测试通过，说明接口规则已经可以作为后续实现的基础。

## 2. 当前还没有完成

### 真实语音闭环

现在还不是：

```text
录音 → 自动转写 → Agent 理解 → 俄语回复 → 语音播放 → 会话复盘
```

当前实际更接近：

```text
口语任务 → 文字提纲 / 本地录音 → 回听与保存
```

### 尚未落地的部分

- ASR 真实服务接入和中俄双通道转写。
- 转写确认、原始转写与最终转写的分层保存。
- 口语 AI 请求从 Reader 页面发出并展示结果。
- TTS 语音回复和字幕播放。
- 会话结束后的复盘、重说和表达激活记录。
- 口语证据进入白夜 Agent 学习画像。
- 真实 LLM 供应商、模型、费用和数据政策的验收。

## 3. 建议的最小口语 MVP

第一版只验证“一道 B2 口语任务能完整练一遍”，不做自由聊天首页、不做每日计划、不做自动进化。

```text
打开一项已有 B2 口语任务
  ↓
查看任务要求和必要支架
  ↓
用户录音
  ↓
保存原始录音
  ↓
ASR 得到俄语/中文转写
  ↓
用户确认或修改转写
  ↓
Agent 给出简短俄语追问或反馈
  ↓
保存本次练习证据
```

第一阶段可以先不做 TTS。只要录音、转写、文字 Agent 回复和本地保存形成闭环，就足以验证核心学习价值。TTS 可以作为下一小步接入。

## 4. MVP 验收标准

完成一项口语任务后，必须能确认：

1. 原始录音仍在本机，刷新页面后可回听。
2. ASR 结果明确区分俄语转写、中文转写和用户确认后的文本。
3. ASR 不确定且影响意思时，Agent 会追问，不静默猜测。
4. Agent 回复以俄语为主，中文只作为必要支架。
5. 纠错集中在少量高价值问题，不给未经校准的精确考试分数。
6. AI 不可用时，录音和文字提纲仍可保存，任务不会丢失。
7. 本次练习至少保存任务 ID、录音 ID、转写状态、用户确认文本和时间。
8. 口语数据不覆盖 Reader 既有阅读、词汇、语法和写作记录。

## 5. 分阶段顺序

### Phase S0：保留现状

- 保持现有录音、回听、删除和文字提纲功能。
- 不接真实 AI，不改变现有页面行为。
- 先确认一项 B2 任务作为验收样例。

### Phase S1：录音到转写

- 接入已选定的 ASR 方案。
- 保存双通道原始结果和确认结果。
- 断网或 ASR 失败时保留录音，显示待处理状态。

### Phase S2：转写到 Agent 文字回复

- 复用现有口语 JSON 契约。
- 先接文字回复和追问，不接 TTS。
- 记录 AI 结果与用户反馈，但不改学习成绩。

### Phase S3：TTS 与复盘

- 接入本地 TTS 或备选服务。
- 增加会话结束复盘、重说和表达激活。
- 再评估哪些证据进入白夜 Agent 画像。

## 6. 明确不在本阶段做

- 阅读文章自动选择“今天练什么”。
- 把 17 本 Skill 全部接入 Reader。
- 跨书自动计划和每日调度。
- Agent 自动修改自身定义或生产配置。
- 实时全双工语音、视频理解、精确发音评分。
- 账号、云同步、多用户和 Android 恢复路线。

## 7. 当前最关键的下一步

先选定一个现有 B2 口语任务作为 S1/S2 的验收样例，并确认三件事：

- 任务原文和参考回答的来源已经可靠；
- 录音、转写和 Agent 回复是否允许保存在本机；
- 第一阶段是否接受“先文字 Agent 回复，暂时没有 TTS”。

在这三点明确前，不开始真实供应商接入。

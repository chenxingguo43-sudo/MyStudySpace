## 二、俄语口语素材库模块（俄语知识库.html）

| 键名 | 数据类型 | 格式说明 | 写入位置 | 读取位置 | 用途 |

| `oral-speak-records` | Object | `{row-id: {count, dates, lastSpeak, rating}}` | 俄语知识库.html | study-stats.html, 俄语知识库.html | 记录口语练习次数及评分 |
| `oral-memo-records` | Object | `{row-id: {count, dates, lastMemo}}` | 俄语知识库.html | study-stats.html, 俄语知识库.html | 记录记忆次数 |

### 数据格式详解

**`oral-read-records` 格式：**
```json
{
  "row-1-1": {
    "count": 3,
    "dates": ["2025-01-15", "2025-01-16", "2025-01-17"],
    "lastRead": "2025-01-17"
  },
  "row-1-2": {
    "count": 1,
    "dates": ["2025-01-16"],
    "lastRead": "2025-01-16"
  }
}
```

**`oral-speak-records` 格式：**
```json
{
  "row-1-1": {
    "count": 2,
    "dates": ["2025-01-15", "2025-01-17"],
    "lastSpeak": "2025-01-17",
    "rating": 4
  }
}
```
> `rating` 值：1=😰 困难, 2=😐 一般, 3=🙂 不错, 4=😊 很好, 5=🌟 完美

**`oral-memo-records` 格式：**
```json

    "count": 5,

    "lastMemo": "2025-01-19"

```

**`oral-chapter-masks` 格式：**
```json
{
  "ch1": {
    "ru": true,
    "zh": false
  },
  "ch2": {
    "ru": false,
    "zh": false
  }
}
```

**`oral-speak-daily` 格式：**
```json
{
  "2025-01-15": [
    {"rowId": "row-1-1", "rating": 3, "timestamp": 1736940000000},

```

**`oral-daily-position` 格式：**
```json
{
  "2025-01-15": 1250,
  "2025-01-16": 3800
}
```

## 三、数据迁移与兼容性

### Zlatoust 语法词汇答题记录

| 键名 | 数据类型 | 格式说明 | 写入位置 | 读取位置 | 用途 |
|------|-----------|----------|----------|----------|------|
| `rr_b2_progress_v1` | Object | `{bookId:unitId: {exerciseId: {selected, submitted, attempts, wrong, everWrong, lastResult, lastAnsweredAt, ...}}}` | reader.html | reader.html | 题目作答、错题和单元进度；Zlatoust 使用 `zlatoust_grammar:gl1` 至 `zlatoust_grammar:gl5` |
| `zlatoust_grammar_progress_answer_repair_v1_backup` | Object | `{version, createdAt, records}`，仅含五章 Zlatoust 迁移前记录 | reader.html | 仅供故障排查 | 首次答案键修正迁移的只读备份 |
| `zlatoust_grammar_progress_answer_repair_v1` | Object | `{version, migratedAt, correctedRecords}` | reader.html | reader.html | 迁移完成标记，保证重复打开页面不会重复处理 |

**答案键修正迁移：** 五章共 88 条答案键修正。首次读取到受影响的已提交单选记录时，`js/zlatoust-progress-migration.js` 会先备份五章记录，再按修复账本重算 `wrong` 和 `lastResult`。它保留 `selected`、`attempts`、`everWrong`、答题时间、开放作答和未知的未来字段；不处理俄语 B2 的其他模块、未提交选择或 `open-response` 记录。

### 版本迁移记录

**V7.0 → V9.0：**
- `oral-read-records` 旧格式：`{row-id: {read: bool, date: string}}`
- V9.0 新格式：`{row-id: {count: number, dates: [], lastRead: string}}`
- 迁移函数：`OralLib._migrate()` （在俄语知识库.html 中）

### 迁移代码示例

```javascript
_migrate: function() {
    try {
        var d = JSON.parse(localStorage.getItem('oral-read-records') || '{}');
        for (var k in d) {
            if (d[k].read && !d[k].count) {
                d[k] = {
                    count: 1,
                    dates: [d[k].date || ''],
                    lastRead: d[k].date || ''
                };
            }
        }
        localStorage.setItem('oral-read-records', JSON.stringify(d));
    } catch(e) {}
}
```

## 四、数据管理操作

### 导出数据

**函数：** `exportAllData()` （在 study-stats.html 中）

**导出内容：** 所有上述键名的当前值

**文件格式：** JSON，格式化输出（2空格缩进）

**文件名：** `mystudyspace-backup-YYYY-MM-DD.json`

### 导入数据

**函数：** `importData(event)` （在 study-stats.html 中）

**支持格式：** JSON 文件，结构与导出格式一致

**注意：** 导入会覆盖当前所有数据

### 清空数据

**函数：** `clearAllData()` （在 study-stats.html 中）

**操作：** 删除所有上述键名

**注意：** 此操作不可恢复，会弹出确认对话框

## 五、跨页面数据同步

### Storage 事件监听

**监听位置：** `study-stats.html`

**监听键名：**
- `pomodoro-today-count`
- `pomodoro-today-minutes`
- `pomodoro-total-count`
- `pomodoro-total-minutes`
- `pomodoro-streak`
- `oral-read-records`
- `oral-speak-records`
- `oral-memo-records`
- `oral-speak-daily`

**同步机制：** 当上述键名在其它页面（pomodoro.html 或 俄语知识库.html）中被修改时，会自动触发 `storage` 事件，`study-stats.html` 接收到事件后自动刷新统计数据显示。

### postMessage 通信

**用例：** 番茄钟迷你模式中的位置同步

**发送方：** `pomodoro.html`

**接收方：** `index.html`

**消息格式：** `'CLOSE_RUSSIAN'` （返回番茄主页）

## 七、注意事项

1. **数据持久性：** localStorage 数据永久存储，除非手动清除或浏览器清除缓存
2. **跨域限制：** localStorage 仅限同源页面访问
3. **存储上限：** 大多数浏览器限制为 5-10MB
4. **隐私模式：** 无痕模式下，localStorage 数据在关闭窗口后会被清除
5. **数据备份：** 建议定期使用"导出所有数据"功能备份

## Reader 精听学习质量层

### 听力工作台基础状态

| 键名 | 类型 | 用途 |
| --- | --- | --- |
| `russian_b2_listening_progress_v1` | Object | 按教材永久题目 ID 保存已提交题目的正确/错误与完成进度。 |
| `rr_listening_drafts_v1` | Object | 按听力章节永久 ID 保存未提交的选项。 |
| `rr_listening_attempts_v1` | Array | 最近 500 次按章节永久 ID 保存的整组提交结果。 |
| `rr_lastread_<NOVEL_ID>` | Object | 当前教材、章节、滚动位置、活动题目和听力模式的恢复记录。 |
| `rr_world_people_resume_v1` | Object | 《В мире людей》各模块最近学习位置的索引，引用章节永久 ID 与上述 last-read 字段。 |
| `rr_listening_settings_v1` | Object | 播放速度、自动续播、句间停顿、字幕和 A/B 循环设置。 |

这些记录均使用教材/章节/题目永久 ID，不依赖会变化的目录数组下标；播放器位置和模式切换不会修改答题或完成记录。

| 键名 | 类型 | 用途 |
| --- | --- | --- |
| `rr_listening_quality_v1` | 以稳定句子 ID 为键的 Object | Reader 听力章节的难句标记、听写记录与仅本地的复习排序。 |

`rr_listening_quality_v1` 的记录字段：`id`、`bookId`、`chapterId`、`segmentIndex`（仅用于展示/定位）、`text`、`mediaFile`、`playlistIndex`、`startTime`、`endTime`、`source`、`isMediaExercise`、`firstMarkedAt`、`lastReviewedAt`、`reviewCount`、`status`、`dictation`。

永久记录 ID 由教材 ID、章节 ID、来源、媒体文件和规范化俄语原文计算内容哈希；`segmentIndex` 只为当前章节的便捷定位保留，绝不是唯一身份。`dictation` 包含 `lastInput`、`lastScore`、`attempts`、`completed`、`lastAttemptAt`、`missingWords`、`extraWords`。所有记录只留在浏览器 localStorage，不会发送到云同步。

# Reader 听力工作台重构设计

## 产品目标

在 Reader 内重做一套原生听力体验，围绕“听懂材料、完成题目、定位依据、精听复盘、错题再练”形成闭环。旧 `immersion-study-space` 只作为技术参考，不复用其页面结构。

## 明确不做

- 不显示波形图。
- 不提供跟读录音、发音评分和波形比较。
- 不把旧 Vue 工作站嵌入 iframe，也不要求 Reader 增加构建步骤。
- 不用 TTS 冒充已有的教材音频。

## 三种模式

### 考试

- 文字稿和答案默认隐藏。
- 答案先作为草稿保存，整组提交后统一批改。
- 显示已答题数、提交状态和本次结果。
- 已有 `russian_b2_listening_progress_v1` 继续作为长期进度来源。

### 精听

- 使用同一份音频，不离开 Reader。
- 支持逐句定位、上一句、下一句、单句循环、倍速和句间停顿。
- B2 VTT 可用时按精确时间轴同步字幕。
- 时间轴不可靠时只展示文字稿，不提供伪造的精准跳播。
- 俄语文字继续使用 Reader 的点击查词能力。

### 复盘

- 显示最近一次答卷的正确率、错题和未答题。
- 每道错题保留题目、当时答案、正确答案和官方依据。
- 可从错题直接进入对应依据句的精听。
- 后续在同一数据模型上增加证据句听写和间隔复习。

## 设置边界

真实音频设置：播放速度、句间停顿、单句循环、自动前进、字幕策略、答错后重播依据。

TTS 声音和音调只用于未来的错词听写兜底，不出现在真实 MP3 的主播放器中。

## 数据与兼容

- `russian_b2_listening_progress_v1`：长期题目掌握记录，兼容当前仪表盘。
- `rr_listening_drafts_v1`：按单元保存未提交答案。
- `rr_listening_attempts_v1`：保存不可覆盖的整组提交记录。
- `rr_listening_settings_v1`：保存本设备的听力偏好。

旧记录只补充字段，不删除、不重置。新会话提交时同步写入旧进度键，保证已有统计继续工作。

## 时间轴策略

1. 优先使用 `media.captions` 指向的 VTT。
2. 没有 VTT 时读取可信的 `transcriptSegments.startTime/endTime`。
3. 时间段重叠、长度异常或全部挤在音频尾部时标记为不可定位。
4. 不可定位时保留文字稿、完整音频和题目，但关闭逐句跳播与循环。

## 代码边界

- `js/russian-b2/listening-session.js`：草稿、提交、长期进度、复习记录和设置归一化。
- `js/russian-b2/listening-workbench.js`：音频、VTT、字幕同步、循环和 UI 事件。
- `css/reader-listening-workbench.css`：Reader 原生听力布局和响应式状态。
- `reader.html`：只保留教材上下文、题目渲染和模式入口。

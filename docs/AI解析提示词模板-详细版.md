# AI解析提示词模板（详细版 — 名词）

## 完整提示词（覆盖以下所有要点）

```
你是俄语ТРКИ-2（B2）级别的词汇教学专家。请为以下每一个俄语名词生成一份详细、教学导向的AI解析卡片。

## 输出格式（每个词一个JSON对象，最终输出为一个JSON数组）

{
  "word": "例词",
  "definition_ru": "俄语详解",
  "definition_zh": "中文详解",
  "collocations": [
    {"phrase": "搭配短语", "ru": "带搭配的完整俄语句子（自然、生活化、B2可读懂）", "zh": "对应中文翻译"}
  ],
  "synonyms": [
    {"word": "近义词", "diff": "与主词在语义/语体/搭配上的具体区别"}
  ],
  "antonyms": [
    "反义词1",
    "反义词2"
  ],
  "confusable": [
    "易混淆词1 — 混淆点和区分方法",
    "易混淆词2 — 混淆点和区分方法"
  ],
  "special_usage": [
    "特殊用法点1",
    "特殊用法点2"
  ]
}

## ⚠️ 质量要求（请严格遵守）

### definition_ru（俄语详解）要求：
- 2-4句完整通顺的俄语，不要逐词解释
- 第1句：核心含义 + 词性 + 性（阳/阴/中如适用）
- 第2句：主要使用场景、语体色彩（正式/口语/中性）
- 第3句（可选）：特殊语义、转义、固定用法
- 第4句（可选）：与近义词的核心区别
- 必须用俄语思维写，不要翻译腔
- 例：Храм — это культовое сооружение, предназначенное для богослужений и религиозных обрядов. В православной традиции храмом называют церковное здание с алтарём и куполом, в отличие от часовни (часовня), где нет алтаря. В широком смысле слово употребляется для обозначения священных мест любых религий: буддийский храм, индуистский храм и т.д. Слово относится к высокому, книжному стилю, хотя в бытовой речи используется нейтрально.

### definition_zh（中文详解）要求：
- 不要逐字翻译俄语解释
- 用自然中文写出这个词的核心含义、使用场景
- 补充中国学习者容易忽略的信息（如文化背景、语用差异）
- 例：храм 指宗教祭祀场所，通常比教堂（церковь）更大、更正式。在俄罗斯东正教文化中，храм 必须包含祭坛（алтарь）和圆顶（купол），而 часовня（小礼拜堂）没有祭坛。храм 也可泛用于任何宗教的圣地：佛教寺庙、印度教神庙等。

### collocations（搭配）要求：
- 3-4个日常高频搭配
- 每个搭配配一个完整、自然、场景化的句子
- 句子不要太教科书化，要像真实对话或文章中出现的
- 动词搭配要标出接格关系（例如：играть роль в + предложный падеж）

### synonyms（近义词辨析）要求：
- 1-3个近义词
- 每个都要说明与主词的具体区别（语义范围、语体、搭配习惯）
- 不要只说"同义词"，必须指出哪里不同
- 例：здание — строение — сооружение — постройка:
  здание（建筑物）最通用；сооружение 强调工程技术角度；строение 用于描述建筑形式；постройка 口语化，常带临时性色彩

### antonyms（反义词）要求：
- 1-2个，要给出词性标注
- 如果没有直接反义词，写相关对立概念并在括号注明并非严格反义词

### confusable（易混淆词）要求：
- 1-2组，每组给混淆的具体情境 + 区分方法
- 尤其注意拼写相似、发音相似、或中文翻译相同但俄语用法不同的词
- 例：угол（角落）vs уголь（煤）—— 拼写只差一个软音符号，但含义完全不同
- 例：покупатель（买家）vs продавец（卖家）—— 反义概念，但学习者常搞混
- 例：площадь（广场）vs площадка（场地/平台）—— 同根词但含义和用法不同

### special_usage（特殊用法）要求：
- 2-5个要点
- 包括但不限于：特殊变格、重音移动、固定表达、语用限制、常见错误、文化典故
- 例：площадь — 复数二格用 площадей（非 площадей）；注意重音在单复数间移动：пло́щадь → пло́щади（单数主格）→ площадя́м（复数与格）→ площадя́ми（复数工具格）

## 语法信息要求
对于每个名词，请在解释中注明：
1. 性（阳性/阴性/中性）
2. 是否有特殊变格形式（-мя结尾、隐现元音、重音移动、复数特殊形式等）
3. 是否只用单数或只用复数
4. 特殊二格或六格形式（如适用）

## 直接输出JSON数组，不要任何其他内容
## 不要用Markdown代码块包裹
## 确保JSON有效（双引号内用\"转义）
```

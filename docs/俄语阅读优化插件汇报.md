## 四、各功能详细说明

### P0：阅读模式

- 通过命令给笔记 frontmatter 添加 `cssclasses: [russian-reading]`
- CSS snippet 精确匹配 `.markdown-preview-view.russian-reading` 和 `.markdown-source-view.russian-reading`
- 效果：正文 19px 字号、1.7 行高、720px 最大宽度、标题/段落/表格间距加大
- 侧边栏、文件列表、工具栏完全不受影响
- 支持暗色模式自动适配

### P1：生词保存

- 选中俄语文本 → 命令/右键 → 弹窗确认
- 弹窗预填：自动清洗选区得到词形原形，用户可修改
- 去重逻辑：按文件名路径判断，已存在的词条只追加 `encounter_dates` 和 `contexts`，不覆盖
- 写入格式：与现有 `词汇/名词/солнце.md` 完全一致的 frontmatter（`word/type/meaning/mastery/tags/created`），新增可选字段 `encounter_dates`、`contexts`
- 自动生成 markdown body：标题、释义、例句表、动词变位表模板
- 词性→目录映射：`noun→名词`、`verb→动词`、`adj→形容词`、`adv/function/particle/other→功能词`（可在设置中修改）

### P1：词性分色标记

- 选中文本 → 命令 → 弹窗选择词性（名词/动词/形容词/其他/移除标记）
- 名词 = 蓝色底线、动词 = 红色底线、形容词 = 绿色底线、其他 = 灰色底线
- 使用 `<mark>` 标签包裹，阅读视图和编辑视图均可显示
- 提供"移除标记"选项，删除选区周围的 `<mark>` 标签

### P2：双语折叠

- 用户手动在笔记中写 `<span class="ru-translation">译文</span>`
- 沉浸模式：所有译文隐藏，无视觉噪声
- 精读模式：译文可见，带左侧灰线、hover 时加深显示
- 不自动迁移现有笔记，只对新格式生效

### 设置面板（Settings → Russian Reading Optimizer）

- 阅读模式：字号、行高、背景色、最大宽度（均可调）
- 词汇存储：根目录、词性→目录名映射（逐项可调）、自动入库开关（默认关闭）
- 双语折叠：沉浸/精读模式下拉选择
- 使用说明：5 条命令的功能列表

## 五、关键设计决策

| 决策 | 原因 |
|------|------|
| 所有写入操作必须弹窗确认 | 避免误触污染词库，`autoSave` 默认关闭 |
| 按文件名去重 | 重复保存只追加日期和上下文，不新建重复文件 |
| 沿用现有 `word/type/meaning/mastery/tags` schema | 兼容 `build-vocabulary.js` 和 Dataview 仪表盘查询 |
| `encounter_dates`/`contexts` 为新增可选字段 | 不破坏现有结构，构建脚本忽略未知字段 |
| 阅读模式用 CSS snippet 实现 | 即使插件未启用，手动添加 cssclass 也能生效 |
| `main.js` 纯 JS 不用 TypeScript | 本地自用，无需构建步骤，Obsidian 直接加载 |
| YAML 解析器支持嵌套对象数组 | 保证 `contexts: [{date, text, source}]` 的读写正确 |

## 八、激活步骤

1. 打开 Obsidian → 设置 → 第三方插件 → 启用 **Russian Reading Optimizer**
2. 设置 → 外观 → CSS Snippets → 确认 **russian-reading-mode** 已启用（配置文件已自动启用）
3. 打开任意俄语笔记 → Ctrl+P → 输入 "Toggle Russian Reading Mode"

# B2 P3 知识点卡片 1-4 总计划

日期：2026-09-06

状态：`计划 4 verified`（2026-09-06）

适用范围：俄语 B2 全模块，P3“形动词与副动词”，P3-Q001 至 P3-Q050

## 1. 最终目标

把 P3 的 50 道题从“按题号分到四张卡”升级为一套真正可学习的知识体系：

- 每道题有且只有一个主要知识归属；
- 一道题可以有少量必要的次要关联，但不重复展示、重复计分；
- 每道题能跳到卡片内部最准确的讲解分支；
- 每张卡拿掉正式题目后，仍然是一节完整知识课；
- 四张卡共同覆盖 P3 的必要知识，同时边界清楚、互不冒充；
- 保留原卡片编号、题目编号、答案、来源和现有学习记录。

这不是让一张卡包揽 50 道题，而是让 4 张卡共同组成 P3 知识地图。

- 四个现有卡片 ID；
- P3-Q001 至 P3-Q050 的题号、题干、选项和答案；

## 4. Gate 0：P3 全 50 题映射审计

这是计划 1 开始前的强制门槛，不算正式改写卡片。

### 4.1 审计顺序

1. 先从教材和相邻卡片建立四张卡的知识覆盖目录。
2. 为每张卡列出核心概念、必要分支、适用条件、禁止情况、边界、改写或表达用途、相邻卡片交接点。
3. 冻结知识目录后，再逐题读取现有题目解析。
4. 为每道题记录主要卡片、主要分支、次要分支、映射理由和风险。
5. 检查题目是否只是因为题号连续而被分入当前卡片。
6. 检查是否存在教材必要分支没有任何正式题覆盖。

### 4.2 每道题的审计字段

| 字段 | 含义 |
|---|---|
| `exerciseId` | 原题 ID |
| `primaryCardId` | 唯一主要卡片 |
| `primaryBranchId` | 卡片内主要讲解位置 |
| `secondaryBranchIds` | 必要的补看位置，可以为空 |
| `mappingReason` | 为什么这样映射，必须指向句中实际判断 |
| `evidenceRefs` | 教材、题目解析或来源记录 |
| `status` | `confirmed`、`needs-review` 或 `blocked` |
| `risk` | 答案歧义、来源冲突、跨卡边界等问题 |

### 4.3 Gate 0 通过条件

- 50 道题全部进入审计表；
- 每题恰好一个主要卡片；
- 每个主要分支 ID 实际存在或已进入明确的待建目录；
- 次要关联不复制完整题目、不产生第二份成绩；
- 四张卡的知识范围在拿掉题目列表后仍然成立；
- Q024 至 Q044 是否保持一张卡有明确结论和理由；
- 未解决问题被标记为 `needs-review` 或 `blocked`，不能为了凑满 50 题假装通过。

Gate 0 的评审稿计划保存为 `docs/READER_B2_P3_MAPPING_AUDIT.md`。用户确认边界后，才把映射写入生产数据。

## 5. 计划 1：升级副动词的时间、条件、原因与让步

卡片：`p3-gerund-meanings`

题目：P3-Q024 至 P3-Q044

优先原因：21 题、知识范围最宽，最可能出现“一张卡只是为了包题”的问题。

### 5.1 先解决的边界问题

- 同时、先后等时间关系与体的提示之间是什么关系；
- 条件、原因、让步是副动词本身固定表达，还是由整句语境恢复；
- “副动词意义关系”和“副动词主体一致”分别负责哪一步；
- 哪些内容属于具体题目的选项解释，不能升级成一般规则；
- 一张总卡内部能否用清晰分支完成教学，是否真的需要拆卡。

### 5.2 交付物

- 概念覆盖账本和相邻卡片边界；
- Q024 至 Q044 的分支级映射；
- 第二版连续微课教学稿；
- 新版彩色曲线思维导图；
- 每个必要分支的例子、最小对比、当场练习、错因、换境重试；
- 综合迁移和来源证据区；
- 桌面与手机试学页面。

### 5.3 通过条件

学习者不只会把副动词翻译成“……着”，而能说明句中什么事实支持时间、原因、条件或让步关系；主体一致只作为独立检查，不替代意义判断。

## 6. 计划 2：升级主动形动词的一致

卡片：`p3-active-participles`

题目：P3-Q001 至 P3-Q015

### 6.1 核心审计方向

- 先找形动词修饰的中心名词；
- 区分动作执行者和其他句子成分；
- 性、数、格一致分别由什么决定；
- 主动现在时、主动过去时及相对时间怎样分工；
- 关系从句改写与形动词形式选择的边界。

最终分支以教材证据和 Gate 0 审计为准，不能直接照搬旧卡四节标题。

### 6.2 通过条件

学习者能够指出“谁执行动作、形动词修饰谁、中心名词是什么形式”，并据此说明选择，而不是只认一个词尾。

## 7. 计划 3：升级被动形动词的一致

卡片：`p3-passive-participles`

题目：P3-Q016 至 P3-Q023

### 7.1 核心审计方向

- 先找动作承受者，再找可能出现的执行者；
- 区分主动关系和被动关系；
- 区分动作过程、经常发生与已完成结果；
- 检查长形、短形和性数格变化在本题范围内各负责什么；
- 关系从句改写是否保留原来的施受关系和时间意义。

最终分支同样以教材证据为准，不把 8 道题的选项类型直接当课程目录。

### 7.2 通过条件

学习者能够说清“谁承受动作、动作是否完成、形式跟哪个名词一致”，并能识别把执行者和承受者反过来的错误。

## 8. 计划 4：P3 模块整体验收

前三张卡升级完成后，不立即宣布 P3 完成，必须做一次模块级验收。

### 8.1 内容验收

- 50 道题全部有一个主要卡片和一个有效主要分支；
- 跨卡关联有理由且不重复题目；
- 四张卡共同覆盖 P3 必要知识，没有明显空白和无说明重叠；
- 每张卡都通过“拿掉正式题仍是一节完整课”的检查；
- 题目解析中的局部结论没有被扩大成整张卡的一般规则；
- 所有 `needs-review` 和 `blocked` 项有清单和恢复条件。

### 8.2 数据与兼容验收

- 四个卡片 ID 和 50 个题目 ID 未改变；
- 现有答案、题面、来源和风险记录未被静默改写；
- 原答题、错题和旧卡记录仍可读取；
- 新版补充练习使用新的稳定子记录，不覆盖旧成绩；
- 从知识点卡片目录和每道映射题进入时，打开同一份新版卡片。

### 8.3 页面验收

- 四张卡统一使用当前 Reader 知识卡 CSS；
- 新版思维导图由 `js/reader-mind-map.js` 统一渲染；
- 每条导图分支能跳到完整讲解；
- 1280×844 和 390×844 下无页面级横向溢出、遮挡或文字丢失；
- 手机仅导图内部横向滑动；
- 返回题目、返回目录和继续学习位置正确。

## 9. 实施顺序和停止条件

正式顺序固定为：

```text
Gate 0 全 50 题映射审计
→ 计划 1 副动词意义关系
→ 计划 2 主动形动词
→ 计划 3 被动形动词
→ 计划 4 P3 整体验收
```

出现以下任一情况时停止后续阶段，并保留已完成结果：

- 教材证据不足以确定卡片边界；
- 原书答案与现有解析发生实质冲突；
- 当前数据契约不能保存主要分支和次要关联；
- 某阶段修改导致共享 Reader 检查失败；
- 拆卡会导致原卡 ID 或学习记录无法兼容。

停止不等于删除或回退已通过内容；问题解决后从最近一个通过的阶段继续。

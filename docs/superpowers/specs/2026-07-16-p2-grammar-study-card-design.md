# P2 语法知识点样板卡设计

## 目标

为俄语 B2 的 P2 建立一张可独立学习的知识点卡：`持续、原因与时间关系`（P2-Q051–Q058）。它服务于“先学规则、再做题、答后回原题看解析”的学习闭环，不复制或替代 B2 原书逐题解析。

## 已确认的体验决策

- 采用一屏全量布局：主要信息在首次打开时完整可读，而非逐层折叠。
- 采用分区、短段、对比表和留白来控制信息密度，避免整面长文。
- 不在卡片内呈现 P2-Q051–Q058 的逐题答案或错项解析；这些继续保留在原题页的“查看答案与解析”功能中。
- 卡片底部仅提供对应练习的入口：全部题目、仅本知识点错题、对应错题本。
- 例句以《新编俄语语法》为主（每张卡 4–6 条）；只在难以直观对比时增加 0–2 组“学习补充”例句，并明确标注。

## 读者页面结构

1. **标题与状态**：P2、知识点名、题号范围；显示已答、历史错题和待掌握数。
2. **考什么**：用一段简短说明界定时间点、完成时长、先后关系与原因关系。
3. **做题判断顺序**：先判断语义关系，再确认结构，最后确认格与词形。
4. **核心规则**：以短卡或表格说明 `через`、`за`、`после`、`благодаря`、`из-за` 等结构的语义、支配格和使用条件。
5. **易混对比**：并排对比 `через неделю / за неделю` 以及积极原因 `благодаря` 与消极原因 `из-за`；不以 B2 选项或答案的形式呈现。
6. **语法书例句**：展示经核验的语法书例句，并附来源文件和小节。
7. **学习补充**：仅在需要成对展示时添加，统一标记为“学习补充”。
8. **高频误区**：将常见混淆转换成可执行的排除步骤。
9. **练习入口**：进入 P2-Q051–Q058、重做本点历史错题、打开已筛选的错题本。

## 数据边界与来源

### 原始来源

- B2 题目范围：`P2-Q051` 至 `P2-Q058`，来源为 B2 原书的已发布练习数据。
- 语法书来源：`D:\MyStudySpace\俄语资料库\新编俄语语法\08 前置词.md`。
- 优先引用的章节：`表示时间意义的前置词辨析` 与 `表示原因关系的前置词辨析`；后者中包含 `благодаря`、`из-за` 的解释和例句。

### 新增数据

新增一个只读卡片数据文件，不修改原语法书 Markdown：

```text
规范数据/语法书映射/p2-time-cause-study-card.json
```

每条规则或例句都要包含：

```json
{
  "kind": "grammar-book | b2-original | study-supplement",
  "sourceFile": "08 前置词.md",
  "sourceSection": "表示时间意义的前置词辨析",
  "sourcePages": [297],
  "label": "新编俄语语法"
}
```

`kind: study-supplement` 不得填写或伪装成语法书来源；`kind: b2-original` 只能概括该组题明确考查的结构，不得写入选项、正确答案、错项排除或原书逐题解析。

## 交互与数据流

1. P2 的知识点导航卡点击后打开此学习卡，而不立即清空并开始该组练习。
2. 学习卡从既有 B2 progress 读取该点 `exerciseIds` 的已答、历史错题（`everWrong`）和待掌握状态。
3. “全部题目”沿用现有 `restartQuiz('knowledge', exerciseIds)` 逻辑。
4. “仅本点错题”只传入既属于当前知识点、又带有 `everWrong` 的题目。
5. “对应错题本”打开现有错题本，并同时传入部分与知识点筛选条件。
6. 原题页的答案、原书解析与 AI 参考解析不变。

## 质量与验收

- 语法书文件、章节、页码引用必须存在且能被自动检查。
- 所有原例句必须来自指定语法书章节；OCR 明显错误或无法核对的片段不得加入卡片。
- 所有学习补充例句必须使用明确来源标签。
- 卡片不得包含 B2 题目的正确选项、错项排除或原书逐题解析。
- 页面在桌面浏览器中能完整阅读，练习按钮能进入题 51–58，错题按钮只筛选该点。
- 原题页的“查看答案与解析”行为保持不变。

## 非目标

- 本样板不扩展到 P1、P3–P6。
- 不重写或复制《新编俄语语法》全文。
- 不把 B2 原书答案或解析迁移到知识点卡。

## 后续推广条件

完成样板并由用户确认内容深度、例句风格和布局可读性后，再复用同一数据模型扩展到其他 31 个知识点。

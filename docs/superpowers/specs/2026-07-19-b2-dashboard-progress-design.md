# 俄语 B2 仪表盘继续学习与模块进度设计

日期：2026-07-19

## 目标

把当前 B2 仪表盘从模块入口集合升级为日常学习入口：用户能够一键返回上次准确位置，并在不进入模块的情况下看懂各模块已经完成多少、还有什么需要继续。

## 范围

本批次包含：

- 仪表盘顶部“继续上次学习”主卡；
- 七个模块的统一进度摘要；
- 写作与会话的手动完成状态；
- 现有进度数据的聚合、异常降级和自动化测试。

本批次不包含：

- 跨模块统一复习列表的重构；
- 学习日历、连续天数或复杂统计图；
- 新的云同步系统；
- 根据草稿长度或录音存在与否自动判定写作、会话完成。

## 设计原则

1. 完成状态必须可解释，不能把“打开过页面”当成完成。
2. 优先复用现有 localStorage 记录，避免迁移和重复数据。
3. 写作、会话只能由用户手动标记完成；草稿、笔记和录音仅作为活动摘要。
4. 没有学习记录时显示“尚未开始”，不强调 0%。
5. 任意一类进度数据损坏时，只降级该模块，仪表盘仍可使用。

## 架构

扩展 `js/russian-b2/dashboard.js`，增加纯数据聚合接口。阅读器负责从 localStorage 读取现有记录并传入聚合器；聚合器输出统一的模块视图模型；`reader.html` 只渲染结果与处理跳转。

统一模块视图模型：

```json
{
  "id": "reading",
  "completed": 3,
  "total": 10,
  "percent": 30,
  "started": true,
  "secondaryLabel": "待复习 2 题",
  "lastActivityAt": "2026-07-19T09:30:00.000Z"
}
```

聚合器不能访问 DOM，也不直接访问 localStorage，以便使用真实数据夹具独立测试。

`lastActivityAt` 是可选字段，只能由带可靠时间戳的作答、手动完成或最后阅读记录生成。旧草稿、旧笔记等没有时间戳的数据不反推时间，界面直接省略“最近活动”。

## 继续学习主卡

来源为 `rr_lastread_russian-novel-reader`。B2 记录已包含：

- `bookId`
- `moduleId`
- `chapter`
- `scroll`
- `activeQuestionId`
- `viewMode`

显示内容：

- 模块名称；
- 章节或题目位置；
- 最近保存时间；
- 主按钮“继续学习”。

保存记录时增加 `updatedAt`。点击主卡调用现有的稳定恢复流程，直接返回模块、章节、题目和滚动位置。记录缺失时不显示主卡；记录损坏、模块被移除或章节越界时，回到 B2 仪表盘并给出非阻塞提示。

## 各模块完成口径

### 语法词汇

- 总数：P1–P6 六部分。
- 某部分全部正式题目已经提交，才计为完成。
- 次要信息：待掌握错题数。

### 阅读

- 总数：十篇阅读。
- 某篇全部原书理解题已经作答，才计为完成。
- 次要信息：未完成题数或待复习错题数；没有相关记录时不显示。

### 听力

- 总数：五个听力任务。
- 某任务全部原书题目已经作答，才计为完成。
- 次要信息：已作答题数。
- 进入精听模式或播放音频本身不计完成。

### 写作

- 总数：十三个写作任务。
- 用户点击“标记完成”后计入完成；再次点击可取消。
- 次要信息：有内容的草稿数量。
- 完成状态使用新键 `russian_b2_writing_completed_v1`，按稳定任务 ID 保存布尔值和时间。

### 会话

- 总数：六个会话任务。
- 用户点击“标记完成”后计入完成；再次点击可取消。
- 次要信息：有内容的笔记数量；录音仍保存在 IndexedDB，不把“有录音”直接等同于完成。
- 完成状态使用新键 `russian_b2_speaking_completed_v1`，按稳定任务 ID 保存布尔值和时间。

### 真题模拟

- 总数：五个原书模拟模块。
- 客观题全部作答、该模块要求的写作任务已手动完成后，才计为完成；仅包含客观题的模块按客观题完成情况计算。
- 真题写作沿用“只能手动确认完成”的原则，状态使用新键 `russian_b2_exam_completed_v1`，按稳定的模拟模块 ID 和任务 ID 保存布尔值与时间。
- 真题写作的草稿存在与否只作为活动摘要，不能替代手动完成状态。
- 若现有数据尚不能完整判断某模块，只显示已作答数量，不提前计为完成。

### 统一复习

- 不显示虚假的百分比。
- 显示当前可可靠聚合的待掌握错题、知识卡自测记录、写作草稿和会话笔记数量。
- 模块卡继续作为入口；跨模块复习页面重构留到下一批。

## 仪表盘页面

页面顺序：

1. B2 标题与简短说明；
2. “继续上次学习”主卡；
3. 七个模块卡片网格。

普通模块卡包含：

- 模块名称；
- `已完成 N / 总数`，未开始时显示“尚未开始”；
- 水平进度条；
- 一条次要摘要；
- 现有模块说明。

统一复习卡不显示完成率，改为复习摘要。

进度条使用现有暖色主题与强调色，不引入新的配色系统。卡片保持可点击，进度条本身不增加单独交互。

## 写作与会话页面

在任务标题区域增加一个明确的状态按钮：

- 未完成：`标记完成`
- 已完成：`✓ 已完成 · 取消`

切换后立即保存并更新按钮状态，不自动离开当前任务。草稿、笔记、录音保存逻辑保持不变。

真题模拟内的写作任务复用同一种按钮和交互，但写入独立的 `russian_b2_exam_completed_v1`，避免与日常写作模块的任务 ID 混淆。

## 学习档案兼容

现有 B2 学习档案导出与导入清单同步加入：

- `russian_b2_listening_progress_v1`；
- `russian_b2_writing_completed_v1`；
- `russian_b2_speaking_completed_v1`；
- `russian_b2_exam_completed_v1`。

导入旧档案时这些键可以缺失，按未完成处理；导入新档案时仍执行已存在的 JSON 校验与覆盖确认。最后阅读位置继续保留为当前浏览器的界面状态，不纳入学习档案，避免在另一台设备导入后突然改变所在页面。

## 数据容错

- JSON 解析失败时，该数据源按空对象处理。
- 未识别的题目或任务 ID不计入统计。
- 分母来自当前教材清单，不从历史记录推断。
- 完成数限制在 `0..total`。
- `updatedAt` 无效时不显示相对时间。
- 仪表盘聚合失败时，仍显示七个模块入口与“进度暂不可用”。

## 测试与验收

自动测试：

- 聚合器对空记录、部分完成、全部完成和损坏记录输出正确；
- 六类学习模块使用各自明确的完成口径；
- 写作、会话只有手动完成记录才增加完成数；
- 真题写作只有独立的手动完成记录才增加完成数；
- 继续学习记录保留模块、章节、题目、滚动位置和更新时间；
- 学习档案可往返保存听力进度和三类手动完成记录，旧档案仍可导入；
- 模块总数与 B2 清单一致；
- 统一复习不生成虚假完成率。

浏览器验收：

- 无记录时显示“尚未开始”；
- 在 P2 中间位置刷新后，主卡能再次直达该题；
- 完成一篇阅读后仪表盘从 `0/10` 更新为 `1/10`；
- 写作有草稿但未手动完成时只增加草稿数，不增加完成数；
- 手动标记写作、会话完成后，返回仪表盘立即更新；
- 暖色主题、桌面与窄屏下卡片没有溢出或低对比度问题。

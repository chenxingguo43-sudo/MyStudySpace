# 阅读器导航与词典缓存修复设计

## 目标

修复《В мире людей — 阅读口语》章节中俄语正文泄漏查词上下文 JSON 的回归问题，并让《俄语 B2 全模块》的页面导航复用阅读口语章节现有的浅色浮动控件，而非纯黑顶栏。

## 已确认范围

- 《В мире людей》保留现有的章节阅读布局、分栏词典和浅色浮动导航；只修复正文渲染。
- 给本地词典脚本使用显式版本参数，确保浏览器不会继续复用旧的、未正确转义上下文属性的缓存副本。
- B2 仪表盘、模块目录以及各专项页面使用同一套浅色浮动导航：主题、字号、查词/目录和返回入口保持清楚可见。
- 不改任何原题、原文、答案、写作草稿或学习进度的存储格式。

## 方案

### 1. 词典静态资源版本化

`reader.html` 中加载的 `core.js`、`storage.js` 与 `runtime.js` 带同一显式版本查询参数。每次词典渲染契约改变时更新版本，从而强制浏览器请求当前脚本。共享渲染器仍只把 JSON 上下文以 HTML 属性安全编码后写入 `data-lookup-context`。

### 2. B2 浮动导航适配器

新增一个 B2 专用的页面壳，复用现有 `fab-group-top`、`fab-btn`、`fab-group-bottom` 与 `fab-nav` 的视觉语言。它提供：

- 左侧：主题、字号；在可查词的学习页面保留查词提示。
- 右侧：返回书架或 B2 仪表盘，以及模块目录。
- 底部：仅在连续题目/连续文章中显示上一篇、下一篇。

旧的 `.toolbar` 不再用于 B2 仪表盘、模块目录和 B2 专项学习页；非 B2 书架页面保持原行为。

### 3. 回归测试与验收

- 单元测试断言词典上下文在 HTML 属性中被编码，且 `reading_speaking` 的长段落不会显示 `sourceLabel`、`sentenceZh` 或原始 JSON 键。
- 静态测试断言 B2 路由使用浮动导航壳，且不生成 `.toolbar`。
- 浏览器验收覆盖 B2 仪表盘与《В мире людей》第一章：无黑顶栏、无 JSON 泄漏、单词仍可点击查词。

## 不做的事

- 不重新设计书架或《В мире людей》章节。
- 不修改词典释义、在线查询流程或 B2 内容数据。
- 不将缓存版本号用于其他无关静态文件。

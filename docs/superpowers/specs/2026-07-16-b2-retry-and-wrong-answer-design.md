# B2 即点即答、二刷与错题复习

## 目标

降低单题作答步骤，并让已完成部分可反复练习；错误记录将成为后续书架错题本的可靠数据源。

## 交互

- 默认模式下，点击选项即提交答案：立即显示正误，解析仍需手动展开。
- 在设置中保留“作答前确认”开关；开启后维持现有“选择 → 确认答案”流程，默认关闭。
- 部分完成页提供三个操作：`再做全部`、`只重做错题`、`按知识点复习`。
- 再做全部清除本轮作答展示；只重做错题只渲染当前部分曾答错题；按知识点复习从导航卡片进入对应题组。

## 数据

- 继续使用 `rr_b2_progress_v1`，每个稳定题号保留累计 `attempts`、最近作答、是否曾错与最近结果。
- 重刷不得删除历史错误；在错题复习中答对只将该题标记为“已掌握”，不抹除历史。
- 当前部分完成状态由本轮已提交题目决定；重刷不影响其他部分。

## 边界与验收

- 不自动展开原书答案、原书解析或 AI 参考解析。
- 单击提交后不可在同一轮更改答案；重刷才产生新一轮机会。
- 自动化覆盖：默认即点即答、确认模式兼容、重刷重置但保留累计记录、错题筛选及知识点题组筛选。
- 浏览器验收：P2 单击选项不再出现额外确认步骤；完成后可启动三种重刷；错误题能被筛出且解析仍手动展开。

# Reader v2 — 分屏布局 + 详细单词卡片

**日期**: 2026-06-27  
**状态**: 设计定案  
**项目**: 俄语学习舱 Reader（`reader.html`）

---

## 一、背景

v1 已实现：词态还原引擎 + 扩展词库（4,970 可查词）+ 点击查词弹窗。

当前限制：
- 查词弹窗仅显示 3 行信息（单词 + 词性 + 释义），vocabulary.json 中 4,000+ 词带有例句、2,900+ 词有详细释义、2,700+ 词有常用搭配——全部未展示
- 弹窗浮在段落上方，遮挡阅读内容，无法同时"看卡片 + 继续读"

## 二、目标

1. **分屏布局**：右侧面板展示完整单词卡片，左侧继续阅读，可拖拽分界线
2. **详细卡片**：按词性展示释义、体/接格/对偶、常用搭配、例句、详细释义、变位表
3. **AI 深度解析过渡**：🤖 按钮改用 AgentChat 后端自动发送 → 返回结果追加到卡片
4. **横竖屏自适应**：≥768px 分屏模式，<768px 叠加模式

## 三、分屏布局设计

### 3.1 横屏模式（≥768px）

```
┌──────────────────────────────────────────────────────────┐
│                        工具栏                              │
├──────────────────────────────────────────────────────────┤
│                                                          │
│   左侧：阅读区 (flex: 自动伸缩)    │   右侧：单词卡片 (300-450px)│
│                                  │                        │
│   俄语段落...                     │  📖 верить             │
│   俄语段落...                     │  [未完成体动词]          │
│   俄语段落...                     │  📝 释义 + 体 + 接格    │
│                                  │  ✍️ 搭配 + 📖 详释      │
│                                  │  📚 例句 + 📐 变位      │
│                                  │  [🤖 AI 深度解析]       │
├──────────────────────────────────────────────────────────┤
│                        底部导航                            │
└──────────────────────────────────────────────────────────┘
              ←── ║ ──→  可拖拽分界线
```

- 右侧面板默认宽度 380px，可通过拖拽分界线在 280px-520px 范围调节
- 点击单词 → 面板滑入（transform + transition）
- 点击关闭按钮或再次点击同一单词 → 面板滑出，阅读区恢复全宽

### 3.2 竖屏模式（<768px）

```
┌──────────────────────┐        ┌──────────────────────┐
│                      │        │                      │
│      俄语段落         │  点击   │   俄语段落  │ 卡片    │
│      俄语段落         │  →→→   │   俄语段落  │ (覆盖)  │
│      俄语段落         │  单词   │             │        │
│                      │        │             │        │
└──────────────────────┘        └──────────────────────┘
```

- 卡片从右侧滑出叠加在阅读区上方
- 占屏幕宽度 55%-75%，可拖拽调节
- 背景半透明遮罩，点击遮罩关闭

### 3.3 关键 CSS

```css
/* 主容器：flex 布局 */
.reader-layout { display: flex; }

/* 阅读区 */
.reader-pane { flex: 1; min-width: 0; overflow-y: auto; }

/* 单词卡片面板 */
.detail-panel {
  width: 380px; flex-shrink: 0;
  transform: translateX(0);
  transition: width 0.1s, transform 0.3s;
}
.detail-panel.hidden { transform: translateX(100%); }

/* 拖拽分界线 */
.resize-handle {
  width: 6px; cursor: col-resize;
  background: var(--border);
}
.resize-handle:hover { background: var(--accent); }

/* 竖屏：叠加模式 */
@media (max-width: 767px) {
  .detail-panel {
    position: fixed; right: 0; top: 48px; bottom: 52px;
    z-index: 200; box-shadow: -4px 0 20px rgba(0,0,0,0.3);
    width: 65vw; min-width: 260px;
  }
}
```

### 3.4 拖拽逻辑

```javascript
// 分界线拖拽
var resizeX = 0;
handle.addEventListener('pointerdown', function(e) {
  resizeX = e.clientX;
  handle.setPointerCapture(e.pointerId);
});
handle.addEventListener('pointermove', function(e) {
  var delta = resizeX - e.clientX;
  var newWidth = Math.max(280, Math.min(520, panel.offsetWidth + delta));
  panel.style.width = newWidth + 'px';
  resizeX = e.clientX;
});
handle.addEventListener('pointerup', function() { /* save preference */ });
```

## 四、单词卡片内容设计

### 4.1 通用区域（所有词性）

```
┌─────────────────────────────┐
│  🔤 单词（原形+重音）         │
│  [词性标签]                  │
│                             │
│  📝 中文释义                 │
└─────────────────────────────┘
```

### 4.2 动词专用模块

按优先级从上到下排列，**无数据的模块不展示，不占空间**：

| 模块 | 数据字段 | 展示形式 | 默认状态 |
|------|------|------|------|
| 体 | `aspect` | `[未完成体]` `[完成体]` 标签 | 显示 |
| 体对偶 | `pair` | `→ поверить (св)` 一行文字 | 显示 |
| 接格 | `case_gov` | `кого-что / кому` 灰色标注 | 显示 |
| 常用搭配 | `collocations[]` | 3-5 条：搭配短语 + 俄语句子 + 中文翻译 | 显示前3条，多余折叠 |
| 详细释义 | `detailZh` | 中俄双语长篇，可折叠 | **折叠** |
| 例句 | `examples[]` | 原句 + 中文翻译 | **折叠** |
| 变位表 | `grammarTable` | 完整变位表格 | **折叠** |

### 4.3 名词专用模块

| 模块 | 数据字段 | 展示形式 | 默认状态 |
|------|------|------|------|
| 性 | `gender` | `[阳性]` `[阴性]` `[中性]` 标签 | 显示 |
| 常用搭配 | `collocations[]` | 同上 | 显示前3条 |
| 详细释义 | `detailZh` | 折叠 | **折叠** |
| 例句 | `examples[]` | 折叠 | **折叠** |
| 变格表 | `grammarTable` | 折叠 | **折叠** |

### 4.4 形容词/副词专用模块

| 模块 | 数据字段 | 展示形式 |
|------|------|------|
| 性 (形容词) | `gender` | 标签 |
| 短尾 (形容词) | `short_form` | `短尾：похож` |
| 比较级 | `comparative` | `→ лучше` |

### 4.5 🤖 AI 深度解析按钮

位置：卡片底部固定

```
┌─────────────────────────────┐
│  ... (卡片内容) ...          │
│                             │
│  ─────────────────────────  │
│  [🤖 AI 深度解析]            │
│  (点击后发送上下文给 AI，     │
│   返回结果追加到卡片下方)      │
└─────────────────────────────┘
```

行为：
1. 点击 → 按钮变灰色 + 显示 spinner
2. 后台调用 AgentChat（Gemini 或豆包）
3. 返回结果追加渲染到卡片底部，带来源标注 `Gemini / 豆包`
4. 按钮恢复可用

### 4.6 数据加载

`loadLocalLookupData()` 当前只存 3 个字段到 `localVocabLookup`。需要**多存一个 `_raw` 引用**指向原始词汇条目，卡片渲染时按需读取富数据。

```javascript
localVocabLookup[key] = {
  meaning: w.meaning,
  type: w.type || '',
  source: '本地词库',
  _raw: w  // 保留原始条目引用，卡片渲染时用
};
```

## 五、🤖 按钮 v2 定位

**短期（过渡方案）**：🤖 按钮保留在卡片底部，点击 → AgentChat 发送 → 返回结果追加显示。用户需等几秒。

**长期（数据预补齐）**：用 Gemini/豆包批量预处理，把缺的释义/搭配/例句一次性翻译好，合并进 vocabulary.json。之后大多数词不需要调 AI，🤖 按钮逐步退出主流程。

# 俄语 B2：六部分连续练习与知识点导航

## 目标

把当前由 30 个十题技术单元构成的《俄语 B2 全模块》阅读器，收束为与原书节奏一致的 P1–P6 六个学习部分。每个部分提供完整、连续的题目流，同时在章首提供可跳转的知识点导航。

本设计服务两种学习方式：

1. 按原书顺序连续完成一个部分；
2. 按知识点回到相关题群复习。

## 范围

### 包含

- 书架中《俄语 B2 全模块》的章节数从 30 改为 6，对应 P1–P6。
- 每个部分将既有十题 JSON 单元按原有题号拼接为一个连续练习章节。
- 章节顶部显示知识点导航卡片：名称、题号范围、简明规则、易错点（如有），以及跳转到第一题的按钮。
- 知识点与题目的关联允许多对多；跳转不重排、不复制题目。
- 已有的稳定题号（例如 `P2-Q055`）、答案、原书依据、AI 参考解析、题目完成状态及 localStorage 学习记录继续有效。
- P6 保持已发布的独立题范围（1–8、27–36）；不把已排除的材料依赖题纳入连续练习。

### 不包含

- 不改变原题、选项、答案或原书页图绑定。
- 不为方便分组而推断未经原书解析支持的规则。
- 不在本次加入错题本、间隔复习算法或新的云同步机制。

## 用户体验

书架点击《俄语 B2 全模块》后，显示六张部分卡片（P1–P6），每张展示部分标题、可用题数与完成进度。点击卡片直接进入该部分，不再出现 30 项目录。

进入 P2 的示意：

```text
P2 名词、形容词与接格（70 题）
完成 18 / 70

知识点导航
[ 时间与持续：51–52 ] [ 原因：53–54 ]
[ 时间关系：55–58 ] [ 前置词搭配：59–69 ] [ 非一致定语：70 ]

连续练习
Q001 … Q070
```

示意中的分组只说明导航形态；实际标题、范围、规则和易错点须逐题比对原书解析后写入规范数据。用户点击某一知识点卡片时，阅读器滚动到该组起始题，并给出可见的定位提示；题目仍按原书次序排列。

## 数据与实现边界

在规范数据中新增“部分学习导航”元数据，而不是依赖显示层的题号计算。每个部分定义：

- `partId`、标题、题号范围与已发布题数；
- 原有 unit ID 的顺序列表；
- 一个或多个知识点条目：稳定 ID、名称、题号/题目 ID 引用、规则、易错点、原书依据页；
- 对 P6 的明确可用题范围。

构建脚本根据此元数据读取既有单元 JSON，生成六个 reader 章节文件；不会更改原始题目 JSON。阅读器以新的部分章节为入口，并以题目稳定 ID 读取/写入现有进度键，因此历史作答不会丢失。

## 错误处理与兼容性

- 元数据引用不存在题目、重复题目或乱序时，构建验证失败，不发布章节。
- 若知识点未提供规则或原书依据页，构建验证失败；避免展示未经核验的概括。
- 缺失或损坏的旧 localStorage 记录按当前迁移逻辑降级为空进度，不妨碍练习。
- 章节加载失败时保留现有“加载失败”提示；不显示半成品导航。

## 验收与测试

- 自动化：六部分题数与既有已发布题总数一致；每道题只在所属部分出现一次；顺序、稳定 ID、答案、来源账本均不变。
- 自动化：每个知识点引用的题目存在、属于本部分，规则与依据页完整。
- 交互：书架显示 P1–P6 六项；进入 P2 可连续看到 Q001–Q070；从知识点卡片跳转至正确首题；提交答案、展开解析后不会回到页面顶部。
- 回归：现有 `npm run test:russian-b2` 与来源账本验证通过。

## 实施顺序

1. 从原书页及已核验解析建立 P1–P6 知识点元数据并验证；
2. 将 30 个发布单元构建为 6 个连续 reader 章节；
3. 更新目录与阅读器交互；
4. 自动化、浏览器和学习进度回归测试。

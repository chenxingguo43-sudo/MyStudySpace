## 1. 文档定位

本规格细化并修订 `2026-07-17-russian-b2-full-reader-rollout-design.md` 中的听力与写作设计。两份规格发生冲突时，听力和写作以本规格为准；整书统一入口、语法、阅读、会话、真题和 190 页覆盖目标继续沿用整书规格。

本次重建解决的不是局部排版问题，而是两项内容链路缺失：

- 听力当前有音频和文字稿，却缺少原书完整俄语题干与选项；对话中的 `А:`、`Б:` 还会被语音读出。
- 写作当前把原书完整任务、广告材料、公文版式和范文压缩成极短中文摘要，不符合“原书可追溯复刻 + 方便学习”的目标。

## 2. 目标与非目标

### 2.1 目标

1. 书架只保留一本《俄语 B2 全模块》，听力和写作作为该书内部模块。
2. 听力默认先进入考试题页，并提供显眼的“精听这段材料”入口。
3. 恢复原书俄语题干、全部选项、答案、解析依据、文字稿和页码。
4. 修复角色语音：页面显示说话人标签，但语音不朗读标签；不同角色使用不同声音。
5. 复用现有精听工具的逐句播放、循环、变速、录音、笔记和导出能力。
6. 写作完整恢复原书任务、材料、版式、范文和评分要求，并提供真正可学习的写作工作台。
7. 建立分层反馈、多版本修改和写作问题本。
8. 所有原书内容、重建媒体、学习整理和 AI 反馈具有明确身份与来源。
9. 首轮至少修复当前已识别的 5 组、25 道听力题和 13 类写作任务；最终数量以 190 页覆盖台账核对出的原书有效任务为准，不以现有残缺数据作为上限。

### 2.2 非目标

- 不以 TTS 冒充原始录音或原视频。
- 不让 AI 猜补并冒充原书题面、答案、范文或评分。
- 不把现有精听工具整体复制进 `reader.html`，也不破坏它原有的独立课程。
- 不在本次规格中重做语法、阅读或会话模块。
- 不因为模块重建而清空已有语法进度、错题和知识卡记录。

## 3. 产品架构：统一入口、双引擎协作

### 3.1 唯一教材入口

```text
俄语 B2 全模块
├─ 学习概览
├─ 语法和词汇
├─ 阅读
├─ 写作
├─ 听力
├─ 会话
├─ 真题与模拟
└─ 复习中心
```

`reader.html` 是整本书的唯一主入口，负责目录、考试题、答案、进度、错题、写作版本和跨模块汇总。听力精听由现有 `immersion-study-space` 提供专用工作台，两端通过稳定任务 ID 协作。

### 3.2 职责边界

- **B2 原书层：** 任务、材料、题干、选项、答案、解析、范文、评分要求与页码。
- **阅读器：** 教材仪表盘、考试作答、模式控制、错题、写作工作台、反馈与版本记录。
- **精听工具：** 波形、逐句播放、AB 循环、变速、跟读录音、笔记和精听记录。
- **学习辅助：** 中文提示、结构拆解、自动检查和 AI 反馈；不得冒充原书。
- **Obsidian/Markdown：** 自动生成的可搜索归档，不作为独立维护的第二套事实源。

### 3.3 降级原则

精听工具、TTS、AI 或同步服务不可用时，原书听力题和写作任务仍能正常打开、保存和作答。单个外部能力失败不得拖垮整本教材。

## 4. 听力模块

### 4.1 默认学习路径

```text
进入听力任务
→ 默认显示考试题页
→ 播放媒体并完成原书题目
→ 提交题组
→ 查看答案与原书依据
→ 按需点击“精听这段材料”
→ 在精听工作台逐句学习
→ 返回原任务
```

“精听这段材料”必须是考试页上的明显主操作之一，但不得取代考试题页成为默认入口。

### 4.2 每个任务的正式内容

1. 原书任务说明；
2. 完整俄语题干；
3. 全部原书选项；
4. 原始媒体或明确标注的替代材料；
5. 原书答案与可追溯依据；
6. 文字稿及其来源；
7. PDF 页码与书内印刷页码；
8. “精听这段材料”入口；
9. 学习模式与模拟考试模式的独立记录。

中文摘要只能作为辅助说明，不得代替俄语题面。

### 4.3 学习模式与模拟考试模式

**学习模式（默认）：**

- 第一次播放时隐藏文字稿；
- 首次播放后可逐句显示或全部显示；
- 单击选项即作答；
- 题组提交后开放答案、原书依据和精听入口；
- 允许重复播放、变速和查看学习辅助。

**模拟考试模式：**

- 提交前隐藏文字稿、翻译、答案和学习辅助；
- 按原书或规范设定播放次数与时间；
- 整组提交后才显示结果；
- 重建音频可以运行完整的模拟交互，但成绩标为“重建媒体模拟练习”；只有具备原始配套录音或原视频的任务进入正式模拟趋势。

两种模式的成绩分开统计，错题进入同一错题本，并标注来源模式。

### 4.4 角色分段与语音生成

对话文字稿必须拆成独立句段：

```text
speaker: A
displayLabel: А
text: Привет! Как дела?
voice: <speaker-a-voice>
```

规则如下：

- 页面保留 `А：`、`Б：` 等说话人标签；
- 送入 TTS 的文本必须剥离标签；
- 不同说话人使用不同的俄语声音；
- 角色轮换时加入自然停顿；
- 音频与句段时间轴能够驱动逐句高亮；
- 无法可靠区分说话人时，标为待核对，不能静默生成错误角色。

### 4.5 原始媒体、重建媒体和视频任务

媒体身份必须在数据和页面上同时可见：

- `original-audio`：原始配套录音；
- `reconstructed-audio`：根据已核对文字稿生成的学习音频；
- `original-video`：原始视频；
- `missing-original-video`：原视频缺失。

原视频缺失的任务仍可提供完整题面、文字稿和重建音频用于学习，但：

- 明确显示“原视频缺失，当前为学习用重建材料”；
- 不把 TTS 表述为视频的等价替代；
- 不进入正式模拟考试成绩；
- 后续替换媒体时保持任务 ID 和历史记录不变。

### 4.6 精听工具复用

现有精听工具复用以下成熟能力：

- 音频波形和播放定位；
- 当前句自动滚动；
- 点句跳播、单句循环和 AB 段循环；
- 变速播放；
- 逐句字幕与翻译；
- 跟读录音与原音对照；
- 句子收藏、笔记、备份与 Obsidian 导出。

B2 构建流程自动预装课程数据，不要求用户手工导入。阅读器向精听工具传递教材、任务、媒体和句段 ID；精听工具返回播放进度、循环次数、跟读和笔记记录。播放过音频不等于完成考试题。

线上站点仅作为已有效果的交互参考。正式学习优先使用本地统一版本，稳定后再决定是否同步发布线上。

## 5. 写作模块

### 5.1 原书复刻层

写作任务必须逐项对照 PDF。首个样板以书内第 90–91 页（PDF-094/095）为基础，并以 PDF-096 核对完整推荐信范文。页面同时记录书内印刷页码与 PDF 文件页码，禁止再将范文错误标为 PDF-095。

正式页面必须保留：

- 完整俄语指令与必要中文说明；
- 广告、通知、图表、收件人、时间、地点、费用、网址等原始材料；
- 原书任务顺序、编号和材料分组；
- 公文中的收件人、申请人、标题、正文、签名、日期等空间关系；
- PDF 页码和书内印刷页码；
- 完整原书范文及准确来源。

复杂材料同时提供扫描页核对入口和适合网页阅读的重排版。网页重排必须保留信息与层次，不得用一条中文摘要代替原材料。

### 5.2 写作工作台布局

采用已确认的 A 布局：

- 桌面端左侧显示原书任务和材料；
- 右侧显示草稿编辑器与当前任务要求；
- 学习辅助在下方连续展开；
- 手机端按“任务材料 → 草稿 → 自检 → 反馈”变成单列；
- 不出现横向溢出。

工作台至少包括：

- 当前身份、写作对象、目的和必须覆盖的任务点；
- 字数目标、实时字数和段落提示；
- 自动保存草稿；
- 原书格式要求与版式预览；
- 自检清单；
- 提交、继续修改、查看范文和版本历史。

### 5.3 范文解锁

采用已确认的 C 规则：

- 完成草稿并完成自检后，正常解锁原书范文；
- 允许提前查看，但先提示这可能影响独立写作；
- 记录该版本是否提前查看过范文；
- 范文与草稿分区展示，不得自动写入或覆盖草稿；
- 原书范文、学习改写和 AI 示例必须分别标注。

### 5.4 分层反馈

采用三层反馈，不生成伪官方分数：

1. **本地自动检查：** 字数、段落、称呼、日期、落款、任务点覆盖和基础格式。
2. **原书标准自检：** 按原书要求逐项确认内容与体裁是否完成。
3. **AI 学习反馈（可选）：** 语法、格、动词体、搭配、衔接、语体和表达自然度；每项建议给出理由。

AI 反馈必须标为“AI 学习反馈”，不能覆盖原稿，也不能冒充官方批改。AI 不可用时，前两层仍完整工作，并可生成结构化文本供用户复制到其他工具后保存反馈。

### 5.5 多版本修改与写作问题本

写作采用不可静默覆盖的版本链：

```text
初稿 → 自检/反馈 → 修改稿 1 → 修改稿 2 → 定稿
```

版本对照突出新增、删除和修改。系统保存版本时间、字数、自检状态、范文解锁状态和反馈来源。

只有用户确认的问题才进入“写作问题本”，分类包括：

- 格与词形；
- 动词体和时态；
- 词汇搭配；
- 句间衔接；
- 语体与格式；
- 任务点遗漏。

AI 建议不得自动污染问题本。问题本支持回到原作文上下文、查看修改前后版本，并用于后续专项复习。

## 6. 统一数据、来源和迁移

### 6.1 永久 ID

整本书只保留一个教材 ID。任务和题目使用永久 ID，例如：

- `B2-LISTEN-T01-Q01`；
- `B2-WRITE-T03`；
- `B2-GRAMMAR-P2-Q055`。

页面顺序、单元合并或媒体替换不得改变 ID。

### 6.2 来源与审核状态

每项规范数据至少记录：

- PDF 页码和书内印刷页码；
- 题面页、答案页、解析页或范文页；
- 内容身份：`b2-original`、`learning-summary`、`reconstructed-media`、`ai-feedback`；
- 媒体身份与缺失状态；
- `reviewStatus`。

只有 `reviewStatus: approved` 的内容进入正式学习区。Markdown/OCR 只作为录入底稿，不是无需核对的事实源。

### 6.3 迁移

- 已有语法进度、错题和知识卡记录保持不变；
- 能映射到永久题号的旧听力记录自动迁移；
- 无法确认原题的中文摘要成绩保留为旧记录，不计入新题准确率；
- 能定位到任务的写作草稿迁入版本历史；
- 无法定位的草稿进入“旧草稿归档”，不得丢弃；
- 旧模块书架入口合并为一本教材后，最近学习位置仍可恢复。

### 6.4 单一内容源

同一份规范数据生成：

- 阅读器题目和工作台数据；
- 精听工具课程数据；
- Obsidian/Markdown 归档；
- 页码映射、媒体清单和质量报告。

禁止网页、精听工具和 Markdown 各自手工维护一份互相漂移的数据。

## 7. 异常与降级

- 原始媒体缺失：显示真实状态，保留可核对的题面和文字学习材料。
- TTS 失败：保持原题可作答；可退回浏览器朗读，但继续标为重建媒体。
- 精听工具不可用：考试页、答案和文字稿不受影响。
- AI 失败：保存草稿和自检结果，不丢失版本；提供可复制的反馈请求。
- 来源校验失败：只阻止该任务发布，不拖垮整本书。
- 存储冲突：写作分叉版本全部保留，由用户选择，不按时间戳静默覆盖。
- 旧数据无法映射：进入旧记录归档并记录原因。

## 8. 实施顺序

1. 固定当前主项目、语法题库和 P2 丰富知识卡基线。
2. 将书架恢复为一本《俄语 B2 全模块》，建立统一模块仪表盘。
3. 建立听力和写作来源台账、永久 ID、媒体状态和发布门禁。
4. 完成一个听力任务样板：完整题面、角色分段、双声音频、考试页、精听往返和记录。
5. 完成书内第 90–91 页对应写作样板：完整材料、A 布局、范文解锁、分层反馈和版本链。
6. 对样板执行内容审核、自动测试和电脑/手机浏览器验收。
7. 按同一门槛推广到全部听力和写作任务。
8. 生成 Markdown 归档、页码覆盖、媒体缺口和验收报告。
9. 执行整书回归，确认语法、错题本、知识卡、阅读和会话入口不受影响。

## 9. 发布门槛

### 9.1 听力

- 每题具有原书俄语题干、完整选项、答案和来源页；
- 中文摘要不替代原题；
- 对话至少区分两个角色，TTS 不朗读角色标签；
- 音频、字幕与句段定位一致；
- 学习模式、模拟考试和精听记录边界明确；
- 原视频缺失的任务有显著状态，且不计入正式模拟趋势；重建音频的模拟成绩明确标为练习记录；
- 考试页进入精听、再返回原题的路径稳定。

### 9.2 写作

- 原书任务、材料、版式、范文和页码完整准确；
- 扫描页与网页重排可以互相核对；
- 范文解锁规则和提前查看记录有效；
- 本地检查、原书自检与 AI 反馈明确分层；
- 初稿、修改稿、定稿和写作问题本不互相覆盖；
- 桌面左右对照和手机单列均可正常使用。

### 9.3 整体

- 书架只显示一本《俄语 B2 全模块》；
- 所有进度使用稳定 ID；
- 未审核或缺来源内容不能发布；
- 构建、来源台账、迁移和交互自动测试通过；
- 代表性首、中、末任务经过真实浏览器验收；
- 语法题库、错题本和丰富知识卡无回归。

## 10. 完成定义

本目标只有在以下条件全部满足时才算完成：

1. 听力所有有效任务均恢复原书题面、选项、答案、文字稿和媒体状态；
2. 对话语音标签不再被朗读，角色声音和逐句精听工作正常；
3. 写作所有任务均恢复完整材料、版式、范文和学习工作台；
4. 写作反馈、版本对照和问题本形成完整闭环；
5. 听力和写作作为同一本 B2 教材的模块出现在统一仪表盘；
6. 页面、精听工具和 Markdown 来自同一规范数据；
7. 自动测试、来源台账、媒体缺口报告与多设备验收全部通过；
8. 改动安全进入主项目，且不混入无关工作区文件。

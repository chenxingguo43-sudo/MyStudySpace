# Reader + Vocabulary V1 Android 封装设计方案

> 日期：2026-07-27  
> 状态：已确认  
> 产品阶段：V1 内容收束与 Android 私人发行  
> 上游需求：`tasks/prd-reader-vocabulary-dual-page.md`

## 1. 背景

V1 的核心功能已经收缩为 Reader 与 Vocabulary。目前最后一个内容阻塞项是《В мире людей — 语法词汇》的固定语法解析收束。内容完成后，项目需要从“依靠 Node 静态服务器运行的网页”转为“可以在用户自己的 Android 设备上安装、离线使用、升级不丢数据的应用”。

本方案只定义第一版 Android 产品。AI 日常对话、Groq、GPT、在线评分、长期 AI 记忆和实时语音均属于 V2，不进入此次封装。

## 2. 已确认决策

| 决策项 | 选择 |
|---|---|
| 发行方式 | 只供用户本人安装的签名 APK |
| 上架要求 | V1 不以应用商店上架为发布门槛 |
| 媒体策略 | 核心 APK + 可导入媒体包 |
| V1 主导航 | 首页、Reader、Vocabulary、我的 |
| 旧浏览器数据 | 必须支持导出后迁移到 Android |
| 联网要求 | 核心学习功能离线可用 |
| AI | V1 不接入 |
| Android 技术方向 | 优先使用 Capacitor 封装现有 HTML/CSS/JS，实施前做真机技术试验 |

## 3. 设计目标

- 安装 APK 后，无需启动 `server.js` 即可使用 Reader 与 Vocabulary。
- 全部文字教材、题目、固定解析、小说、学习进度和本地词典离线可用。
- 大体积听力、视频和发音文件不拖大核心 APK，用户按需导入。
- App 从一次点击进入核心学习，不出现旧番茄钟调度中心。
- 旧浏览器中的阅读、生词、错题、写作和口语记录可以迁入 App。
- App 更新保留 localStorage、IndexedDB、媒体包和用户设置。
- V1 的导航、数据和 Android 壳可以自然扩展到 V2 五入口结构。
- 打包过程使用明确的运行文件白名单，不把 OCR、测试、备份、密钥或临时文件放进 APK。

## 4. 非目标

- 不重做 Reader 和 Vocabulary 的核心学习逻辑。
- 不在封装阶段重新设计全部视觉。
- 不接入 GPT、Groq、AI 语音、AI 解析或联网账户。
- 不实现多人登录、云同步、付费和应用商店发布。
- 不把整个仓库原样复制进 Android assets。
- 不在 APK 中运行 Node.js 或 `server.js`。
- 不继续尝试把生词同步到本机 Obsidian 路径。
- 不把 600 MB 以上媒体塞入核心 APK。
- 不删除现有网页版本；Android 构建来自独立生产目录。

## 5. 产品结构

```text
V1 Android App
├─ 首页
│  ├─ 继续阅读
│  ├─ 今日待复习
│  ├─ 最近教材
│  └─ 待完成练习
├─ Reader
│  ├─ 书架与教材
│  ├─ 阅读、语法、听力、写作、口语任务
│  ├─ 错题与知识卡
│  └─ 本地录音与回听
├─ Vocabulary
│  ├─ 今日复习
│  ├─ 生词本与来源回跳
│  ├─ 刷词及其他既有模式
│  └─ 本地单词发音或系统 TTS
└─ 我的
   ├─ 数据备份与恢复
   ├─ 教材媒体
   ├─ 外观与字体
   ├─ 存储占用
   ├─ App 版本
   └─ 清除数据
```

V2 增加“口语”后，底部导航扩展为：

```text
首页 | Reader | Vocabulary | 口语 | 我的
```

## 6. App 壳与导航

### 6.1 底部导航

- V1 使用四项底部导航：`首页 | Reader | Vocabulary | 我的`。
- 当前项必须有图标、文字和非纯颜色的选中状态。
- 触控区域不小于 44 x 44 px。
- 底部高度包含 `env(safe-area-inset-bottom)`。
- Android 系统返回键优先返回 Reader 内部上一层；到达页面根级时再执行页面或 App 返回。
- 导航不得覆盖词典抽屉、录音控件、Vocabulary 操作区和备份提醒。

### 6.2 不使用 iframe

Reader 与 Vocabulary 保持直接页面导航，不恢复旧 `index.html` iframe 调度中心。Android 壳通过共享的 `app-shell.css` 与 `app-shell.js` 在各页面注入一致导航。

### 6.3 Web 与 Android 入口

- 开发服务器访问 `/` 可以继续进入现有 Reader，直到 App 壳实现阶段完成。
- Android 生产包入口为新的轻量首页。
- 构建脚本负责为 Android 生成正确的 `index.html`，不要求开发目录和 Android 包使用完全相同的入口文件。

## 7. 首页设计

首页是学习继续页，不是营销欢迎页。

### 7.1 第一屏

- 当前日期和简短问候不是必需信息，不得挤占主要空间。
- 主行动为“继续上次阅读”，显示教材名、章节和最近位置。
- 次行动为“今日待复习”，显示 Vocabulary 到期数量。

### 7.2 后续内容

- 最近打开的 2–3 本教材。
- 尚未完成的写作、口语或错题复练。
- 最近一次本地备份时间。

### 7.3 空状态

- 没有阅读记录：显示“打开书架”。
- 没有到期单词：显示“今天已经完成”，并允许进入生词本。
- 没有旧浏览器数据：不展示迁移警告，只在“我的”提供导入入口。

首页不复制完整书架或完整 Vocabulary 列表。

## 8. Reader 设计

### 8.1 保留能力

- 书架、教材仪表盘和章节阅读。
- 《В мире людей》各模块。
- B2 全模块、错题、知识卡与学习记录。
- 本地词典、划词收藏和 Vocabulary 回跳。
- 写作草稿、口语提纲、本地录音和回听。

### 8.2 Android 运行差异

- 教材索引和章节直接读取静态文件，不先请求 `/api/novel/index` 或 `/api/novel/...`。
- 本地词典作为主要词典。
- “联网补查 Russian Wiktionary”仅在有网络且存在可用代理时展示；V1 私人离线包默认隐藏或明确标为不可用。
- 收藏生词只写共享 App 数据，不请求 `/api/novel-vocab`。
- 不建立永远失败的 Obsidian 同步队列，不显示“同步笔记库失败”。
- Reader 中缺失的媒体显示明确安装状态，而不是坏链接或无限加载。

### 8.3 语法解析完成门槛

《В мире людей — 语法词汇》解析完成后，必须冻结一份可发布内容清单：

- 题目、正确答案和选项一致性完成审计。
- 固定解析不存在空白占位。
- 映射来源和争议状态可追溯。
- 现有语法导航、学习卡与测试通过。
- 生成内容版本和校验摘要，之后才进入 APK 核心包。

打包脚本不得在构建时重新生成或改写正在校对的语法数据。

## 9. Vocabulary 设计

### 9.1 保留能力

- 当前全部复习模式、筛选、刷词和问题卡。
- `vocabulary-review-records` 及现有复习调度。
- Reader 收藏后立即可见。
- 从词条返回来源教材和章节。
- 进度导入导出。

### 9.2 Android 运行差异

- `/api/novel-vocab-list` 不再作为 Reader 收藏的必要来源。
- `/api/vocab-sync` 在 Android 中禁用，不产生网络错误。
- Google Fonts 改为打包字体或系统字体。
- 默认背景只引用生产包白名单中的图片。
- 未安装发音包时优先使用 Android 俄语 TTS；系统没有俄语语音时提示安装发音包，不播放错误空音频。

### 9.3 声音包

现有发音文件拆成两个可选包：

| 包 | 文件数 | 当前未压缩体积 | 用途 |
|---|---:|---:|---|
| `vocab-dmitry` | 3018 | 约 81.8 MB | 男声单词和例句 |
| `vocab-svetlana` | 3018 | 约 81.4 MB | 女声单词和例句 |

用户可以只安装一种声音。切换到未安装声音时，App 必须先提示安装，不能静默失败。

## 10. 我的

### 10.1 数据备份

- 一键导出“V1 学习档案”。
- 导入旧浏览器档案或 Android 档案。
- 展示最后导出时间和档案版本。
- 导入前预览包含哪些模块和记录数量。
- 合并优先，除非用户明确选择覆盖。

### 10.2 教材媒体

- 显示每个媒体包的状态：未安装、校验中、已安装、需要更新、损坏。
- 显示包大小、版本和来源教材。
- 支持从 Android 文件选择器导入本地包。
- 导入过程显示真实进度，可以取消。
- 校验失败时删除临时文件，不破坏旧版本媒体。
- 支持删除单个媒体包释放空间。

### 10.3 外观

- 字号和主题沿用 Reader/Vocabulary 既有设置。
- 新首页和“我的”继承当前学习应用视觉语言，不引入另一套设计系统。
- 不把暂时审美偏好写成永久个人资料。

### 10.4 存储与版本

- 分别显示核心数据、学习记录、录音、媒体包和缓存占用。
- 显示 App 版本、内容版本和媒体清单版本。
- 显示安装来源为私人签名包。
- 清除学习数据和删除媒体必须分开操作并二次确认。

## 11. 核心包与媒体包

### 11.1 核心 APK 内容

核心包采用白名单，至少包含：

- App 壳、首页、Reader、Vocabulary、“我的”。
- 运行所需 CSS、JS、本地字体和图标。
- 全部文字教材 JSON，排除 `media/`。
- 小说数据。
- Vocabulary 主词库、句库、词形索引和来源索引。
- 运行期词典文件，排除 `.backup`、构建中间物和原始语料。
- 音频 manifest，但不包含 `data/audio/*.mp3`。
- 六张实际被 Vocabulary 使用的背景图。

核心包明确排除：

- `tmp/`、`test-results/`、`_zlatoust_check/` 和其他 OCR/审计目录。
- `tests/`、`scripts/`、`docs/`、`俄语资料库/` 和 `俄语笔记库/`。
- `node_modules/`、开发服务器和构建工具。
- `cloudsync-config.js`、任何 API Key、日志和本机路径配置。
- 旧番茄钟、旧知识库、旧统计页和未被 V1 引用的 68 MB 场景视频。
- 词典备份文件和重复数据。

### 11.2 媒体包划分

| 包 ID | 当前内容 | 当前未压缩体积 |
|---|---|---:|
| `listening-audio` | 《听力口语》78 个主音频 | 约 313.6 MB |
| `world-people-video` | 《世界人物》56 个媒体文件 | 约 183.3 MB |
| `listening-mock` | 听力模拟媒体 | 约 15.2 MB |
| `vocab-dmitry` | Dmitry 发音 | 约 81.8 MB |
| `vocab-svetlana` | Svetlana 发音 | 约 81.4 MB |

媒体包物理格式在技术试验后确定，但逻辑 manifest 至少包含：

```json
{
  "schema": "mystudyspace-media-pack-v1",
  "id": "listening-audio",
  "version": "content-version",
  "files": 78,
  "bytes": 313599744,
  "sha256": "archive checksum",
  "contentVersion": "reader-content-version"
}
```

### 11.3 媒体寻址

学习页面不直接拼接固定相对路径，而是调用媒体解析器：

```text
resolveMedia(packId, logicalPath)
-> bundled URL
-> imported app-private file URL
-> missing state
```

这使核心包、导入媒体和未来下载媒体使用同一个页面逻辑。

## 12. 离线与运行适配

### 12.1 Android 不运行 Node API

增加运行环境适配层，统一提供：

```text
loadCatalogue()
loadChapter(bookId, chapter)
lookupDictionary(term)
saveVocabulary(entry)
loadVocabularyExtras()
syncStudyStats()
resolveMedia(packId, path)
```

- Web 开发环境可以继续连接 `server.js`。
- Android 环境必须使用静态数据、本地存储和系统插件。
- 页面不得直接散落判断 `Capacitor` 或硬编码 `/api`。

### 12.2 字体

- Vocabulary 当前 Google Fonts 请求必须移除或替换。
- 优先打包实际使用的字体子集；体积不合理时使用 Android 系统字体回退。
- 俄语、西里尔字母、中文和重音组合符必须在离线字体测试中覆盖。

### 12.3 网络状态

V1 核心页面不因为无网出现错误横幅。仅明确属于在线增强的操作展示离线状态。

## 13. 数据设计

### 13.1 稳定数据范围

V1 学习档案覆盖：

- Reader 最近位置、阅读统计和书签。
- B2 进度、错题、知识卡和设置。
- 写作草稿、版本和解锁记录。
- 本地口语提纲、完成状态和录音索引。
- 听力进度、草稿、尝试与设置。
- Vocabulary 复习记录、附加词条、设置和问题卡。
- 词典用户收藏、别名、缺词记录和临时词条。
- 首页最近项目和 App 设置。

缓存、自动生成索引、媒体文件和 API Key 不进入普通学习档案。

### 13.2 档案格式

```json
{
  "schema": "mystudyspace-v1-archive",
  "version": 1,
  "exportedAt": "ISO timestamp",
  "source": "web|android",
  "records": {},
  "indexedDb": {
    "recordings": []
  },
  "summary": {}
}
```

录音可以选择包含在完整备份中；普通进度备份默认不包含大体积 Blob，只列出录音数量和缺失提醒。

### 13.3 浏览器迁移

```text
浏览器 V1
-> 导出 V1 学习档案
-> 复制到 Android
-> 我的 / 数据恢复
-> 校验 schema
-> 预览与合并
-> 重启后验证 Reader 与 Vocabulary
```

迁移不依赖浏览器与 Android 共享 localStorage origin。

### 13.4 App 更新

- 包名、签名密钥和 WebView origin 首次发布后不得随意改变。
- localStorage 与 IndexedDB schema 必须版本化。
- 每次破坏性迁移前自动生成 App 内部备份。
- APK 更新验收必须覆盖旧版本安装后直接升级，不只测试全新安装。

## 14. 视觉与移动端原则

- 复用 Reader 与 Vocabulary 当前成熟视觉，不在封装时整体换肤。
- 首页和“我的”以清晰排版、少量必要分组和低干扰背景为主。
- 不堆叠“卡片里的卡片”。
- 俄语正文、中文说明、按钮和状态信息保持明确层级。
- 手机竖屏是首要视口，同时保留平板横屏能力。
- Android 系统字体放大到 130% 时，底部导航和主要操作不重叠。
- 深色/浅色行为应与现有页面一致，不在首页单独发明主题。

## 15. 错误与空状态

- 媒体未安装：显示包名、大小和导入入口。
- 媒体损坏：显示重新导入，不删除学习进度。
- 档案无效：说明第一条校验错误，不写入任何记录。
- 存储空间不足：导入前预检，保留原媒体包。
- 麦克风权限拒绝：Reader 口语任务仍可填写提纲，提供再次授权入口。
- Android TTS 缺少俄语：提示安装语音数据或发音包。
- 本地词典未找到：记录缺词，但 V1 不自动联网编造释义。

## 16. 隐私与安全

- V1 不要求账户。
- 学习记录和录音默认只存本机。
- 核心包、媒体包、学习档案和日志不得包含凭据。
- `cloudsync-config.js` 永远不进入生产白名单。
- 签名 keystore 保存在仓库外，并至少备份两份。
- 清除全部学习数据必须说明不可恢复；删除媒体不删除学习进度。

## 17. 发布门槛

只有同时满足以下条件才生成 V1 候选 APK：

- 语法解析内容完成并冻结。
- Reader/Vocabulary 核心测试通过。
- Android 运行不依赖 Node API。
- 核心包白名单审计无密钥、无临时文件。
- 所有核心文字教材在飞行模式下可打开。
- Reader 收藏的词在 Vocabulary 中立即可见。
- 旧浏览器档案可以导入并恢复关键进度。
- 至少一个媒体包可以导入、校验、播放和删除。
- APK 覆盖安装后学习数据和媒体不丢失。
- 真机完成首页、Reader、Vocabulary、“我的”全流程。

## 18. 延后决定

以下技术标识在实施 Phase 0 冻结，不改变本方案：

- App 正式显示名称。
- Android application ID。
- 最低 Android 版本和首批验收设备。
- Capacitor 具体稳定版本。
- 媒体包压缩与解压实现。
- 首个 APK 是否内置一个默认发音声线。

这些标识一旦发布必须记录在交付说明中；其中 application ID 与签名密钥不得在普通更新中更换。

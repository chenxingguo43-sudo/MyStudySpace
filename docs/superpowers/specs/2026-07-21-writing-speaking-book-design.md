## 2. 架构决策

| 决策 | 选项 | 理由 |
|---|---|---|
| 拆分 vs 合并 | **B（合并）** | 一个主题 = 一个完整学习闭环，保留原文逻辑 |
| 全部 vs 仅原书 | **A（全部）** | 与 B2 阅读模块一致，学习辅助标注 `needs_review` |
| 新 format | `writing-speaking` | 混合型，需新建 reader 渲染函数 |
| 数据形式 | **JSON（转换脚本）** | 19 个 Markdown → 19 个 JSON，进 `data/textbook/writing_speaking/` |

## 5. 实施计划（概览）

### Phase 1: 数据转换（一次性脚本）

写 `scripts/convert-writing-speaking.js`，遍历 19 个 Markdown 文件 → 生成 19 个 JSON 到 `data/textbook/writing_speaking/ch0000.json` ~ `ch0018.json`。

脚本需要解析：
- YAML frontmatter（title, source_pages, status）
- `[!note] 原书内容` 块 → vocabularyPrep / readingMaterial / writingTasks / speakingTasks
- `[!info] 学习辅助` 块 → studySupport
- Markdown 表格 → vocabularyPrep 配对

### Phase 2: 书架 + 路由

- `data/textbook/index.json` 添加 `writing_speaking` 条目
- `renderChapter` 加 `writing-speaking` format 分支
- `goChapter` 导航栏适配

### Phase 3: Reader 渲染（reader.html）

- 新增 `renderWritingSpeakingChapter(data, scrollPosition)`
- 复用现有 `.learning-card` + `.source-warning` CSS
- 草稿存储 localStorage key: `rr_ws_drafts_v1`
- 写作草稿 textarea + 口语录音按钮

### Phase 4: 测试

- 静态测试：`tests/russian-b2/reader-static.test.js` 加 writing-speaking 相关断言
- 手动验证：19 章完整性、草稿保存、录音功能

## 6. 风险与注意事项

1. **OCR 质量** — 全部 292 页标 `needs_review`，阅读材料中可能有 OCR 噪声
2. **无答案区** — 5 个页码范围（语法测试答案）未录入，标注即可
3. **无音频** — 写作口语不需要音频，无依赖
4. **转换脚本精度** — Markdown 中 `[!note]` 和 `[!info]` 的嵌套关系需准确解析
5. **附录处理** — 方法论注释和简历材料暂不录入，或作为独立章节

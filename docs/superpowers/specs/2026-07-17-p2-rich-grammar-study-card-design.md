# P2 丰富版语法知识点卡片设计

## 1. 目标与范围

把 P2 知识点卡片“持续、原因与时间关系”（P2-Q051–Q058）从规则提纲升级为可独立学习的微型语法课，同时保留做题前快速复习的效率。

本次只升级这一张样卡。用户完成实际学习体验并确认内容深度、可靠性和页面可读性后，才以同一标准推广到其他知识点。

本卡片不复制 P2-Q051–Q058 的正确选项、错项排除或逐题解析。原书题目的答案和解析继续保留在练习页的“查看答案与解析”中。

## 2. 已确认的设计决策

- 采用“两层结合”：顶部为 3–5 分钟速查，下方为完整详细课程。
- 页面采用 A“上简下详”的连续长页布局，主要内容默认展开，不使用标签页切断学习过程。
- 允许加入经核查的中文学习讲解和自编例句，但必须和原书内容明确区分。
- 每个大类后设置 1–2 道即时检查，卡片末尾设置 3–5 道综合自测。
- 自测答案默认隐藏；选择选项后立即判定，不增加“确认答案”按钮。
- 每条规则就地展示典型格变化，不在本卡片中塞入完整变格表。
- 先按语义问题建立判断路径，再进入具体结构的详细讲解。
- 核心区只覆盖 P2-Q051–Q058 的直接考点；密切相关的其他结构进入视觉上独立的“关联扩展”。
- 内容生产采用“证据驱动的编辑型”，不采用未经核对的自由扩写。
- 卡片自测单独保存为知识点掌握记录，不进入正式 B2 原书错题本。

## 3. 页面信息架构

### 3.1 速查层

速查层控制在 3–5 分钟内读完，包含：

1. 本知识点解决什么问题。
2. 四类语义判断：持续多久、多久以后发生、在多久内完成、因为什么发生。
3. 核心结构速查表。
4. 最小易混对比。
5. 一句可执行的做题口诀。
6. 详细学习目录锚点。

速查层只保留做出第一步判断所需的信息，不堆放完整例句或来源细节。

### 3.2 详细学习层

详细学习层按以下顺序连续展开：

1. **持续多久**：时间段第四格、`в течение + 第二格`及适用边界。
2. **计划或维持多久**：`на + 第四格`，并与直接第四格对比。
3. **多久以后发生**：`через + 第四格`，说明参照点和动作发生时间。
4. **在多久内完成**：`за + 第四格`，强调完成结果，并与 `через`、`на` 对比。
5. **先后与期限**：`после`、`до`、`за … до …`、`к` 等结构。
6. **原因关系**：`из-за`、`благодаря`、`от` 的语义、支配格和结果倾向。
7. **关联扩展**：与核心考点密切相关、但不是 Q051–Q058 主干的结构。
8. **综合辨析表**：分别汇总时间结构和原因结构。
9. **综合自测**：3–5 道混合题，答案和判断依据默认隐藏。

### 3.3 每个详细小节的固定结构

每个详细小节统一使用以下顺序：

> 含义 → 使用条件 → 结构公式 → 就地格变化 → 原书例句 → 补充例句 → 易错边界 → 即时检查 → 来源

“就地格变化”至少覆盖当前规则最有代表性的名词、形容词短语或复数形式。例如：

- `дождь → из-за дождя`
- `ошибка → из-за ошибки`
- `плохая погода → из-за плохой погоды`
- `проблемы → из-за проблем`

只展示理解当前结构所需的变化，不把本卡片扩张为完整变格教材。完整变格内容以后可以链接到独立的“格速查卡”。

## 4. 内容身份与来源分级

每一条规则、例句、对比或解释必须具有明确身份：

- `grammar-book-rule` / 语法书规则：可定位到来源文件、章节和页码。
- `grammar-book-example` / 语法书例句：逐字核对俄语原句，并核对中文翻译。
- `b2-original-focus` / B2 原书考点：只界定原题考查范围，不泄露答案。
- `learning-explanation` / 学习讲解：根据已核实规则重新组织的中文解释。
- `supplement-example` / 补充例句：为展示变化、对比或迁移而编写，必须单独标注。
- `related-extension` / 关联扩展：与当前考点密切相关，但不是 Q051–Q058 的直接考查内容。

来源草稿在审查阶段允许使用 `pending-review` 状态；发布器只能把 `approved` 内容写入网页读取的正式数据，正式网页不得收到或显示待复核内容。

## 5. 证据驱动的编辑流程

内容生产按以下顺序进行：

1. 从《新编俄语语法》和 B2 原书确定规则事实、考查范围和可引用例句。
2. 把事实转写为适合中国学习者的中文学习讲解。
3. 只在原书例句不足以展示变格或对比时编写补充例句。
4. 对每条内容执行五项审核。
5. 只有全部审核通过的内容才能进入正式数据文件和网页。

五项审核为：

1. **规则核对**：支配格、语义条件、时间关系和完成性是否正确。
2. **形式核对**：名词、形容词、单复数和数词结构是否正确。
3. **例句核对**：俄语是否自然，且确实体现当前规则。
4. **翻译核对**：中文是否准确表达时间关系、原因关系和语用倾向。
5. **边界核对**：是否把常见倾向错误写成绝对规则。

例如，`благодаря` 与积极结果有强烈的常见关联，但卡片不得把这种常见倾向表述成没有例外的绝对禁令。

## 6. 即时检查与综合自测

### 6.1 即时检查

- 每个核心大类后设置 1–2 道短题。
- 计分题使用单选或判断题，以检验刚讲完的一个判断点为主。
- 单击选项后立即判定，不再要求确认。
- 需要主动回忆词形时，可以使用不计分的“先思考，再展开答案”，避免为短填空增加提交按钮。
- 判定后先显示一句核心依据；详细解释可继续展开。
- 支持立即重做，不永久锁定。

### 6.2 综合自测

- 卡片末尾设置 3–5 道混合题。
- 覆盖 `через / за / на`、持续时间、先后期限和原因结构的跨类辨析。
- 不直接复制或近似改写 P2-Q051–Q058。
- 保存最近一次得分、最高得分、作答次数和最后学习时间。
- 自测错题不进入原书错题本。

### 6.3 掌握状态

卡片顶部显示独立状态，例如：

`最近自测 4/5｜最高 5/5｜已练习 3 次｜最后学习 7月17日`

“已学习”不得通过滚动到底部自动判定。知识点掌握状态由卡片自测表现和对应 B2 原题表现共同呈现，但两套作答记录保持独立。

## 7. 页面交互

- 主要课程内容默认展开，保持连续阅读。
- 顶部提供轻量目录：`速查｜持续时间｜через / за｜先后期限｜原因关系｜综合辨析｜自测`。
- 向下阅读时，目录缩成不遮挡正文的悬浮栏；点击目录项平滑跳转到对应小节。
- 来源默认显示简短标签，例如“语法书·第297页”；点击后展开完整文件、章节和页码。
- 底部保留三个正式练习入口：本知识点全部原题、本点原书错题、筛选后的错题本。
- 原题页现有的单击作答、重复刷题和“查看答案与解析”行为保持不变。

## 8. 数据结构与容错

丰富内容继续存放在独立的知识卡数据文件中，不直接写死到 `reader.html`。每个详细小节至少包含：

- 稳定标识和标题；
- 核心或扩展标记；
- 学习目标；
- 规则公式和使用条件；
- 格变化示例；
- 原书例句和补充例句；
- 易错边界；
- 即时检查；
- 来源信息；
- 审核状态；正式输出中的每项内容必须为 `approved`。

生成器必须拒绝以下内容：

- 原书规则缺少可验证的文件、章节或页码；
- 原书例句无法在声明的来源中找到；
- 补充内容冒充原书内容；
- 自测题缺少答案或判断依据；
- 意外包含 P2-Q051–Q058 的正确选项、错项排除或逐题解析；
- 核心内容和关联扩展身份不清；
- 空标题、缺少翻译或未审核内容。

如果知识卡文件缺失、请求失败或校验不通过，P2 原题练习必须仍然可用。知识导航可显示“知识卡暂不可用”，但不能让整个 P2 页面无法打开。

## 9. 验收标准

### 9.1 内容审查

- 逐条核对规则、格变化、例句、翻译、边界说明和来源。
- 所有补充内容均有明确身份标签。
- 正式卡片中没有 `pending-review` 内容。
- 卡片不泄露对应 B2 原题的答案和逐题解析。

### 9.2 自动测试

- 验证数据结构和审核状态完整。
- 验证所有语法书来源和原书例句可追溯。
- 验证核心练习范围仍为 P2-Q051–Q058。
- 验证即时检查和综合自测均有答案与依据。
- 验证自测记录和原书错题记录相互独立。
- 验证知识卡失败时原题练习可以正常降级使用。

### 9.3 浏览器验收

- 检查桌面和窄窗口下的连续长页阅读体验。
- 检查顶部速查、悬浮目录和锚点跳转。
- 检查来源展开、即时判题、答案展开和重复自测。
- 检查学习记录更新和原书错题本不被污染。
- 检查底部三个正式练习入口。
- 检查原题作答和“查看答案与解析”没有回归。

## 10. 非目标

- 本轮不推广到其他知识点。
- 不在本卡片中制作完整的俄语格变化教材。
- 不把 B2 原书逐题解析迁移到知识点卡片。
- 不把知识卡自测错题混入正式原书错题本。
- 不发布未经审核或来源身份不明确的内容。

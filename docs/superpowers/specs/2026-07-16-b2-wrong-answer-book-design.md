# B2 错题本设计

## 目标

将已有的错题历史转为可集中复习的入口，支持按部分和知识点回到原题或发起题组复习。

## 体验

- 书架顶部显示 `📕 错题复习 · 待掌握 N 题`。
- 默认页为“待掌握”：曾答错且最近一次作答仍错误的题。
- 支持 P1–P6、知识点、最近答错筛选；每题显示部分、知识点、题号和最近结果。
- 点击题目直接打开其所属部分并定位到原题；知识点操作可启动该知识点全题组重刷。
- 每个 B2 部分顶部显示该部分待掌握数量，进入错题本时自动带入该部分筛选。
- 最近一次答对的历史错题转入“已掌握”，历史错误和 attempts 保留。

## 数据与边界

- 只读取 `rr_b2_progress_v1` 的 `everWrong`、`lastResult`、`lastAnsweredAt` 与稳定题号；不新增云同步。
- 题目、原书答案和解析不复制到错题本；错题本始终跳回原题渲染。
- 无错题时展示空状态和“开始练习”入口。

## 验收

- 自动化验证错题聚合、待掌握/已掌握分类、部分和知识点筛选、稳定题号跳转参数。
- 浏览器验证书架入口数量、P2 过滤、原题定位、答对后状态更新。

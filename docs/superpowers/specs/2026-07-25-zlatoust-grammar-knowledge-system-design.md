## 1. 项目目标

把现有的“知识点卡片”升级为一套能够覆盖原书理论、597 道练习及其相互关系的语法知识系统。

本项目不以卡片短小为目标。完整性优先于篇幅，但通过分层阅读、折叠区块、对比表和练习入口，保证内容多且难时仍然容易定位和理解。

## 4. 知识层级

```text
章 Chapter
└── 原书小节 Source section
    └── 规则单元 Rule unit
        ├── 快速理解
        ├── 完整规则
        ├── 使用条件
        ├── 形式、格或支配关系
        ├── 语义与语体差异
        ├── 例外和边界
        ├── 原书例句
        ├── 易错对比
        ├── 对应练习
        └── 来源与核对状态
```

一个原书小节可以拆成多个规则单元，不能为了保持“一节一卡”而把不同规则硬塞在一起。动词体、动词支配、复杂句连接方式和近义词辨析等内容预计需要继续细分。

## 5. 分层阅读方式

每个知识单元默认呈现第一层：

- 中文定位：这个知识点解决什么问题；
- 核心判断：做题时先看什么；
- 最小充分示例；
- 对应题量和学习状态。

完整内容通过内部区块展开：

1. 完整规则与适用条件；
2. 形式、词形、格和支配表；
3. 语义、语体及近义结构对比；
4. 例外、限制和常见误判；
5. 原书例句与逐句说明；
6. 对应练习、错题和复习入口；
7. 来源页码与校对记录。

折叠只是组织内容，不能成为省略内容的理由。

## 6. 来源等级

每一条规则、例句和补充解释必须标记来源类型：

| 类型 | 含义 | 可以作为已核对内容 |
|---|---|---|
| `source-rule` | 原书规则正文 | 是，需人工核对 |
| `source-table` | 原书表格或清单 | 是，需核对结构 |
| `source-example` | 原书理论区例句 | 是，需人工核对 |
| `exercise-example` | 从原书练习提取的例句 | 是，需保留题号 |
| `learning-note` | 为中文学习者增加的解释 | 不能冒充原书内容 |
| `external-note` | 来自其他权威资料的补充 | 必须单独给出来源 |

禁止用模型推断的规则填补 OCR 空缺后标记为“原书已核对”。无法确认的文字必须保留 `needs-review` 状态。

## 7. 页码规范

后续数据同时保存两套页码，避免当前数据中“PDF 页”和“印刷页”混用：

```json
{
  "source": {
    "printedPages": [91, 92],
    "pdfPages": [93, 94]
  }
}
```

界面主要显示印刷页码，同时允许在调试信息中查看 PDF 页码。

## 9. 覆盖矩阵

覆盖矩阵至少回答以下问题：

- 原书目录中的每个练习小节是否有知识单元；
- 理论区中的每条规则是否已转录；
- 每个知识单元对应哪些题；
- 597 道题是否全部至少映射到一个知识单元；
- 哪些题跨越多个规则；
- 哪些规则没有直接练习；
- 哪些内容仅有 OCR、哪些已经人工核对；
- 哪些中文说明属于学习辅助而非原书内容。

完成条件不是“卡片数量达到某个值”，而是覆盖矩阵不存在未解释的空白。

## 10. 质量门槛

一个知识单元只有同时满足以下条件才能标记为完成：

- 原书俄文正文与表格已经逐页核对；
- 原书重音、标点、斜体或语义对立没有在 OCR 中丢失；
- 中文解释没有改变原规则的适用范围；
- 条件、例外、语体限制和反例均已保留；
- 对应练习题已映射；
- 来源页码可追溯；
- 在桌面和移动视口下可以分层阅读，不产生超宽表格或过长连续文本；
- 二次渲染不重复添加重音符号；
- 不影响现有答题和错题记录。

## 12. 首个样板建议

首个样板使用第 1 章第 1.4 节“未完成体与完成体的使用”。它包含多个子规则、否定、命令式、不定式和语义差异，足以检验：

- 内容很多时是否仍然容易定位；
- 对比表是否清晰；
- 条件和例外是否能够完整保留；
- 多个规则单元如何共享同一组练习；
- 卡片与错题复习如何双向连接。

如果这个复杂单元能用好，其他较短单元可以沿用同一结构；反过来先做简单小节，无法验证系统是否承载得住真正困难的内容。

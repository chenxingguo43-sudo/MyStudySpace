## 2. 执行顺序

### P0-1：建立实施基线

1. 读取 `AGENTS.md`、目标提示词、`CONTENT_CONTRACT.md`、`WORKFLOW.md` 和本设计规格。
2. 记录 `section-1.4.1.json` 的阶段、题目、例句、来源和 ID 清单。
3. 记录当前 localStorage 相关 key、教学页状态字段和正式题共用路径。
4. 运行现有项目验证、静态测试和 1.4.1 Playwright，保存基线结果。
5. 截取桌面和手机页面，记录总高度、横向溢出、控件数和主要交互状态。

退出条件：基线可复现，且没有把其他窗口的失败误判为本轮造成。

### P0-2：逐字核对原书来源

1. 以 `E:\Desktop\语法词汇（同一本书）.pdf` 的 1.4.1 页面为最终依据。
2. 对照：
   - `theory/raw-ocr` 对应页；
   - `theory/cleaned-source/chapter-01.md`；
   - `theory/rule-units/gl1/section-1.4.1.json`；
   - `theory/learning-pages/gl1/section-1.4.1.json`。
3. 为每段规则判断是“逐字原文”还是“整理摘要”。
4. 逐条核对 20 条 `source-example`，补齐印刷页和 PDF 页。
5. 找出缩写、拼接、改写和 OCR 不确定内容：
   - 能恢复逐字内容的，恢复并保留 `source-example`；
   - 不能证明逐字一致的，改为 `learning-note` 并标注“根据原书例句改写”；
   - 有疑点的保留 `needs-review` 和具体原因。
6. 建立来源核对表：内容 ID、页面位置、来源类型、印刷页、PDF 页、核对结果、风险。

退出条件：没有无页码的 `source-rule` / `source-example`，没有摘要或改写冒充逐字原文；OCR 状态仍为 REVIEW。

### P0-3：重构学习页数据模型

在不改变 `sectionId`、stage ID、正式题 ID 的前提下，补充或调整：

- `timeGate`：现在意义、将来时、过去时的适用路径；
- `decisionAxes`：交际目的、动作轮廓、事件数量、事件关系、当前关联；
- `crossAxisWarnings`：四条防误解关系；
- `learningRoute`：五阶段进度数据，与思维导图数据分离；
- `deepDive`：更多例句、信号词边界、常见误判和来源核验的折叠层；
- `retry` 或等价字段：每道首练的真实同类再练；
- `feedback.misconceptionType`：结构化误判类型；
- `transferTasks`：过去时、将来时、改写和解释任务；
- `estimatedMinutes`：核心首学 70–100 分钟，并支持分阶段时长。

若现有渲染器不能识别新字段，应先以向后兼容方式读取；缺失字段不得造成旧知识页报错。

退出条件：JSON 可解析，旧 ID 全部保留，1.4.2 数据无需同步修改也能继续使用旧结构。

### P0-4：重写歧义随堂题与同类再练

逐题审查 10 道随堂题，重点处理：

1. `исследовали / исследовали и завершили`：替换为同一词汇意义下的自然体对或重新设计语境。
2. `писала / выбирала` 对 `написала / подписала`：改为只改变体或只改变时间关系的对比。
3. `наблюдали / понаблюдали`：避免把界限化前缀和完成结果混为一谈；必要时换用更干净的体对。
4. 补足将来时题：至少覆盖一般/具体事实、过程/结果、次数或事件关系中的多个轴。
5. 每道首练新增一题同类再练；同类再练必须使用新语境，但考查同一决定条件。
6. 每题反馈逐项填写：误判类型、失效原因、决定条件、最小对比、回看节点。

退出条件：10/10 首练都有可作答的同类再练；不存在同时更换体和词义却声称“最小对比”的题。

### P0-5：重写综合迁移任务

将当前单一策略选择题替换或保留为热身，再新增四类任务：

- 过去时多轴分析；
- 将来时分析，并明确排除“当前关联”轴；
- 改写一个条件后重新选择；
- 中文解释信号词为何不能单独决定答案。

综合任务需记录完成和正确性，但不得污染原书正式题记录。

退出条件：学习者必须处理新句子并说明依据，不能靠记住页面上的策略句直接通过。

### P0-6：细化 13 道原书题解析

1. 保留 13 个正式 exercise ID 和现有双向映射。
2. 核对每题题面、选项和答案与正式题库一致。
3. 为每题标出主要判断轴和辅助判断轴。
4. 把 25 个主要干扰项从 4 种模板理由改为针对当前语境的具体解释。
5. 验证从教学页作答后，正式题库、错题、收藏和统计立即反映同一记录。

退出条件：每个正确项和主要干扰项都有题目级解释，且不存在第二套答题记录。

### P1-1：重构思维导图渲染

1. 搜索现有思维导图渲染函数和 CSS 选择器，不假设具体位置。
2. 渲染“中心 → 时态闸门 → 五个判断轴”的层级关系。
3. 将“当前关联”标注为“仅过去时”。
4. 显示四条跨轴防误解关系，但避免做成额外平级节点。
5. 节点点击只滚动到正文锚点，不写入完成状态。
6. 支持键盘、触屏、焦点样式和 `aria-current` / 等价语义。
7. 手机端改为可读的纵向树，不依赖横向拖动或缩放。

退出条件：用户不会从视觉上理解成“五选一”，且学习路线和思维导图仍分开。

### P1-2：调整页面节奏与折叠层

1. 主线保留：预测、老师拆解、关键证据、一个最小对比、立即判断。
2. 深挖折叠：更多证据、全部信号词、全部误判、外部核验、额外练习。
3. 原书正式题按阶段折叠，但提供清晰题数与完成数。
4. 返回页面时恢复阶段、滚动位置和折叠状态；折叠状态不参与掌握统计。
5. 控件使用稳定尺寸，展开反馈不得导致按钮或题目布局横跳。

退出条件：内容总量没有减少，连续滚动负担显著降低，手机端无嵌套卡片和横向溢出。

### P1-3：调整进度与掌握统计

1. 区分“进入页面”“完成首练”“完成同类再练”“完成迁移任务”。
2. 保持旧 localStorage key；新增字段采用可选、可迁移结构。
3. “已学习”以五阶段首练完成为准。
4. “已掌握”以关键题正确率至少 80% 且迁移任务完成为准。
5. 薄弱轴综合随堂题、同类再练和原书题错误，不只统计最后一次点击。
6. 用带旧数据的浏览器上下文做兼容测试，确认记录不会清空或重算失真。

退出条件：旧记录可读、正式题记录共用、折叠和导图点击不虚增进度。

### P1-4：完成中文化与无障碍修复

1. 将所有可见 `vs` 替换为“对比”或自然中文。
2. 将可见 `needs-review` 替换为“待复核”，内部状态值不强制改变。
3. 为每个“标记复习”按钮生成包含阶段或题目名称的 `aria-label`。
4. 检查折叠按钮、导图节点、选项和反馈区域的键盘操作及焦点顺序。
5. 反馈更新使用适当的 live region，避免重复朗读整个页面。

退出条件：除俄语原文、来源专名和必要技术标识外，学习界面无需英语理解。

### P1-5：更新质量报告

更新 `integrated-learning-sample-1.4.1.md`，逐项记录：

- 新导图层级；
- 10/10 同类再练的实际证据；
- 过去时和将来时题量；
- 13 道原书题和 25 个干扰项解析覆盖；
- 原书逐字规则、例句和页码覆盖；
- 改写内容降级记录；
- OCR REVIEW 风险；
- 桌面和手机实测结果；
- localStorage 兼容结果。

禁止继续保留与实际数据不符的“已实现”表述。

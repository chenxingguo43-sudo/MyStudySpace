# 背单词页面 UI 优化计划书

## 目标

让 `vocabulary.html` 用起来更顺手——顶部控件不占屏、长卡片能看完、手柄完全覆盖所有操作。

---

## 一、顶部控件侧边栏化 · 自动隐藏

### 现状问题

模式栏（今日待复习/生词本/B2口语…共 8 个按钮）、筛选栏（搜索框+筛选+下拉）、统计条、进度条 全堆在页面顶部。在笔记本/小平板上占了大量空间，卡片区域被压缩。

### 方案

将顶部控件改为**可折叠侧边抽屉**，平时隐藏，悬停/点击时滑出。

```
【收起状态】                    【展开状态】
┌──────────────────┐          ┌─┬──────────────────┐
│ 🍔  📅今日待复习  │          │ ≡│ 📅 今日待复习     │
├──────────────────┤          │  │ 📖 生词本        │
│                  │          │  │ 🇷🇺 B2口语       │
│   卡片区域       │   →    │  │ 🔥 高频词        │
│   (全屏)         │          │  │ 📖 小说词汇      │
│                  │          │  │ ❌ 错题本        │
│                  │          │  │ ⭐ 收藏          │
│                  │          │  │ 🚩 问题卡        │
│                  │          │  │ ⚙ 设置           │
│                  │          │  │──────────────────│
│                  │          │  │ 🔍 搜索...       │
│                  │          │  │ 📊 0/20 本轮     │
│                  │          │  │ ▓▓▓▓░░░░ 进度    │
└──────────────────┘          └─┴──────────────────┘
```

### 交互细节

| 触发方式 | 行为 |
|----------|------|
| 鼠标移到左侧边缘 8px | 侧边栏滑出 (300ms ease) |
| 鼠标移出侧边栏区域 | 侧边栏收起 (300ms ease) |
| 点击 🍔 按钮 | 锁定展开 / 解锁 |
| 触摸屏：左边缘右滑 | 侧边栏滑出 |
| 触摸屏：点击卡片区域 | 侧边栏收起 |
| 按 `M` 键 | 切换锁定状态 |

### 侧边栏内容排列（从上到下）

1. Logo / 当前模式名称
2. 8 个模式按钮（竖向排列）
3. 分隔线
4. 搜索框
5. 来源/词性/章节 下拉筛选
6. 错词/未掌握 快捷按钮
7. 分隔线
8. 统计数字（本轮/通过/回炉/今日）
9. 进度条

### CSS 关键点

- 侧边栏宽度：展开 ~240px，收起 ~0px（实际留 8px 触发边距）
- `z-index: 100`，覆盖在卡片上方
- 玻璃态背景 `backdrop-filter: blur(16px)`
- 移动端使用 `touchstart/touchmove/touchend` 手势

## 二、卡片区域优化 · 长内容自适应

### 现状问题

加了资料真实例句后，卡片背面内容变得很长（释义 + 例句 + 语法表 + 来源例句），经常超出屏幕高度。现在 `.card-back` 虽然设置了 `overflow-y: auto`，但 `min-height: 340px` 太小，卡片没充分利用屏幕空间。

### 方案

让卡片高度**动态适配可视区域**，内部内容足够长时自动滚动。

```
桌面端 (1440x900)              移动端 (375x812)
┌──────────────────┐          ┌────────────┐
│ [侧边栏] 卡片区域 │          │ 卡片区域    │
│ ┌──────────────┐ │          │ ┌────────┐ │
│ │ 俄语单词      │ │          │ │ 单词    │ │
│ │ 释义          │ │          │ │ 释义    │ │
│ │ ★★★☆☆        │ │          │ │ ★★★    │ │
│ │ ✍️ 例句1      │ │          │ │ ✍️ 例句  │ │
│ │ ✍️ 例句2  ↕   │ │          │ │ ↕ 滚动  │ │
│ │ 📐 语法       │ │          │ │         │ │
│ └──────────────┘ │          │ └────────┘ │
│ [←不认识][↓模糊] │          │[不认识][模糊]│
│ [→认识]  [↑撤销] │          │[认识] [撤销]│
└──────────────────┘          └────────────┘
```

### 实现

```css
/* 卡片容器高度 = 视口高度 - 顶部留白 - 底部按钮区 */
.card-zone {
  min-height: calc(100dvh - 80px);
  max-height: calc(100dvh - 80px);
  display: flex; flex-direction: column;
}
/* 卡片本身可伸缩 */
.flashcard {
  flex: 1; min-height: 280px;
}
/* 背面允许滚动 */
.card-back {
  overflow-y: auto;
  -webkit-overflow-scrolling: touch;
  scroll-behavior: smooth;
}
```

### 键盘/手柄滚动背面

| 方式 | 操作 |
|------|------|
| 键盘 | `W/S` 或 `↑/↓`（仅在背面时）滚动 |
| 手柄 | 左摇杆上下 → 滚动背面 |
| 触摸 | 直接滑动手势 |

## 三、键盘快捷键补全

### 现状
Space=翻转, ←=不认识, ↓=模糊, →=认识, ↑=撤销, P=发音, G=语法（刚加）

### 补充

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `M` | 切换侧边栏 | 锁定/解锁侧边栏 |
| `F` | 切换筛选抽屉 | 打开/关闭筛选面板 |
| `S` | 收藏/取消收藏 | 当前卡片 |
| `1`~`8` | 切换模式 | 快速跳到对应模式 |
| `W`/`↑` | 卡片向上滚 | 仅在背面时 |
| `S`/`↓` | 卡片向下滚 | 仅在背面时 |

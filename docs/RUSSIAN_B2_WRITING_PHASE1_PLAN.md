# 俄语 B2 写作第一轮升级计划

状态：已确认方向，待按本计划实施

范围：俄语 B2 全模块写作中的“推荐信”三轮训练。第一轮完成并验收后，再决定是否推广到正式应用文和非正式介绍信。

## 一、目标

把“任务 1 · 推荐学习项目（私人信函）”从资料展示页改成一节能带着学生完成的纸笔课程。

学生即使有不少生词，也应能完成以下过程：

```text
读懂题目
→ 看懂广告
→ 标出重点
→ 判断哪些信息值得写
→ 把广告信息变成自己的俄语句子
→ 在纸上列提纲
→ 在纸上写初稿
→ 用范文分析自己的问题
→ 回纸上修改
→ 换一则材料再做一次
```

网页负责解释、提示、分类、对照和记录阶段；长篇作文主要在纸上完成。

## 二、必须遵守的原书依据

原书材料和版式以以下目录中的 PDF / Markdown 为准：

`D:\下载\MinerU\俄语B2.pdf-c2ec7e90-9178-4da4-bf4d-c589bd00d285`

其中：

- `full.md` 用于检索文字内容和译文核对；
- PDF 原页面用于核对广告的版面结构、标题、空行、项目层级和应用文固定格式；
- Markdown 把页面压平或出现断行不明确时，必须回看 PDF 原页，不能凭文字顺序推测排版。

原书所有题干、广告、范文、时间要求、字数要求和格式说明都必须保留。新增中文讲解、翻译、提示和练习不能覆盖或改写原书材料。

## 三、页面总顺序

页面采用一个大页面，阶段可以直接点击跳转，当前阶段有明显提示。学习阶段固定为：

```text
1. 本节课要学什么
2. 看懂题目
3. 看懂材料
4. 提取和筛选重点
5. 学做法：老师示范从材料到整篇信
6. 纸上形成内容
7. 纸上写初稿
8. 看范文并逐段逐句讲解
9. 对照范文修改
10. 烹饪课程半独立练习
11. 真题职业培训独立练习
```

“看材料”必须排在“学做法”之前。学生要先知道材料说了什么，才能理解老师如何使用材料。

## 四、各阶段的教学责任

### 1. 本节课要学什么

不要只写抽象目标，要明确本节课结束时学生手上会留下什么：

- 一张已经理解并分类的广告信息表；
- 2—4 条选中的写作重点；
- 一份推荐信纸上提纲；
- 一篇纸上初稿；
- 一份按范文反馈修改后的版本。

同时明确这些产出之间的关系：广告重点会进入提纲，提纲会进入初稿，范文分析会用于修改初稿。

### 2. 看懂题目

题干必须同时显示：

- 原书俄语题干；
- 完整中文翻译；
- 收信人是谁；
- 写信目的是什么；
- 必须提供什么信息；
- 阅读时间、写作时间和字数要求。

不能只给一句中文概述。学生需要知道题目要求和后续每个动作的对应关系。

### 3. 看懂材料

广告材料必须保留原书版面层级，而不是把所有内容改成普通卡片段落。每则广告至少包含：

- 原书标题和标题层级；
- 原书俄语正文；
- 完整中文翻译；
- 原书中的网址、价格、时间和其他数字；
- 对应 PDF 页码。

广告排版复核是本轮的前置工作。先逐页核对 PDF，再决定网页中的标题、分栏、项目符号、空行和信息块如何呈现。

### 4. 提取和筛选重点

逐行带练升级为完整的信息处理练习。每个材料行都要支持：

- 俄语原文；
- 完整中文翻译；
- 信息类型：课程、对象、地点、时间、费用、人数、优势、联系方式等；
- 这一行对收信人有什么用；
- 这一行适合放在信件哪一部分；
- 不懂时的词汇或结构提示；
- 可改写成作文的简单俄语句子；
- 标记为重点的操作。

标重点后不能直接结束。页面必须继续要求学生回答：

```text
为什么选这条？
它对朋友作决定有什么用？
准备把它放进信的哪一段？
```

被选中的重点最后整理成纸上提纲。

### 5. 学做法：老师示范从材料到整篇信

这一阶段不是句型清单，而是完整演示：

```text
一条广告信息
→ 中文理解
→ 是否值得写的判断
→ 与朋友需求的连接
→ 俄语句子
→ 段落位置
→ 在整封信中的作用
```

至少示范以下内容：

- 如何写称呼和交代写信原因；
- 如何介绍朋友的愿望或困难；
- 如何选择 2—4 条广告重点；
- 如何把广告事实改写成自然句子；
- 如何说明“为什么适合这个朋友”；
- 如何补充联系方式、祝愿、署名和日期。

每个重要句型都要说明中文意思、句法结构、可替换部分、常见错误和基础替代表达，并说明它在整篇信中的位置。

### 6. 纸上形成内容

这个阶段只负责学生产出，不重复讲“学做法”。工作单承接上一阶段的标记结果，包含：

- 收信人；
- 朋友的愿望或困难；
- 推荐的项目；
- 选中的广告重点；
- 每条重点对朋友的作用；
- 推荐理由；
- 每段准备写什么；
- 准备调用的俄语表达。

工作单要让学生先写关键词，再扩展成句子，最后形成段落提纲。

### 7. 纸上写初稿

页面不承担长篇输入。页面给出明确限时和纸上任务：

- 按提纲写 50—70 词；
- 保留私人信函格式；
- 写完后回到网页进行自查；
- 网页只记录“已列提纲、已写初稿、已完成修改”等学生确认状态。

### 8. 看范文并逐段逐句讲解

核心范文默认展开，不能自动折叠。范文和讲解合并成一个完整教学区，至少包含：

- 完整俄语范文；
- 完整中文翻译；
- 原书段落和空行；
- 每段完成的题目要求；
- 重点词组和句型；
- 句型中的可替换位置；
- 更简单的替代表达；
- 常见错误和修正方式；
- 对照学生初稿的检查问题。

范文讲解不能停留在“这是开头、这是结尾”。必须解释句子如何完成任务，以及学生如何把同一结构迁移到另一则广告。

### 9. 对照范文修改

自查必须与修改动作绑定。例如：

- 没有写朋友需求：补充 `Ты мне рассказывал(а), что...`；
- 没有明确推荐：加入 `Я думаю, что эта программа подходит тебе, потому что...`；
- 信息太多：删掉与朋友无关的广告内容；
- 信息太少：补时间、费用、地点、条件或联系方式；
- 格式不完整：补称呼、结束语、署名和日期。

## 五、三轮训练安排

### 第一轮：出国学习项目，老师带做

使用原书出国学习广告和第一篇范文。提示最完整，重点演示信息分类、筛选、改写和段落组织。

### 第二轮：烹饪课程，半独立完成

保留原书烹饪课程题干、广告和范文。只提供部分句型和信息分类，要求学生自行选择重点并完成纸上作文，之后用范文对照。

### 第三轮：真题职业培训，独立完成

保留原书真题材料、题干、时间、字数和参考范文。只保留必要的翻译、格式和考试提示。学生先独立完成，再查看范文分析。

## 六、原书广告排版整改要求

这是本轮必须单独完成的工作，不属于普通 UI 美化。

复核每则广告在 PDF 中的：

- 主标题、机构名称和国家/城市标题的层级；
- 广告内部的小标题；
- “语言、课程、时间、费用、网址”等字段的顺序；
- 项目符号和列表层级；
- 空行和段落间距；
- 数字、货币、日期和网址的原样显示；
- 同一广告跨页时的连续关系；
- 原书图片、表格或视觉分栏是否需要保留为版式，而不能转成普通段落。

网页呈现采用“原书版式复刻 + 教学辅助层”的原则：原书材料区保持稳定、可核对的版面；翻译、标记、提示和写作改写放在相邻的辅助区域，不打乱原书信息顺序。

应用文格式也遵守同一硬性要求。申请书、投诉信、解释信、名片等必须按 PDF 原页核对收件人、写信人、标题、正文、署名、日期和空行的位置，不能只保留文字内容。

## 七、空间布局

电脑端：

- 写作主体保持宽工作区；
- 广告原文与完整翻译使用整行材料区；
- 逐行带练使用整行宽度，不被两栏卡片限制；
- 材料左侧显示原文，右侧显示翻译、分类、写作用途和提示；
- 范文使用整行固定格式区域；
- 纸上工作单和修改区也使用整行区域。

手机端：

- 改为单栏顺序；
- 先原文，再翻译，再辅助，再纸上任务；
- 不压缩俄语句子；
- 范文的空行和格式关系仍然保持。

## 八、验收标准

第一轮完成后，学生应该能够：

- 看懂题目要求，而不是只看中文摘要；
- 用完整译文理解广告，再定位需要学习的俄语表达；
- 标记并筛选真正对朋友有用的信息；
- 解释每条重点在推荐信中的作用；
- 根据前面处理好的信息完成纸上提纲；
- 看着完整展开的范文理解每一段和每个关键句；
- 用范文诊断自己的作文并知道怎么修改；
- 换一则广告后重复同一套流程；
- 看见的广告版式和应用文格式与原 PDF 一致。

## 九、实施顺序

1. 只读复核 PDF 中推荐信广告和范文的原始版式。
2. 修订广告材料的数据结构，区分原文、完整译文、教学标注和写作改写。
3. 重排页面阶段顺序：看材料在学做法之前。
4. 完成一则广告的整行带练和重点筛选样板。
5. 将重点筛选结果接入纸上工作单。
6. 将学做法改成完整的材料到整篇信示范。
7. 将范文改为默认展开的固定格式讲解区。
8. 加入对照修改流程。
9. 将同一结构扩展到烹饪课程和真题训练。
10. 用 PDF、数据测试、桌面和手机页面共同验收。

# 🚀 刷词模式 — 最终方案

## 一句话

新增独立「🚀 刷词」模式。从生词本/B2口语等来源取词，一卡一卡刷，不认识/模糊的塞回队列隔几张后再来，循环直到**全部认识**。

---

## 一、入口

模式栏新增第 9 个按钮：

```
📅 今日待复习 | 📖 生词本 | 🇷🇺 B2口语 | 🔥 高频词 | 📖 小说 | ❌ 错题本 | ⭐ 收藏 | 🚩 问题卡 | 🚀 刷词
```

点击「🚀 刷词」→ 弹出选择面板（或用当前筛选源）→ 确定后开始刷。

---

## 二、刷词循环（核心逻辑）

### 数据结构

```
刷词主队列 deck[]      — 全部待刷词（一次性加载，不会增长）
回炉黑名单 retried{}   — wordId → 第几次回炉了（fail/fuzzy 次数）
回炉排队 retryQueue[]  — [{wordId, retryAfterSeen}] 最多保留当前一批
sessionResult{}        — wordId → 'known' | 空（还没掌握）
seenCount              — 当前已拉取的总卡数（用于计算回炉时机）
```

### 循环算法

```
1. 从 deck 遍历，跳过已标记 known 的
2. 检查 retryQueue：有没有 retryAfterSeen <= seenCount 的？
   → 有：优先插入（插在当前 + 某间隔位置）
3. 弹出一张卡 → 翻面 → 用户评分：

   认识(5分)：标记 known，更新 SM-2 → 下次不会出现
   模糊(3分)：retried[wordId]++，计算 retryAfterSeen = seenCount + 5，塞入 retryQueue
   不认识(1分)：retried[wordId]++，计算 retryAfterSeen = seenCount + 8，塞入 retryQueue

4. seenCount++
5. 重复，直到所有词都标记 known
```

### 关键规则

- **永不放弃**：没有 leech 阈值，不认识 100 次也继续回炉
- **回炉按张数，不按时间**：`seenCount + 5` 或 `seenCount + 8`
- **回炉插入位置**：第 `seenCount + N` 张卡时弹出，N=5（模糊）或 N=8（不认识）
- **评分写入 SM-2**：每次评分都更新 SM-2 长期记录，不影响本轮队列
- **无上限**：整个来源有多少词就刷多少，dailyLimit 不参与

## 三、统计栏（刷词模式专用）

```
┌─────────────────────────────────────────────────┐
│ ✓ 380 掌握    📋 12 排队    📦 108 剩余          │
│ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░░░░░░ 76%          │
└─────────────────────────────────────────────────┘
```

| 字段 | 含义 | 变化时机 |
|------|------|---------|
| ✓ 掌握 | 本轮已评「认识」的词数 | 每次评分认识 → +1 |
| 📋 排队 | retryQueue 中等待回炉的词数 | 不认识/模糊 → +1；回炉后认识 → -1 |
| 📦 剩余 | deck 中还没被首次拿到的词数 | 主队列每取走一张 → -1 |
| 进度条 | 掌握 / 总数 | |

## 四、完成页

```
┌─────────────────────────────────────────────────┐
│                                                 │
│                🎉 本轮完成！                      │
│                                                 │
│        500 个词全部掌握                          │
│                                                 │
│    ┌──────┐   ┌──────┐   ┌──────┐              │
│    │ 一次过 │   │ 回炉后 │   │  总回   │              │
│    │  320  │   │  180  │   │ 炉次数 │              │
│    │ (64%) │   │ (36%) │   │  245  │              │
│    └──────┘   └──────┘   └──────┘              │
│                                                 │
│    [🔄 全量重刷]    [🔁 只刷不认识的]             │
│                                                 │
└─────────────────────────────────────────────────┘
```

- **一次过**：第一遍就评「认识」的
- **回炉后通过**：至少回炉过一次才认识的
- **总回炉次数**：所有回炉加起来（可能 > 总词数，因为一张卡可能回炉多次）
- [🔁 只刷不认识的]：新建一个临时 session，只包含本轮至少回炉过一次的词

## 五、与 SM-2 模式的关系

| | 📅 今日待复习 (SM-2) | 🚀 刷词 |
|---|---|---|
| 词来源 | 到期 + 新词（受 dailyLimit） | 所选来源的全部词 |
| 上限 | dailyLimit（如 20） | 不限 |
| 回炉 | 30-90 秒后 + leech 放弃 | 5-8 张后 + 永不放弃 |
| 进度 | seenCount / deck.length + delayed | ✓ 掌握 / 总数 |
| SM-2 写入 | 是 | 是 |
| 完成页 | SM-2 风格（明日预计复习…） | 刷词风格（一次过/回炉后通过…） |

两个模式**共享同一份 SM-2 数据**，但**队列逻辑完全独立**。

📐 设计方案总结：可拖拽分栏布局

基于我们的讨论，这是完整的设计方案。请逐项确认。

📋 需求确认清单

1. 手机竖屏 ✅ 上下真分栏（flex-direction: column）
2. 比例记忆 ✅ localStorage 持久化，横/竖屏各存一份
3. 拖拽边界 ✅ 默认 70%，最小 25%，最大 85%
4. 分割线风格 ✅ 低调透明 → 悬停高亮 → 拖拽发光
5. 面板显示 ✅ 始终显示双栏，面板空时显示占位提示

🏗️ 技术方案

核心技术栈

  • Pointer Events — 统一鼠标+触控，替代现有 mousedown
  • Flexbox + flex-basis 百分比 — 替代现有 px 宽度
  • CSS Media Query — @media (max-width: 767px) 切换 flex-direction
  • 移除 CSS transition — 拖拽时不能有动画，否则不跟手
  • touch-action: none — 禁用浏览器默认手势

改动范围

只改 reader.html 一个文件：

  • CSS — 重写 .reader-layout、.reader-pane、.detail-panel、.resize-handle，新增竖屏媒体查询
  • HTML — 调整 .reader-layout 内的元素顺序
  • JS — 重写拖拽逻辑（pointerdown→move→up），新增 localStorage 读写
  • 移除 — .detail-panel 的 CSS transition、.detail-overlay（不再需要浮层）

🔄 行为对比

✅ 改后

  • 拖拽实时跟手

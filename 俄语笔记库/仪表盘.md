# 📖 俄语学习仪表盘

---

## 🔴 需要复习的生词

```dataview
TABLE without ID
  file.link AS "单词",
  meaning AS "释义",
  type AS "词性",
  mastery AS "掌握度"
FROM "词汇"
WHERE mastery <= 2
SORT mastery ASC
```

---

## 🆕 最近 7 天新增

```dataview
TABLE without ID
  file.link AS "单词",
  meaning AS "释义",
  date(created) AS "添加日期"
FROM "词汇"
WHERE date(created) >= date(today) - dur(7 days)
SORT created DESC
```

---

## 📋 动词接格分组

```dataview
TABLE without ID
  file.link AS "动词",
  meaning AS "释义",
  case_gov AS "接格"
FROM "词汇"
WHERE type = "verb" AND case_gov != ""
SORT case_gov ASC
```

---

## 🔄 体的对照表

```dataview
TABLE without ID
  file.link AS "未完成体",
  pair AS "完成体"
FROM "词汇"
WHERE type = "verb" AND aspect = "несов." AND pair != ""
```

## 📊 掌握度分布

```dataviewjs
const pages = dv.pages('"词汇"')
const levels = [1,2,3,4,5]
const groups = levels.map(level => ({
  level: level,
  count: pages.where(p => p.mastery == level).length
}))
const total = pages.length
if (total > 0) {
  dv.paragraph(
    groups.map(g => `${"⭐".repeat(g.level)}: ${g.count} 个`).join(" &nbsp;|&nbsp; ")
  )
} else {
  dv.paragraph("_还没有词汇笔记，去「词汇」文件夹创建第一篇吧_")
}
```

## 📝 最近练习

```dataview
TABLE without ID
  file.link AS "练习",
  date(date) AS "日期",
  exam AS "考试"
FROM "每日练习"
SORT date DESC
```

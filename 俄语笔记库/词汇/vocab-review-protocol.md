# 俄语单词复习协议

> 本文档定义了 QClaw 处理俄语词汇复习的完整流程。
> 路径：D:\MyStudySpace\俄语笔记库\词汇

---

## 📂 文件结构

| 文件 | 用途 |
|------|------|
| `vocab-index.json` | 词库索引（word → file/type/meaning/tags），由脚本生成 |
| `vocab-progress.json` | 学习进度（掌握度、答题记录、当前会话状态） |

---

## 🎯 触发关键词

| 触发词 | 模式 | 每轮词数 | 交互方式 | 答案详细度 |
|--------|------|----------|----------|-----------|
| `刷词` | 快速模式 | 8个 | **批量推送，不互动** | 俄语 + 中文释义 |
| `复习` | 标准模式 | 12个 | 逐题互动 | 俄语 + 词性 + 中文释义 + 语法要点 |
| `深练` | 深度模式 | 6个 | 逐题互动 | 俄语 + 词性 + 释义 + 例句 + 完整语法 |

其他可用指令：
- `结束` — 提前结束当前复习，保存进度
- `会了` — 标记当前词为已掌握
- `不会` — 标记当前词为未掌握
- `进度` — 查看总体学习进度
- `更新索引` — 重新扫描词库文件（新增词汇后使用）

## 🔄 选词算法

### 掌握度等级

| mastery | 含义 | 选词权重 |
|---------|------|----------|
| 0 | 从未见过 | 最高优先 |
| 1 | 见过但答"不会" | 高优先 |
| 2 | 答过一次"会了" | 低优先（偶尔抽查） |
| 3 | 多次确认会了 | 极少出现 |

### 7:3 原则

- **70%** 的新词或低掌握度词（mastery 0-1）
- **30%** 的旧词间隔复习（mastery 1-2，上次答"不会"的）

### 去重规则

- 同一个词 **24小时内不重复出现**
- 当前会话中已出过的词不重复

### mastery 更新规则

| 操作 | mastery 变化 |
|------|-------------|
| 答"不会" | 设为 1（如果已经是1则不变） |
| 答"会了"且之前 mastery=0 | 设为 2 |
| 答"会了"且之前 mastery=1 | 设为 2 |
| 答"会了"且之前 mastery=2 | 设为 3 |
| 答"不会"且之前 mastery≥2 | 降回 1 |

## 💬 交互流程

### 刷词模式（批量推送，不互动）

用户发送 `刷词` → QClaw 执行：
1. 按算法选8个词
2. 一次性推送全部8个词（俄语 + 中文）
3. 更新 `lastSeen`，不更新 mastery
4. 流程结束，无需等待用户回复

输出格式：
```
🇷🇺 刷词 x8

1. совладать — 克服，控制，制服
2. застенчивость — 腼腆，害羞，羞怯
3. струйка — 细流
...
```

### 复习 / 深练模式（逐题互动）

用户发送 `复习` 或 `深练` → QClaw 执行：
1. 读取 `vocab-index.json` 和 `vocab-progress.json`
2. 检查是否有未完成的会话（currentSession），有则提示继续
3. 如无，按算法选词，创建新会话
4. 发送第一个词（只发俄语）

逐题交互：
```
我：1/12：власть

你：（回复任何内容，比如猜的释义，或者"不知道"）

我：✅ власть（名·阴）— 权力；政权；当局
   👉 回复「会了」或「不会」

你：会了 / 不会

我：（记录结果，发下一个词）
```

结束（全部完成或发`结束`）：
```
🎉 本轮复习结束！

✅ 认识：7个  |  ❌ 不认识：5个
📊 总进度：32/515 已见过（6.2%）
🏆 掌握度分布：⬜0: 483 | 🟨1: 18 | 🟩2: 10 | ✅3: 4
```

## 📝 答案格式（按模式）

### 刷词模式
```
✅ власть — 权力；政权
```

### 复习模式
```
✅ власть（名·阴）— 权力；政权；当局
   💡 常见搭配：прийти к власти（上台执政）
```
注：语法要点根据词性自动提取：
- 名词：性属（阴/阳/中）、变格提示
- 动词：体（完成体/未完成体）、接格关系
- 形容词：短尾形式提示

### 深练模式
```
✅ власть（名·阴）— 权力；政权；当局

例句：
   Он пришёл к власти. — 他上台执政了。
   Власть принадлежит народу. — 权力属于人民。

变格：
   主(1): власть | 属(2): власти | 与(3): власти
   宾(4): власть | 造(5): властью | 前(6): о власти
```
注：深练模式需要读取完整 .md 文件内容

## 💾 状态管理

### vocab-progress.json 结构

```json
{
  "version": 1,
  "lastUpdated": "2026-05-22T21:30:00+08:00",
  "stats": {
    "totalSeen": 0,
    "totalCorrect": 0,
    "totalIncorrect": 0
  },
  "words": {
    "власть": {
      "mastery": 1,
      "lastSeen": "2026-05-22T14:30:00+08:00",
      "correct": 1,
      "incorrect": 2
    }
  },
  "currentSession": {
    "mode": "review",
    "startedAt": "2026-05-22T14:00:00+08:00",
    "words": ["власть", "село", "погибнуть"],
    "currentIndex": 2,
    "phase": "reveal",
    "results": {
      "власть": "correct"
    }
  }
}
```

### phase 说明

| phase | 含义 | 期待用户输入 |
|-------|------|-------------|
| `question` | 已出题，等待用户猜 | 任意内容 |
| `reveal` | 已揭晓答案，等待会/不会 | `会了` 或 `不会` |

### 会话恢复

如果 currentSession 不为 null，用户发触发词时：
- 提示"你有一个未完成的复习，回复「继续」恢复，回复「新复习」开始新的"

## ⚙️ 索引更新

当用户在笔记库中新增词汇文件后，发送 `更新索引` 触发重新扫描。

---

## 🔒 注意事项

1. **不改原始笔记文件** — mastery 等进度信息只存在 vocab-progress.json
2. **编码** — 读取文件时使用 UTF-8 编码
3. **微信消息长度** — 单条消息控制在合理范围内，深练模式如果内容太长则拆分
4. **错误处理** — 如果索引文件损坏，提示用户执行 `更新索引`

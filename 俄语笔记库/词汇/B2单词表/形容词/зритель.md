# зритель

## 📝 详细释义
**俄语解释：** Зри́тель — существительное мужского рода: 1) тот, кто смотрит, наблюдатель (зритель спектакля, зритель фильма, зритель матча); 2) собирательно: публика, аудитория (зрители восторженно аплодировали). Множественное число: зри́тели. Образовано от глагола «зреть» (видеть). 注意：这是名词，不是形容词！frontmatter type 已修正。

**中文解释：** зритель 有以下含义：1) 观看者、观察者（戏剧观众、电影观众、比赛观众）；2) 集合名词：观众、听众（观众们热情鼓掌）。复数形式：зрители。由动词「зреть」（看见）构成。注意：这是名词，不是形容词！frontmatter type 已修正。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **наблюдатель** | 侧重「观察者」（наблюдатель за выборами — 选举观察员），比 зритель 更正式，常用于监督语境。 |
| **публика** | 侧重「观众/公众」（публика восторженно встретила — 观众热烈欢迎），集合名词，比 зрители 更概括。 |
| **болельщик** | 侧重「球迷/粉丝」（болельщики команды — 球队的粉丝），特指体育迷。 |
| **очевидец** | 侧重「目击者」（очевидец происшествия — 事件目击者），常用于新闻/法律语境。 |

## ⚠️ 易混淆词
- зритель vs наблюдатель — зритель 是娱乐/体育观众，наблюдатель 是正式观察员：зритель спектакля（戏剧观众） vs наблюдатель на выборах（选举观察员）。
- зритель vs публика — зритель 是个体观众，публика 是集体观众：один зритель（一个观众） vs публика аплодировала（观众们鼓掌了）。

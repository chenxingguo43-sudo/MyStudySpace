# крупный

## 📝 详细释义
**俄语解释：** Кру́пный — качественное прилагательное: 1) большой по размеру, величине (крупный шрифт, крупные черты лица); 2) значительный, большой по масштабу (крупный город, крупный бизнес); 3) состоящий из больших частиц (крупный песок, крупный сахар). Краткая форма: крупен, крупна, крупно, крупны. Степени сравнения: крупнее, крупнейший.

**中文解释：** крупный 是性质形容词：1) 大尺寸的（大号字体、粗犷的五官）；2) 大规模的（大城市、大生意）；3) 大颗粒的（粗砂、粗糖）。短尾形式：крупен, крупна, крупно, крупны。比较级：крупнее。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **большой** | 侧重「大的」（通用词），比 крупный 更广泛。крупный 更强调「显著的/突出的」。 |
| **значительный** | 侧重「重要的、可观的」（значительная сумма — 可观的金额），比 крупный 更正式。 |
| **огромный** | 侧重「巨大的」（огромный дом — 巨大的房子），比 крупный 程度更强。 |

## ⚡ 反义词
- **мелкий — 小的、细的**
- **небольшой — 不大的**

## 💬 谚语/俗语
- Крупная рыба глубже сидит. — 大鱼潜得深（喻大人物难以接近）。
- Крупный план виднее. — 特写看得更清（喻细节重要）。

## ⚠️ 易混淆词
крупный vs большой — крупный 更具体（大颗粒/大企业），большой 更通用（大面积/大量）。крупный план（特写镜头）vs большой план（大计划）。

## 💡 特殊用法
视觉：крупный план（特写镜头）。商业：крупный бизнес（大企业）、крупный инвестор（大投资者）。日常：крупный шрифт（大号字体）。

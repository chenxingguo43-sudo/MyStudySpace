# ра́вный

## 📝 详细释义
**俄语解释：** Равный — это прилагательное, означающее «одинаковый по величине, количеству, значению или положению; не уступающий кому-либо». Используется в математике (равные величины), в социальном контексте (равные права) и для сравнений (равный по силе).

**中文解释：** 相等的、平等的、同样的。在数学中指数值相等，在社会语境中指权利平等，用于比较时表示"不相上下"。短尾形式 равен 常用于数学等式。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **одинаковый** | 强调"完全相同的"，равный 更侧重"在某方面相等"，不一定完全相同。 |
| **эквивалентный** | 更正式/学术，常用于科学和数学语境；равный 更通用。 |
| **соразмерный** | 强调"成比例的、相称的"，比 равный 更侧重比例关系。 |

## 💬 谚语/俗语
- **Все равны перед законом.** — 法律面前人人平等。
- **Равному равное.** — 以牙还牙（直译：给平等的人平等的东西）。

## ⚠️ 易混淆词
- **равный vs одинаковый** — одинаковый 强调"一模一样"（одинаковые рубашки 一样的衬衫），равный 强调"在某方面相等"（равные шансы 平等的机会）。
- **短尾 равен 的用法** — 数学中 Два плюс два равно четырём（2+2=4），这是固定用法。

## 💡 特殊用法
- **数学用法**：短尾 равно 在数学中表示等号：X равно Y。名词 равенство 表示"等式"。
- **接格**：равный + 与格（чему/кому）：равный тебе（与你平等的）、равный нулю（等于零的）。
- **前置词用法**：ради 从 рад 派生，表示"为了"：ради тебя（为了你）、ради денег（为了钱）。
- **仅短尾**：рад 没有长尾形式，只有短尾：рад, рада, радо, рады。

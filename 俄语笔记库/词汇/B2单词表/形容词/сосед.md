# сосе́д

## 📝 详细释义
**俄语解释：** Сосед — существительное мужского рода, означающее «человек, живущий рядом; тот, кто находится по соседству; рядом сидящий/стоящий». Женская форма: соседка. Используется в прямом и переносном значении.

**中文解释：** 阳性名词，意为邻居、邻座的人。阴性形式：соседка。既可用于本义（住得近的人），也可用于转义（邻座的人、邻国）。

| 搭配 | 例句 | 翻译 |
|------|------|------|
| сосед по дому | Мой сосед по дому очень шумный. | 我楼上的邻居很吵。 |
| сосед по парте | Мой сосед по парте — хороший друг. | 我同桌是个好朋友。 |
| соседний дом | Он живёт в соседнем доме. | 他住在隔壁的房子里。 |
| по соседству | Мы живём по соседству. | 我们住得近。 |
| соседка | Наша соседка испекла нам пирог. | 我们的邻居给我们烤了一个馅饼。 |

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **земляк** | 强调同乡，来自同一个地方；сосед 强调空间上的接近。 |
| **соотечественник** | 强调同胞，同一个国家的人；сосед 更具体，指住得近的人。 |
| **попутчик** | 强调旅伴，临时的同行者；сосед 是长期的邻居。 |

| [[соседний]] | 形容词 | 隔壁的、邻近的 |
| [[соседство]] | 名词 | 邻居关系、邻近 |
| [[соседка]] | 名词 | 女邻居 |
| [[соседствовать]] | 动词 | 毗邻、相邻 |

## 💬 谚语/俗语
- Не имей сто рублей, а имей сто соседей. （宁有百个邻居，不有百个卢布。）

## ⚠️ 易混淆词
- сосед vs земляк — 都可指来自同一个地方的人，但 земляк 强调同乡，сосед 强调住得近。
- 注意原义：сосед 的意思是邻居，不是邻近的（邻近的 = соседний）。
- сосед 是阳性名词，不是形容词。

## 💡 特殊用法
- **日常用法**：сосед по квартире（室友）、сосед по парте（同桌）、сосед по купе（车厢隔间旅伴）。
- **转义**：соседняя страна（邻国）、соседний двор（隔壁院子）。
- **口语称呼**：Здравствуйте, сосед!（你好，邻居！）——打招呼用语。
- **习语**：жить по-соседски（和睦相处）。

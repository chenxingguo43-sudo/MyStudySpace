# да́нный

## 📝 详细释义
**俄语解释：** Данный — это прилагательное (причастие от дать), означающее «этот, упомянутый, имеющийся в виду» (в формальном стиле) и «тот, который был дан, предоставлен» (прямое значение). В научном и официальном стилях широко используется вместо «этот»: данный вопрос, данный момент. Множественное число: данные (также «данные» = факты, цифры).

**中文解释：** 这个、该（正式用语）；给予的、被赋予的。在学术和官方语体中广泛替代「этот」使用： данный вопрос（这个问题）。注意：复数「данные」作名词时意为「数据」。

## ✍️ 补充搭配
| 搭配 | 例句 | 翻译 |
|------|------|------|
| в данный момент | В данный момент мы не можем ответить. | 目前我们无法回答。 |
| данный вопрос | Данный вопрос требует дополнительного изучения. | 这个问题需要进一步研究。 |
| в данном случае | В данном случае вы правы. | 在这种情况下您是对的。 |
| данный факт | Данный факт подтверждается исследованиями. | 这一事实得到了研究的证实。 |
| имеющиеся данные | Имеющиеся данные говорят о росте экономики. | 现有数据表明经济在增长。 |

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **этот** | 更口语化、通用；данный 更正式，常用于学术和官方文本。 |
| **упомянутый** | 侧重「上述提到的」；данный 含义更广，包括「当前的、这个」。 |
| **означенный** | 非常正式，指「上述的、指定的」；данныий 更常用。 |

## 💬 谚语/俗语
- **Данное слово — не воробей: вылетит — не поймаешь. — 说出去的话如泼出去的水。（改编自「слово не воробей」）**

## ⚠️ 易混淆词
данный vs преданный — 拼写非常相似但意义完全不同！данный = 这个/该；преданный = 忠诚的。
данный (形容词) vs данные (名词) — данные 作名词时意为「数据、资料」（собирать данные 收集数据）。
正式 vs 口语：在日常口语中很少用 данный，一般用 этот。данный 主要出现在书面语中。

## 💡 特殊用法
- 形动词来源：данный 原是动词 дать 的过去被动形动词（被给予的），后发展为独立形容词。
- 固定搭配：в данный момент（此刻）、в данном случае（在这种情况下）、при данных условиях（在这些条件下）。
- 注意：名词 данные（数据）只有复数形式：Эти данные важны.

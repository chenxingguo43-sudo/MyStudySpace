# двухместный

## 📝 详细释义
**俄语解释：** Двухместный — это прилагательное, означающее «рассчитанный на два места, на двух человек». Используется для описания номеров, кают, транспортных средств и т.д.

**中文解释：** 双座的、双人的。用于描述可容纳两人或两个座位的房间、舱位、交通工具等。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **парный** | 更广泛，表示"成对的"，不一定指座位；двухместный 特指"双座/双人的"。 |
| **сдвоенный** | 表示"合并为二的"（如 сдвоенная кровать = 双人床），强调合并；двухместный 强调容量。 |
| **двойной** | 表示"双倍的、双重的"，用于数量；двухместный 用于座位/空间。 |

## ⚡ 反义词
- **одноместный** — 单座的、单人的
- **трёхместный** — 三座的、三人的

## 💬 谚语/俗语
- **Двухместный номер — для двоих, а не для одного.** — 双人房是给两个人住的，不是给一个人的。（关于合理利用资源）

## ⚠️ 易混淆词
- **двухместный vs двойной** — двухместный 容纳两人的（двухместный номер = 双人房）；двойной 双倍的（двойная порция = 双份）。

## 💡 特殊用法
- **旅游用语**：двухместный номер 是酒店常用术语，区别于 одноместный（单人间）和 люкс（豪华套房）。
- **交通用语**：двухместный самолёт/вертолёт 在航空领域指双座飞行器。
- **注意连字符**：有时会看到 «двух-местный» 的写法（带连字符），但标准写法不带连字符。

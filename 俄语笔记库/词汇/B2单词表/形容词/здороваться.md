# здороваться

## 📝 详细释义
**俄语解释：** Здоро́ваться — возвратный глагол несовершенного вида: приветствовать кого-либо, говорить «здравствуйте» или другое приветствие при встрече (Они здороваются каждый день). Употребляется с предлогом «с» + творительный падеж (здороваться с кем-либо). Также используется в значении «поздороваться» (完成体: поздороваться). 注意：这是动词，不是形容词！frontmatter 中的 type 已修正。

**中文解释：** здороваться 是一个反身动词（未完成体）：打招呼、问好（他们每天打招呼）。与前置格 с + 工具格连用（和某人打招呼）。完成体为 поздороваться。注意：这是动词，不是形容词！frontmatter 中的 type 已修正。原来的 meaning "健康的" 完全错误。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **приветствовать** | 更正式，侧重「致欢迎辞、欢迎」（приветствовать гостей — 欢迎客人），比 здороваться 更隆重。 |
| **кланяться** | 侧重「鞠躬、致意」，可以是不说话的点头致意，比 здороваться 更含蓄。 |
| **打招呼 (中文)** | здороваться 最接近中文的「打招呼」，是最日常的见面问候方式。 |

## 💬 谚语/俗语
- Здоровайся первым — не потеряешь друга. — 先打招呼，就不会失去朋友。（主动示好）
- Здороваться — не значит дружить. — 打招呼不等于交朋友。（表面礼貌不等于真心）

## ⚠️ 易混淆词
- здороваться vs здоровый — здороваться 是动词（打招呼），здоровый 是形容词（健康的）；两者词根相同但含义不同。
- здороваться vs здравствуйте — здороваться 是动词（打招呼的动作），здравствуйте 是感叹词（您好——具体的问候语）。

## 💡 特殊用法
- **文化差异**：在俄罗斯，握手是最常见的问好方式（здороваться за руку）；亲密朋友间可以拥抱。
- **否定用法**：Они не здороваются.（他们不打招呼。）—— 表示关系不好。
- **完成体**：поздороваться 表示一次性的打招呼动作：Я хотел поздороваться.（我想打个招呼。）

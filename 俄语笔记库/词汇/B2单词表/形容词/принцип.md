# при́нцип


## 📝 详细释义
**俄语解释：** Принцип — это существительное мужского рода, означающее «основное правило, положение, руководящая идея». Также может означать «устройство, способ действия механизма». Множественное число: при́нципы. Слово заимствовано из латинского principium (начало, основа).

**中文解释：** 原则、原理、准则。阳性名词。指基本的规则、立场、指导思想，也可指机械装置的运作方式。复数形式：принципы。源自拉丁语 principium（开始、基础）。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **правило** | 强调行为准则、规矩；принцип 更强调根本性的理念基础。 |
| **основа** | 强调基础、根本；принцип 更强调指导性的思想。 |
| **идея** | 强调思想、概念；принцип 更强调可操作的准则。 |
| **доктрина** | 更正式，指系统的学说；принцип 可以是个人的信条。 |

## 💬 谚语/俗语
- Принцип есть принцип. — 原则就是原则。（意为有些事不可妥协）

## ⚠️ 易混淆词
- **принцип vs принц** — принц 意为「王子、亲王」；принцип 意为「原则」。拼写和含义完全不同。
- **принцип vs принципиальный** — принципиальный 是形容词，意为「原则性的、有原则的」；принцип 是名词。注意词性不同！

## 💡 特殊用法
- **固定搭配**：в принципе — 原则上、基本上；по принципу — 按照…的原则。
- **口语**：Это принципиальный вопрос! — 这是原则问题！
- **科学用语**：принцип неопределённости — 不确定性原理（物理学术语）。
- **注意词性**：这是名词，不是形容词！形容词形式是 принципиальный。

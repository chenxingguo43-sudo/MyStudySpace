# большо́й

## 📝 详细释义
**俄语解释：** Большой — это прилагательное, обозначающее 1) значительный по размеру, объёму, площади (большой дом); 2) значительный по количеству (большое количество); 3) высокий по росту (большой мальчик — взрослый); 4) важный, значительный (большой человек — важный человек). Одно из самых частотных прилагательных русского языка.

**中文解释：** 1）大的，体积大的（большой дом — 大房子）。2）大量的（большое количество — 大量）。3）长大的（большой мальчик — 大男孩，长大了的男孩）。4）重要的，了不起的（большой человек — 大人物）。俄语中最常用的形容词之一。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **крупный** | 强调"大而重要、大而显眼"，常用于体型、规模、金额（крупный мужчина — 魁梧的男人，крупная сумма — 大笔款项）。 |
| **огромный** | 比 большой 程度更强，指"巨大的、庞大的"（огромный дом — 巨大的房子）。 |
| **великий** | 带有崇高的感情色彩，指"伟大的"（великий писатель — 伟大的作家）。 |
| **громадный** | 与 огромный 相近，指"极大的"，强调令人惊叹的大。 |

## ⚡ 反义词
- **маленький** — 小的
- **небольшой** — 不大的

## 💬 谚语/俗语
- **Большому кораблю — большое плавание.** — 大船走远航。（大人物有大事业。）
- **В тесноте, да не в обиде.** — 挤是挤了点，但不生气。（与 большой 相关：人多地方小也无所谓。）
- **Больше дела — меньше слов.** — 多做事，少说话。

## ⚠️ 易混淆词
- **большой vs большой (强调)** — 注意区分：большой дом（大房子）vs. большой палец（大拇指，固定搭配）。
- **больше vs больше не** — больше не = 不再（Я больше не хочу. — 我不想再要了。），注意否定含义。

## 💡 特殊用法
- **专有名词**：Большой театр（大剧院，莫斯科著名芭蕾歌剧院）、Большой каньон（大峡谷）。
- **口语强调**：Он из себя большой! = 他觉得自己了不起！（讽刺语气）。
- **日常口语**：Большое спасибо! = 非常感谢！（比 просто спасибо 更热情。）
- **习语**：большая часть（大部分）、в большой мере（在很大程度上）。

# гнездо́

## 📝 详细释义
**俄语解释：** Гнездо — существительное среднего рода, обозначающее «место, где живёт и выводит птенцов птица; жилище животного». Также используется в переносном смысле: притон, рассадник (гнездо преступности); в технике: гнездо для кабеля, розетка. Множественное число: гнёзда.

**中文解释：** 巢穴、窝。中性名词。本义指鸟类筑巢育雏的地方，也指动物的栖息地。转义指犯罪窝点、滋生地。技术领域指插孔、插座。复数：гнёзда。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **гнездовье** | 更专业的生态学术语，指动物的巢址；гнездо 更通用。 |
| **логово** | 指猛兽的巢穴（狼穴、熊穴）；гнездо 主要指鸟类和昆虫的巢。 |
| **притон** | 仅用于转义「犯罪窝点」；гнездо 的转义范围更广。 |

## 💬 谚语/俗语
- **Всякая птица своё гнездо хвалит. — 每只鸟都夸自己的巢。（金窝银窝不如自己的狗窝）**

## ⚠️ 易混淆词
гнездо vs логово — гнездо 主要指鸟巢、蜂巢等；логово 指猛兽的巢穴。转义中 гнездо 更中性，логово 更具威胁性。
注意复数重音变化：гнездо́ → гнёзда。注意原文件 frontmatter type 误标为 adj，已修正。

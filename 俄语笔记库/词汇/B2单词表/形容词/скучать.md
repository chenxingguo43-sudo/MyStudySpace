# скучать

## 📝 详细释义
**俄语解释：** ВНИМАНИЕ: скучать — это ГЛАГОЛ, а не прилагательное! Значение: «испытывать скуку, томиться от отсутствия занятий или общения; тосковать по кому-либо». Управление: скучать по кому-чём (разг.) / скучать по кому-чему (устар./лит.) / скучать без кого-чего / скучать о ком-чём (книжн.). Несовершенный вид.

**中文解释：** 注意：скучать 是动词，不是形容词！含义：感到无聊、想念某人。接格：скучать по + 前置格（口语）/ по + 与格（旧式/文学）/ без + 属格 / о + 前置格（书面语）。未完成体。对应的形容词形式是 скучный（无聊的）。

| 词 | 区别 |

## ⚠️ 易混淆词
- **скучать vs скучный** — скучать 是动词「感到无聊、想念」；скучный 是形容词「无聊的」。不要混淆词性！
- Мне скучно.（我感到无聊。）——无人称句，用状态词
- Это скучный фильм.（这是部无聊的电影。）——形容词
- **скучать по vs скучать без** — скучать по + 前置格 = 想念某人/某事（Я скучаю по тебе.）
скучать без + 属格 = 没有某人而无聊（Мне скучно без тебя.）
两者意思相近，但接格不同。

## 💡 特殊用法
- **词性纠正**：原文件中标注 type: "adj" 是错误的。скучать 是动词，不是形容词！正确的形容词形式是 скучный。
- **接格难点**：скучать 的接格比较复杂，口语中最常用的是 по + 前置格（скучать по тебе），但传统语法要求 по + 与格（скучать по тебе 在口语中已取代了 по тебе）。
- **无人称用法**：Мне скучно.（我感到无聊。）——这是无人称句，скучно 是状态词，不是动词。
- **日常高频**：Я скучаю по тебе.（我想你。）是最常用的表达思念的句子之一。

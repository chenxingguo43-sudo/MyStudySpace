# руль

## 📝 详细释义
**俄语解释：** Руль — это существительное мужского рода, означающее «устройство для управления направлением движения транспортного средства (автомобиля, корабля, самолёта)». Основное значение — руль автомобиля (汽车方向盘). Также: руль корабля (船舵), руль самолёта (飞机的方向舵). В переносном смысле: быть за рулём (驾驶、掌控).

**中文解释：** 方向盘、舵——阳性名词，指控制交通工具行驶方向的装置。基本含义是汽车的方向盘。也有船舵、飞机方向舵的意思。引申义：быть за рулём（驾驶、掌控）。

## ⚠️ 易混淆词
- **руль vs ру́ль** — 注意重音：руль（方向盘）是名词，重音在 ю 上。此词条原始数据中 type: "adj" 和 meaning: "绯红色的" 均为严重错误。руль 不是形容词，也不是绯红色的意思。绯红色 = алый / багровый。

## 💡 特殊用法
- **注意**：此词为阳性名词，非形容词。原始数据中 type: "adj" 和 meaning: "绯红色的" 为严重错误，将被修正。
- быть за рулём = 驾驶（字面：在方向盘后面）；сесть за руль = 坐到驾驶座上、开始开车。
- руль 在航海/航空中 = 舵：руль направления（方向舵）、руль высоты（升降舵）。

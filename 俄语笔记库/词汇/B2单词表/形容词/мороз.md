# мороз

## 📝 详细释义
**俄语解释：** Моро́з — существительное мужского рода, неодушевлённое: 1) очень низкая температура воздуха, холод (сильный мороз, десять градусов мороза); 2) морозное вещество для замораживания (сухой мороз). Склоняется по типу «стол».注意：此词为名词（非形容词），位于形容词文件夹中。

**中文解释：** мороз 是阳性非动物名词：1) 极低的气温、严寒（严寒、零下十度）；2) 冷冻剂（干冰）。按照 стол 类型变格。注意：此词为名词（非形容词），位于形容词文件夹中。

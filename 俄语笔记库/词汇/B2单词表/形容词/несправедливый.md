# несправедли́вый

## 📝 详细释义
**俄语解释：** Несправедливый — прилагательное, означающее «не соответствующий справедливости; предвзятый; незаслуженный».

**中文解释：** 不公平的、不公正的。指违反公平原则的、偏袒的、不合理的。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **пристрастный** | 强调偏袒的、有偏见的；несправедливый 更广泛。 |
| **неправый** | 强调不对的、错误的；несправедливый 更侧重公平性。 |
| **беспощадный** | 强调无情的；несправедливый 侧重不公正。 |

## ⚡ 反义词
- **справедливый — 公平的、公正的**
- **объективный — 客观的**
- **законный — 合法的**

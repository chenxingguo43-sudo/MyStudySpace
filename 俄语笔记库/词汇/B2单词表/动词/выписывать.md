# выписывать

## 📝 详细释义

**俄语解释：** Выписывать — многозначный переходный глагол несовершенного вида. 1) Выбирать и записывать что-либо из текста, книги, газеты — выписывать цитаты, выписывать выдержки. 2) Оформлять подписку на издание — выписывать газету, выписывать журнал. 3) Оформлять документы — выписывать рецепт, выписывать справку. 4) Выселять, выгонять — выписывать из общежития. 5) Отмечать списывая — выписывать со склада.

**中文解释：** выписывать 是一个多义及物未完成体动词：1）摘录、抄下（从文本、书籍、报纸中选取并记录——выписывать цитаты 引用名言）；2）订阅（办理订阅手续——выписывать газету 订报纸）；3）开（处方、证明等文件——выписывать рецепт 开处方）；4）注销、开除（从宿舍等迁出——выписывать из общежития 从宿舍除名）；5）从仓库等出库登记。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **записывать** | 更通用，指"记录"；выписывать 强调"有选择地摘抄"。 |
| **извлекать** | 侧重"提取"，偏书面；выписывать 更日常化。 |
| **оформлять** | 开证明义近义，但 оформлять 更正式，范围更广。 |

## ⚡ 反义词

- **вписывать — 写入、列入**
- **подписывать — 签署**

## ⚠️ 易混淆词

- выписывать vs записывать — выписывать 强调从已有文本中摘抄选出，записывать 更通用，指任何记录行为。
- выписывать vs выписать — выписывать 未完成体（过程、习惯），выписать 完成体（一次结果）。

## 💡 特殊用法

接格：что（выписывать цитаты 摘录引文）；из чего（выписывать из книги 从书中摘录）。口语中"выписывать кому"可表示"痛打、教训某人"（俗语）。被动形式：выписываемый。

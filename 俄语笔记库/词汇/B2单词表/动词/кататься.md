# кататься

## 📝 详细释义

**俄语解释：** Кататься — значит 1) передвигаться на чём-либо для удовольствия: кататься на велосипеде, кататься на лыжах; 2) катиться, перекатываться: Мяч катается по полу; 3) (разг.) отдыхать, развлекаться: Куда ты кататься едешь? Несовершенный вид. Совершенный вид — покататься（去玩一会儿）。Глагол используется с предлогом на + предложный падеж (на чём)。

**中文解释：** Кататься 意为：1）为了 pleasure 而骑、乘：骑自行车、滑雪；2）滚动：球在地板上滚；3）（口语）去玩、去度假：你要去哪儿玩？未完成体。完成体为 покататься（去玩一会儿）。该动词接 на + 第六格（на чём）。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **ехать** | 更通用，指一般的移动、行驶；кататься 强调为了 pleasure 或反复的动作。 |
| **прокатиться** | 完成体，指去玩一趟；кататься 强调持续或反复的动作。 |
| **развлекаться** | 更广泛，指各种娱乐活动；кататься 特指骑、乘类的活动。 |

## 💬 谚语俗语

- Кататься — не работать. — 玩乐不是工作。（对比休闲与劳动）
## ⚠️ 易混淆词

- кататься vs катить — катить 是及物动词（推滚某物）；кататься 是不及物（自己骑、滚、玩）。
- кататься vs ехать — ехать 指一般的行驶；кататься 强调为了 pleasure 的骑乘。
## 💡 特殊用法

- 口语用法：Куда катаешь?（你要去哪儿玩？）——朋友间的 informal 问法。
- 固定搭配：кататься с горки（滑滑梯），кататься по волнам（冲浪）。
- 反身动词：-ся 后缀表示为自己做某事或反复动作。
- 完成体：покататься — 去玩一会儿：Давай покатаемся!（我们去玩一会儿吧！）

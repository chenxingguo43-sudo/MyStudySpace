# исключать

## 📝 详细释义

**俄语解释：** Исключать (нсв) — несовершенный вид глагола исключить. Означает: 1) удалять, вычёркивать из состава (исключать из списка, из группы); 2) отчислять, увольнять (исключать из школы, из организации); 3) допускать невозможность, отрицать (исключать возможность — не исключать); 4) исключать из себя — не включать, не содержать. Имеет два основных значения: 'удалять' и 'не допускать'.

**中文解释：** исключать（未完成体）是 исключить 的未完成体形式。含义：1）删除、从名单中划去（从名单中排除、从小组中排除）；2）开除、解雇（从学校开除、从组织中开除）；3）排除可能性（不排除可能性）；4）исключать из себя——不包含。有两个主要意义：'删除'和'排除可能性'。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **исключить** | 完成体，强调结果；исключать 强调过程或重复。 |
| **удалять** | 侧重'移除、清除'；исключать 侧重'从整体中剔除'。 |
| **отчислять** | 特指'开除学籍'；исключать 更通用。 |

- **принимать** — 接受

## ⚠️ 易混淆词

| 对比 | 区别 |
|---|---|
| **исключать vs исключить** | исключать 是未完成体（正在排除），исключить 是完成体（排除了）。 |
| **исключать vs включать** | исключать 是'排除'；включать 是'纳入'——反义词。 |
| **исключать vs удалять** | исключать 侧重'从整体中剔除'；удалять 侧重'移走、清除'。 |


## 💡 特殊用法

- 未完成体动词，完成体对应形式为 исключить。
- 接格：кого-что из чего（从…中排除…）：исключать его из списка（把他从名单中排除）。
- 否定形式：не исключать（不排除）——常用于表示'有可能'：Я не исключаю этого.（我不排除这种可能。）
- 名词 исключение 表示'例外'：За исключением...（除了…之外）。
- 形容词 исключительный 表示'杰出的、非凡的'：исключительный талант（非凡的天赋）。

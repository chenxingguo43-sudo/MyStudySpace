# вынуть

## 📝 详细释义

**俄语解释：** Вынуть — значит достать, извлечь что-либо из какого-либо места, контейнера. Совершенный вид глагола вынимать. Употребляется в прямом (вынуть ключ из замка) и переносном смысле (вынуть душу — изматывать).

**中文解释：** Вынуть 意为从某处、容器中取出、掏出。是 вынимать 的完成体。既用于字面意义（从锁里拔出钥匙），也用于引申义（令人精疲力竭）。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| вынуть из замка | Он вынул ключ из замка. | 他从锁里拔出了钥匙。 |
| вынуть из кармана | Она вынула платок из кармана. | 她从口袋里掏出手帕。 |
| вынуть из коробки | Ребёнок вынул игрушку из коробки. | 孩子从盒子里取出了玩具。 |
| вынуть из розетки | Вынь шнур из розетки. | 把电线从插座上拔出来。 |
| вынуть занозу | Мама вынула ребёнку занозу. | 妈妈给孩子拔出了刺。 |

## 💬 谚语/俗语

- **Вынь да положь — 原封不动地拿出来（形容要求原样归还或要求立即做到某事）。**

## ⚠️ 易混淆词

- **вынуть vs вынести** — вынуть 是从容器/空间中"取出"；вынести 是从里面"搬到外面"，通常需要体力。例：вынуть ключ из кармана（从口袋掏出钥匙） vs вынести мебель из комнаты（把家具从房间搬出去）。
- **вынуть vs вытащить** — вынуть 是平稳地取出；вытащить 是"拖出来、拽出来"，动作更费力。

## 💡 特殊用法

- 谚语：Вынь да положь — 要求立即做到或原样归还（如：Он хочет, чтобы всё было вынь да положь. 他什么都要求现成的。）。
- 变位不规则：выну, вынешь, вынет...（不是 *выну, *вынишь）。
- 搭配：вынуть занозу — 拔刺（常用生活场景）。

# выселять

## 📝 详细释义

**俄语解释：** Выселять (нсв) — несовершенный вид глагола выселить. Означает: 1) принудительно заставлять кого-либо покинуть жилище, помещение (выселять неплательщиков, выселять жильцов); 2) переносно: выгонять, изгонять (выселять из памяти — забывать). Официально-юридический оттенок: используется в контексте судебных решений, договоров аренды, жилищного права.

**中文解释：** выселять（未完成体）是 выселить 的未完成体形式。含义：1）强制某人离开住所、房屋（驱逐欠租者、让住户搬走）；2）转义：驱赶、从记忆中抹去。带有官方/法律色彩：常用于法院判决、租赁合同、住房法等语境。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **выселить** | 完成体，强调结果；выселять 强调过程或重复。 |
| **выгонять** | 更口语化，泛指'赶出去'；выселять 专指'从住所赶出'，更正式。 |
| **изгонять** | 更书面、更文雅，可用于抽象意义（изгонять страхи）；выселять 更具体、更法律化。 |

## ⚡ 反义词

- **вселять** — 使迁入,安置
- **поселять** — 安置,安排住下

## 💬 谚语/俗语

- **Выселять — не строить, слёзы лить придётся. — 驱逐不是建造，少不了要流泪。（赶人走总是伤感情的事）**
## ⚠️ 易混淆词

| 对比 | 区别 |
|---|---|
| **выселять vs выселять** | выселять 是未完成体（正在驱逐、经常驱逐），выселить 是完成体（赶走了）。 |
| **выселять vs выгонять** | выселять 专指'从住所赶出'，有法律意味；выгонять 更通用，泛指'赶出去'。 |
| **выселять vs изгонять** | выселять 是具体的'赶出住所'；изгонять 更抽象，可以是'驱逐出境'或'驱除（恐惧等）'。 |

## 💡 特殊用法

- 未完成体动词，完成体对应形式为 выселить。
- 接格：кого-что（直接补语）+ из + 第二格（从哪里驱逐）：выселять жильцов из дома。
- 法律语境常用：выселение по решению суда（依法院判决驱逐）。
- 前缀 вы- 表示'向外'的运动方向：вы- + селить（安置）→ 从住所赶出。

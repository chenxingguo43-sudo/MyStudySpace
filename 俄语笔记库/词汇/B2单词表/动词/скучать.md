# скучать

## 📝 详细释义

**俄语解释：** Скучать — испытывать скуку, тоску, одиночество. 1) скучать без дела (чувствовать скуку от безделья); 2) скучать по кому-то (тосковать по отсутствующему человеку); 3) скучать по чему-то (тосковать по чему-то). Непереходный глагол несовершенного вида. Управление: скучать по кому/чём (дательный падеж) или без дополнения.

**中文解释：** скучать 意为感到寂寞、烦闷、思念。1）因无所事事而无聊；2）想念某人；3）怀念某事物。不及物未完成体动词。接格关系：скучать по кому/чём（第三格）或不带补语。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| скучать по кому-то | Я скучаю по тебе. | 我想你。 |
| скучать без кого | Она скучает без мужа. | 她想念丈夫。 |
| скучать по дому | Студент скучает по дому. | 学生想家。 |
| скучать от безделья | Я скучаю от безделья. | 我因无所事事而无聊。 |
| не скучай! | Ну, не скучай! — Прощание. | 别太无聊哦！——告别语。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| тосковать | 更强烈，带有深沉的忧伤，скучать 更日常、更轻度。 |
| грустить | 表示忧伤、难过，不一定是因为思念，скучать 更侧重想念。 |
| заскучать | 开始感到无聊，强调从不无聊到无聊的变化。 |

## 💬 谚语/俗语

- **Скучен день до вечера, делать нечего. — 百无聊赖，无事可做。**（出自莱蒙托夫的诗）

## ⚠️ 易混淆词

- **скучать vs соскучиться** — скучать 是未完成体（持续感到无聊/想念），соскучиться 是完成体（表达了想念的结果）：Я скучаю по тебе（我想你——持续状态） vs Я по тебе соскучился（我好想你——表达想念的结果）。
- **скучать по vs скучать без** — 两者含义相近，по 更标准（скучать по тебе），без 更口语化（скучать без тебя）。
- **注意：** 接格用法有争议，标准语中用 по + 第六格（по ком/чём），口语中也用 по + 第三格。

## 💡 特殊用法

- 变位：скучаю, скучаешь, скучает, скучаем, скучаете, скучают。
- 接格说明：скучать по ком-чём — 第六格（标准）。口语中也有人说 скучать по тебе（第三格），但这是非标准的。
- 口语高频句：Скучаю!（想念你！——常用于亲密关系中）；По тебе скучаю（我想你——更完整的表达）。
- 告别用法：Не скучай!（别太无聊哦！——轻松的告别语，类似中文的"保重"）。

# проспект

## 📝 详细释义

**俄语解释：** Проспект — существительное, мужской род. Значения: 1) широкая, прямая улица в городе (Невский проспект); 2) проспект — краткое описание, обзор (проспект выставки). Управление: на проспекте (六格), по проспекту (三格). Слово используется для обозначения главных, широких улиц города.

**中文解释：** проспект 是阳性名词。含义：1) 城市中宽阔、笔直的大街（涅瓦大街）；2) 简介、概览（展览会简介）。接格：на проспекте（六格）、по проспекту（三格）。这个词用于指城市中主要的、宽阔的街道。

## ✍️ 补充搭配

## 🎯 近义词辨析

| 词 | 区别 |

| **улица** | 更通用，指任何街道；проспект 特指宽阔、笔直的主要街道。 |
| **шоссе** | 侧重于'公路、大道'，通常指城市间的道路；проспект 专指城市内的大街。 |
| **бульвар** | 侧重于'林荫道'，通常有树木；проспект 更侧重于'宽阔的大街'。 |

## ⚠️ 易混淆词

- **проспект vs улица** — проспект 是宽阔的主要街道；улица 是通用的'街道'。
- **проспект vs бульвар** — проспект 侧重于'宽阔'；бульвар 侧重于'有树木的林荫道'。

## 💡 特殊用法

проспект 是一个名词，不是动词！注意：虽然词形以 -ект 结尾，但它是阳性名词。文化背景：Невский проспект（涅瓦大街）是俄罗斯最著名的街道之一，也是果戈理的同名小说标题。注意：проспект 还有'简介、概览'的含义，但这个用法比较正式，不常用。接格变化：проспект（一格）、проспекта（二格）、проспекту（三格）、проспект（四格）、проспектом（五格）、проспекте（六格）。

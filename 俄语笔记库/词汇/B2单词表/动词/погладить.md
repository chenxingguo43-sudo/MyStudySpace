# погладить

## 📝 详细释义

**俄语解释：** Погладить — св, два основных значения: 1) разгладить утюгом; 2) провести рукой с лаской. Нсв — гладить.

**中文解释：** погладить 是完成体及物动词，有两个主要含义：1）熨平（熨衣服）；2）抚摸（抚摸猫、抚摸头顶）。未完成体为 гладить。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| погладить бельё / одежду | Нужно погладить бельё перед поездкой. | 出行前需要熨好衣服。 |
| погладить кота / собаку | Дети погладили щенка. | 孩子们抚摸了小狗。 |
| погладить по голове | Бабушка погладила девочку по голове. | 奶奶抚摸了女孩的头。 |
| погладить по спине | Он погладил друга по спине утешительно. | 他安慰地拍了拍朋友的背。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **разгладить** | 侧重「熨平」，更强调消除褶皱的结果；погладить 更通用。 |
| **пощупать** | 侧重「触摸」，不一定是抚爱；погладить 带有爱抚含义。 |
| **ласкать** | 更文学化，强调持续的爱抚；погладить 是一次性的动作。 |

## ⚠️ 易混淆词

- погладить (熨平) vs разгладить (熨平) — разгладить 更强调消除褶皱的结果。
- погладить (完成体) vs гладить (未完成体) — 体的区别。

## 💡 特殊用法

- 多义性：同形多义——熨烫和抚摸是两个不同的语义场，需通过上下文区分。
- 完成体：过去时 погладил, погладила, погладило, погладили。
- 接格：кого-что（及物动词）。抚摸义时常加 по + 第三格。

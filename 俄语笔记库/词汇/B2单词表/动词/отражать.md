# отражать

## 📝 详细释义

**俄语解释：** Отражать имеет три основных значения: 1) физическое: отбрасывать свет, зеркально воспроизводить (зеркало отражает лицо); 2) абстрактное: показывать, выражать (книга отражает эпоху); 3) военное/защитное: отбивать атаку (отражать врага). Несовершенный вид; совершенный — отразить.

**中文解释：** Отражать 有三种主要含义：1）物理：反射、映出（镜子映出面容）；2）抽象：反映、表现（书反映时代）；3）军事/防御：击退、抵御（击退敌人）。未完成体；完成体是 отразить。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **выражать** | 侧重'表达（思想、情感）'；отражать 更侧重'客观反映、映出'。 |
| **изображать** | 侧重'描绘、画像'；отражать 更强调'自然映射、反映'。 |
| **отбивать** | 特指'击退、打退'（军事语境）；отражать 更通用，可用于物理和抽象意义。 |

## ⚠️ 易混淆词

- **отражать vs отразить** — отражать 未完成体（过程/反复）；отразить 完成体（结果）。对比：Зеркало отражает свет（镜子在反射光——持续） vs Зеркало отразило вспышку（镜子反射了闪光——一次性）。
- **отражать (反射) vs отражать (击退)** — 同一动词的不同义项，需根据上下文区分。物理/抽象语境 = 反映；军事语境 = 击退。

## 💡 特殊用法

- 物理学用法：отражать свет / звук / изображение = 反射光/声音/图像。
- 社会学/哲学用法：отражать действительность / реальность / тенденции = 反映现实/趋势。
- 军事用法：отражать атаку / нападение / удар = 击退进攻/袭击/打击。
- отражение 是常用名词：узнать себя в отражении（在倒影中认出自己）。
- 被动形动词：отражённый = 被反射的（отражённый свет — 反射光）。

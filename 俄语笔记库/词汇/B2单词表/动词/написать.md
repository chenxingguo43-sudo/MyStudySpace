# написать

## 📝 详细释义

**俄语解释：** Написать — многозначный глагол совершенного вида: 1) создать текст, записать (写、写出): написать письмо; 2) завершить процесс письма (写完): написать сочинение; 3) создать произведение искусства (创作): написать картину (нарисовать красками). Управление: кого-что (四格) — написать текст; кому (三格) — написать другу (письмо). Также используется без дополнения: Напиши мне!（写信给我！）

**中文解释：** написать 是完成体多义动词：1) 创建文本、记录（写、写出）：写信；2) 完成书写过程（写完）：写完作文；3) 创作艺术作品（创作）：画油画。接格：кого-что（四格）——写文本；кому（三格）——给朋友写（信）。也用于无补语：写信给我！未完成体为 писать。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **писать** | 未完成体，表示书写的过程或反复动作；написать 强调完成结果。 |
| **сочинить** | 侧重创作（文学、音乐）；написать 更通用，可用于各种书写。 |
| **изложить** | 侧重以书面形式表达思想；написать 更侧重书写行为本身。 |

## 💬 谚语/俗语

- **Написано пером — не вырубишь топором. — 笔下写了，斧头也砍不掉。（白纸黑字，不可更改）**

## ⚠️ 易混淆词

- **написать vs писать** — написать 是完成体（写完了——结果）；писать 是未完成体（正在写——过程）。比较：Я написал дипломную（我写完了毕业论文——完成） vs Я пишу дипломную（我在写毕业论文——进行中）。
- **написать vs нарисовать** — написать картину = 用颜料画油画（写生）；нарисовать картину = 用铅笔/钢笔画素描/图画。在艺术语境中 написать 特指油画创作。

## 💡 特殊用法

- **变位：** 第一变位法，不规则。напишу́, напи́шешь, напи́шет, напи́шем, напи́шете, напи́шут。
- 完成体动词。变位特殊：написать → напишу, напи́шешь...（词干变化，类似 писать → пишу）。过去时：написал, написала, написало, написали。被动形动词：написанный（被写的）。注意：написать картину = 画油画（用颜料），而 нарисовать картину = 画素描/图画（用铅笔）。口语中：Напиши мне, когда доберёшься!（到了给我发消息！）

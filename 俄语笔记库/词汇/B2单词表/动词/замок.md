# замок

## 📝 详细释义

**俄语解释：** Замок — сущ. м. р. Два значения с разным ударением: 1) зáмок (ударение на первый слог) — устройство для запирания: дверной замок, навесной замок; 2) замо́к (ударение на второй слог) — средневековое укрепление: королевский замок, воздушные замки (мечты). Корень: -мок- / -мк- (ср. замыкать).

**中文解释：** Замок 是阳性名词，有两种含义且重音不同：1） зáмок（重音在第一音节）——锁：门锁、挂锁；2）замо́к（重音在第二音节）——城堡：皇家城堡、воздушные замки（空中楼阁、幻想）。词根 -мок- / -мк-（同 замыкать 锁上）。

## 💬 谚语/俗语

- Замок без ключа — железо. — 没有钥匙的锁就是废铁。（比喻：没有方法的工具毫无用处）

## ⚠️ 易混淆词

- замок (锁/城堡) vs замÓк (城堡, 重音不同) — 同一词但重音决定意义：зÁмок = 锁，замÓк = 城堡。此前文件 meaning 写"沉默起来"——这是 замолчать/затихнуть 的释义，已修正！
- замок (锁, 名词) vs замок (城堡, 名词) — 两个义项通过上下文和重音区分。
- замок (名词) vs замок + verb (如 закрыть на замок) — 注意搭配：закрыть на замок = 用锁锁上。

## 💡 特殊用法

- 这是一个名词（сущ. м. р.），不是动词！此前文件错误标注为 verb。
- 此前文件 meaning 写"沉默起来"——这是错误的！已修正为"锁; 城堡"。
- 重音不同意义不同：зÁмок（锁）vs замÓк（城堡）。
- 复数：замки́ (城堡) / зáмки (锁)。
- 成语：воздушные замки（空中楼阁、不切实际的幻想）。

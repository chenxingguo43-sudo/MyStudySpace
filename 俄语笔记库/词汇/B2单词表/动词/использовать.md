# использовать

## 📝 详细释义

**俄语解释：** Использовать — глагол двувидовой (св/нсв), означает «применять, употреблять, извлекать пользу» (使用、利用). Переходный глагол: использовать что (使用什么). От существительного «польза» (好处) с приставкой «ис-». Совершенный и несовершенный вид совпадают: использовать — не имеет отдельной формы НСВ. Альтернативная пара НСВ: пользоваться. Типичные контексты: использовать шанс (利用机会), использовать метод (使用方法).

**中文解释：** использовать 是兼体动词（完成体/未完成体同形），意为应用、使用、利用。及物动词：使用什么。由名词 польза（好处）加前缀 ис- 构成。没有单独的未完成体形式，替代的未完成体为 пользоваться。典型语境：利用机会、使用方法。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **применять** | 侧重应用、实施（方法、知识）；использовать 更通用。 |
| **употреблять** | 侧重使用（物品、词语）；использовать 更强调目的性。 |
| **пользоваться** | 未完成体替代形式；использовать 兼体。 |

## ⚠️ 易混淆词

- **использовать (使用) vs применять (应用)** — использовать 更通用（利用机会、使用工具）；применять 更侧重应用知识、方法。
- **использовать (兼体) vs пользоваться (未完成体)** — использовать 可兼作完成体和未完成体；пользоваться 是专门的未完成体形式。
- **использовать (使用) vs употреблять (使用)** — употреблять 侧重消耗性使用（吃、喝、用掉）；использовать 更强调利用。

## 💡 特殊用法

- 体：兼体（св/нсв同形），替代未完成体为 пользоваться。
- 接格：四格（使用什么）。
- 变位：использую, используешь, использует, используем, используете, используют。
- 被动形式：используемый（被使用的）。

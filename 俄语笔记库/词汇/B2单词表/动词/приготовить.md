# приготовить

## 📝 详细释义

**俄语解释：** Приготовить — совершенный вид глагола «готовить». Значения: 1) сделать пищу годной к употреблению, сварить/испечь (приготовить обед); 2) подготовить, сделать заранее (приготовить уроки); 3) приготовить кого-что к чему — подготовить (приготовить документы к совещанию). Управление: кого-что. Также: приготовить что для кого-чего (приготовить подарок для друга).

**中文解释：** приготовить 是 готовить 的完成体。含义：1) 把食物做好、烹饪（做午饭）；2) 预先准备好（准备功课）；3) 准备某人/某事物——预备（为会议准备文件）。接格：кого-что。也用：приготовить что для кого-чего（为朋友准备礼物）。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **сготовить** | 口语化，侧重于'做好了饭菜'；приготовить 更通用。 |
| **сварить** | 特指'煮'；приготовить 更广泛，包括各种烹饪方式。 |
| **подготовить** | 侧重于'预先准备'，更广泛；приготовить 在烹饪语境中更常用。 |

## ⚠️ 易混淆词

- **приготовить vs готовить** — приготовить 是完成体（做好了/准备好了），готовить 是未完成体（正在做/经常做）。
- **приготовить vs приготовиться** — приготовить 是及物动词（准备什么东西），приготовиться 是反身动词（自己做好准备）。
- **приготовить vs сварить** — приготовить 泛指各种烹饪方式；сварить 特指'煮'。

## 💡 特殊用法

приготовить 是日常生活中极高频的动词，最常用于烹饪语境。口语中：Что приготовить на ужин?（晚饭做什么？）是最常见的家庭对话。注意区分：приготовить（准备什么东西）和 приготовиться（自己做好准备——反身形式）。固定搭配：приготовить из чего（用什么做）、приготовить для кого（为谁做）。

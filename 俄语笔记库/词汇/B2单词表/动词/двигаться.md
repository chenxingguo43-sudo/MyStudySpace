# двигаться

## 📖 释义
走动,移动,运动

## ✍️ 例句

| 俄语 | 中文 |
|------|------|
| — Полиция! Всем не ==двигаться==! |  |
| Чэнь Фэн уже собирался ==выдвигаться==. |  |
| «Небожитель, мы должны ==выдвигаться== немедленно». |  |


## 📐 变位/变格/接格

| 人称 | 现在时 | 过去时 |
|------|--------|--------|
| я |двигаюсь | двигался / двигалась |
| ты | двигаешься | двигался / двигалась |
| он/она | двигается | двигался / двигалась |
| мы | двигаемся | двигались |
| вы | двигаетесь | двигались |
| они | двигаются | двигались |

- 命令式: двигайся / двигайтесь
- 接格: 无特殊接格要求（可用 в + 前置格 表示方向：двигаться вперёд / к цели）
- 完成体: двинуться (двинусь, двинешься, двинутся)

## 📝 详细释义

**俄语解释：** Двигаться — это перемещаться, менять своё положение в пространстве. Также используется в переносном смысле: продвигаться (в работе, учёбе), развиваться. Несовершенный вид; совершенный вид — двинуться.

**中文解释：** двигаться 意为移动、改变空间位置。引申义为推进（工作、学习）、发展。未完成体动词，完成体为 двинуться。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **передвигаться** | 强调从一处移到另一处，更具体；двигаться 更通用，可指抽象进展。 |
| **перемещаться** | 更正式，强调位置的变化；двигаться 可用于物理和抽象意义。 |
| **продвигаться** | 侧重向前推进、取得进展；двигаться 泛指一切运动。 |

## ⚠️ 易混淆词

- **двигаться vs двинуться** — двигаться 是未完成体（过程）；двинуться 是完成体（开始运动的一瞬间）。
- **двигаться vs выдвигаться** — двигаться 泛指运动；выдвигаться 强调从某处出发或提出（方案、候选人）。

## 💡 特殊用法

- 未完成体动词，第一变位法：двига-юсь, двига-ешься, двига-ются。
- 反身动词（возвратный глагол），-ся 后缀。
- 可用于抽象意义：переговоры двигаются（谈判在推进）。

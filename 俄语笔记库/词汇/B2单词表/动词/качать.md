# качать

## 📝 详细释义

**俄语解释：** Качать — значит 1) двигать из стороны в сторону: качать ребёнка (укачивать); 2) перекачивать, перемещать с помощью насоса: качать воду, качать воздух; 3) (разг.) тренировать, накачивать: качать мышцы, качатьпресс. Несовершенный вид. Совершенный вид — качнуть (для значения 1) 或 накачать (для значения 2, 3)。Глагол используется с винительным падежом (кого-что)。

**中文解释：** Качать 意为：1）来回摇晃：摇晃孩子（哄睡）；2）用泵抽送：抽水、打气；3）（口语）锻炼、练：练肌肉、练腹肌。未完成体。完成体为 качнуть（义项1）或 накачать（义项2、3）。该动词接第四格（кого-что）。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **укачивать** | 特指摇晃哄睡；качать 更广泛，可指任何摇晃动作。 |
| **перекачивать** | 更侧重「转移、输送」；качать 更侧重「抽、泵」的动作。 |
| **накачивать** | 侧重「使充满」；качать 更侧重「抽送」的动作。 |

## 💬 谚语俗语

- Качай, да не раскачивай. — 摇吧，但别摇过头。（做事要有分寸）
## ⚠️ 易混淆词

- качать vs качаться — качать 是及物（摇晃某物）；качаться 是不及物（自己摇晃、荡秋千）。
- качать vs кивать — кивать 特指点（头）；качать 指一般的摇晃。
## 💡 特殊用法

- 口语用法：качать мышцы / качаться — 健身、练肌肉。
- 游戏用法：прокачать персонажа — 升级角色（游戏术语）。
- 否定命令：Не качай лодку!（别摇 boat！比喻别制造麻烦。）
- 完成体变体：качнуть（摇一下），накачать（打满气，练出肌肉）。

# выехать

## 📝 详细释义

**俄语解释：** Выехать — глагол совершенного вида. Основные значения: 1) уехать, отправиться (выехать из города — 离开城市); 2) выступить, появиться наружу (выехать из гаража — 从车库开出). Нсв. — выезжать. Часто используется с предлогами: из + род. пад., на + вин. пад., в + вин. пад.

**中文解释：** Выехать 意为出发、启程、驶出、离开。完成体动词。主要含义：1）出发、离开（离开城市）；2）驶出、开出来（从车库开出）。未完成体为 выезжать。常搭配前置词：из + 第二格、на + 第四格、в + 第四格。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| выехать из города | Мы выехали из города к рассвету. | 我们在黎明前离开了城市。 |
| выехать на дорогу | Он выехал на главную дорогу. | 他开上了主路。 |
| выехать за границу | Она выехала за границу на учёбу. | 她出国学习了。 |
| выехать на работу | Нужно выехать на работу пораньше. | 需要早点出发去上班。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **уехать** | 更通用，指离开、开走；выехать 更强调从某处出来的动作。 |
| **отправиться** | 更正式，指出发、启程；выехать 更侧重乘车出发。 |
| **двинуться** | 更口语化，指开始移动；выехать 更具体。 |

## ⚡ 反义词

- **заехать — 顺路到**
- **въехать — 驶入**

- **Кто вовремя выехал — тот не опоздал. — 谁准时出发——谁就不会迟到。**

## ⚠️ 易混淆词

- **выехать vs уехать** — выехать 强调从某处出来的动作（出城、出车库）；уехать 强调离开的行为（去了别的地方）。Выехать из города = 出城；Уехать из города = 离开城市。
- **выехать vs выдать** — 完全不同！выехать = 出发、驶出；выдать = 发放、交出。

## 💡 特殊用法

- 完成体动词。前缀 вы- + ехать。变位：выеду, выедешь, выедет... 命令式：выедь。常见表达：выехать на дорогу（上路）、выехать за границу（出国）、выехать на чём-то（靠……出名/出头）。

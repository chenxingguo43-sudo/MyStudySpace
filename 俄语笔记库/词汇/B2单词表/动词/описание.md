# описание

## 📝 详细释义

**俄语解释：** Описание — это словесное изображение кого-чего-либо, перечисление основных признаков, свойств, качеств. В лингвистике описание — один из типов речи наряду с повествованием и рассуждением. Также может означать документ с перечнем чего-либо.

**中文解释：** Описание 意为描述、描写，是对某人/某事的文字描绘，列举其主要特征、性质、品质。在语言学中，描写是与叙述、议论并列的语篇类型之一。也可指列有某物清单的文件。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| подробное описание | В статье дано подробное описание метода. | 文章对该方法进行了详细描述。 |
| описание товара | На сайте есть описание каждого товара. | 网站上有每件商品的描述。 |
| дать описание | Свидетель дал описание подозреваемого. | 目击者提供了嫌疑人的描述。 |
| по описанию | По описанию он похож на моего знакомого. | 根据描述，他像我的一个熟人。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **характеристика** | 侧重"特征描述"，常用于评价性描述；описание 更中性、更通用。 |
| **изображение** | 更书面、文学性强；описание 更通用。 |
| **портрет** | 专指人物描写；описание 可用于任何对象。 |

## ⚡ 反义词

- молчание — 沉默
- умолчание — 隐瞒不提

## 💬 谚语/俗语

- **Лучше один раз увидеть, чем сто раз прочитать описание. — 百闻不如一见。**

## ⚠️ 易混淆词

- описание vs характеристика — характеристика 侧重"特征、评价"，常用于对人的评价或产品的规格说明；описание 更中性，是对事物的客观描述。
- описание vs изложение — изложение 是"复述、概述"（用自己的话转述）；описание 是"描写"（描绘特征）。

## 💡 特殊用法

- 作为名词，описание 不适用动词变位和体的描述。
- 描写（описание）是俄语语篇三大类型之一：描写、叙述（повествование）、议论（рассуждение）。
- 常见搭配模式：описание + 生格（описание события 事件描述）、形容词 + описание（подробное описание 详细描述）。

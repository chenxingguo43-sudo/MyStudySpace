# разливать

## 📝 详细释义

**俄语解释：** Разливать — значит наливать жидкость в несколько сосудов, распределять по ёмкостям; в переносном значении — распространяться, заполнять пространство (о свете, звуке, тумане). Нсв. глагол. Св. — разлить.

**中文解释：** разливать 意为把液体倒入多个容器、分斟；转义为（光、声音、雾等）弥漫、充满空间。未完成体动词。完成体为 разлить。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| разливать чай/вино | Она разливала чай по чашкам. | 她给大家倒茶。 |
| разливать по бутылкам | Завод разливает молоко по бутылкам. | 工厂把牛奶分装到瓶子里。 |
| разливаться (о свете) | Свет разливался по комнате. | 光线弥漫在房间里。 |
| разливаться (о тумане) | Туман разливался по долине. | 雾气弥漫在山谷中。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **наливать** | 侧重倒入一个容器；разливать 侧重分到多个容器。 |
| **разламывать** | 侧重打碎、破碎；разливать 侧重液体的分散。 |
| **распространять** | 更通用，指传播、散布；разливать 特指液体的弥漫。 |

- **собирать — 收集**
- **сливать — 倒在一起，合并**

## ⚠️ 易混淆词

- **разливать vs наливать** — наливать 是倒入一个容器；разливать 是分到多个容器或弥漫开。
- **разливать vs выливать** — выливать 是倒出（丢弃）；разливать 是分斟（有意为之）。

## 💡 特殊用法

- 及物动词，直接接第四格宾语。
- 反身形式 разливаться 有转义：弥漫、充满（о свете, звуке, тумане）。
- 工业用语：разливать по бутылкам（分装到瓶子里）。
- 文学用语：разливаться мелодией（旋律弥漫）。

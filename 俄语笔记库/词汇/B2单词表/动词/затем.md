# затем

## 📝 详细释义

**俄语解释：** Затем — наречие. Означает: 1) после этого, потом — указывает на последовательность событий; 2) для этого, с этой целью — указывает на цель. В значении «потом» используется для связки событий в叙事中. В значении «для этого»常与 чтобы 连用或独立使用。

**中文解释：** Затем 是副词。含义：1) 然后，之后——表示事件的先后顺序；2) 为此，为了这个目的——表示目的。在'之后'义中用于连接叙事中的事件。在'为此'义中常与 чтобы 连用或独立使用。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| сначала... затем | Сначала я пообедал, затем пошёл гулять. | 我先吃了午饭，然后去散步了。 |
| а затем | Он прочитал книгу, а затем посмотрел фильм. | 他读了书，然后又看了电影。 |
| затем чтобы (= для того чтобы) | Я пришёл затем, чтобы помочь вам. | 我来是为了帮助你们。 |
| и затем | Она сдала экзамен, и затем можно было отдохнуть. | 她考完试了，然后就可以休息了。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **потом** | 更口语化，日常用语；затем 更书面。 |
| **после этого** | 更明确地表示'在此之后'。 |
| **для этого** | 在表示目的时与 затем 互换。 |

## ⚡ 反义词

- сначала — 首先
- до этого — 在此之前
- раньше — 之前

## 💬 谚语/俗语

- Сначала думай, затем делай. 先想后做。

## ⚠️ 易混淆词

- **затем (然后) vs потом** — затем 更书面，потом 更口语：Затем он ушёл.（然后他走了。——书面）vs Потом он ушёл.（然后他走了。——口语）
- **затем (为此) vs зачем** — затем 表示目的（为此），зачем 表示疑问（为什么）：Я пришёл затем, чтобы помочь.（我来是为了帮忙。）vs Зачем ты пришёл?（你为什么来？）

## 💡 特殊用法

- 词性注意：затем 是副词，不是动词。没有变位、时态等动词形式。
- 连接功能：затем 常用于叙事中连接两个事件，表示时间顺序。
- 目的功能：затем 常与 чтобы 连用（затем чтобы = для того чтобы），表示目的。

# кондиционер

## 📖 释义
空调，调节器

## 📝 详细释义

**俄语解释：** Кондиционер — устройство для поддержания заданной температуры и влажности воздуха в помещении. Означает: 1) бытовой кондиционер — сплит-система для охлаждения/обогрева воздуха (включить кондиционер, выключить кондиционер); 2) кондиционер для волос — средство для смягчения и питания волос; 3) промышленный кондиционер — система климат-контроля для больших помещений. Слово широко используется в быту и технике.

**中文解释：** кондиционер 是一种用于维持室内指定温度和湿度的设备。含义：1）家用空调——用于制冷/制热的分体式空调（开空调、关空调）；2）护发素——用于柔顺和滋养头发的产品；3）工业空调——大型建筑的气候控制系统。该词在日常和技术领域广泛使用。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **климат-контроль** | 自动温控系统，通常在汽车中使用；кондиционер 更通用。 |
| **сплит-система** | 特指分体式空调；кондиционер 包括所有类型的空调。 |
| **бальзам для волос** | 护发素的另一种说法；кондиционер для волос 更常用。 |

## ⚠️ 易混淆词

| 对比 | 区别 |
|---|---|
| **кондиционер vs вентилятор** | кондиционер 能制冷制热；вентилятор 只是吹风，不改变温度。 |
| **кондиционер vs обогреватель** | кондиционер 主要用于制冷；обогреватель 专门用于加热。 |
| **кондиционер (для волос) vs шампунь** | кондиционер 是护发素，用于柔顺；шампунь 是洗发水，用于清洁。 |

## 💡 特殊用法

- 阳性名词，变格：кондиционер, кондиционера, кондиционеру, кондиционер, кондиционером, кондиционере。
- 复数：кондиционеры, кондиционеров, кондиционерам...。
- 源自英语 conditioner（调节器），20世纪进入俄语。
- 多义词：既指空调设备，也指护发素（кондиционер для волос）。

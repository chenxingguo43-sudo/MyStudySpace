# описание

## 📖 释义
描述，描写

## 📝 详细释义

**俄语解释：** Описание — 1) изображение чего-либо в словах, рассказ о чём-либо (описание природы, описание внешности); 2) инструкция, руководство (описание товара, описание процесса); 3) характеристика, представление (дать описание). Описание — важный тип речи наряду с повествованием и рассуждением. В научном стиле описание используется для характеристики объектов.

**中文解释：** описание 含义：1）用语言描绘某事物，对某事的叙述（自然描写、外貌描写）；2）说明、指南（商品说明、过程说明）；3）特征、描述（给予描述）。描写是与叙述、议论并列的重要语体。在科学语体中，描写用于描述事物特征。

## ✍️ 补充搭配

| 搭配 | 例句 | 翻译 |
|------|------|------|
| описание природы | В романе много описания природы. | 小说中有很多自然描写。 |
| описание товара | Описание товара должно быть точным. | 商品说明应该准确。 |
| дать описание | Он дал подробное описание происшествия. | 他详细描述了事件。 |
| подробное описание | Подробное описание поможет понять. | 详细描述有助于理解。 |
| описание процесса | Описание процесса занимает много страниц. | 过程说明占了很多页。 |

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **изображение** | 侧重描绘、展现；описание 更侧重语言描述。 |
| **характеристика** | 侧重特征、评价；описание 更中性。 |
| **рассказ** | 侧重叙述、故事；описание 更侧重静态描绘。 |

## ⚠️ 易混淆词

| 对比 | 区别 |
|---|---|
| **описание vs изображение** | описание 侧重语言描述；изображение 侧重视觉呈现。 |
| **описание vs характеристика** | описание 更中性，侧重描绘；характеристика 侧重评价和特征。 |
| **описание (描写) vs описание (说明)** | 根据上下文区分：описание природы（自然描写）vs описание товара（商品说明）。 |

## 💡 特殊用法

- 中性名词，变格：описание, описания, описанию, описание, описанием, описании。
- 复数：описания, описаний, описаниям...。
- 语法术语：описательное предложение（描写句）。
- 在议论文中，描写常与叙述和议论交替使用。

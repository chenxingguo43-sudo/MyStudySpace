# ветчина

## 📝 详细释义
**俄语解释：** Ветчина — это мясной продукт, изготовленный из свинины (реже из других видов мяса) путём засолки, копчения или варки. Обычно делается из окорока (задней ноги) свинины. Ветчина — один из самых популярных мясных деликатесов во многих кухнях мира.

**中文解释：** ветчина 指通过腌制、熏制或煮制等方法加工的猪肉制品（有时也用其他肉类）。通常使用猪后腿肉制作。火腿是世界各地最受欢迎的肉类美食之一。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **окорок** | 指"火腿"（整条猪后腿），ветчина 是加工后的成品。 |
| **колбаса** | 指"香肠"（碎肉灌制），ветчина 是整块肉加工。 |
| **бекон** | 指"培根"（猪胸肉或肋条肉），ветчина 用猪后腿肉。 |
| **карбонат** | 指"脊肉火腿"（猪里脊），ветчина 通常用后腿。 |

## ⚠️ 易混淆词

- **ветчина vs окорок** — окорок 是原料（整条猪后腿），ветчина 是成品（加工后的火腿）。
- **ветчина vs бекон** — бекон 是培根（猪胸肉），ветчина 是火腿（猪后腿）。
- **ветчина vs колбаса** — колбаса 是香肠（碎肉灌制），ветчина 是整块肉加工。

## 💡 特殊用法

- **阴性名词：** 搭配阴性动词形式（ветчина готов**а**，不是 готово）。
- **只用单数：** ветчина 作为不可数名词时只用单数：Дайте мне ветчины.（给我一些火腿。）
- **烹饪语境：** ветчина в тесте（面皮火腿）、ветчина с ананасом（菠萝火腿）是常见菜式。
- **商业语境：** 在超市中，ветчина 通常放在 мясной отдел（肉类区）或 кулинария（熟食区）。

# газопровод

## 📝 详细释义
**俄语解释：** Газопровод — это сооружение для транспортировки газа (обычно природного) на большие расстояния. Представляет собой систему труб большого диаметра с компрессорными станциями. Крупнейшие газопроводы мира проходят по территории России («Сила Сибири», «Северный поток»).

**中文解释：** газопровод 指用于远距离输送气体（通常是天然气）的设施。由大口径管道系统和压缩站组成。世界上最主要的天然气管道经过俄罗斯境内（"西伯利亚力量"、"北溪"）。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **трубопровод** | 更广泛的"管道"（可输送油、气、水），газопровод 特指输气管道。 |
| **нефтепровод** | 指"输油管道"，газопровод 指"输气管道"。 |
| **водопровод** | 指"自来水管"，газопровод 指输气管道。 |
| **газовая магистраль** | 与 газопровод 近义，但 магистраль 更强调"干线"。 |

## ⚠️ 易混淆词

- **газопровод vs трубопровод** — трубопровод 是广义的管道（包括油管、水管等），газопровод 专指输气管道。
- **газопровод vs нефтепровод** — нефтепровод 输油，газопровод 输气。
- **газопровод vs водопровод** — водопровод 是自来水管道，газопровод 是天然气管道。

## 💡 特殊用法

- **阳性名词：** 搭配阳性动词形式（газопровод построе**н**，不是 построена）。
- **复合词：** газо-（气体）+ провод（传导），结构类似 водопровод（水管道）。
- **政治经济术语：** газопровод 是俄罗斯重要的经济战略资源，常出现在国际新闻中。
- **大型工程：** Северный поток（北溪管道）、Сила Сибири（西伯利亚力量管道）、Турецкий поток（土耳其溪管道）。

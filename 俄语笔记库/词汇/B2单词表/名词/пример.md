## 📝 详细释义
**俄语解释：** Пример — 1) случай, факт, служащий для пояснения, подтверждения чего-л. (привести пример); 2) образец для подражания (подавать пример); 3) задача для упражнения (решить пример); 4) приблизительное количество (примерно — нареч.).

**中文解释：** пример 有四义：1）例子、实例——用以说明或证实某事的事实（举例）；2）榜样——可以效仿的典范（树立榜样）；3）练习题——用于练习的题目（解题）；4）大约的数量（примерно = 大约）。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **образец** | 指样品、范本；пример 更偏向举例说明 |
| **случай** | 泛指事件；пример 强调其说明性 |
| **модель** | 指模型、模式；пример 更具体、更直观 |
| **задача** | 指任务、问题；пример 特指数学练习题 |

## 💬 谚语/俗语
- **Пример заразителен.** — 榜样是有感染力的。
- **Не пример, а урок.** — 不是榜样，而是教训。
- **Пример лучше слова.** — 身教胜于言教。

## ⚠️ 易混淆词
- **пример vs. образец** — пример 是举例说明；образец 是实物样品或模范。
- **пример vs. случай** — пример 用于说明某观点；случай 泛指发生的事件。
- **пример vs. задача** — пример 特指简单练习题；задача 泛指问题或任务。

## 💡 特殊用法
- 阳性名词，变格：пример → примера → примеру → пример → примером → примере。
- 固定搭配：例如（например）是最常用的插入语之一。
- 数学用语：решить пример（解题），пример на сложение（加法题）。
- 名词义和副词义的关联：пример → примерно（大约）是从"以……为例"引申出的"大概"义。

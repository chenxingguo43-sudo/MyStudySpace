# булочка

## 📖 释义
(圆形或糊圆形的)白面包

## 📝 详细释义

**俄语解释：** Булочка — это небольшое мучное изделие из дрожжевого теста, обычно круглой или овальной формы. Булочки бывают сдобные (с маслом, яйцами), простые, с начинкой (маком, повидлом, творогом). Также — булочка для гамбургера (разрезанная пополам).

**中文解释：** булочка 指用酵母面团制作的小面包，通常是圆形或椭圆形的。小面包分奶油的（含黄油、鸡蛋）、普通的、带馅的（罂粟籽、果酱、奶渣）。也指汉堡面包（从中间切开的圆面包）。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **хлеб** | 泛指"面包"（大块的、主食型），булочка 是小个的、点心型的。 |
| **пирожок** | 指"馅饼"（通常有馅且形状不同），булочка 是面包类（可以无馅）。 |
| **калач** | 指一种传统的圆形白面包（更大、更特殊），булочка 更小更日常。 |
| **батон** | 指长条面包（椭圆长形），булочка 是圆形或椭圆小面包。 |

## 💬 谚语/俗语

- **Булочка с маслом — не роскошь, а удовольствие.** — 黄油面包不是奢侈，而是享受。
- **Как булочка из печи, разлетаются.** — 像刚出炉的面包一样被抢光。（形容很受欢迎）
- **Горячие булочки разлетаются.** — 热面包一抢而空。（比喻抢手货）

## ⚠️ 易混淆词

- **булочка vs хлеб** — хлеб 是大面包（主食），булочка 是小面包（点心/零食）。
- **булочка vs пирожок** — пирожок 有馅且通常是烤的或炸的面团，булочка 是无馅或少馅的面包。
- **булочка vs рогалик** — рогалик 是牛角面包（月牙形），булочка 是圆形小面包。

## 💡 特殊用法

- **阴性名词：** 搭配阴性动词形式（булочка остыл**а**，不是 остыло）。注意：很多学习者误以为 булочка 是阳性，因为以 -ка 结尾容易与阳性词混淆，但它是阴性。
- **指小表爱：** булочка 本身就是指小形式（от слова «булка»），所以一般不再用更小的形式。
- **日常语境：** В булочной продают свежие булочки.（面包店里卖新鲜的小面包。）
- **快餐语境：** булочка для бургера（汉堡面包）、булочка для хот-дога（热狗面包）是快餐用语。

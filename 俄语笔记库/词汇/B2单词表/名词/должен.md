# должен

## 📖 释义
应该的，有义务的（短尾形容词，与不定式连用表示义务、必要或推测）

## ✍️ 例句

| 俄语 | 中文 |
|------|------|
| Кто виноват в их судьбе и кто ==должен== им помочь? | 谁该为他们的命运负责，谁又应该帮助他们？ |
| По его мнению, отец Саши ==должен== сам заботиться о своей семье. | 在他看来，萨沙的父亲应该自己照顾自己的家庭。 |
| Он, как и художник, ==должен== рвать логику! Раздирать её!.. | 他，和艺术家一样，应该撕裂逻辑！把它撕碎！…… |


## 📐 变位/变格/接格

短尾形容词变化：

| 性/数 | 形式 |
|-------|------|
| 阳性 | должен |
| 阴性 | должна |
| 中性 | должно |
| 复数 | должны |

接格：должен + 动词不定式（инфинитив）

| 用法 | 例句 | 翻译 |
|------|------|------|
| должен + inf.（义务） | Я должен уйти. | 我该走了。 |
| должен + inf.（推测） | Он должен быть дома. | 他应该在家。 |
| быть должен + 数量（债务） | Он мне должен тысячу рублей. | 他欠我一千卢布。 |

体对：无（短尾形容词，非动词，无体对变化）

## 🔗 语义关系

### 近义词
- **[[обязан]]** (短尾形容词) — 有义务的，必须的（比должен更正式）
- **[[нужно]]** (谓语副词) — 需要，应该（无人称形式）
- **[[необходимо]]** (谓语副词) — 必须（强调客观必要性）

### 反义词
- **не должен** — 不应该（表示无义务）
- **свободен** — 自由的，不受约束的
- **разрешено** — 被允许的（义务的反面是许可）

# должен

## 📝 详细释义
**俄语解释：** Должен — это краткое прилагательное, выражающее обязанность, необходимость или предположение. Используется с инфинитивом глагола. «Я должен сделать» означает «я обязан сделать» или «я собираюсь сделать». Также выражает предположение: «Он должен прийти» = «Вероятно, он придёт».

**中文解释：** должен 是短尾形容词，表示义务、必要性或推测。与动词不定式搭配使用。"Я должен сделать" 意为"我应该做"或"我打算做"。也可表示推测："Он должен прийти" = "他大概会来"。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **обязан** | 指"有义务的"，比 должен 更正式、更强硬，常用于规章制度。 |
| **нужно** | 指"需要"，无人称形式；должен 有人称变化（должен/должна/должны）。 |
| **необходимо** | 指"必须"，比 должен 更强调客观必要性。 |
| **надо** | 指"应该、需要"，更口语化；должен 更强调责任或义务。 |

- **свободен** — 自由的（受约束 vs 自由）
- **разрешено** — 被允许的（义务 vs 许可）

## 💬 谚语/俗语

- **Долг платёжом красен.** — 债要还得漂亮。（欠债还钱天经地义）
- **Кто должен — тот и платит.** — 谁欠债谁还钱。
- **Должен — не значит виноват.** — 应该做不等于有罪过。
- **Долг — не кнут, но бьёт крепче.** — 义务不是鞭子，但抽得更疼。

## ⚠️ 易混淆词

- **должен vs обязан** — обязан 更正式，用于法律/规则；должен 更通用，可用于日常。
- **должен (短尾形容词) vs долг (名词)** — долг 是名词（债务、义务）；должен 是短尾形容词（应该的）。
- **должен + 不定式 vs нужно + 不定式** — должен 有人称变化； нужно 是无人称的。

## 💡 特殊用法

- **短尾形容词：** 有性数变化：должен（阳）、должна（阴）、должно（中）、должны（复）。
- **表示推测：** Он должен прийти к трём часам.（他应该三点前来。）此处表示预期而非义务。
- **表示债务：** Он мне должен денег.（他欠我钱。）此处表示经济上的亏欠。
- **否定形式：** не должен 表示"不应该"：Ты не должен так делать.（你不应该这样做。）

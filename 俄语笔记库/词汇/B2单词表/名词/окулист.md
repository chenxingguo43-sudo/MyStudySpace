# окулист

## 📖 释义
眼科医生

## 📝 详细释义

**俄语解释：** Окулист — врач, который лечит глаза. Означает: 1) специалист по заболеваниям глаз (пойти к окулисту); 2) офтальмолог (синоним); 3) врач, который проверяет зрение (окулист выписал очки). Окулист — более разговорное слово, чем офтальмолог.

**中文解释：** окулист 含义：1）治疗眼睛的医生（去看眼科医生）；2）眼科医生（同义词为 офтальмолог）；3）检查视力的医生（眼科医生开了眼镜处方）。окулист 比 офтальмолог 更口语化。

## 🎯 近义词辨析

| 词 | 区别 |
|---|---|
| **офтальмолог** | 更正式的医学术语；окулист 更口语化。 |
| **глазной врач** | 更通俗的表达；окулист 更专业。 |
| **optician** | 英语对应词，但在英语中特指配镜师。 |

| 对比 | 区别 |

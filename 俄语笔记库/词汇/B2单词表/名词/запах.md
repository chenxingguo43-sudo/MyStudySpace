# запах

## 📖 释义
气味

## ✍️ 例句

| 俄语 | 中文 |
|------|------|
| В нос ударил ==запах== медяков — или, вернее, ==запах== денег. |  |
| «Не то... ==запах== не тот». |  |
| Вот он, тот самый ==запах==. |  |

## 📝 详细释义
**俄语解释：** Запах — ощущение, воспринимаемое органом обоняния (носом). Также переносное: атмосфера, предчувствие чего-либо.

**中文解释：** запах 指嗅觉器官（鼻子）感知到的感觉，即「气味」。也可用于引申义，表示某种氛围或预感。

## 🎯 近义词辨析
| 词 | 区别 |
|---|---|
| **аромат** | 更偏正面、优雅的气味，常用于花香、香水等；запах 是中性通用词 |
| **смрад** | 恶臭，贬义强烈的臭味 |
| **вонь** | 口语，强烈的臭味 |

## ⚡ 反义词
无直接反义词。可对比：отсутствие запаха（无气味）。

## 💬 谚语/俗语
- **Учуять запах** — 察觉到苗头，预感到危险或机会。

## ⚠️ 易混淆词
- **запах vs. аромат** — запах 中性通用；аромат 偏正面、优雅。

## 💡 特殊用法
- 可用于抽象意义：запах свободы（自由的气息）、запах опасности（危险的预兆）。
- 复数形式 за́пахи 不常用，通常用单数泛指。

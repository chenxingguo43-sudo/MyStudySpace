# защитник

## 📖 释义
保卫者,保护人

## ✍️ 例句

| 俄语 | 中文 |
|------|------|
| — Я — ==Защитник== Богатства. |  |

| В этот момент в зале грянул выстрел. Белый ==защитник== по прозвищу «Глаз, видящий радость» рухнул, сражённый пулей. |  |

## 📝 详细释义
**俄语解释：** Защитник — 1) тот, кто защищает, оберегает; 2) в спорте — игрок оборонительной линии; 3) адвокат, юрист, представляющий интересы обвиняемого.

**中文解释：** защитник 有三个含义：1）保卫者、保护人；2）体育中的防守球员；3）法律中的辩护人、辩护律师。

## 💬 谚语/俗语
- **«Каждый сам себе защитник»** — 每个人都是自己的保护者。

## ⚠️ 易混淆词
- **защитник vs. охранник** — защитник 是抽象的保护者；охранник 是具体的保安。

## 💡 特殊用法
- День защитника Отечества（2月23日）是俄罗斯重要节日，类似「建军节」。
- 在足球中 защитник = 后卫。

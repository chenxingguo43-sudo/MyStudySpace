# по

## 📝 详细释义

**词性：** adv  |  **含义：** 用俄语/某种语言（口语）

**俄语解释：**
По — в значении наречия (разговорное) означает «говорить по-русски, по-английски» и т. д. В основном по — это предлог с множеством значений: по улице (по поверхности), по дороге (вдоль), по радио (через), по этому поводу (относительно).

**中文解释：**
作为副词（口语用法），意为「用某种语言说话」，如：говорить по-русски（说俄语）。但 по 主要是前置词，含义丰富：沿着（по улице）、通过（по радио）、关于（по этому поводу）等。

**词源：** 原始斯拉夫语前置词，与印欧语根 *po 相关，表示沿面运动。

## ⚠️ 易混淆词

- **по (副词) vs по (前置词)** — 副词用法仅限于 по-русски 等语言表达；前置词用法极为广泛：по улице（沿着街道），по радио（通过广播），по поводу（关于）。
- **по-русски vs на русском языке** — по-русски 更口语化；на русском языке 更正式，用于书面语。

## 💡 特殊用法

重音：по，单音节词。作为副词仅用于语言表达：говорить по-русски（说俄语）。注意：по- 是前缀，构成副词表示「以……方式」：по-новому（以新方式），по-хорошему（好好地），по-другому（以另一种方式）。⚠️ 本词条实际为前置词/前缀，非典型副词。

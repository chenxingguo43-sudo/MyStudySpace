# /health — 笔记库健康检查

## 触发

用户说 "health"、"健康检查"、"检查笔记库"、"/health"

## 检查项目（零 LLM 调用，纯结构检查）

### 1. 空文件 / 占位文件
- 扫描所有 `.md` 文件
- 标记 `ru: ""` 或 `word: ""` 等空字段
- 标记内容 < 20 字符的残缺文件

### 2. Frontmatter 完整性
- 检查 `B2口语素材/` 下每条笔记是否有：ru, zh, chapter, section, tags, mastery
- 检查 `词汇/` 下每条笔记是否有：word, type, meaning
- 标记缺失必填字段的笔记

### 3. 断链检测
- 扫描所有 `[[wikilink]]`
- 检查目标文件是否存在
- 列出所有断链

### 4. 索引同步
- 对比 `B2口语素材总索引.md` 中的文件数与实际目录文件数
- 标记不一致的章节

### 5. 标签规范
- 检查 tags 数组长度是否为 4 个元素（B2口语素材标准）
- 检查 section 是否为 5 种标准值之一
- 检查是否有 `�` 损坏字符

## 输出格式

```
🏥 笔记库健康报告 — 2026-05-16

### 概览
  总笔记: 1780
  健康: 1,750
  问题: 30

### 问题明细
  🔴 空文件 (2):
    - 语法/未命名.md
  🟡 缺少 section (0): ✅
  🟡 Frontmatter 缺失字段 (5):
    - B2口语素材/.../xxx.md — 缺 tags
  🔵 断链 (3):
    - 词汇/студент.md → [[университет]] (目标不存在)
  ⚪ 标签不规范 (20):
    - xxx.md — tags 只有 3 个元素
```

## 注意

- 此检查不调用 LLM，纯文件扫描，可每次会话都跑
- 如需内容质量检查（语义重复、分类准确性），用 `/lint`

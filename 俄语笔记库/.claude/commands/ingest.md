# /ingest — 摄入俄语学习素材

## 触发

用户说 "ingest"、"摄入"、"处理 raw/"、"/ingest <文件名>" 或 "/ingest --all"

## 工作流程

### 1. 确定摄入目标
- 如果用户指定了文件名：只处理 `raw/<文件名>`
- 如果 `--all`：处理 `raw/` 下所有新文件（跳过 log.md 中已记录的）
- 否则列出 `raw/` 中待处理的文件，让用户选择

### 2. 逐文件处理

对每个源文件执行以下步骤：

#### A. 读取源文件
读取 `raw/<文件名>` 的完整内容。

#### B. 识别内容类型
- **对话/访谈** → 侧重提取口语表达、反应句、语气词
- **文章/新闻** → 侧重提取正式表达、书面句型
- **词汇表** → 直接按生词模板归档
- **语法讲解** → 归档到 语法/

#### C. 提取与归档

**生词（每个生词创建一个文件到 `词汇/`）：**
- 文件名：`<单词>.md`
- 使用 `模板/生词模板.md` 格式
- 填写：word, type, meaning, gender（名词）/aspect（动词）
- tags: ["名词"/"动词", "生词", "来自<源文件名>"]

**核心句型（每个句型创建一个文件到 `B2口语素材/`）：**
- 自动判断应归入哪个章节（根据话题内容）
- 文件名：`<俄语句子前50字符>.md`
- Frontmatter: ru, zh, chapter, section, tags
- 自动推断 section：短句→核心句型，长句→场景对话

**语法点（归档到 `语法/`）：**
- 如果素材包含语法讲解，提取关键规则
- 使用 `模板/语法模板.md` 格式

#### D. 更新索引
- 更新 `B2口语素材总索引.md` 中的计数（Dataview 自动刷新则跳过）
- 更新 `wiki/log.md`：追加 `## [YYYY-MM-DD] ingest | <文件名>`

### 3. 完成后报告
```
摄入完成: <文件名>
  新增生词: N 个
  新增句型: N 个 → <章节名>
  新增语法: N 条
```

## 示例

用户: "ingest raw/2026-05-16-俄语播客-饮食话题.md"

Agent:
1. 读取文件
2. 识别为对话类型
3. 提取生词 → 词汇/ (按模板)
4. 提取句型 → B2口语素材/三_三、饮食·健康·生活习惯/
5. 更新 log.md
6. 报告结果

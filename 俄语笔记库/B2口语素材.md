# B2口语素材

- [[B2口语素材/B2口语素材总索引|B2口语素材总索引]]
- [[仪表盘|俄语学习仪表盘]]

```dataview
TABLE WITHOUT ID
  length(rows) AS "数量",
  rows[0].chapter AS "章节"
FROM "B2口语素材"
WHERE ru AND chapter AND !contains(file.name, "索引")
GROUP BY chapter
SORT length(rows) DESC
```

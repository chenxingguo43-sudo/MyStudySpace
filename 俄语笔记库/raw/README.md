# 原料目录 (Raw)

将俄语学习素材丢到这里，然后对 Claude 说 **"ingest"** 或运行 `/ingest`，AI 会自动：

1. 读取素材内容
2. 提取 **生词** → 生成笔记到 `词汇/`（按生词模板）
3. 提取 **核心句型** → 归档到 `B2口语素材/` 对应章节
4. 识别 **语法点** → 归档到 `语法/`
5. 更新各索引文件 + 操作日志

## 支持格式

- Markdown (`.md`) — 直接摄入
- 纯文本 (`.txt`) — 直接摄入
- YouTube 字幕 — 粘贴文本即可

## 命名建议

使用有意义的文件名，例如：
- `2026-05-16-俄语播客-饮食话题.md`
- `YouTube-对话中的未完成体用法.txt`
